# 向量性质

*向量性质描述了定义向量行为的几何和代数特征。本篇涵盖模长、方向、单位向量、相等、平行、正交以及线性无关——这些是每个 ML 特征空间的基本构件。*

- 向量的**模长**（magnitude，又称长度）告诉你它*延伸到多远*。把它想象成箭头的长度。对于向量 $\mathbf{a} = (a_1, a_2, a_3)$，其模长为：

$$\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

- 这就是勾股定理推广到高维，测量从原点到该点的直线距离。

- 向量的**方向**（direction）告诉你它*指向哪里*；只需想象从原点到坐标点的一条直线。

- 当没有明确指定原点时，我们通常隐含 (0,0,...0) 即中心点，至少在可视化时是这样。

- 位置并不重要，关键是位移：从原点画出的向量 $(3, 2)$ 和从另一个点画出的相同的 $(3, 2)$ 仍然是相等的。

![向量相等：从两个不同起点画出的同一个 (3,2) 向量](../../images/vector_equality.svg)

- 两个向量可以有相同的长度但指向完全不同的方向，也可以指向相同但长度不同。

![相同方向不同模长（v 和 2v）vs 相同模长不同方向](../../images/magnitude_direction.svg)

- 两个向量**相等**（equal）当且仅当它们所有对应分量都匹配；相同长度、相同方向，完全相同的箭头。

$$\mathbf{a} = \mathbf{b} \iff a_i = b_i \text{ 对所有 } i$$

- 两个向量**平行**（parallel）若其中一个是另一个的标量倍数。它们沿同一条直线指向，可以是同向或恰好反向。

$$\mathbf{a} \parallel \mathbf{b} \iff \mathbf{a} = k\mathbf{b} \text{ 对某个标量 } k \neq 0$$

![平行向量：a 和 b 指向相同，a 和 -b 指向相反](../../images/parallel_vectors.svg)

- 若 $k > 0$，它们指向相同。若 $k < 0$，它们指向相反。无论哪种情况，它们都位于经过原点的同一条直线上。

- 直观上，平行向量不携带"新的"方向信息。一个只是另一个的拉伸或翻转版本。

- 两个向量**正交**（orthogonal，即垂直）若它们指向完全独立的方向。沿一个方向移动不会在另一个方向上产生任何进展。

![正交向量：u 和 v 以直角相遇](../../images/orthogonal_vectors.svg)

- 想象向北走和向东走——这是正交的方向，无论向北走多少步都不会让你向东移动。我们会经常遇到正交性。

- 正交性在 ML 中至关重要：正交的特征携带完全独立的信息，这对于表示来说是最理想的状态。

- 更一般地，任意两个向量都有一个**夹角** $\theta$，范围从 $0°$ 到 $180°$。

- 这个夹角捕捉了两个方向之间的全部关系：$0°$ 意味着平行（同向），$180°$ 意味着平行（反向），$90°$ 意味着正交。中间的值则是两者的混合。

- ML 中大多数向量关系都落在这个范围的某处。稍后我们将看到计算这个夹角的精确工具（点积、余弦相似度）。

- 一组向量是**线性相关**（linearly dependent）的，如果其中至少一个可以由其他向量通过缩放和相加构造出来。它不会为这个集合带来任何新信息。

- 例如，若 $\mathbf{c} = 2\mathbf{a} + 3\mathbf{b}$，则 $\mathbf{c}$ 是冗余的——你已经通过 $\mathbf{a}$ 和 $\mathbf{b}$ 拥有了 $\mathbf{c}$ 所提供的一切。

- 平行向量总是线性相关的，因为一个只是另一个的缩放副本。任何包含零向量的集合也是线性相关的。

- 向量是**线性无关**（linearly independent）的，如果它们中没有一个可以由其他向量构造出来。每个向量都贡献了一个真正的新方向。正交向量总是线性无关的。

- 一点直觉：如果你想研究不同的人并把它们表示为向量，线性相关的向量（人）会使观测偏向被过度采样的数据点——这是设计 AI 训练数据集时的一个重要因素。

- 在 2D 中，两个线性无关的向量可以到达平面中的任意点。在 3D 中，你需要三个。这个"你需要多少个独立向量"的概念直接关联到维数。

- 当一个向量的绝大多数分量为零时，称其为**稀疏**（sparse）的。相反，大多数分量非零时，称为**稠密**（dense）。

$$\mathbf{s} = [0, 0, 3, 0, 0, 0, 1, 0, 0, 0]$$

- 稀疏性很重要，因为它影响存储和计算。稀疏向量只需记录非零条目就能更高效地存储和处理。

- **单位向量**（unit vector）是模长恰好为 1 的向量。它纯粹表示方向，不含长度信息。你可以将任何向量除以其模长来将其变成单位向量：

$$\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$

- 这个过程叫做**归一化**（normalisation）。它剥离了"多远"，只保留"哪个方向"——这是机器学习中的一个重要因素。

- 标准单位向量沿各坐标轴指向：$\hat{\mathbf{i}} = (1, 0, 0)$、$\hat{\mathbf{j}} = (0, 1, 0)$、$\hat{\mathbf{k}} = (0, 0, 1)$。任何向量都可以写成这些向量的组合，例如 $(3, 2, 4) = 3\hat{\mathbf{i}} + 2\hat{\mathbf{j}} + 4\hat{\mathbf{k}}$。

## 编码任务（使用 CoLab 或 notebook）

1. 计算一个向量的模长并验证它与勾股定理一致，然后修改代码来计算单位向量。
```python
import jax.numpy as jnp

a = jnp.array([3.0, 4.0])

magnitude = jnp.sqrt(jnp.sum(a ** 2))
print(f"Magnitude of a: {magnitude}")
```

2. 通过检验一个向量是否是另一个的标量倍数来判断两个向量是否平行。
```python
import jax.numpy as jnp

a = jnp.array([2, 4, 6])
b = jnp.array([1, 2, 3])

ratios = a / b
print(f"Ratios: {ratios}")
print(f"Parallel: {jnp.allclose(ratios, ratios[0])}")
```

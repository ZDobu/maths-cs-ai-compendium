# 度量与范数

*范数衡量单个向量的大小；度量衡量两个向量之间的距离。本篇涵盖 L1、L2 和 L∞ 范数，欧几里得距离和余弦距离，以及为什么选择正确的距离函数对 kNN、聚类和 ML 中的检索至关重要。*

- 我们知道向量有模长和方向。但我们如何实际衡量一个向量"有多大"，或者两个向量"相距多远"？这就是**范数**（norm）和**度量**（metric）的用武之地。

- 对标量，我们知道 10 > 5，因为它们的数值可以量化它们。但我们如何量化一个向量？答案是**范数**——它衡量单个向量的大小。

- 最熟悉的范数是**欧几里得范数**（Euclidean norm，L2），也就是我们已经知道的模长公式：

$$\|\mathbf{v}\|_2 = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$$

- 但还有其他衡量大小的方法。想象你身处一个有方格街道的城市中。你无法沿对角线穿过建筑物，所以你的旅程"长度"是沿每条街道走的总步数。这就是**曼哈顿范数**（Manhattan norm，L1）：

$$\|\mathbf{v}\|_1 = |v_1| + |v_2| + \cdots + |v_n|$$

- 或者你可能只关心最大的那个分量，忽略其余。这就是**最大范数**（Max norm，L∞）：

$$\|\mathbf{v}\|_\infty = \max(|v_1|, |v_2|, \ldots, |v_n|)$$

- 这三者都是**一般 Lp 范数**的特例：

$$\|\mathbf{v}\|_p = (|v_1|^p + |v_2|^p + \cdots + |v_n|^p)^{1/p}$$

- 令 $p = 2$ 得到欧几里得范数，$p = 1$ 得到曼哈顿范数，当 $p \to \infty$ 时得到最大范数。随着 $p$ 增大，最大的分量贡献越来越大，最终只有它比较关键。

- 每种范数必须遵守三条规则：

    - **非负性**（Non-negativity）：$\|\mathbf{v}\| \geq 0$，且 $\|\mathbf{v}\| = 0$ 仅当 $\mathbf{v} = \mathbf{0}$。大小永远不会为负，只有零向量的大小为零。

    - **缩放性**（Scaling）：$\|c\mathbf{v}\| = |c| \cdot \|\mathbf{v}\|$。将向量加倍，其大小也加倍。

    - **三角不等式**（Triangle inequality）：$\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$。捷径永远不会比绕远路更长。

- 接下来，**度量**（metric）衡量两个向量*之间*的距离。把它想象成在问："这两个点相距多远？"

- 获取度量的最简单方法是测量差异的范数：$d(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|$。将两个向量相减，然后衡量剩余部分的大小。

- 使用欧几里得范数，我们得到熟悉的**欧几里得距离**：

$$d(\mathbf{u}, \mathbf{v}) = \sqrt{(u_1 - v_1)^2 + (u_2 - v_2)^2 + \cdots + (u_n - v_n)^2}$$

- 使用曼哈顿范数得到**曼哈顿距离**——沿各轴的总差，就像数两个地点之间的城市街区数。

- 每种度量必须遵守四条规则：

    - **非负性**：$d(\mathbf{u}, \mathbf{v}) \geq 0$。距离永远不会为负。

    - **同一性**（Identity）：$d(\mathbf{u}, \mathbf{v}) = 0$ 当且仅当 $\mathbf{u} = \mathbf{v}$。零距离意味着同一点。

    - **对称性**（Symmetry）：$d(\mathbf{u}, \mathbf{v}) = d(\mathbf{v}, \mathbf{u})$。从 A 到 B 的距离等于从 B 到 A 的距离。

    - **三角不等式**：$d(\mathbf{u}, \mathbf{w}) \leq d(\mathbf{u}, \mathbf{v}) + d(\mathbf{v}, \mathbf{w})$。直走永远不会比绕路更长。

- 那么两者之间是什么关系？范数衡量一个向量，度量衡量两个向量之间的差距。每个范数自然地产生一个度量（通过测量差异），但并非每个度量都来自于一个范数。

- 例如，**汉明距离**（Hamming distance）统计两个向量在多少个位置上不同。它是一个有效的度量，但不来自任何范数。

- 在 ML 中，选择正确的范数或度量很重要。

- L2 距离在求和前对每个差取平方，因此单个大差值会主导结果。

- L1 距离对绝对差求和，对每个差一视同仁。与 L2 相比，单个大差值的影响较小。

## 编码任务（使用 CoLab 或 notebook）

1. 计算同一个向量的 L1 和 L2 范数。尝试改变数值，观察哪种范数对大分量更敏感而非对多个小分量更敏感。然后对递增的 p 值（如 1, 2, 5, 10, 50, 100）计算 Lp 范数，观察它如何收敛到 L∞ 值。
```python
import jax.numpy as jnp

v = jnp.array([3.0, -4.0, 1.0])

l1 = jnp.sum(jnp.abs(v))
l2 = jnp.sqrt(jnp.sum(v ** 2))

print(f"L1: {l1}, L2: {l2:.2f}")
```

2. 计算两个向量之间的欧几里得距离和曼哈顿距离。尝试将向量移近或移远，观察每种距离的不同响应。
```python
import jax.numpy as jnp

u = jnp.array([1.0, 2.0, 3.0])
v = jnp.array([4.0, 0.0, 1.0])

euclidean = jnp.sqrt(jnp.sum((u - v) ** 2))
manhattan = jnp.sum(jnp.abs(u - v))

print(f"Euclidean: {euclidean:.2f}, Manhattan: {manhattan}")
```

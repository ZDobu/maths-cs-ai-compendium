# 向量空间

*向量空间是机器学习赖以存在的数学乐园。本篇涵盖向量加法、标量乘法、封闭性公理、子空间，以及为什么 AI 中几乎所有东西都以向量表示。*

- 可以把向量空间想象成一个数学对象生活的特定乐园，每个对象都叫做一个**向量**（vector）。

- 向量空间的正式定义是：一组可以向量的集合，这些向量可以相加和缩放，且运算结果不会离开该空间。

- 一个有用的反例：整数 $\mathbb{Z}$ **不**构成实数上的向量空间，因为将 $3$ 缩放 $0.5$ 得到 $1.5$，它不在整数集合内。定义中"不会离开该空间"这一部分是有实际意义的。

- 在机器学习（ML）中，为了几何直观，我们始终将向量视为欧几里得空间中的一个点，用其坐标表示。

- 向量 $\mathbf{a}$（数学上用粗体小写字母表示）有 $n$ 个坐标，每个坐标表示沿某个轴的位置。

$$\mathbf{a} = [a_1, a_2, a_3]$$

![向量 a = (3, 2, 4) 绘制在带有 x, y, z 轴的三维空间中](../../images/vector_3d.svg)

- 向量空间中的向量遵循一套非常明确、不可打破的规则：

    - **向量加法（组合）**：
    你可以取任意两个向量，将它们组合成一个新向量。
    把向量想象成移动指令。
    若向量 A 表示"向前走 3 步"，向量 B 表示"向右走 2 步"，
    将它们相加（A + B）会创建一条新的单一指令："向前走 3 步再向右走 2 步"。

    - **标量乘法（缩放）**：
    你可以用普通的数（"标量" scalar）对任意向量进行缩放。
    可以拉伸、缩小或反转它。
    若向量 A 是"向前走 3 步"，缩放 2 倍变成"向前走 6 步"。
    缩放 -1 倍则完全翻转成"向后走 3 步"。

- 向量空间的**维数**（dimension）是它所包含的独立方向的个数。$\mathbb{R}^2$ 是 2 维的（需要 2 个坐标），而上面的 $\mathbf{a}$ 生活在 $\mathbb{R}^3$ 中。

- 例如，我们可以将任意物体（比如一个人）表示为一个向量，其中 $h_1$ = 身高（cm），$h_2$ = 体重（kg），$h_3$ = 年龄。

$$\mathbf{h} = [185, 75, 30]$$

- 于是我们创建了一个向量空间，其中有一个表示人的向量。

- 我们可以表示多个人，并观察他们之间的远近关系！

![三个人的向量表示：Alice 和 Carol 很接近，Alice 和 Bob 相距很远](../../images/human_vectors.svg)

- 我们可以添加更多特征，为一个人创建丰富的表示，这在 ML 中常被称为特征向量（feature vector）。

- 你拥有的独特而有意义的特征越多，特征向量的描述力就越强——这是一个需要牢记的重要因素。

- 超过 3 维后，向量变得很难可视化，这催生了一门叫做**线性代数**（Linear Algebra）的数学分支。

- **线性代数**是研究向量、向量空间以及向量之间映射的学科。

- 在 AI/ML 中，我们几乎把所有东西都表示为向量，这使得线性代数成为整个领域的基础。

- 向量加法可以通过将一个向量的尾部放在另一个向量的尾部来可视化，然后从原点画到终点。

![向量加法：a（红色）加 b（蓝色）得到结果 a + b（绿色虚线）](../../images/vector_addition.svg)

- 对于两个向量 $\mathbf{a} = (a_1, a_2)$ 和 $\mathbf{b} = (b_1, b_2)$：$\mathbf{a} + \mathbf{b} = (a_1 + b_1, a_2 + b_2)$

- 向量也可以相减，所有加法规则同样适用。

- 将向量乘以一个标量会将该向量按该因子在同一方向上缩放。

![标量乘法：v（红色），2v（蓝色，加倍），-v（紫色，反向）](../../images/scalar_multiplication.svg)

- 对于标量 $c$ 和向量 $\mathbf{v} = (v_1, v_2)$：$c\mathbf{v} = (cv_1, cv_2)$

- **加法封闭性**（Closure under Addition）：如果把向量空间中的任意两个向量相加，结果仍是同一空间中的一个向量：若 $\mathbf{u} \in V$ 且 $\mathbf{v} \in V$，则 $\mathbf{u} + \mathbf{v} \in V$

- **标量乘法封闭性**（Closure under Scalar Multiplication）：如果将向量空间中的任意向量乘以一个标量，结果仍是同一空间中的一个向量：若 $\mathbf{v} \in V$ 且 $c \in F$，则 $c\mathbf{v} \in V$

- **加法交换律**（Commutativity）：对任意两个向量 $\mathbf{u}$ 和 $\mathbf{v}$：$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$

![平行四边形法则：无论先走 u 再走 v，还是先走 v 再走 u，都到达同一个点](../../images/commutativity.svg)

- 走平行四边形两条边到达的是同一个终点。

- **（零向量）**（Zero Vector）：存在一个向量 $\mathbf{0}$，使得对任意向量 $\mathbf{v}$：$\mathbf{v} + \mathbf{0} = \mathbf{v}$

![零向量：v + 0 = v](../../images/zero_vector.svg)

- **加法逆元**（Additive Inverse）：对每个向量 $\mathbf{v}$，存在一个向量 $-\mathbf{v}$，使得：$\mathbf{v} + (-\mathbf{v}) = \mathbf{0}$

![加法逆元：v（红色）和 -v（蓝色）抵消为零](../../images/additive_inverse.svg)

- **分配律 1**：对任意标量 $c$ 和向量 $\mathbf{u}$、$\mathbf{v}$：$c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$

![分配律：缩放和（金色）等于缩放后的向量之和](../../images/distributivity.svg)

- 缩放和（金色）得到的结果与先缩放再相加完全相同。

- **分配律 2**：对任意标量 $c$、$d$ 和向量 $\mathbf{v}$：$(c + d)\mathbf{v} = c\mathbf{v} + d\mathbf{v}$

- **结合律**（Associativity）：对任意标量 $c$、$d$ 和向量 $\mathbf{v}$：$(cd)\mathbf{v} = c(d\mathbf{v})$

- **单位元**（Identity Element）：对任意向量 $\mathbf{v}$：$1\mathbf{v} = \mathbf{v}$，其中 $1$ 是标量域中的乘法单位元。

- 一些向量空间的例子：

    - **$\mathbb{R}^n$（n 维空间）**：n 维空间中的所有实数，示例向量 [1, 4, 3000...第 n 项]，将两个点相加或缩放一个点，你仍然落在该平面上的某处。

    - **灰度图像**：一个 $28 \times 28$ 的图像就是 784 个像素强度值，即 $\mathbb{R}^{784}$ 中的一个向量。将两幅图像相加（混合）或缩放一幅图像（增亮）会得到同样大小的另一幅图像。

    - **音频信号**：以 44.1kHz 采样的 1 秒音频片段是一个包含 44,100 个条目的向量。将两段音频混音就是向量加法。

    - **多项式**：将两个多项式相加或乘以一个数仍得到一个多项式，因此它们也构成一个向量空间。向量不一定看起来像箭头！

- **子空间**（subspace）就是更大空间内部的一个较小的乐园。把 3D 空间想象成一个房间。穿过房间中心的一张平纸就是一个子空间，穿过中心的一条直线也是。

- 关键要求是子空间必须经过原点。如果你把那纸移离中心，它就不再是子空间，因为零向量不在它上面了。

![子空间：3D 空间内经过原点的一条直线和一个平面](../../images/subspaces.svg)

- 向量空间的所有规则（加法、缩放、封闭性）在子空间内仍然有效。你可以在其中对向量进行加法和缩放，永远不会"掉出"到更大的空间中。

- 经过原点的直线是 1 维子空间，经过原点的平面是 2 维子空间，整个空间本身也是自己的子空间。

- 在 ML 中，子空间自然出现。高维数据往往具有存在于低维子空间上的结构。PCA 等技术找到那个子空间，让我们能更高效地处理数据。

2. 运行代码可视化不同的向量，然后修改坐标值，理解每个轴对位置的影响。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

# 试着修改这些向量！
a = jnp.array([3, 2, 4])
b = jnp.array([1, 4, 2])
c = jnp.array([4, 1, 3])

fig = plt.figure()
ax = fig.add_subplot(111, projection="3d")

for vec, name, color in [(a, "a", "red"), (b, "b", "blue"), (c, "c", "green")]:
    ax.quiver(0, 0, 0, *vec, color=color, arrow_length_ratio=0.1, linewidth=2, label=name)

lim = int(jnp.abs(jnp.stack([a, b, c])).max()) + 1
ax.set_xlim([0, lim]); ax.set_ylim([0, lim]); ax.set_zlim([0, lim])
ax.set_xlabel("X"); ax.set_ylabel("Y"); ax.set_zlabel("Z")
ax.legend()
plt.show()
```

## 支线任务（一些需要了解的数学符号）

| 符号 | 含义 | 示例 |
|---|---|---|
| ∈ | 是……的元素 | x ∈ A：x 在集合 A 中 |
| ∉ | 不是……的元素 | x ∉ A |
| ⊂ | 是……的真子集 | A ⊂ B |
| ⊆ | 是……的子集或等于 | A ⊆ B |
| ∪ | 并集 | A ∪ B：在 A 或 B 中的元素 |
| ∩ | 交集 | A ∩ B：同时属于 A 和 B 的元素 |
| ∅ | 空集 | A = ∅ |
| ℝ | 实数 | x ∈ ℝ |
| ℤ | 整数 | -2, -1, 0, 1, 2 |
| ℕ | 自然数 | 1, 2, 3, ... |
| ℚ | 有理数 | 如 1/2 这样的分数 |
| ⇒ | 蕴含 | x > 2 ⇒ x > 1 |
| ⇔ | 当且仅当 | x = 2 ⇔ x² = 4，需附加条件 |
| ∀ | 对所有 | ∀x ∈ ℝ |
| ∃ | 存在 | ∃x 使得 x² = 4 |
| ¬ | 非 | ¬P：非 P |
| ∧ | 且 | P ∧ Q |
| ∨ | 或 | P ∨ Q |
| ∴ | 因此 | x = 2, ∴ x² = 4 |

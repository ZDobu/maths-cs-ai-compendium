# 向量乘积

*向量乘积是衡量相似度和计算投影的基本运算。本篇涵盖内积、点积、余弦相似度、叉积和外积——这些运算驱动着 AI 中的注意力机制、嵌入和几何推理。*

- 我们已经学习了如何相加和缩放向量。但我们能*相乘*两个向量吗？事实上不止一种方法，每种回答不同的问题。

- **内积**（inner product）是一般概念：一个接收两个向量并产生一个数（标量）的函数。它是"相乘"向量的抽象蓝图。

- 任何内积必须满足三条规则：

    - **正定性**（Positive definiteness）：$\langle \mathbf{v}, \mathbf{v} \rangle \geq 0$，且仅对零向量等于零。一个向量和自身相乘总是得到非负结果。

    - **对称性**（Symmetry）：$\langle \mathbf{u}, \mathbf{v} \rangle = \langle \mathbf{v}, \mathbf{u} \rangle$。顺序无关紧要。

    - **线性性**（Linearity）：$\langle a\mathbf{u} + b\mathbf{v}, \mathbf{w} \rangle = a\langle \mathbf{u}, \mathbf{w} \rangle + b\langle \mathbf{v}, \mathbf{w} \rangle$。内积对加法和缩放可分配。

- **点积**（dot product）是最常见的内积。它是几乎随处可用的具体版本。对于两个向量 $\mathbf{a} = (a_1, a_2, \ldots, a_n)$ 和 $\mathbf{b} = (b_1, b_2, \ldots, b_n)$：

$$\mathbf{a} \cdot \mathbf{b} = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n$$

- 将对应分量相乘，然后全部相加。就这么简单。

- 但这个数*意味着*什么？点积有一个优美的几何解释：

$$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \, \|\mathbf{b}\| \cos(\theta)$$

![点积：向量 a 投影到 b 上，显示了夹角 θ 和投影](../../images/dot_product.svg)

- 这把点积直接关联到两个向量之间的夹角 $\theta$。结果告诉你两个向量在方向上的"一致"程度。

- 若它们指向相同（$\theta = 0°$），$\cos(\theta) = 1$，点积最大化。

- 若它们正交（$\theta = 90°$），$\cos(\theta) = 0$，点积恰好为零。这给了我们一个精确的正交性检验方法。

- 若它们指向相反（$\theta = 180°$），$\cos(\theta) = -1$，点积为负。

- 一个向量与自身点积等于其模长的平方：$\mathbf{a} \cdot \mathbf{a} = \|\mathbf{a}\|^2$。

- 点积还可以给出**投影**（projection）——一个向量在另一个向量上的"影子"。$\mathbf{a}$ 在 $\mathbf{b}$ 上的投影是：

$$\text{proj}_{\mathbf{b}}(\mathbf{a}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|^2} \, \mathbf{b}$$

- 想象用光垂直照向 $\mathbf{b}$。$\mathbf{a}$ 在那条线上的影子就是投影。它告诉你 $\mathbf{a}$ 有多少分量落在 $\mathbf{b}$ 的方向上。

- **余弦相似度**（cosine similarity）将点积除以两个模长来做归一化：

$$\cos(\theta) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \, \|\mathbf{b}\|}$$

- 这给出一个范围在 $-1$ 到 $1$ 之间的值，衡量方向的一致程度，忽略向量有多长。它被广泛用于 ML 中比较文档、嵌入和用户偏好等。

- 现在，点积接收两个向量并返回一个标量。**叉积**（cross product）则相反——它接收两个向量并返回一个*新向量*。

- 叉积 $\mathbf{a} \times \mathbf{b}$ 产生一个同时垂直于 $\mathbf{a}$ 和 $\mathbf{b}$ 的向量：

$$\mathbf{a} \times \mathbf{b} = (a_2 b_3 - a_3 b_2, \; a_3 b_1 - a_1 b_3, \; a_1 b_2 - a_2 b_1)$$

- 叉积仅在 3D 中有效。点积在任意维度中都有定义，但叉积是三维空间特有的。

- 其模长等于两个向量形成的平行四边形的面积：

$$\|\mathbf{a} \times \mathbf{b}\| = \|\mathbf{a}\| \, \|\mathbf{b}\| \sin(\theta)$$

- 注意这个模式：点积使用 $\cos(\theta)$，叉积使用 $\sin(\theta)$。点积衡量两个向量有多一致，叉积衡量它们在方向上有多大*差异*。

- 结果的方向遵循**右手定则**（right-hand rule）：将右手的四指从 $\mathbf{a}$ 向 $\mathbf{b}$ 卷曲，拇指指向 $\mathbf{a} \times \mathbf{b}$ 的方向。

- 与点积不同，叉积**不满足交换律**：$\mathbf{a} \times \mathbf{b} = -(\mathbf{b} \times \mathbf{a})$。交换顺序会翻转方向。

- 如果两个向量平行，它们的叉积是零向量（因为 $\sin(0°) = 0$）。没有面积，没有垂直方向。

- 当你用这两种乘积组合三个向量时会发生什么？这得到了**三重积**（triple product）。

- **标量三重积** $\mathbf{a} \cdot (\mathbf{b} \times \mathbf{c})$ 先计算两个向量的叉积，再将结果与第三个点积。输出是一个数，等于三个向量形成的平行六面体（一个倾斜的 3D 盒子）的体积。

- 如果标量三重积为零，三个向量**共面**（coplanar）——它们都位于同一个平面中，不构成体积。

- 顺序可以循环而不改变结果：$\mathbf{a} \cdot (\mathbf{b} \times \mathbf{c}) = \mathbf{b} \cdot (\mathbf{c} \times \mathbf{a}) = \mathbf{c} \cdot (\mathbf{a} \times \mathbf{b})$。

- **向量三重积** $\mathbf{a} \times (\mathbf{b} \times \mathbf{c})$ 应用两次叉积并返回一个向量。它可以用恒等式优雅展开：

$$\mathbf{a} \times (\mathbf{b} \times \mathbf{c}) = (\mathbf{a} \cdot \mathbf{c})\mathbf{b} - (\mathbf{a} \cdot \mathbf{b})\mathbf{c}$$

- 结果始终位于 $\mathbf{b}$ 和 $\mathbf{c}$ 所张成的平面内。注意叉积**不满足结合律**：$\mathbf{a} \times (\mathbf{b} \times \mathbf{c}) \neq (\mathbf{a} \times \mathbf{b}) \times \mathbf{c}$。

## 编码任务（使用 CoLab 或 notebook）

1. 计算两个向量的点积并用它求它们之间的夹角。尝试让它们正交、平行或反向，观察夹角如何变化。
```python
import jax.numpy as jnp

a = jnp.array([1.0, 2.0, 3.0])
b = jnp.array([4.0, -1.0, 2.0])

dot = jnp.dot(a, b)
angle = jnp.arccos(dot / (jnp.linalg.norm(a) * jnp.linalg.norm(b)))

print(f"Dot product: {dot}")
print(f"Angle: {jnp.degrees(angle):.1f}°")
```

2. 计算两个 3D 向量的叉积，并通过检验结果与每个原向量的点积是否为零来验证其同时垂直于两者。
```python
import jax.numpy as jnp

a = jnp.array([1.0, 0.0, 0.0])
b = jnp.array([0.0, 1.0, 0.0])

cross = jnp.cross(a, b)

print(f"a x b = {cross}")
print(f"Perpendicular to a: {jnp.dot(cross, a) == 0}")
print(f"Perpendicular to b: {jnp.dot(cross, b) == 0}")
```

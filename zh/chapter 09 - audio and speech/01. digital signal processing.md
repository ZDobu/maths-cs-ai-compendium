# 数字信号处理

_数字信号处理将原始音频波形转换为机器学习模型可以学习的结构化表示。本文件涵盖声音物理、采样与量化、傅里叶变换（DFT、FFT）、语谱图、梅尔滤波器组、MFCC和加窗——所有语音和音频AI的特征提取流水线。_

- **声音（sound）**是通过介质（空气、水、固体）传播的压力波。振动物体（声带、吉他弦、扬声器锥体）推拉空气分子，产生交替的高压区（压缩）和低压区（稀疏）。

- 这些压力变化以大约343米/秒的速度在空气中向外传播，到达你的耳朵，在那里它们振动耳膜并转换为神经信号。

- 把声音想象成往平静的池塘里丢一块石头：石头是振动源，涟漪是压力波，水面上下浮动的一个软木塞是麦克风或耳膜对波到达的响应。

- 软木塞上下浮动的高度是**振幅（amplitude）**，每秒浮动的次数是**频率（frequency）**，当波到达时它是在上浮还是下沉的顶部则是**相位（phase）**。

- **波形（waveform）**是压力（或电压，在麦克风将声音转换为电信号之后）相对于时间的图像。最简单的波形是**纯音（pure tone）**，一个单一正弦波：

$$x(t) = A \sin(2\pi f t + \phi)$$

- 其中：
  - $A$是振幅（偏离零的峰值，决定响度），
  - $f$是频率（以Hz为单位，每秒的周期数，决定音高），
  - $\phi$是相位（以弧度为单位，波的时间偏移）。

- **周期（period）**是$T = 1/f$，一个完整周期的持续时间。

![标注了振幅、周期、频率和相移的正弦波](../../images/audio_waveform.svg)

- **振幅**决定感知的响度。振幅加倍使功率变为四倍（因为功率与振幅的平方成正比）。

- 人类听觉跨越巨大的振幅范围，所以我们使用对数刻度：**分贝（decibel，dB）**。声压级为：

$$L = 20 \log_{10}\left(\frac{A}{A_\text{ref}}\right) \text{ dB}$$

- 其中$A_\text{ref}$是参考振幅（通常为听觉阈值，$20 \mu\text{Pa}$）。耳语约为30 dB，正常对话为60 dB，摇滚音乐会是110 dB。每增加6 dB大约使振幅加倍；每增加10 dB大约使感知响度加倍。这里的对数与第03章中的对数函数相同。

- **频率**决定音高。低频（20-250 Hz）听起来是低音；高频（2000-20000 Hz）听起来是高音。人类听觉范围大约为20 Hz到20 kHz。音乐会音高A为440 Hz。频率加倍使音高提高一个**八度（octave）**。

- 大多数自然声音不是纯音，而是多种频率的复杂混合，这就是为什么钢琴和小提琴演奏相同音符听起来不同：它们共享相同的**基频（fundamental frequency）**，但在其**泛音（harmonics，基频的整数倍）**及其相对振幅（**音色（timbre）**）上有所不同。

- **相位**决定波在其周期中的起始位置。两个具有相同振幅和频率但不同相位的波可能产生相长干涉（相位对齐，振幅相加）或相消干涉（相位相反，振幅抵消）。

- 相位在立体声音频和波束成形中至关重要，但在许多语音处理流水线中被大量丢弃，因为人类对音高和音色的感知大多与相位无关。

- 现实世界的音频信号是时间的**连续**函数，但计算机使用离散的数字。**采样（sampling）**通过以规则间隔测量信号值将连续信号转换为离散序列。

- **采样率（sample rate）** $f_s$是每秒的测量次数。CD音频使用$f_s = 44{,}100$ Hz；电话使用8000 Hz；现代语音模型通常使用16000 Hz。

- **奈奎斯特-香农采样定理（Nyquist-Shannon sampling theorem）**指出，当且仅当采样率至少是信号中存在的最高频率的两倍时，连续信号才能从其样本中完美重建：

$$f_s \geq 2 f_\text{max}$$

- 频率$f_s / 2$称为**奈奎斯特频率（Nyquist frequency）**。如果信号包含高于奈奎斯特频率的频率成分，这些频率会折叠回有效范围，表现为虚假的低频成分。这种现象称为**混叠（aliasing）**。混叠是不可逆的：一旦发生，原始信号无法从样本中恢复。

- 混叠的日常类比是电影中的车轮效应：一个以略高于帧率速度旋转的轮子看起来会缓慢向后旋转，因为相机对旋转采样不足。在音频中，以16 kHz采样（$f_\text{Nyquist} = 8$ kHz）的15 kHz音调混叠为$16 - 15 = 1$ kHz，一个完全不同的音高。

![信号的正确采样与采样率过低时的混叠采样对比](../../images/sampling_aliasing.svg)

- 为防止混叠，**抗混叠滤波器（anti-aliasing filter）**（一个低通滤波器）在采样前移除所有高于$f_s/2$的频率。这由模数转换器（ADC）硬件在信号数字化之前应用。

- **量化（quantisation）**将每个连续值样本映射到有限级别集合中最接近的值。一个$n$位量化器具有$2^n$个级别。CD音频使用16位量化（$2^{16} = 65{,}536$个级别）；电话常使用8位加$\mu$律或A律**压扩（companding）**（一种非线性映射，为小幅值分配更多级别，匹配人类感知）。量化引入**量化噪声（quantisation noise）**，一种舍入误差，方差为$\Delta^2/12$，其中$\Delta$是级别之间的步长。

- **时域分析（time-domain analysis）**直接从波形提取特征，无需将其变换到另一个域。这些特征简单、计算快，并捕获基本信号属性。

- 一帧$N$个样本的**能量（energy）**测量总体响度：

$$E = \sum_{n=0}^{N-1} x[n]^2$$

- 语音片段能量高；静音能量低。能量是应用于信号向量的第01章平方$\ell_2$范数。

- **过零率（zero-crossing rate，ZCR）**计算一帧内信号改变符号的次数：

$$\text{ZCR} = \frac{1}{2(N-1)} \sum_{n=1}^{N-1} |\text{sign}(x[n]) - \text{sign}(x[n-1])|$$

- 高ZCR表示高频内容或噪声；低ZCR表示低频或浊音语音（声带有规律地振动）。ZCR是一个粗略的频率估计器：频率为$f$ Hz的纯音每秒过零$2f$次。

- **自相关（autocorrelation）**测量信号与自身的延迟副本有多相似：

$$R[k] = \sum_{n=0}^{N-1-k} x[n] \cdot x[n+k]$$

- 在滞后$k = 0$时，自相关等于能量。对于周期性信号，自相关在等于周期及其倍数的滞后处有峰值。这是**基音检测（pitch detection）**的标准技术：在$k=0$之后找到$R[k]$中的第一个显著峰值，音高为$f_s / k_\text{peak}$。自相关与第01章的点积相关：$R[k]$是信号与其$k$位移版本的向量点积。

- **频域分析（frequency-domain analysis）**揭示信号的频谱内容，这些信息在波形中不可见。关键工具是**离散傅里叶变换（Discrete Fourier Transform，DFT）**，它将$N$个样本的信号分解为$N$个复值频率成分：

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j 2\pi k n / N}, \quad k = 0, 1, \ldots, N-1$$

- 每个$X[k]$是一个复数，其幅值$|X[k]|$给出频率成分在$f_k = k \cdot f_s / N$ Hz处的振幅，其相位$\angle X[k]$给出相位偏移。DFT是从时域基（单位脉冲）到频域基（复指数）的基变换，这是第02章基概念的直接应用。DFT可以写为矩阵乘法$\mathbf{X} = W \mathbf{x}$，其中$W$是$N \times N$的DFT矩阵，其元素$W_{kn} = e^{-j2\pi kn/N}$。

- **快速傅里叶变换（Fast Fourier Transform，FFT）**是一种算法，通过递归地将问题分成偶数索引和奇数索引的子问题（Cooley-Tukey算法），以$O(N \log N)$次运算计算DFT，而不是朴素的$O(N^2)$。这种加速使实时的频谱分析变得实用。FFT是所有计算中最重要的算法之一。

- **功率谱（power spectrum）** $|X[k]|^2$显示能量在频率上的分布。**幅值谱（magnitude spectrum）** $|X[k]|$显示振幅。绘制这些可以揭示哪些频率主导信号：元音在基频的整数倍处有强泛音；摩擦音（如"s"）有宽频带的高频能量。

- **语谱图（spectrogram）**是信号频率内容如何随时间变化的视觉表示。它通过将信号分割成短的、重叠的帧，计算每帧的FFT，并将产生的幅值谱并排堆叠来计算。水平轴是时间，垂直轴是频率，每个点的颜色（或亮度）表示幅值。语谱图是音频处理中最重要的可视化工具。

![显示水平轴为时间、垂直轴为频率、强度为颜色的语谱图](../../images/spectrogram_stft.svg)

- **梅尔刻度（mel scale）**是一种感知频率刻度，反映人类如何感知音高。人类将相等的频率比感知为相等的音高间隔（正如我们将相等的强度比感知为相等的响度间隔）。低于约1000 Hz，梅尔刻度近似线性；高于1000 Hz，它近似对数：

$$m = 2595 \log_{10}\left(1 + \frac{f}{700}\right)$$

- 其逆为$f = 700(10^{m/2595} - 1)$。梅尔刻度是为什么音乐半音在对数频率轴上均匀分布的原因：A4（440 Hz）到A5（880 Hz）和A5到A6（1760 Hz）都听起来像"升高一个八度"，尽管Hz间隔分别为440和880。

- **梅尔滤波器组（mel filterbank）**是一组在梅尔刻度上均匀分布的三角形带通滤波器。每个滤波器覆盖一个频带，将该频带内的频谱能量求和，产生一个单一数字。典型的语音系统使用40-80个梅尔滤波器。低频滤波器窄（在我们感知敏感的地方有高频率分辨率），高频滤波器宽（在我们不太敏感的地方有低分辨率）。这模仿了人类耳蜗的频率分辨率。

![叠加在线性频率轴上的三角形梅尔刻度滤波器组，显示低频处的窄滤波器和高频处的宽滤波器](../../images/mel_filterbank.svg)

- **梅尔频率倒谱系数（Mel-Frequency Cepstral Coefficients，MFCC）**是语音和音频的经典特征表示。它们将梅尔频谱压缩为少量去相关的系数，捕获频谱包络的形状（编码声道配置，因此编码了音素身份），同时丢弃精细的频谱细节（编码音高和相位）。

- MFCC流水线：
  1. **预加重（pre-emphasis）**：应用一阶高通滤波器$y[n] = x[n] - \alpha x[n-1]$（通常$\alpha = 0.97$）以增强被声道衰减的高频。
  2. **分帧（framing）**：将信号分割成重叠的帧（通常25 ms长，10 ms跳跃）。
  3. **加窗（windowing）**：将每帧乘以窗函数（Hamming窗）以减少频谱泄漏（见下文）。
  4. **FFT**：计算每个加窗帧的功率谱。
  5. **梅尔滤波器组**：将三角形梅尔滤波器组应用于功率谱，产生梅尔频带能量。
  6. **对数（log）**：取梅尔频带能量的对数。对数压缩动态范围并将乘法（频谱成分的乘法）转换为加法，匹配人类响度感知。
  7. **DCT**：对对数梅尔能量应用离散余弦变换。DCT对梅尔频带去相关（因为相邻频带高度相关），并将能量压缩到前几个系数。保留前13个系数（MFCC-0到MFCC-12）。

![MFCC流水线从原始音频通过加窗帧、FFT、梅尔滤波器组、对数压缩和DCT到最终MFCC特征](../../images/mfcc_pipeline.svg)

- 第7步中的DCT本质上是"频谱的傅里叶变换"（因此得名**倒谱（cepstrum）** = spectrum的字母重排）。低阶倒谱系数捕获宽频谱形状（声道共振，称为**共振峰（formants）**），而高阶系数捕获精细频谱细节（音高泛音）。通过仅保留前13个，我们保留了共振峰信息并丢弃了音高细节。

- **Delta**和**delta-delta** MFCC（MFCC的一阶和二阶时间导数，通过相邻帧的有限差分计算）捕获频谱形状的动态，添加时间上下文。完整的MFCC特征向量通常是39维：13个静态 + 13个delta + 13个delta-delta。

- 现代神经网络模型（第06章）已在很大程度上用学习到的特征取代了MFCC：对数梅尔语谱图（第6步的输出，跳过DCT）是深度学习ASR和音频分类的标准输入。模型学习自己的去相关。尽管如此，MFCC对于低资源环境、经典机器学习流水线和理解信号处理基础仍然很重要。

- **加窗（windowing）**是在计算FFT之前将信号帧乘以平滑窗函数的过程。没有加窗，FFT假设帧无限重复；帧的突然开始和结束产生人为的不连续性，将能量扩散到所有频率，这种伪影称为**频谱泄漏（spectral leakage）**。

- **矩形窗（rectangular window）** $w[n] = 1$（对所有$n$）：无渐缩，泄漏最大，但主瓣最宽（给定帧长的最佳频率分辨率）。实践中很少使用。

- **Hamming窗**：$w[n] = 0.54 - 0.46 \cos(2\pi n / (N-1))$。在边缘渐缩到接近零，大大减少泄漏。语音处理的标准选择。

- **Hann窗**（也称为Hanning窗）：$w[n] = 0.5 - 0.5 \cos(2\pi n / (N-1))$。在边缘渐缩到精确为零。与Hamming窗非常相似，但具有稍好的旁瓣抑制。

- **Blackman窗**：$w[n] = 0.42 - 0.5 \cos(2\pi n / (N-1)) + 0.08 \cos(4\pi n / (N-1))$。更好的旁瓣抑制，但主瓣更宽（频率分辨率更差）。当旁瓣伪影特别成问题时使用。

- 存在一个基本权衡：泄漏更少的窗具有更宽的主瓣，这意味着它们无法分辨两个紧密靠近的频率。这是**频谱分辨率与泄漏的权衡（spectral resolution vs. leakage tradeoff）**，是第03章不确定性原理的结果。

- **叠加相加（overlap-add，OLA）**是一种从加窗、处理后的帧重建信号的技术。帧重叠（通常为50-75%），处理后，加窗的输出被求和。如果窗和重叠选择正确（例如，Hann窗与50%重叠），重叠的窗求和为常数，给出完美重建。这对于任何基于帧的音频修改（降噪、变调、时间拉伸）都是必不可少的。

- **短时傅里叶变换（Short-Time Fourier Transform，STFT）**是语谱图背后的形式化框架。它对信号的每个加窗帧应用DFT：

```math
\text{STFT}\{x[n]\}(m, k) = \sum_{n=0}^{N-1} x[n + mH] \cdot w[n] \cdot e^{-j 2\pi k n / N}
```

- 其中$m$是帧索引，$H$是跳跃大小（连续帧之间的样本数），$w[n]$是窗函数，$N$是FFT大小。输出是一个二维复值矩阵：信号的**时频表示（time-frequency representation）**。

- STFT体现了一个基本的**时频权衡（time-frequency tradeoff）**：
  - 长帧（大$N$）：高频率分辨率（可以区分紧密排列的频率），但时间分辨率差（无法确定频率何时改变）。
  - 短帧（小$N$）：高时间分辨率，但频率分辨率差。
  - 时间分辨率和频率分辨率的乘积有下界：$\Delta t \cdot \Delta f \geq \frac{1}{4\pi}$。这是**Gabor极限（Gabor limit）**，物理学中海森堡不确定性原理的信号处理类比。

- 典型的语音STFT参数：25 ms帧长（16 kHz时为$N = 400$），10 ms跳跃（$H = 160$），Hamming窗，512点FFT（从400补零以获得效率和更平滑的频谱插值）。

- **滤波（filtering）**通过放大某些频率并衰减其他频率来修改信号的频率内容。**滤波器（filter）**是一个接受输入信号并产生输出信号的系统。滤波器由其**频率响应（frequency response）** $H(f)$表征，描述应用于每个频率的增益和相移。

- **低通滤波器（low-pass filter）**：通过截止频率$f_c$以下的频率，衰减其以上的频率。去除高频噪声和细节。采样前的抗混叠滤波器是一个低通滤波器。

- **高通滤波器（high-pass filter）**：通过$f_c$以上的频率，衰减以下的频率。去除低频隆隆声和直流偏移。MFCC提取中的预加重滤波器（$y[n] = x[n] - 0.97 x[n-1]$）是一个简单的高通滤波器。

- **带通滤波器（band-pass filter）**：通过范围$[f_1, f_2]$内的频率，衰减范围外的频率。梅尔滤波器组中的每个三角形是一个带通滤波器。

- **带阻（陷波）滤波器（band-stop / notch filter）**：衰减特定的窄频率范围。用于去除特定干扰（例如，50/60 Hz电源线嗡嗡声）。

- **有限脉冲响应（Finite Impulse Response，FIR）滤波器**将每个输出样本计算为当前和过去输入样本的加权和：

$$y[n] = \sum_{k=0}^{M} b_k \cdot x[n-k]$$

- 权重$b_k$是**滤波器系数（filter coefficients）**（也称为**抽头（taps）**）。滤波器具有阶数$M$。FIR滤波器始终稳定（输出永不发散），并可以被设计为具有完美线性相位（所有频率延迟相同量，保持波形形状）。它们的缺点是实现锐利截止需要很多抽头（高$M$），增加计算量。输出是输入与系数向量的卷积，恰好是第06章中的一维卷积运算。

- **无限脉冲响应（Infinite Impulse Response，IIR）滤波器**使用反馈：输出同时依赖于过去的输入和过去的输出：

```math
y[n] = \sum_{k=0}^{M} b_k \cdot x[n-k] - \sum_{k=1}^{L} a_k \cdot y[n-k]
```

- 反馈项$a_k$创建了一个递归结构，其脉冲响应在理论上是无限持续的。IIR滤波器用比FIR滤波器少得多的系数实现锐利截止，但它们可能不稳定（如果传递函数的极点位于单位圆外，输出会无限增长，这是$z$变换的一个概念）。它们还具有非线性相位，可能扭曲波形形状。经典滤波器设计（Butterworth、Chebyshev、椭圆）都是IIR。

- 离散时间滤波器的**传递函数（transfer function）**通过$z$变换获得：

$$H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{L} a_k z^{-k}}$$

- 分子的根称为**零点（zeros）**，分母的根称为**极点（poles）**。零极点图完全表征了滤波器的行为。单位圆附近的极点放大附近的频率；单位圆附近的零点衰减它们。FIR滤波器只有零点（分母为1）。这与第02章和第03章的特征值和根查找概念相关。

- **卷积定理（convolution theorem）**：时域中的卷积等于频域中的逐元素乘法。这意味着滤波可以通过直接卷积信号与滤波器脉冲响应来执行，或者通过乘以它们的傅里叶变换并对结果进行逆变换来执行。对于长滤波器，频域方法（使用FFT）更快：$O(N \log N)$相对于$O(NM)$。

- **逆STFT（inverse STFT，iSTFT）**从其STFT表示重建时域信号。这对于任何在频域中修改音频的系统（降噪、源分离、语音转换）都是必不可少的。重建使用叠加相加：

```math
x[n] = \frac{\sum_{m} w[n - mH] \cdot \text{IDFT}\{X(m, k)\}[n - mH]}{\sum_{m} w[n - mH]^2}
```

- 分母对窗重叠进行归一化，当合成窗与分帧窗匹配且重叠足够时确保完美重建。

- **语音DSP链总结**：原始音频以16 kHz采样，进行预加重，分割成25 ms的Hamming窗帧，10 ms跳跃，每帧进行FFT变换，通过梅尔滤波器组，进行对数压缩，然后要么保留为对数梅尔特征（用于神经网络模型），要么进行DCT变换产生MFCC（用于经典模型）。这整条链将一维时域信号转换为适合下游机器学习的二维时频表示，这将是文件02的主题。

3. 在JAX中从零开始构建完整的MFCC流水线：预加重、分帧、加窗、FFT、梅尔滤波器组、对数、DCT。将梅尔滤波器组和生成的MFCC可视化为热力图。

```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

# --- Generate a synthetic speech-like signal ---
key = jax.random.PRNGKey(42)
fs = 16000
duration = 1.0
t = jnp.arange(0, duration, 1.0 / fs)

# Simulate voiced speech: fundamental + harmonics with amplitude decay
f0 = 150.0  # fundamental frequency
x = sum(jnp.sin(2 * jnp.pi * f0 * k * t) / k for k in range(1, 8))
# Add some noise
x = x + 0.1 * jax.random.normal(key, t.shape)
x = x / jnp.max(jnp.abs(x))  # normalise

# --- Step 1: Pre-emphasis ---
alpha = 0.97
x_pre = jnp.concatenate([x[:1], x[1:] - alpha * x[:-1]])

# --- Step 2: Framing ---
frame_len = int(0.025 * fs)   # 25 ms = 400 samples
hop_len = int(0.010 * fs)     # 10 ms = 160 samples
n_frames = (len(x_pre) - frame_len) // hop_len + 1
frames = jnp.stack([x_pre[i * hop_len : i * hop_len + frame_len]
                     for i in range(n_frames)])

# --- Step 3: Hamming window ---
hamming = 0.54 - 0.46 * jnp.cos(2 * jnp.pi * jnp.arange(frame_len) / (frame_len - 1))
windowed = frames * hamming

# --- Step 4: FFT ---
n_fft = 512
spectra = jnp.fft.rfft(windowed, n=n_fft)
power_spectra = jnp.abs(spectra) ** 2 / n_fft

# --- Step 5: Mel filterbank ---
n_mels = 40
f_min, f_max = 0.0, fs / 2.0

def hz_to_mel(f):
    return 2595 * jnp.log10(1 + f / 700)

def mel_to_hz(m):
    return 700 * (10 ** (m / 2595) - 1)

mel_min = hz_to_mel(f_min)
mel_max = hz_to_mel(f_max)
mel_points = jnp.linspace(mel_min, mel_max, n_mels + 2)
hz_points = mel_to_hz(mel_points)

freq_bins = jnp.floor((n_fft + 1) * hz_points / fs).astype(jnp.int32)
n_freqs = n_fft // 2 + 1
filterbank = jnp.zeros((n_mels, n_freqs))

for m in range(n_mels):
    f_left = freq_bins[m]
    f_center = freq_bins[m + 1]
    f_right = freq_bins[m + 2]
    # Rising slope
    for k in range(int(f_left), int(f_center)):
        if f_center != f_left:
            filterbank = filterbank.at[m, k].set((k - f_left) / (f_center - f_left))
    # Falling slope
    for k in range(int(f_center), int(f_right)):
        if f_right != f_center:
            filterbank = filterbank.at[m, k].set((f_right - k) / (f_right - f_center))

# Apply filterbank
mel_spectra = jnp.dot(power_spectra, filterbank.T)

# --- Step 6: Log ---
log_mel = jnp.log(mel_spectra + 1e-10)

# --- Step 7: DCT (type-II) ---
n_mfcc = 13
n_mel_channels = log_mel.shape[1]
dct_matrix = jnp.zeros((n_mfcc, n_mel_channels))
for i in range(n_mfcc):
    for j in range(n_mel_channels):
        dct_matrix = dct_matrix.at[i, j].set(
            jnp.cos(jnp.pi * i * (j + 0.5) / n_mel_channels)
        )
mfccs = jnp.dot(log_mel, dct_matrix.T)

# --- Visualisation ---
fig, axes = plt.subplots(3, 1, figsize=(14, 11))

# Mel filterbank
freq_axis = jnp.linspace(0, fs / 2, n_freqs)
for m in range(n_mels):
    color = '#3498db' if m % 2 == 0 else '#e74c3c'
    axes[0].plot(freq_axis, filterbank[m], color=color, alpha=0.6, linewidth=0.8)
axes[0].set_title(f'Mel Filterbank ({n_mels} filters)')
axes[0].set_xlabel('Frequency (Hz)'); axes[0].set_ylabel('Weight')
axes[0].grid(True, alpha=0.3)

# Log-mel spectrogram
im1 = axes[1].imshow(log_mel.T, aspect='auto', origin='lower',
                      extent=[0, duration, 0, n_mels], cmap='viridis')
axes[1].set_title('Log-Mel Spectrogram')
axes[1].set_xlabel('Time (s)'); axes[1].set_ylabel('Mel Band')
plt.colorbar(im1, ax=axes[1], label='Log Energy')

# MFCCs
im2 = axes[2].imshow(mfccs.T, aspect='auto', origin='lower',
                      extent=[0, duration, 0, n_mfcc], cmap='coolwarm')
axes[2].set_title(f'MFCCs (first {n_mfcc} coefficients)')
axes[2].set_xlabel('Time (s)'); axes[2].set_ylabel('MFCC Index')
plt.colorbar(im2, ax=axes[2], label='Coefficient Value')

plt.tight_layout(); plt.show()
```

4. 实现FIR低通和高通滤波器，并可视化它们对包含低频和高频成分的信号的影响。同时显示时域和频域视图。

```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

# Create a signal with low (100 Hz) and high (2000 Hz) components
fs = 8000
duration = 0.05  # 50 ms for clear visualisation
t = jnp.arange(0, duration, 1.0 / fs)

x_low = jnp.sin(2 * jnp.pi * 100 * t)
x_high = 0.5 * jnp.sin(2 * jnp.pi * 2000 * t)
x = x_low + x_high

# Design a simple FIR low-pass filter using windowed sinc
def fir_lowpass(cutoff_hz, fs, n_taps=51):
    """Design FIR low-pass filter using windowed sinc method."""
    fc = cutoff_hz / fs  # normalised cutoff
    n = jnp.arange(n_taps)
    mid = (n_taps - 1) / 2.0
    # Sinc function (ideal low-pass impulse response)
    h = jnp.where(n == mid, 2 * fc,
                  jnp.sin(2 * jnp.pi * fc * (n - mid)) / (jnp.pi * (n - mid)))
    # Apply Hamming window
    window = 0.54 - 0.46 * jnp.cos(2 * jnp.pi * n / (n_taps - 1))
    h = h * window
    h = h / jnp.sum(h)  # normalise to unity gain at DC
    return h

def apply_filter(x, h):
    """Apply FIR filter via convolution."""
    return jnp.convolve(x, h, mode='same')

# Low-pass filter at 500 Hz (passes 100 Hz, blocks 2000 Hz)
h_lp = fir_lowpass(500, fs, n_taps=51)
x_lp = apply_filter(x, h_lp)

# High-pass = delta - low-pass (spectral inversion)
delta = jnp.zeros(51)
delta = delta.at[25].set(1.0)
h_hp = delta - h_lp
x_hp = apply_filter(x, h_hp)

# Compute spectra for all signals
def compute_spectrum(signal, fs):
    X = jnp.fft.rfft(signal)
    freqs = jnp.fft.rfftfreq(len(signal), d=1.0 / fs)
    mag = jnp.abs(X) / len(signal) * 2
    return freqs, mag

fig, axes = plt.subplots(3, 2, figsize=(14, 10))

# Time domain plots
for i, (sig, title, color) in enumerate([
    (x, 'Original (100 Hz + 2000 Hz)', '#3498db'),
    (x_lp, 'Low-pass filtered (< 500 Hz)', '#27ae60'),
    (x_hp, 'High-pass filtered (> 500 Hz)', '#e74c3c')
]):
    axes[i, 0].plot(t * 1000, sig[:len(t)], color=color, linewidth=1)
    axes[i, 0].set_title(f'Time Domain: {title}')
    axes[i, 0].set_xlabel('Time (ms)'); axes[i, 0].set_ylabel('Amplitude')
    axes[i, 0].grid(True, alpha=0.3)

# Frequency domain plots
for i, (sig, title, color) in enumerate([
    (x, 'Original', '#3498db'),
    (x_lp, 'Low-pass', '#27ae60'),
    (x_hp, 'High-pass', '#e74c3c')
]):
    freqs, mag = compute_spectrum(sig, fs)
    axes[i, 1].plot(freqs, mag, color=color, linewidth=1.5)
    axes[i, 1].set_title(f'Spectrum: {title}')
    axes[i, 1].set_xlabel('Frequency (Hz)'); axes[i, 1].set_ylabel('Magnitude')
    axes[i, 1].set_xlim(0, 3000)
    axes[i, 1].axvline(x=500, color='#f39c12', linestyle='--', alpha=0.7,
                        label='Cutoff (500 Hz)')
    axes[i, 1].legend(); axes[i, 1].grid(True, alpha=0.3)

plt.tight_layout(); plt.show()
```

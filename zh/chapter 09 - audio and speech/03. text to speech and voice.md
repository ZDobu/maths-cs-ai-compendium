# 文本转语音与语音

*文本转语音合成将 ASR 流水线反转，从书面文本生成自然听感音频。本篇涵盖 TTS 流水线（文本归一化、G2P、声学模型、声码器）、Tacotron、WaveNet、HiFi-GAN、语音克隆、语音转换以及语音活动检测（VAD）。*

- 在第 01 篇中，我们建立了信号处理工具包：波形、频谱图、mel 滤波器组和 MFCC。在第 02 篇中，我们将语音转为文本。现在我们反转箭头：给定文本，合成自然听感的语音。这就是**文本转语音（TTS，Text-to-Speech）**，这个问题也打开了语音转换、语音克隆和语音活动检测的大门。

- 把 TTS 想象成一场舞台演出。脚本是文本输入。导演（声学模型）决定每一句应该怎样念——音高、时长、重音。管弦乐队（声码器）然后演奏乐谱，产生观众听到的实际声波。现代神经 TTS 用媲美人类说话者的表现取代了基于规则系统僵硬、机械的语音。

![TTS 流水线：文本归一化、转为音素、由声学模型处理生成 mel 频谱图，然后通过声码器生成最终波形](../../images/tts_pipeline.svg)

- **文本转语音流水线**：标准 TTS 流水线有四个阶段：(1) 文本归一化，(2) 音素转换，(3) 声学模型，(4) 声码器。一些现代系统将阶段 3 和 4 合并为单一端到端模型，但概念上的分解仍然有用。

- **文本归一化**（text normalisation）将原始文本转为可发音的形式。缩写展开（"Dr." → "Doctor"），数字变成单词（"1984" → "nineteen eighty-four"），货币符号被口头化（"$5" → "five dollars"），URL 或特殊字符被处理。此阶段通常基于规则，使用特定语言的语法，虽然也存在神经归一化模型。这里的错误会传播到每个下游阶段：如果 "St." 被读作 "saint" 而不是 "street"，整个话语就错了。

- **字素到音素（G2P）转换**将归一化文本映射为音素序列。英语出了名地不规则（"though"、"through"、"tough" 都用 "ough" 但发音不同），因此字典查找（CMU 发音词典）处理常见词，而神经序列到序列模型（第 06 章的编码器-解码器或第 07 章的 Transformer）处理生僻词。拼写浅的语言（西班牙语、芬兰语）需要更简单的 G2P。输出通常是 IPA（国际音标）序列或等效的内部音素集。

- **声学模型**（acoustic model）接收音素序列并产生一个中间声学表示，几乎总是一个 **mel 频谱图**（第 01 篇）。mel 频谱图捕捉了每个时间帧的频谱包络，它编码了声码器重建波形所需的感知相关信息。声学模型必须决定时长（每个音素持续多久）、音高（基频 $F_0$）和能量（响度）。

- **声码器**（vocoder）接收 mel 频谱图并产生原始音频波形。这是一个不适定的求逆问题：由于相位信息被丢弃，许多波形可以产生相同的频谱图。经典声码器（Griffin-Lim、WORLD）使用迭代或信号模型方法，但神经声码器现在在质量上占主导地位。

- **声码器：WaveNet**（van den Oord et al., 2016）是第一个产生几乎与人类录音无法区分的语音的神经声码器。它自回归地对波形建模，以所有先前样本为条件预测每个样本 $x_t$：

$$P(x) = \prod_{t=1}^{T} P(x_t \mid x_1, \ldots, x_{t-1}, c)$$

- 其中 $c$ 是条件信号（mel 频谱图）。每个样本是 16 位的，所以朴素的 65536 类 softmax 不切实际。WaveNet 使用 **mu-law 压扩**将之减少到 256 个量化级别，或后期变体使用混合逻辑斯蒂分布。

- WaveNet 的核心构建块是**扩张因果卷积**。因果意味着滤波器权重仅查看过去的样本（无未来泄漏）。扩张意味着滤波器以指数增长的间隔跳跃采样：扩张因子 $1, 2, 4, 8, \ldots, 512$。这给出了指数级大的感受野，同时保持参数数量线性。

- 每层的门控激活是：

$$z = \tanh(W_{f} \ast x) \odot \sigma(W_{g} \ast x)$$

- 其中 $W_f$ 和 $W_g$ 是滤波器和门的卷积权重，$\ast$ 表示扩张因果卷积，$\odot$ 是逐元素乘法。此门控机制（来自第 06 章的 LSTM）允许网络控制信息流。

- WaveNet 产生卓越的质量但在推理时痛苦地慢：生成一秒 24 kHz 音频需要 24000 次顺序前向传播。这推动了所有后续声码器的研究。

- **WaveRNN**（Kalchbrenner et al., 2018）用单层循环网络替换了 WaveNet 的深层卷积堆栈。它将每个 16 位样本拆分为粗（高 8 位）和细（低 8 位）分量，用 GRU（第 06 章）预测每个分量。这种双 softmax 方法在保持高质量的同时显著减少了计算。经过仔细的内核优化，WaveRNN 足够快以在移动 CPU 上实时运行。

- **WaveGlow**（Prenger et al., 2019）是一种**基于流**的声码器，完全避免了自回归生成。它使用一系列可逆变换（仿射耦合层，第 06 章的正则化流）将简单高斯分布映射到波形分布。训练使用变量替换公式最大化精确对数似然：

$$\log P(x) = \log P(z) + \sum_{i} \log \left| \det \frac{\partial f_i}{\partial f_{i-1}} \right|$$

- 其中 $z = f(x)$ 是通过将 $x$ 送入流获得的隐变量。推理时，从 $z \sim \mathcal{N}(0, I)$ 采样并通过反向流单次并行传播。WaveGlow 以模型大小（耦合层的大型网络）换取生成速度。

- **HiFi-GAN**（Kong et al., 2020）使用**生成对抗网络**从 mel 频谱图合成波形。生成器通过一系列转置卷积对 mel 频谱图进行上采样，每个后面跟着一个**多感受野融合（MRF）**模块。MRF 模块并行应用具有不同内核大小和扩张率的多个残差块，然后对其输出求和。这允许生成器同时捕获多个时间尺度上的模式。

![HiFi-GAN 生成器架构：mel 频谱图输入经过转置卷积上采样层，每层后面跟着组合了具有不同扩张模式的并行残差堆栈的多感受野融合块](../../images/hifi_gan_generator.svg)

- HiFi-GAN 使用两种判别器类型。**多周期判别器（MPD）**通过按不同周期（2、3、5、7、11）折叠将 1D 波形重塑为 2D，然后应用 2D 卷积。这捕获了不同基频下的周期结构。**多尺度判别器（MSD）**在原始波形、2 倍下采样和 4 倍下采样版本上操作，捕获不同时间分辨率下的模式。

- 训练目标组合了对抗损失、**mel 频谱图重建损失**（合成音频与真值音频 mel 频谱图之间的 L1 距离）、以及**特征匹配损失**（判别器中间特征之间的 L1 距离）：

$$\mathcal{L}_G = \mathcal{L}_{\text{adv}}(G) + \lambda_{\text{mel}} \mathcal{L}_{\text{mel}}(G) + \lambda_{\text{fm}} \mathcal{L}_{\text{fm}}(G)$$

- HiFi-GAN 实现了与 WaveNet 相当的合成质量，同时快 1000 多倍，使在单个 GPU 上实时生成成为可能。

- **神经源-滤波器（NSF）模型**将传统信号处理与神经网络相结合。在经典的源-滤波器模型中，浊音语音由通过声道滤波器（频谱包络）的源激励（基频 $F_0$ 处的周期脉冲串）产生。NSF 模型用神经网络替换了手工设计的滤波器，同时保持显式的源信号。输入 $F_0$ 轮廓提供了纯粹数据驱动的声码器有时难以实现的精细音高控制。

- **声学模型：Tacotron**（Wang et al., 2017）是第一个将字符序列直接转换为 mel 频谱图的端到端神经 TTS 系统。它使用带有注意力的编码器-解码器架构（第 07 章）。编码器用卷积组、高速网络和双向 GRU 处理字符/音素序列。解码器是一个自回归 GRU，每次预测一个 mel 帧，使用前帧和注意力上下文作为输入。

- **Tacotron 2**（Shen et al., 2018）显著改进了架构。编码器是一个 3 层 1D 卷积堆栈后跟一个双向 LSTM（第 06 章）。解码器是一个带有**位置敏感注意力**（location-sensitive attention）的 2 层 LSTM，该注意力机制不仅以编码器输出和解码器状态为条件，还以前几步的累积注意力权重为条件。这防止了注意力跳过或重复词的常见故障模式。

- 位置敏感注意力在解码器步骤 $i$ 对编码器位置 $j$ 的能量为：

$$e_{i,j} = w^T \tanh(W_s s_{i-1} + W_h h_j + W_f f_{i,j} + b)$$

- 其中 $s_{i-1}$ 是前一个解码器状态，$h_j$ 是编码器位置 $j$ 的输出，$f_{i,j}$ 是通过对累积注意力权重 $\sum_{k<i} \alpha_{k,j}$ 进行 1D 卷积获得的位置特征。注意力权重为 $\alpha_{i,j} = \text{softmax}(e_{i,j})$。

- Tacotron 2 的解码器还在每步预测一个**停止标记**概率，指示 mel 频谱图何时完成。输出 mel 频谱图随后送入声码器（最初是 WaveNet，后来被 HiFi-GAN 或类似模型取代）。

- Tacotron 2 的自回归性质意味着合成速度受 mel 帧数的限制。对于典型的每秒 80 帧的 mel 频谱图，5 秒的话语需要 400 个顺序解码器步骤。

- **FastSpeech**（Ren et al., 2019）用**非自回归**声学模型解决了速度问题。FastSpeech 不是顺序生成 mel 帧，而是并行生成所有帧。关键挑战是确定每个音素应该产生多少 mel 帧，FastSpeech 通过**时长预测器**处理。

- **FastSpeech 2**（Ren et al., 2021）通过移除师生蒸馏来改进 FastSpeech。它使用强制对齐（来自第 02 篇的声学模型框架）直接提取真值时序，并在时长之外添加了显式的**方差适配器**用于音高（$F_0$）和能量。

- **VITS**（Kim et al., 2021）是一个**端到端**TTS 模型，直接从文本生成波形，消除了单独的声码器阶段。VITS 组合了条件变分自编码器（第 06 章）与正则化流和对抗训练。

- **VALL-E**（Wang et al., 2023）将 TTS 从根本上重新定义为基于离散音频标记的**语言建模问题**。它使用神经音频编解码器（EnCodec）将语音表示为来自多个码本级别的离散码序列。给定一个文本提示和一个 3 秒的注册话语（同样被编码为离散标记），VALL-E 使用 Transformer 语言模型自回归地预测音频标记。

- 现代 TTS 格局正在分叉为两种范式：(1) 将语音生成视为对离散音频码进行下一个标记预测的**编解码器语言模型**（VALL-E、Orpheus、Fish Speech），利用 LLM 的缩放定律；(2) 通过迭代细化生成连续 mel 频谱图或波形的**基于流/扩散的模型**（VITS、StyleTTS 2、Kokoro）。编解码器语言模型在零样本克隆和表现力方面表现出色；流/扩散模型往往更小更快。

- **韵律建模**（prosody modelling）控制语音的"音乐性"：音高、时长、能量、节奏和语调。没有好的韵律，合成语音听起来平坦而机械。

- **语音转换（VC）**改变话语的说话者身份同时保留语言学内容。**语音克隆**（voice cloning）以目标说话者声音合成语音。**零样本语音克隆**完全不需要适配：仅需一段简短的话语（3-30 秒）即可。

- **语音活动检测（VAD）**在每个时间帧回答一个简单的二元问题：有人在说话还是没有？**Silero VAD**（Silero Team, 2021）是用于生产的实际标准神经 VAD，整个模型不到 2MB。

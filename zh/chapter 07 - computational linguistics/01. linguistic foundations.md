# 语言学基础（Linguistic Foundations）

*语言学为自然语言处理（NLP）系统提供了它们隐式学习和利用的结构性词汇。本章涵盖形态学（Morphology）、句法学（Syntax）、语义学（Semantics）、语用学（Pragmatics）、音系学（Phonology）、成分与依存句法分析，以及分布假说——这些人类语言科学为AI中的分词、语法和意义奠定了基础。*

- 在我们构建能够理解或生成语言的系统之前，我们需要理解语言本身是如何运作的。

- 语言学是对语言的科学研究，它为NLP提供了不断借鉴的概念词汇。

- 即便是从原始数据中学习语言的现代神经网络模型，也会隐式地重新发现语言学家们数十年来已编录的许多结构。

- 语言在每一个层面上都具有结构：构成词语的声音、构成词语的部分、将词语组合成句子的规则、这些句子所承载的意义，以及上下文影响解释的方式。我们将自底向上地逐一考察每个层面。

- **形态学（Morphology）**是对词语内部结构的研究。词语并非原子性的；它们由更小的有意义的单元——**语素（morpheme）**——构建而成。

- 词语"unhappiness"包含三个语素："un-"（表示"不"的前缀）、"happy"（词根）和"-ness"（将形容词变为名词的后缀）。每个语素都对意义有所贡献。

- **词根（root，或称词干 stem）**是承载主要意义的核心语素。"happy"、"run"、"compute"都是词根。

- **词缀（affix）**是附加到词根上以修饰词根的语素。

- 英语有**前缀（prefix）**（位于词根前：un-、re-、pre-）和**后缀（suffix）**（位于词根后：-ing、-ed、-tion）。一些语言还有中缀（infix，插入词根内部）和环缀（circumfix，环绕词根）。

![语素树："unhappiness"分解为前缀"un"、词根"happy"、后缀"ness"](../../images/morpheme_tree.svg)

- 形态过程有两种类型。**屈折（Inflection）**改变词语的语法属性，而不改变其核心意义或词性："run"变为"runs"（第三人称）、"running"（进行体）、"ran"（过去时）。该词仍然是动词，意义相同。

- **派生（Derivation）**创造一个新词，通常会改变词性："happy"（形容词）变为"happiness"（名词），"compute"（动词）变为"computation"（名词），再变为"computational"（形容词）。每次派生都会改变意义和语法范畴。

- 不同语言在形态复杂性上差异巨大。英语相对偏**分析语（analytic）**（每个词的语素少，依赖词序）。

- 土耳其语和芬兰语是**黏着语（agglutinative）**（词语可以包含许多串联在一起的语素）。阿拉伯语和希伯来语使用**模板式（templatic）**形态学（词根是辅音骨架，如表示"写"的k-t-b，通过插入元音模式来创造不同的词：kitab"书"，kataba"他写了"，maktub"被写的"）。

- 形态学对NLP很重要，因为它影响分词（tokenisation）。词级分词器将"run"、"runs"、"running"和"ran"视为四个无关的符号。

- 一个具有形态学意识的系统能够识别它们共享一个词根。子词分词（subword tokenisation，如BPE、WordPiece），我们将在第02章中介绍，是形态分析的一种统计近似方法。

- **句法学（Syntax）**是对词语如何组合成短语和句子的研究。每种语言都有支配词序和结构的规则；违反这些规则会产生无意义的乱码。

- "The cat sat on the mat"是合乎语法的英语；"Mat the on sat cat the"则不是。

- 描述句法结构有两个主要框架。

- **短语结构语法（Phrase structure grammar）**（也称成分语法 constituency grammar）认为句子是通过短语嵌套短语来构建的。一个句子（S）由一个名词短语（NP）和一个动词短语（VP）组成。

- 名词短语可以是限定词（Det）后接名词（N）。动词短语可以是动词（V）后接名词短语。这些规则构建出一棵树：

![成分树："the cat sat on the mat"：S分支为NP和VP，NP分支为Det "the"和N "cat"，VP分支为V "sat"和PP，PP分支为P "on"和NP](../../images/constituency_tree.svg)

- 这棵树称为**成分树（constituency tree）**（或句法分析树 parse tree）。每个内部节点是一个短语类型，每个叶子节点是一个词。这棵树捕捉了层级分组："on the mat"是一个单元（介词短语），"sat on the mat"是一个单元（动词短语），整个句子是一个句子。

- **上下文无关文法（Context-Free Grammar，CFG）**将这些规则形式化。它由一组产生式规则组成，每条规则的形式为$A \to \alpha$，其中$A$是一个非终结符（短语类型，如NP或VP），$\alpha$是一个终结符（词语）和非终结符的序列。例如：

```
S  → NP VP
NP → Det N
NP → Det N PP
VP → V NP
VP → V PP
PP → P NP
Det → "the" | "a"
N  → "cat" | "mat" | "dog"
V  → "sat" | "chased"
P  → "on" | "under"
```

- 从S开始，反复应用规则，可以生成该文法允许的所有句子。解析（parsing）则相反：给定一个句子，找出生成它的那棵（或那些）树。具有多棵有效解析树的句子是**句法上有歧义的（syntactically ambiguous）**。"I saw the man with the telescope"有两种解析：我用望远镜看到了那个人，或者我看到了一个拿着望远镜的人。

- **依存语法（Dependency grammar）**采取了不同的视角。它不关注短语嵌套，而是描述词语之间的直接关系。句子中的每个词都依赖于恰好另一个词（其**中心词 head**），除了句子的根节点。结果是一棵**依存树（dependency tree）**，其中边标注了语法关系（主语、宾语、修饰语等）。

![依存树："the cat sat on the mat"：从"sat"到"cat"的箭头（nsubj），到"on"（prep），从"on"到"mat"（pobj），从"cat"到"the"（det），从"mat"到"the"（det）](../../images/dependency_tree.svg)

- 在依存视角下，"sat"是根节点。"Cat"依赖于"sat"作为其主语（nsubj）。"On"依赖于"sat"作为介词修饰语。"Mat"依赖于"on"作为介词宾语。每个词都挂在一个中心词上，形成一棵树。

- 依存语法已成为现代NLP的主导框架，因为依存树更容易用统计解析器生成，且关系更直接地映射到语义角色（谁对谁做了什么）。

- **配价（Valency）**描述一个动词需要多少个论元。"Sleep"是**不及物（intransitive）**的（一个论元：睡眠者）。"Eat"是**及物（transitive）**的（两个：吃者和被吃的东西）。"Give"是**双及物（ditransitive）**的（三个：给予者、被给予的东西和接收者）。了解动词的配价可以约束哪些解析树是有效的。

- **语义学（Semantics）**是对意义的研究。句法告诉你句子的结构；语义告诉你句子的意思。

- **词汇语义学（Lexical semantics）**关注单个词语的意义。词语之间以系统的方式相互关联：

    - **同义关系（Synonymy）**：意义（几乎）相同的词。"Big"和"large"是同义词。真正的完全同义很少见；在内涵或用法上几乎总存在细微差别。
    - **反义关系（Antonymy）**：意义相反的词。"Hot"和"cold"，"buy"和"sell"。
    - **上下义关系（Hypernymy/hyponymy）**："是一个（is-a）"关系。"Dog"是"animal"的下义词（hyponym）（狗是一种动物）。"Animal"是"dog"的上义词（hypernym）。这些形成了分类层级结构。
    - **部分整体关系（Meronymy）**："部分-属于（part-of）"关系。"Wheel"是"car"的部分词（meronym）。
    - **多义性（Polysemy）**：一个词有多个相关的意义。"Bank"表示金融机构或河岸。上下文可以消歧。

- **词义消歧（Word Sense Disambiguation，WSD）**是确定多义词在给定上下文中意图使用哪个义项的任务。在"I deposited money at the bank"中，金融义项是正确的。在"We sat by the river bank"中，地理义项是正确的。WSD曾是早期NLP的核心问题；现代上下文嵌入（contextual embeddings，如ELMo、BERT）通过对同一词的不同使用生成不同的向量表示，在很大程度上解决了这一问题。

- **组合语义学（Compositional semantics）**探讨单个词语的意义如何组合形成短语或句子的意义。**组合性原则（Principle of compositionality）**（源于弗雷格 Frege）指出：一个复杂表达式的意义由其各组成部分的意义以及组合这些部分所使用的规则决定。"The cat chased the dog"与"the dog chased the cat"意义不同，因为句法结构（谁做主语 vs 宾语）与词义相互作用。

- 并非所有意义都是组合性的。**习语（idioms）**如"kick the bucket"（意为"死亡"）的意义无法从其组成部分推导出来。这对任何组合性方法都构成挑战。

- **分布语义学（Distributional semantics）**是支撑现代NLP的计算性意义研究方法。**分布假说（Distributional hypothesis）**（Firth，1957）指出："你可以通过一个词所结交的伙伴来认识这个词（You shall know a word by the company it keeps）。"出现在相似上下文中的词往往具有相似的意义。这是词嵌入（word embeddings，如Word2Vec、GloVe）的理论基础，我们将在第03章中探讨。

- **语用学（Pragmatics）**研究上下文如何影响意义。同一个句子可能因说话者、时间、地点和原因的不同而表达不同的意思。

- "Can you pass the salt?"在句法上是一个关于能力的yes/no问句。在语用上，它是一个请求。你不会回答"Yes, I can"然后坐着不动。理解这一点需要超越字面词语的知识，具体来说就是**言语行为（speech acts）**的惯例。

- **言语行为理论（Speech act theory）**（Austin、Searle）区分了：
    - **言内行为（Locutionary act）**：字面内容（"你能把盐递过来吗？"）
    - **言外行为（Illocutionary act）**：意图功能（一个请求）
    - **言后行为（Perlocutionary act）**：对听话者的效果（他们递过盐来）

- **隐含意义（Implicature）**（Grice）是暗示但未明确陈述的意义。如果有人问"Is John a good cook?"，而你回答"He's British"，你并未从字面上回答问题，但听话者可以推断（通过文化刻板印象，无论公平与否）你的意思是"否"。Grice的**合作原则（Cooperative principle）**指出：说话者通常努力做到信息充分、真实、相关和清晰，听话者在解读话语时也假设这些准则成立。

- **共指（Coreference）**是一种语用现象，即不同的表达式指向同一个实体。在"Alice went to the store. She bought milk"中，"she"指的是Alice。解析共指对于理解多句文本至关重要，也是NLP的一项关键任务。

- **语篇结构（Discourse structure）**描述句子如何连接形成连贯的文本。叙述有开头、中间和结尾。论证有主张和证据。**修辞结构理论（Rhetorical Structure Theory，RST）**将文本分析为语段之间语篇关系（阐述、对比、因果等）的树状结构。

- 语用学是NLP中最困难的部分。现代语言模型通过训练数据隐式地处理了大部分句法和语义，但语用推理——理解讽刺、隐含意义和上下文依赖的意义——仍然是一个前沿挑战。

- **音系学（Phonology）**研究语言的音系系统。虽然本章关注的是文本，但简要概述可以为理解音频和语音章节（第09章）搭建桥梁。

- **音素（Phoneme）**是区分意义的最小声音单元。英语大约有44个音素。词语"bat"和"pat"仅由一个音素（/b/ vs /p/）不同，这完全改变了意义。这被称为**最小对立体（minimal pair）**。

- **音位变体（Allophones）**是同一音素的不同物理实现，不改变意义。"pin"中的"p"（送气，带一股气流）和"spin"中的"p"（不送气）在英语中是/p/的音位变体；母语者将它们视为同一个音。

- **国际音标（International Phonetic Alphabet，IPA）**提供了跨所有语言的标准音素记法。单词"cat"被转写为/kæt/。IPA是书面文本与语音系统之间的桥梁。

- **韵律（Prosody）**涵盖言语的节奏、重音和语调。"I didn't say he stole the money"根据重读不同词，有七种不同的意义。韵律承载着仅靠文本会丢失的信息，这就是为什么文本转语音系统必须仔细建模韵律。

- 在NLP中，音系学知识出现在文本转语音（字素到音素的转换）、语音识别（将声学信号映射到音素），甚至在拼写纠正和音译中。

1. 构建一个简单的形态分析器，使用常见前缀和后缀列表将英语单词分解为可能的语素。
```python
prefixes = ['un', 're', 'pre', 'dis', 'mis', 'over', 'under', 'out', 'non']
suffixes = ['ing', 'ed', 'ly', 'ness', 'ment', 'tion', 'able', 'ible', 'er', 'est', 'ful', 'less', 'ous']

def analyse_morphemes(word):
    """Simple morpheme analysis using known affixes."""
    parts = []
    remaining = word.lower()

    # Check prefixes
    for p in sorted(prefixes, key=len, reverse=True):
        if remaining.startswith(p) and len(remaining) > len(p) + 2:
            parts.append(f"[prefix: {p}]")
            remaining = remaining[len(p):]
            break

    # Check suffixes
    for s in sorted(suffixes, key=len, reverse=True):
        if remaining.endswith(s) and len(remaining) > len(s) + 2:
            root = remaining[:-len(s)]
            parts.append(f"[root: {root}]")
            parts.append(f"[suffix: {s}]")
            remaining = None
            break

    if remaining is not None:
        parts.append(f"[root: {remaining}]")

    return parts

for word in ['unhappiness', 'reusable', 'disconnected', 'overreacting', 'kindness']:
    print(f"{word:20s} → {' + '.join(analyse_morphemes(word))}")
```

2. 实现一个使用递归下降法的简单上下文无关文法解析器。定义一个简单的文法，将句子解析为成分树。
```python
class CFGParser:
    """Recursive descent parser for a tiny English grammar."""
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos = 0

    def peek(self):
        return self.tokens[self.pos] if self.pos < len(self.tokens) else None

    def consume(self, expected=None):
        tok = self.peek()
        if expected and tok != expected:
            return None
        self.pos += 1
        return tok

    def parse_det(self):
        if self.peek() in ('the', 'a'):
            return ('Det', self.consume())
        return None

    def parse_noun(self):
        if self.peek() in ('cat', 'dog', 'mat', 'man'):
            return ('N', self.consume())
        return None

    def parse_verb(self):
        if self.peek() in ('sat', 'chased', 'saw'):
            return ('V', self.consume())
        return None

    def parse_prep(self):
        if self.peek() in ('on', 'under', 'with'):
            return ('P', self.consume())
        return None

    def parse_np(self):
        save = self.pos
        det = self.parse_det()
        noun = self.parse_noun()
        if det and noun:
            # Check for optional PP
            pp = self.parse_pp()
            if pp:
                return ('NP', det, noun, pp)
            return ('NP', det, noun)
        self.pos = save
        return None

    def parse_pp(self):
        save = self.pos
        prep = self.parse_prep()
        np = self.parse_np()
        if prep and np:
            return ('PP', prep, np)
        self.pos = save
        return None

    def parse_vp(self):
        save = self.pos
        verb = self.parse_verb()
        if verb:
            np = self.parse_np()
            if np:
                return ('VP', verb, np)
            pp = self.parse_pp()
            if pp:
                return ('VP', verb, pp)
        self.pos = save
        return None

    def parse_sentence(self):
        np = self.parse_np()
        vp = self.parse_vp()
        if np and vp and self.pos == len(self.tokens):
            return ('S', np, vp)
        return None

def print_tree(tree, indent=0):
    if isinstance(tree, str):
        print(' ' * indent + tree)
    elif isinstance(tree, tuple):
        print(' ' * indent + tree[0])
        for child in tree[1:]:
            print_tree(child, indent + 2)

sentences = [
    "the cat sat on the mat",
    "a dog chased the cat",
]

for sent in sentences:
    tokens = sent.split()
    parser = CFGParser(tokens)
    tree = parser.parse_sentence()
    print(f"\n'{sent}':")
    if tree:
        print_tree(tree)
    else:
        print("  (no parse found)")
```

3. 通过构建简单的词语关系图来探索词汇关系。给定一个包含同义、反义和上下义关系的小词汇表，找到词之间的路径。
```python
relations = {
    ('big', 'large'): 'synonym',
    ('big', 'small'): 'antonym',
    ('small', 'tiny'): 'synonym',
    ('dog', 'animal'): 'hypernym',
    ('cat', 'animal'): 'hypernym',
    ('puppy', 'dog'): 'hypernym',
    ('happy', 'glad'): 'synonym',
    ('happy', 'sad'): 'antonym',
    ('hot', 'cold'): 'antonym',
    ('hot', 'warm'): 'synonym',
}

# Build adjacency list
from collections import defaultdict, deque

graph = defaultdict(list)
for (w1, w2), rel in relations.items():
    graph[w1].append((w2, rel))
    graph[w2].append((w1, rel))

def find_path(start, end):
    """BFS to find a path between two words through the relation graph."""
    queue = deque([(start, [(start, None)])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor, rel in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [(neighbor, rel)]))
    return None

pairs = [('big', 'tiny'), ('puppy', 'cat'), ('happy', 'sad')]
for w1, w2 in pairs:
    path = find_path(w1, w2)
    if path:
        steps = " → ".join(f"{w}({r})" if r else w for w, r in path)
        print(f"{w1} → {w2}: {steps}")
    else:
        print(f"{w1} → {w2}: no path found")
```

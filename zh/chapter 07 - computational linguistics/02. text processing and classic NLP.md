# 文本处理与经典NLP（Text Processing and Classic NLP）

*文本处理将原始字符转换为模型可以消费的结构化表示。本章涵盖分词（词级、子词、BPE、WordPiece）、文本规范化、编辑距离、TF-IDF、n元语法语言模型、词性标注、命名实体识别和情感分析——这些经典NLP流程至今仍然支撑着现代系统。*

- 原始文本是混乱的。在任何一个NLP模型能够处理语言之前，文本必须经过清洗、规范化，并转换为结构化的表示。本章涵盖了从原始字符到模型可消费特征的整个处理流程，以及深度学习兴起之前主导NLP的经典算法。

- **文本规范化（Text normalisation）**将原始文本转换为规范形式。其目标是减少无关的变异，使得"Hello"、"hello"、"HELLO"和"héllo"能够被适当地处理。

- **大小写折叠（Case folding）**将文本转换为小写。这会将"The"和"the"折叠为一个token。这对大多数任务有帮助，但在某些情况下会破坏有用的信息："US"（国家）vs "us"（代词），或"Apple"（公司）vs "apple"（水果）。

- **Unicode规范化（Unicode normalisation）**处理同一个字符可以以多种方式编码的问题。字符"é"可以是一个单一码点（U+00E9），也可以是基础"e"加组合重音符号（U+0065 + U+0301）。NFC规范化将它们合成为一个码点；NFD则将其分解。没有规范化，两个看起来相同的字符串可能无法匹配。

- **编辑距离（Edit distance）**衡量两个字符串之间的差异程度。**莱文斯坦距离（Levenshtein distance）**计算将一个字符串转换为另一个字符串所需的最少单字符插入、删除和替换次数。"kitten" → "sitting"的编辑距离为3（k→s，e→i，插入g）。

- 编辑距离使用动态规划（dynamic programming）来计算（我们在算法章节中回顾）。定义$D[i][j]$为字符串$s$的前$i$个字符与字符串$t$的前$j$个字符之间的距离：

```math
D[i][j] = \begin{cases} j & \text{if } i = 0 \\ i & \text{if } j = 0 \\ D[i{-}1][j{-}1] & \text{if } s[i] = t[j] \\ 1 + \min(D[i{-}1][j], \; D[i][j{-}1], \; D[i{-}1][j{-}1]) & \text{otherwise} \end{cases}
```

- 编辑距离支撑着拼写纠正、模糊匹配和DNA序列比对。在NLP中，它被用来处理拼写错误和查找相似的词语。

- **分词（Tokenisation）**将文本分割为离散单元（token），供模型处理。这是第一步，也可能是最重要的预处理步骤。分词策略的选择深刻影响模型的行为。

- **空格分词（Whitespace tokenisation）**按空格分割。简单但粗糙："New York"变成两个token，"don't"是一个token（或根据分割方式拆分为"don"和"'t"），而中文和日文等语言在词语之间根本没有空格。

- **基于规则的分词（Rule-based tokenisation）**使用手工编写的模式（正则表达式）来处理缩写、标点和特殊情况。"I'm" → "I" + "'m"，"U.S.A."作为一个token保留。每种语言都需要自己的规则，这劳动密集。

- **子词分词（Subword tokenisation）**是现代解决方案。它不是按词边界分割，而是从数据中学习频繁出现的子词单元的词表。这优雅地处理了未知词：如果"unhappiness"不在词表中，它可以被分成"un" + "happi" + "ness"，从而保留形态结构。

![词级、字符级和子词分词对"unhappiness"和"transformers"的比较](../../images/tokenisation_comparison.svg)

- **字节对编码（Byte-Pair Encoding，BPE）**以单个字符作为初始词表。它反复找到最频繁的相邻词对，并将它们合并成一个新的token。经过足够多的合并后，常见词成为单个token，而罕见词则被分割为频繁的子词片段。

- BPE算法：
    1. 用训练语料中所有单个字符初始化词表
    2. 统计每个相邻token对的频率
    3. 将频率最高的词对合并为一个新的token
    4. 重复步骤2-3，达到期望的合并次数（词表大小）

- 例如，从"l o w"（5次）、"l o w e r"（2次）、"n e w e s t"（6次）开始：频率最高的对可能是"e s" → 合并为"es"。然后是"es t" → "est"。然后是"n e w" → "new"。最终词表同时包含完整词和子词片段。

- **WordPiece**（BERT中使用）与BPE相似，但基于似然（likelihood）而非频率来选择合并。它合并能使训练数据的语言模型似然最大化的词对。非词首位置的子词token前缀为"##"（例如，"playing" → "play" + "##ing"）。

- **Unigram**（SentencePiece中使用）采取相反的方法：从一个大的词表开始，迭代地移除其移除对训练数据似然伤害最小的token。最终词表是能够最好地解释语料的子词单元集合。

- **SentencePiece**是一个与语言无关的分词库，将输入视为原始字节流（不预先按空格分词）。这使得它可以处理任何语言，包括那些没有空格的语言。它同时实现了BPE和Unigram算法。

- 词表大小是一个关键的超参数。典型选择在30,000到100,000个token之间。较大的词表意味着每条序列的token更少（更高效），但嵌入表更大。较小的词表意味着更多的子词拆分和更长的序列。

- 词干提取和词形还原这两种技术都将词缩减为基本形式，但方法不同。

- **词干提取（Stemming）**使用粗略规则砍掉后缀。Porter词干提取器将"running"缩减为"run"，"happiness"缩减为"happi"，"studies"缩减为"studi"。它速度快但不够精确："university"和"universe"都被提取为"univers"，尽管它们并不相关。

- **词形还原（Lemmatisation）**使用词表和形态分析来找到真正的词典形式（词元 lemma）。"Running" → "run"，"better" → "good"，"mice" → "mouse"。它需要知道词性："saw"作为动词的词形还原为"see"，但作为名词则保持"saw"。

- 现代子词分词已在很大程度上取代了神经NLP中的词干提取和词形还原，但它们在信息检索以及使用较小型模型或有限数据时仍然有用。

- **词性标注（Part-of-Speech Tagging，POS Tagging）**为每个词分配一个语法范畴：名词、动词、形容词、限定词等。这是最古老的NLP任务之一，也是句法分析的基础。

- 宾州树库（Penn Treebank）标注集是英语中最常见的标注集，共有36个标注（NN表示单数名词，NNS表示复数名词，VB表示动词原形，VBD表示过去式动词，JJ表示形容词等）。

- 词性标注比较困难，因为许多词有歧义。"Book"可以是名词（"the book"）或动词（"book a flight"）。"Run"在不同词性下有数十种义项。上下文是至关重要的。

- 早期的标注器使用来自第05章的**隐马尔可夫模型（Hidden Markov Models，HMM）**。隐状态是POS标签，观测值是词语。转移概率捕获标签序列（限定词后面很可能接名词或形容词），发射概率捕获哪些词与哪些标签同时出现。维特比算法（Viterbi algorithm）找到最可能的标签序列。

- POS标注的HMM模型：

$$\hat{t}_{1:n} = \arg\max_{t_{1:n}} \prod_{i=1}^{n} P(w_i \mid t_i) \cdot P(t_i \mid t_{i-1})$$

- 现代词性标注器使用神经网络（双向LSTM或Transformer），在英语上达到超过97%的准确率，接近人类水平。

- **命名实体识别（Named Entity Recognition，NER）**识别和分类文本中的专有名词和其他特定实体：人名、组织、地点、日期、金额等。

- 在"Apple CEO Tim Cook announced the event in Cupertino on Monday"中，NER系统应该识别出：Apple（组织ORG）、Tim Cook（人名PER）、Cupertino（地点LOC）、Monday（日期DATE）。

- NER通常被框架化为使用**BIO标注（BIO tagging）**（也称为IOB标注）的**序列标注（sequence labelling）**。每个token获得一个标签：
    - **B-TYPE**：类型为TYPE的实体的开始
    - **I-TYPE**：类型为TYPE的实体的内部（延续）
    - **O**：不在任何实体中

- "Tim Cook visited New York"变为：Tim/B-PER Cook/I-PER visited/O New/B-LOC York/I-LOC。B标签标记新实体的开始位置，这在同一类型的两个实体相邻时非常重要。

![带有颜色编码BIO标签的句子：B-PER（红色），I-PER（红色），O（灰色），B-LOC（蓝色），I-LOC（蓝色）](../../images/bio_tagging.svg)

- 经典NER使用来自第05章的**条件随机场（Conditional Random Fields，CRF）**，它建模了给定输入下的整个标签序列的条件概率。与生成式的HMM（建模$P(x, y)$）不同，CRF是判别式的，直接建模$P(y \mid x)$。线性链CRF定义为：

$$P(y_{1:n} \mid x_{1:n}) = \frac{1}{Z(x)} \exp\!\left(\sum_{i=1}^{n} \left[\sum_k \lambda_k f_k(y_i, x, i) + \sum_j \mu_j g_j(y_i, y_{i-1}, x, i)\right]\right)$$

- 其中$f_k$是**发射特征（emission features）**（给定位置$i$的输入，标签$y_i$的可能性有多大），$g_j$是**转移特征（transition features）**（给定前一个标签$y_{i-1}$，标签$y_i$的可能性有多大）。

- 配分函数$Z(x) = \sum_{y'} \exp(\ldots)$对所有可能的标签序列求和以对分布进行标准化。训练最大化条件对数似然，这需要使用前向算法（第05章）高效计算$Z(x)$。

- 相比独立地对每个token进行分类，CRF的关键优势在于：CRF的转移特征强制执行结构约束（例如，I-PER只能跟在B-PER或I-PER之后，永远不会出现在O之后）。

- 现代NER在神经编码器（BiLSTM-CRF或BERT-CRF）之上叠加CRF，由神经网络产生发射分数，CRF层学习转移结构。

- **句法解析（Syntactic parsing）**将句子转换为其句法结构——成分树或依存树（两者均来自第01章）。

- **CYK算法（Cocke-Younger-Kasami）**使用动态规划以上下文无关文法解析句子。

- 它要求文法采用**乔姆斯基范式（Chomsky Normal Form）**（每条规则的右侧要么是两个非终结符，要么是一个终结符）。该算法自底向上填充一个三角形表：单元格表示句子的不同跨度，每个单元格存储可以生成该跨度的非终结符。

- CYK运行时间为$O(n^3 \cdot |G|)$，其中$n$是句子长度，$|G|$是文法大小。这是精确的，但对于大型文法来说较慢。

- **移进-归约解析（Shift-reduce parsing）**从左到右处理句子，维护一个栈。在每一步，它要么**移进（shift）**（将下一个词压入栈），要么**归约（reduce）**（从栈中弹出元素并用一个短语替换）。一个训练好的分类器决定每一步的动作。其运行时间为$O(n)$，比CYK快得多。

- **依存解析（Dependency parsing）**在实践中现在比成分解析更常见。基于转移的依存解析器（如移进-归约）和基于图的解析器（对所有可能的边打分并找到最大生成树）是两种主要方法。使用BiLSTM或Transformer的神经依存解析器达到了最先进水平。

- 在嵌入（embeddings）出现之前，NLP使用简单的计数方法将文档表示为向量。

- **词袋模型（Bag-of-Words，BoW）**将文档表示为词计数向量，完全忽略词序。如果词表有$V$个词，每个文档是$\mathbb{R}^V$中的一个向量（这与第01章中的向量空间联系起来）。词$w$对应的条目是该词在文档中出现的次数。

![词袋模型：一个文档被转换为词计数表，然后转换为R^V中的稀疏向量，每个词表词一个条目](../../images/bag_of_words.svg)

- 词袋模型虽然简单，但在文档分类和垃圾邮件过滤等任务中出乎意料地有效。它的主要弱点是它对每个词一视同仁："the"和"revolutionary"被赋予相等的权重。

- **TF-IDF**（词频-逆文档频率，Term Frequency-Inverse Document Frequency）通过根据词语的信息量来加权，解决了这个问题。在某一文档中频繁出现但在整个语料库中很少出现的词语很可能对该文档很重要。

$$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)$$

- **词频**$\text{TF}(t, d)$通常是词项$t$在文档$d$中的原始计数（或其对数：$1 + \log(\text{count})$）。

- **逆文档频率**$\text{IDF}(t) = \log\frac{N}{|\{d : t \in d\}|}$，其中$N$是文档总数。出现在每个文档中的词（如"the"）的IDF接近0。罕见词获得高IDF。

- TF-IDF向量可以使用余弦相似度（cosine similarity，来自第01章）进行比较，以衡量文档相似度。这是经典信息检索和搜索引擎的基础。

- **语言模型（Language model）**为一个词序列赋予一个概率。它回答的问题是：这个句子有多大的可能性？语言模型是机器翻译、语音识别、拼写纠正和文本生成的核心。

- 句子$w_1, w_2, \ldots, w_n$的概率，根据概率的链式法则（第05章）：

$$P(w_1, w_2, \ldots, w_n) = \prod_{i=1}^{n} P(w_i \mid w_1, \ldots, w_{i-1})$$

- 这在理论上是精确的，但不切实际：你需要为每一种可能的历史存储概率。**马尔可夫假设（Markov assumption）**（第05章）将历史截断为最后$k-1$个词，得到**n元语法模型（n-gram model）**（其中$n = k$）。

- **二元语法模型（Bigram model）**（$n = 2$）仅以紧前一个词为条件：

$$P(w_i \mid w_1, \ldots, w_{i-1}) \approx P(w_i \mid w_{i-1})$$

- **三元语法模型（Trigram model）**（$n = 3$）以前两个词为条件。n元概率通过在语料库中计数来估计：

$$P(w_i \mid w_{i-1}) = \frac{\text{count}(w_{i-1}, w_i)}{\text{count}(w_{i-1})}$$

- **困惑度（Perplexity）**衡量语言模型预测测试集的好坏程度。它是测试集概率的倒数，按词数标准化：

$$\text{PPL} = P(w_1, \ldots, w_N)^{-1/N} = \exp\!\left(-\frac{1}{N} \sum_{i=1}^{N} \log P(w_i \mid w_{<i})\right)$$

- 困惑度越低，说明模型对测试数据越不"惊讶"，因此越好。一个在10,000词词表上分配均匀概率的模型的困惑度为10,000。一个好的二元语法模型可能达到约200的困惑度。现代神经语言模型达到低于20的困惑度。

- 请注意，困惑度就是取幂后的交叉熵（cross-entropy，来自第05章的信息论）。训练期间最小化交叉熵损失直接最小化了困惑度。

- **平滑（Smoothing）**处理零概率问题：如果一个n元语法从未在训练中出现过，模型赋予它概率0，这会使整个句子的概率为0。**拉普拉斯平滑（Laplace smoothing）**（加1）为每个n元语法添加一个小的计数：

$$P_{\text{Laplace}}(w_i \mid w_{i-1}) = \frac{\text{count}(w_{i-1}, w_i) + 1}{\text{count}(w_{i-1}) + V}$$

- 这对于大型词表来说过于激进（它从已观测到的n元语法中偷走了太多概率）。**Kneser-Ney平滑**是n元语法模型的黄金标准。它结合了两个思想：绝对折扣（absolute discounting）和用于回退的延续概率（continuation probability）。

- 首先，**绝对折扣**从每个已观测计数中减去一个固定的折扣$d$（通常$d \approx 0.75$），而不是添加伪计数。释放的概率质量被重新分配给未观测的n元语法。插值形式为：

$$P_{\text{KN}}(w_i \mid w_{i-1}) = \frac{\max(\text{count}(w_{i-1}, w_i) - d, \; 0)}{\text{count}(w_{i-1})} + \lambda(w_{i-1}) \cdot P_{\text{cont}}(w_i)$$

- 其中$\lambda(w_{i-1})$是一个归一化常数，用于分配折扣的概率质量。关键的创新是**延续概率**$P_{\text{cont}}(w_i)$，它衡量$w_i$出现在多少种不同的上下文中，而不是它总体出现的频率：

$$P_{\text{cont}}(w_i) = \frac{|\{w' : \text{count}(w', w_i) > 0\}|}{|\{(w', w'') : \text{count}(w', w'') > 0\}|}$$

- 分子统计了语料库中有多少个不同的词出现在$w_i$之前。像"Francisco"这样的词出现在极少数上下文中（几乎总是在"San"之后），所以即使"San Francisco"非常频繁，"Francisco"也获得很低的延续概率，不会在其他上下文中被错误地预测出来。

- 相反，像"the"这样的常见词出现在许多不同的词之后，获得较高的延续概率。这捕捉到了一个直觉：对于回退估计，一个词的通用性比其原始频率更重要。

- n元语法模型曾是数十年的最先进技术。它们快速、可解释，且不需要训练（只需计数）。但它们难以处理长程依赖（long-range dependencies）："The keys that I left on the table **are** missing"需要知道主语"keys"是复数，而它距离动词很远。从RNN开始，最终发展到Transformer的神经语言模型解决了这一局限。

1. 使用动态规划实现莱文斯坦编辑距离。在词对上测试，并用它进行简单的拼写纠正。
```python
import jax.numpy as jnp

def edit_distance(s, t):
    """Compute Levenshtein edit distance using DP."""
    m, n = len(s), len(t)
    D = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        D[i][0] = i
    for j in range(n + 1):
        D[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s[i-1] == t[j-1]:
                D[i][j] = D[i-1][j-1]
            else:
                D[i][j] = 1 + min(D[i-1][j], D[i][j-1], D[i-1][j-1])

    return D[m][n]

# Test
pairs = [("kitten", "sitting"), ("sunday", "saturday"), ("hello", "hallo")]
for s, t in pairs:
    print(f"d('{s}', '{t}') = {edit_distance(s, t)}")

# Simple spelling correction
dictionary = ["the", "their", "there", "then", "than", "this", "that", "these", "those"]
misspelled = "thier"
corrections = sorted(dictionary, key=lambda w: edit_distance(misspelled, w))
print(f"\nClosest to '{misspelled}': {corrections[:3]}")
```

2. 从零实现BPE分词。从字符级token开始，迭代合并最频繁的词对。
```python
from collections import Counter

def get_pairs(corpus):
    """Count adjacent token pairs across all words."""
    pairs = Counter()
    for word, freq in corpus.items():
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pairs[(symbols[i], symbols[i+1])] += freq
    return pairs

def merge_pair(pair, corpus):
    """Merge all occurrences of a pair in the corpus."""
    new_corpus = {}
    bigram = ' '.join(pair)
    replacement = ''.join(pair)
    for word, freq in corpus.items():
        new_word = word.replace(bigram, replacement)
        new_corpus[new_word] = freq
    return new_corpus

# Training corpus with word frequencies
text = "low low low low low lower lower newest newest newest newest newest newest"
word_freqs = Counter(text.split())
# Initialise: split each word into characters with end-of-word marker
corpus = {' '.join(word) + ' _': freq for word, freq in word_freqs.items()}

print("Initial corpus:")
for word, freq in corpus.items():
    print(f"  {word}: {freq}")

# Run BPE for 10 merges
for i in range(10):
    pairs = get_pairs(corpus)
    if not pairs:
        break
    best_pair = max(pairs, key=pairs.get)
    corpus = merge_pair(best_pair, corpus)
    print(f"\nMerge {i+1}: {best_pair} (freq={pairs[best_pair]})")
    for word, freq in corpus.items():
        print(f"  {word}: {freq}")
```

3. 构建一个二元语法语言模型，并计算测试句子的困惑度。实验拉普拉斯平滑。
```python
from collections import Counter, defaultdict
import math

# Training corpus
train = """the cat sat on the mat . the dog chased the cat .
the cat ran from the dog . a dog sat on a mat .""".split()

# Count bigrams and unigrams
bigrams = Counter(zip(train[:-1], train[1:]))
unigrams = Counter(train)
vocab_size = len(set(train))

def bigram_prob(w2, w1, alpha=0):
    """P(w2 | w1) with optional Laplace smoothing."""
    return (bigrams[(w1, w2)] + alpha) / (unigrams[w1] + alpha * vocab_size)

# Compute perplexity
test = "the cat sat on a mat .".split()

for alpha in [0, 1, 0.1]:
    log_prob = 0
    for w1, w2 in zip(test[:-1], test[1:]):
        p = bigram_prob(w2, w1, alpha=alpha)
        if p > 0:
            log_prob += math.log(p)
        else:
            log_prob += float('-inf')

    ppl = math.exp(-log_prob / (len(test) - 1)) if log_prob > float('-inf') else float('inf')
    print(f"Smoothing α={alpha}: perplexity = {ppl:.2f}")
```

4. 从零实现TF-IDF，并使用余弦相似度找到与查询最相似的文档。
```python
import jax.numpy as jnp
import math
from collections import Counter

documents = [
    "the cat sat on the mat",
    "the dog chased the cat around the park",
    "a mat was placed on the floor by the door",
    "the quick brown fox jumped over the lazy dog",
]

# Build vocabulary
vocab = sorted(set(word for doc in documents for word in doc.split()))
word_to_idx = {w: i for i, w in enumerate(vocab)}
V = len(vocab)
N = len(documents)

# Compute TF-IDF matrix
doc_freq = Counter()
for doc in documents:
    for word in set(doc.split()):
        doc_freq[word] += 1

tfidf_matrix = jnp.zeros((N, V))
for i, doc in enumerate(documents):
    word_counts = Counter(doc.split())
    for word, count in word_counts.items():
        tf = 1 + math.log(count)
        idf = math.log(N / doc_freq[word])
        j = word_to_idx[word]
        tfidf_matrix = tfidf_matrix.at[i, j].set(tf * idf)

# Query
query = "cat on the mat"
query_vec = jnp.zeros(V)
query_counts = Counter(query.split())
for word, count in query_counts.items():
    if word in word_to_idx:
        tf = 1 + math.log(count)
        idf = math.log(N / doc_freq.get(word, 1))
        query_vec = query_vec.at[word_to_idx[word]].set(tf * idf)

# Cosine similarity (from chapter 01)
def cosine_sim(a, b):
    return jnp.dot(a, b) / (jnp.linalg.norm(a) * jnp.linalg.norm(b) + 1e-8)

print(f"Query: '{query}'\n")
for i, doc in enumerate(documents):
    sim = cosine_sim(query_vec, tfidf_matrix[i])
    print(f"  Doc {i} (sim={sim:.3f}): '{doc}'")
```

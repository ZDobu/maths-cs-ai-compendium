# 机器人学习（Robot Learning）

*机器人学习在算法与物理行动之间架起桥梁。本文件涵盖运动学、动力学、经典控制、模仿学习（imitation learning）、从仿真到现实（sim-to-real）的迁移、操作（manipulation）、运动（locomotion）和安全——这些技术赋予机器人在现实世界中移动、抓取、行走和交互的能力。*

- 在前面的章节中，我们研究了如何感知世界（第 8 章、第 11 章文件 1）以及如何从数据中学习（第 6 章）。但感知和学习还不够。机器人必须**行动**：移动手臂去抓取杯子，穿越不平的地形，或在仓库中导航。这正是机器人学习的用武之地。

- 核心挑战在于物理世界是连续的、高维度的、接触密集的，并且毫不宽容。图像识别中的分类错误只是一个错误标签。机器人学中的控制错误则是坏掉的机器人或掉落的物体。赌注是不同的。

## 机器人运动学（Robot Kinematics）

- **运动学**描述运动的几何学，而不考虑力。机器人手臂是由刚性连杆通过关节连接而成的链条。每个关节有一个自由度（DoF）：它要么旋转（旋转关节，revolute joint），要么滑动（棱柱关节，prismatic joint）。

- 机器人的**构型**（configuration）是所有关节角度（或位移）的集合 $\mathbf{q} = [q_1, q_2, \ldots, q_n]^T$。这个向量存在于**关节空间**（joint space，或构型空间）中，即一个 $n$ 维空间，其中每个轴对应一个关节。一个 6-DoF 机器人手臂拥有一个 6 维构型空间。

![2 连杆机器人手臂：关节角度 q1 和 q2 通过正运动学确定末端执行器位置](../../images/robot_arm_fk.svg)

- **正运动学**（Forward kinematics, FK）在给定关节角度的情况下计算末端执行器（"手"）的位置和朝向。这是一个将关节空间映射到**任务空间**（task space，末端执行器的 3D 位置和朝向，也称为笛卡尔空间）的函数 $\mathbf{x} = f(\mathbf{q})$。

- 每个关节由一个 $4 \times 4$ 齐次变换矩阵（回顾第 2 章的仿射变换）描述。**Denavit-Hartenberg (DH) 约定**用四个数字参数化每个关节：连杆长度 $a$、连杆扭转 $\alpha$、连杆偏移 $d$ 和关节角度 $\theta$。关节 $i$ 的变换为：

$$T_i = \begin{bmatrix} \cos\theta_i & -\sin\theta_i \cos\alpha_i & \sin\theta_i \sin\alpha_i & a_i \cos\theta_i \\ \sin\theta_i & \cos\theta_i \cos\alpha_i & -\cos\theta_i \sin\alpha_i & a_i \sin\theta_i \\ 0 & \sin\alpha_i & \cos\alpha_i & d_i \\ 0 & 0 & 0 & 1 \end{bmatrix}$$

- 完整的正运动学是所有关节变换的乘积：$T_{0 \to n} = T_1 T_2 \cdots T_n$。这是矩阵乘法链式变换（第 2 章）：每个关节的变换按顺序应用，将坐标系从基座旋转和平移到末端执行器。

- **逆运动学**（Inverse kinematics, IK）是反向问题：给定一个期望的末端执行器位姿 $\mathbf{x}^*$，找到关节角度 $\mathbf{q}$ 使得 $f(\mathbf{q}) = \mathbf{x}^*$。这要困难得多，因为：

    - 映射是非线性的（涉及正弦和余弦）。
    - 可能存在多个解（不同的手臂构型到达同一点）。
    - 可能无解（目标超出范围）。

- 解析解仅存在于特定的机器人几何形状中。对于一般机器人，IK 使用**雅可比矩阵**（Jacobian）迭代求解。雅可比矩阵 $J(\mathbf{q})$ 关联了关节角度的小变化与末端执行器位置的小变化（回顾第 3 章的雅可比）：

$$\dot{\mathbf{x}} = J(\mathbf{q}) \dot{\mathbf{q}}$$

- 要将末端执行器移动一个小量 $\Delta \mathbf{x}$，我们需要 $\Delta \mathbf{q} = J^{-1} \Delta \mathbf{x}$（或当 $J$ 不是方阵时使用伪逆 $J^+ \Delta \mathbf{x}$）。反复迭代直到末端执行器到达目标，这本质上是应用于运动学方程的牛顿法（第 3 章）。

- 在**奇异点**（singularities）附近，雅可比矩阵失去秩（某些列变得线性相关，如我们在第 2 章研究的）。物理上，这意味着机器人失去一个自由度：无论关节移动多快，末端执行器都不能朝某些方向移动。伪逆在奇异点附近会发散，因此改用阻尼最小二乘（添加正则化项 $\lambda^2 I$）：

$$\Delta \mathbf{q} = J^T(JJ^T + \lambda^2 I)^{-1} \Delta \mathbf{x}$$

## 动力学与控制（Dynamics and Control）

- **动力学**将力加入到图景中。机器人手臂的运动方程遵循**操作臂方程**（manipulator equation）：

$$M(\mathbf{q})\ddot{\mathbf{q}} + C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau}$$

- 其中 $M(\mathbf{q})$ 是质量（惯性）矩阵，$C(\mathbf{q}, \dot{\mathbf{q}})$ 捕获科里奥利（Coriolis）和离心效应，$\mathbf{g}(\mathbf{q})$ 是重力向量，$\boldsymbol{\tau}$ 是关节力矩向量（控制输入）。这是一个二阶微分方程组，每个关节一个。

- 质量矩阵 $M$ 总是对称正定的（回顾第 2 章，正定矩阵保证唯一最小值，在这里它确保系统对施加的力矩做出可预测的响应）。

- **PID 控制**是机器人学中使用最广泛的控制器。对于每个关节，它根据误差 $e(t) = q_{\text{desired}}(t) - q_{\text{actual}}(t)$ 计算力矩：

$$\tau(t) = K_p e(t) + K_i \int_0^t e(s) \, ds + K_d \dot{e}(t)$$

- 三个项具有直观的作用：
    - **比例**（Proportional，$K_p$）：按当前误差的比例进行校正。误差越大 → 校正越大。就像弹簧将关节拉向目标。
    - **积分**（Integral，$K_i$）：累积过去的误差以消除稳态偏移。如果关节持续低于目标，积分项会累积并提供额外的推力。
    - **微分**（Derivative，$K_d$）：对误差变化率做出反应，提供阻尼。它在误差减小时减慢响应，防止超调和振荡。

![PID 控制器调参：高 Kp 产生振荡，高 Kd 反应迟钝，良好调参的 PID 快速达到目标](../../images/pid_response.svg)

- 调参 $K_p, K_i, K_d$ 是一种平衡：过多的 $K_p$ 导致振荡，过多的 $K_d$ 使系统反应迟钝，过多的 $K_i$ 导致积分饱和（wind-up）（在持续误差期间积分项无限增长）。

- **模型预测控制**（Model Predictive Control, MPC）会向前看。在每个时间步，它求解一个优化问题：在满足动力学模型和约束的条件下，找到在有限时域内最小化成本函数（例如，跟踪误差 + 控制代价）的未来控制序列。只应用第一个控制，然后在下一个时间步重复该过程。

$$\min_{\mathbf{u}_{0:T}} \sum_{t=0}^{T} \left[ \|\mathbf{x}_t - \mathbf{x}_t^*\|_Q^2 + \|\mathbf{u}_t\|_R^2 \right] \quad \text{subject to} \quad \mathbf{x}_{t+1} = f(\mathbf{x}_t, \mathbf{u}_t)$$

- 这里 $\|\mathbf{x}\|_Q^2 = \mathbf{x}^T Q \mathbf{x}$ 是使用正定矩阵 $Q$（第 2 章）的加权范数，允许你以不同方式惩罚不同的状态误差。MPC 自然地处理约束条件（关节限制、力矩限制、避障），因为它们被显式包含在优化中。

- **阻抗控制**（Impedance control）调节力与运动之间的关系，而不是跟踪刚性轨迹。它不命令"到达位置 $x$"，而是命令"表现得像一个以 $x$ 为中心的弹簧-阻尼系统"：

$$F = K_s(\mathbf{x}^* - \mathbf{x}) + D(\dot{\mathbf{x}}^* - \dot{\mathbf{x}})$$

- 其中 $K_s$ 是刚度矩阵，$D$ 是阻尼矩阵。这使机器人顺应：如果它接触到障碍物，它会屈服而不是强行通过。阻抗控制对于接触密集的任务至关重要，例如将销钉插入孔中或将物体递给人类。

## 模仿学习（Imitation Learning）

- 我们可以从演示中学习控制策略，而不是手工设计控制器。人类执行任务，机器人观察，学习算法提取策略。这就是**模仿学习**（或从演示中学习，learning from demonstration）。

- **行为克隆**（Behavioural cloning, BC）是最简单的方法：将演示视为监督学习数据集。给定来自专家的观测-动作对 $\{(\mathbf{o}_t, \mathbf{a}_t)\}$，训练策略 $\pi_\theta(\mathbf{a} \mid \mathbf{o})$ 从观测中预测专家的动作。这是标准的监督学习（第 6 章）：最小化损失：

$$\mathcal{L}(\theta) = \mathbb{E}_{(\mathbf{o}, \mathbf{a}) \sim \mathcal{D}} \left[ \| \pi_\theta(\mathbf{o}) - \mathbf{a} \|^2 \right]$$

![行为克隆中的分布偏移：小误差累积，导致学到的策略远离专家轨迹漂移](../../images/distribution_shift_bc.svg)

- 问题在于**分布偏移**（distribution shift，也称为**复合误差问题**，compounding error problem）。在训练期间，策略看到专家的状态。在部署期间，策略自身的微小误差将其推入专家从未访问过的状态。这些不熟悉的状态导致更糟糕的动作，进而导致更不熟悉的状态，误差迅速复合。

- 想象通过观看完美驾驶员来学习驾驶。你从未见过轻微转向后会发生什么，因为专家从未偏离过。当你第一次轻微漂移时，你根本不知道如何恢复。

- **DAgger**（数据集聚合，Dataset Aggregation）通过迭代来解决这个问题：
    1. 在当前数据上训练策略。
    2. 在环境中运行策略，收集新状态。
    3. 请专家为这些新状态标注正确的动作。
    4. 将新数据加入数据集并重新训练。

- 经过多次迭代，数据集涵盖了学习到的策略实际访问的状态，而不仅仅是专家的轨迹。策略因此改善，因为它已经看到并学会从自己的错误中恢复。

- **基于 Transformer 的动作分块**（Action Chunking with Transformers, ACT）是一种现代方法，其中策略预测一个未来动作序列（一个"块"，chunk），而不是一次一个动作。这是使用带 transformer 主干的 conditional VAE 实现的。预测动作块更鲁棒，因为它捕获了时间相关性：伸向运动的平滑性被编码在块中，而不是依赖于可能漂移的自回归单步预测。

- **扩散策略**（Diffusion Policy）将扩散模型（第 8 章）应用于动作生成。它不预测单一动作，而是对以观测为条件的所有可能动作的完整分布进行建模。从噪声开始，迭代去噪以产生动作序列。这自然地处理**多模态**（multimodality）：当存在多种有效方式完成任务时（从左边或右边伸手），扩散模型可以表示两种模式，而回归策略会取它们的平均值（并伸向中间某处，可能两边都不成立）。

## 从仿真到现实的迁移（Sim-to-Real Transfer）

- 在现实世界中训练机器人昂贵、缓慢且危险。一个通过试错学习抓取的机器人可能需要数千次尝试，期间会破坏物体和自身。**仿真**提供无限、安全、快速的经验。但仿真器是不完美的：物理是近似的，视觉是合成的，接触被简化。

- **sim-to-real 差距**（sim-to-real gap）是仿真性能与现实性能之间的差异。在仿真中完美工作的策略可能在真实机器人上完全失败，因为它过度拟合了仿真器的特定细节。

![通过域随机化的 sim-to-real：在许多随机化的仿真上训练，使现实世界只是另一种变体](../../images/sim_to_real.svg)

- **域随机化**（Domain randomisation）通过跨广泛范围的仿真器设置进行训练来应对这一点。不是一个仿真实例，而是使用数千个带有随机化参数的实例：
    - 物理：摩擦系数、质量、阻尼
    - 视觉：光照、纹理、颜色、相机位置
    - 动力学：电机延迟、噪声水平

- 其思想是：如果策略在所有这些变体上都有效，那么现实世界只是分布内的"另一种变体"。策略学习对随机化属性不变的特征，这些不变特征可以迁移。

- **系统辨识**（System identification）采取相反的方法：不是随机化一切，而是仔细测量真实系统的物理参数并调校仿真器以匹配。这提供了更精确的仿真，但是脆弱的（任何未建模的效应都会造成差距）。

- 在实践中，最佳结果结合了两者：系统辨识使仿真器相当接近，然后域随机化覆盖剩余的不确定性。

- **通过微调的 sim-to-real** 主要在仿真中训练，然后进行少量现实世界微调。仿真提供良好的初始化，现实世界数据纠正仿真器特定的偏差。这比从头训练需要少得多的现实世界数据。

## 用于机器人学的世界模型（World Models for Robotics）

- 上述所有 RL 和模仿学习方法都是**无模型**（model-free）的：策略通过直接交互（或演示）学习行动，而不显式建模世界如何运作。另一种选择是**基于模型**（model-based）的学习：首先学习环境动力学的模型，然后使用该模型进行规划或生成合成经验。

- **世界模型**学习转移函数 $p(s_{t+1} \mid s_t, a_t)$：给定当前状态和动作，预测下一个状态（如第 10 章介绍的）。在机器人学中，这意味着预测如果机器人采取特定行动将会发生什么："如果我把这个方块向左推，它会滑动 3cm，它后面的杯子会倒下。"

- 其吸引力在于**样本效率**（sample efficiency）。现实世界的机器人交互是昂贵的。如果机器人能从适量的真实数据中学习一个世界模型，它就可以通过在模型中展开数千条轨迹来"想象"，在不动用物理世界的情况下规划和精化其策略。这类似于国际象棋棋手通过在心里模拟走法来提前思考。

- **DreamerV3** 是一个通用的基于模型的 RL 智能体。它联合学习三个组件：
    - **表示模型**（representation model），将观测编码为紧凑的潜在状态。
    - **转移模型**（transition model，即世界模型），给定当前状态和动作预测下一个潜在状态。
    - **奖励模型**（reward model），从潜在状态预测奖励。

- 然后智能体通过在潜在空间中用转移模型展开多步来"做梦"，在这些想象的轨迹上训练策略，并将策略迁移到真实环境中。关键创新在于所有想象都发生在潜在空间（紧凑的学习表示）而非像素空间中，使其在计算上可行。

$$\hat{s}_{t+1} = f_\theta(s_t, a_t), \quad \hat{r}_t = g_\theta(s_t)$$

- 转移模型 $f_\theta$ 和奖励模型 $g_\theta$ 在真实经验上训练，策略在想象的 rollout 上训练。这解耦了数据收集和策略优化。

- 对于机器人操作，世界模型实现了**心理排练**（mental rehearsal）。在尝试抓取之前，机器人可以在其学习到的模型中模拟几种方法，并选择最可能成功的那种。这对于接触密集的任务尤其有价值，因为现实世界的试错是缓慢且有风险的。

- 世界模型也与 **sim-to-real** 自然连接：在真实数据上训练的世界模型实际上是一个学习到的仿真器，自动捕获真实世界的物理特性，完全绕过 sim-to-real 差距。对于理解充分的场景，该模型可能不如手工构建的仿真器精确，但它捕获了手工仿真器经常搞错的效应（摩擦、变形、接触动力学）。

- **JEPA**（联合嵌入预测架构，Joint Embedding Predictive Architecture，在第 10 章中介绍）提供了像素级预测的替代方案。JEPA 不是在像素空间预测，而是在嵌入空间中预测："下一个状态的潜在表示将接近这个向量。"这避免了预测像素完美未来的困难（这既无必要又浪费计算），并专注于预测对决策制定有意义的未来方面。

- 世界模型的局限性在于**复合预测误差**（compounding prediction error）。转移模型中的小误差在长 rollout 中累积，导致想象轨迹偏离现实。缓解措施包括短的想象时域、集成模型（使用不确定性检测预测何时变得不可靠），以及定期用新的现实世界数据校准模型。

## 操作（Manipulation）

- **操作**是使用机器人末端执行器与物体交互的艺术：拾取、放置、推动、插入、组装。

- **抓取**（Grasping）是基础的操作技能。目标是找到稳定的抓取位姿：夹爪的一个位置和朝向，能够牢固地握住物体。

- **分析式抓取规划**使用物理学。如果接触力能够抵抗外部力和力矩，抓取就是稳定的。对于平行夹爪，最简单的准则是**力封闭**（force closure）条件：接触法向量必须跨越所有力的方向，使抓取能够抵抗任何扰动。这涉及检查抓取力矩矩阵的秩，秩概念（第 2 章）的直接应用。

- **数据驱动的抓取**学习从感知输入预测抓取成功率。给定桌面上物体的深度图像，网络为每个候选夹爪位姿预测抓取质量分数。**GraspNet** 及类似架构使用点云编码器（PointNet 风格，第 8 章）预测带有置信度分数的 6-DoF 抓取位姿（位置 + 朝向）。

- **灵巧操作**（Dexterous manipulation）超越了简单的抓放。一个多指手有 20+ 个自由度，可以执行单手旋转（在手指之间旋转笔）、工具使用和精细组装等任务。状态空间巨大，接触复杂，使其成为机器人学中最困难的问题之一。

- 学习灵巧操作通常使用强化学习（第 6 章）在带有大量域随机化的仿真中进行。OpenAI 使用 Shadow 手求解魔方的工作在带有随机化物理参数的仿真中训练 PPO 策略，实现了向真实机器人手的迁移。

- **接触密集任务**如销钉插入孔中或擦拭表面，要求机器人维持与环境的受控接触。这些任务需要力感知和顺应控制（阻抗控制），并且难以精确仿真，因为接触物理出了名地难以建模。

## 运动（Locomotion）

- 运动是使机器人身体在世界中移动：行走、奔跑、攀爬、游泳。与操作的关键区别在于，机器人必须在移动的同时保持平衡，并且与地面的接触点随时间变化。

- **腿足式运动**（Legged locomotion）具有挑战性，因为它本质上是稳定的。在迈步过程中单腿站立的人形机器人（humanoid）就像一个倒立摆。质心必须保持在支撑多边形（与地面接触的脚的凸包）上方，否则机器人会摔倒。

- **零力矩点**（Zero Moment Point, ZMP）是地面上由重力和惯性力产生的净力矩为零的点。如果 ZMP 保持在支撑多边形内，机器人就不会翻倒。传统的人形机器人控制器（如 Honda 的 ASIMO）规划轨迹使 ZMP 保持在边界内。

- **中枢模式发生器**（Central Pattern Generators, CPGs）是受生物学启发的基于振荡器的控制器。动物使用脊髓中的神经回路生成节律性运动模式（行走、小跑、奔跑），无需大脑持续参与。CPG 模型使用耦合微分方程：

$$\dot{\phi}_i = \omega_i + \sum_j w_{ij} \sin(\phi_j - \phi_i - \psi_{ij})$$

- 其中 $\phi_i$ 是振荡器 $i$ 的相位，$\omega_i$ 是自然频率，$w_{ij}$ 是耦合强度，$\psi_{ij}$ 是期望的相位偏移。不同的相位关系产生不同的步态：所有腿同步（跳跃），交替对（小跑），顺序（行走）。正弦耦合自然地同步振荡器，类似于傅里叶级数（第 3 章）将运动分解为频率分量。

- **用于运动的强化学习**已成为敏捷四足和人形机器人的主导方法。机器人通过在仿真中试错（第 6 章）学习策略 $\pi(\mathbf{a} \mid \mathbf{o})$，以对前进速度、稳定性和能量效率的奖励以及对摔倒、关节极限违规和颤动运动的惩罚为目标。

- 近期工作（例如 Agility Robotics、Boston Dynamics 和学术实验室的工作）的关键洞察是，RL 训练的运动策略远比手工设计的控制器更鲁棒。它们自然地学会从推搡中恢复、适应地形变化，并处理任何工程师都未曾预料到的情况。训练通常使用 PPO（第 6 章）结合域随机化。

- **四足机器人**（如 Boston Dynamics Spot 或 Unitree Go2）已成为腿足式机器人学的主力。四条腿提供了固有的稳定性（当一条腿移动时，三条腿的三脚架始终可以支撑身体）。四足机器人的 RL 策略取得了令人印象深刻的成果：以 3+ m/s 的速度奔跑、爬楼梯、在岩石地形中导航，以及从踢击中恢复。

- **人形机器人运动**更难，因为双足动物的支撑多边形更小、质心更高。近期进展（Tesla Optimus、Figure、Unitree H1）使用在仿真中用精心设计的奖励来训练的 RL。人形机器人不仅要学会行走，还要学会协调手臂摆动以保持平衡、在不平坦表面上导航，以及从扰动中恢复。

## 机器人学习中的安全（Safety in Robot Learning）

- 一个随机探索以学习的机器人（如 RL 中的那样）可能会损坏自身、环境或附近的人类。**安全机器人学习**约束探索以避免灾难性后果。

- **约束 RL** 向 MDP（第 6 章）添加安全约束。目标变为：在 $J_c(\pi) \leq d$ 的条件下最大化奖励，其中 $J_c$ 是期望累积代价（例如碰撞事件），$d$ 是最大允许代价。约束策略优化（CPO）等算法扩展 PPO 以处理这些约束。

- **安全包络**（Safety envelopes）定义了机器人绝不能越过的硬边界，无论学习到的策略说什么。安全控制器监视机器人的状态，并在约束即将被违反时（例如接近关节极限、在人类附近移动太快或超过力阈值）覆盖学习到的策略。这是一种分层架构：学习算法处理性能，安全层处理约束。

- **风险感知规划** 显式地建模环境和机器人自身状态估计中的不确定性。它不只是为最可能的结果做规划，而是为置信界内的最坏情况做规划。这关联到条件数概念（第 2 章）：一个良条件系统对扰动是鲁棒的，而风险感知规划寻求在扰动下保持安全的控制策略。

1. 实现一个简单的 2 连杆平面机器人手臂的正运动学。计算并可视化不同关节角度下的末端执行器位置。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

def forward_kinematics(q1, q2, l1=1.0, l2=0.8):
    """Compute joint and end-effector positions for a 2-link arm."""
    x1 = l1 * jnp.cos(q1)
    y1 = l1 * jnp.sin(q1)
    x2 = x1 + l2 * jnp.cos(q1 + q2)
    y2 = y1 + l2 * jnp.sin(q1 + q2)
    return jnp.array([0, x1, x2]), jnp.array([0, y1, y2])

fig, ax = plt.subplots(figsize=(6, 6))
configs = [(0.5, 0.3), (1.0, -0.5), (1.5, 1.0), (2.0, -1.5)]
colors = ["#e74c3c", "#3498db", "#27ae60", "#9b59b6"]

for (q1, q2), c in zip(configs, colors):
    xs, ys = forward_kinematics(q1, q2)
    ax.plot(xs, ys, "o-", color=c, linewidth=2, markersize=6,
            label=f"q=({q1:.1f}, {q2:.1f})")

ax.set_xlim(-2, 2); ax.set_ylim(-2, 2)
ax.set_aspect("equal"); ax.grid(True); ax.legend()
ax.set_title("2-Link Robot Arm: Forward Kinematics")
plt.show()
```

2. 使用雅可比伪逆实现逆运动学。从随机构型开始，迭代将末端执行器移动到目标。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

l1, l2 = 1.0, 0.8

def end_effector(q):
    x = l1 * jnp.cos(q[0]) + l2 * jnp.cos(q[0] + q[1])
    y = l1 * jnp.sin(q[0]) + l2 * jnp.sin(q[0] + q[1])
    return jnp.array([x, y])

jacobian_fn = jax.jacobian(end_effector)

target = jnp.array([0.5, 1.2])
q = jnp.array([0.1, 0.1])
trajectory = [end_effector(q)]

for _ in range(50):
    pos = end_effector(q)
    error = target - pos
    if jnp.linalg.norm(error) < 1e-4:
        break
    J = jacobian_fn(q)
    # Damped pseudo-inverse to handle near-singularities
    dq = J.T @ jnp.linalg.solve(J @ J.T + 0.01 * jnp.eye(2), error)
    q = q + dq
    trajectory.append(end_effector(q))

traj = jnp.stack(trajectory)
plt.plot(traj[:, 0], traj[:, 1], "b.-", label="end-effector path")
plt.plot(*target, "r*", markersize=15, label="target")
plt.gca().set_aspect("equal"); plt.grid(True); plt.legend()
plt.title(f"IK converged in {len(trajectory)-1} steps")
plt.show()
```

3. 模拟一个简单的 PID 控制器跟踪期望的关节轨迹。观察调节增益的效果。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

# Desired trajectory: smooth sinusoidal motion
dt = 0.01
t = jnp.arange(0, 5, dt)
q_desired = jnp.sin(2 * t)

# Simulate second-order dynamics: m * q_ddot + b * q_dot = tau
m, b_damp = 1.0, 0.5

for Kp, Kd, Ki, label in [(10, 5, 0, "PD only"), (10, 5, 2, "PID"), (50, 10, 2, "Aggressive PID")]:
    q, q_dot, integral = 0.0, 0.0, 0.0
    qs = []
    for i in range(len(t)):
        error = q_desired[i] - q
        integral += error * dt
        d_error = -q_dot  # derivative of error (desired velocity is known but simplified here)
        tau = Kp * error + Kd * d_error + Ki * integral
        q_ddot = (tau - b_damp * q_dot) / m
        q_dot += q_ddot * dt
        q += q_dot * dt
        qs.append(float(q))

    plt.plot(t, qs, label=label)

plt.plot(t, q_desired, "k--", label="desired", linewidth=2)
plt.xlabel("Time (s)"); plt.ylabel("Joint angle")
plt.legend(); plt.title("PID Controller Tracking")
plt.show()
```

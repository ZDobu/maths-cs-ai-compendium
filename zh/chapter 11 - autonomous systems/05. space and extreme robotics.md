# 太空与极端环境机器人学（Space and Extreme Robotics）

*太空和极端环境机器人学将自主性推向极限，在通信延迟、辐射和非结构化地形要求机器人自主思考。本文件涵盖行星探测车、轨道服务、通信受限下的自主性、抗辐射计算、水下机器人、搜索与救援、群体机器人学（swarm robotics）和人机交互*

- 在本章中，我们研究了在相对良性环境中运行的自主系统：带有车道标线的道路、具有平整地板的仓库、具有已知物体类别的厨房。但机器人学中一些最具影响力的应用是在人类不能去的地方，或人类存在的代价极高的地方：火星表面、深海海底、核灾难现场和燃烧的建筑物。

- 这些**极端环境**共享共同的挑战：通信有限或延迟、地形非结构化且不可预测、硬件必须经受恶劣条件，并且附近没有人类在出现问题时进行修复。机器人必须是真正自主的，而不仅仅是"有一个人看着屏幕的自主"。

## 太空机器人学（Space Robotics）

- 太空是终极的极端环境。没有空气，温度从 -170°C 波动到 +120°C，辐射轰击电子设备，帮助远在数百万公里之外。太空机器人必须极其可靠、节能且自主。

- **行星探测车**（Planetary rovers）是探索其他世界表面的移动机器人。NASA 的火星探测车（Spirit、Opportunity、Curiosity、Perseverance）是最著名的例子。每一代都比上一代更自主。

![地球-火星通信延迟：单向 4-24 分钟，往返 8-48 分钟，使实时控制不可能实现](../../images/earth_mars_delay.svg)

- 根本约束是**通信延迟**（communication delay）。火星距离地球无线电 4-24 分钟（取决于轨道位置），因此往返通信需要 8-48 分钟。探测车不能被实时遥控操作。如果它遇到一块岩石，它不能请求地球的帮助并等待回复。它必须自己决定。

- 早期探测车（Spirit、Opportunity）严重依赖地面闭环规划：人类研究图像、规划路径、上传指令，探测车执行它们。一个单独的驾驶周期需要一整个火星日（sol）。探测车每个 sol 最多能穿越 50-100 米。

- Curiosity 和 Perseverance 上的 **AutoNav**（自主导航，Autonomous Navigation）极大地提高了自主性。探测车使用立体相机构建局部 3D 地图（回顾第 8 章的立体深度），评估地形可通过性（坡度、粗糙度、岩石大小），并使用基于网格的规划器和可通过性成本地图规划安全路径。探测车在人类团队睡觉时自主驾驶，将每日穿越距离提高到 100+ 米。

- 火星探测车上的感知流水线受到抗辐射处理器的限制，这些处理器比消费级硬件慢几个数量级（下文讨论）。算法必须在计算上精打细算：经典的立体匹配而非深度神经网络，简单的成本地图规划器而非学习的策略。

- **轨道服务**（Orbital servicing）涉及在轨道上检测、修复、加油或离轨卫星的机器人。随着太空变得越来越拥挤，这是一个不断增长的领域。像 **OSAM-1**（NASA）和商业企业（Astroscale、Northrop Grumman MEV）这样的任务使用机器人手臂和对接机构来服务卫星。

- 挑战在于**近距离操作**（proximity operations）：服务航天器必须接近目标卫星（可能正在翻滚、不合作的且缺乏对接接口），并在微重力下执行精确操作。基于视觉的位姿估计（从相机图像确定目标的 3D 位置和朝向）至关重要。这使用了第 8 章的技术：特征检测、PnP（Perspective-n-Point）求解，以及更近期的基于深度学习的位姿估计器。

- **卫星检测**使用小型航天器目视检查其他卫星的损坏或异常。检测器必须自主围绕目标导航，避免碰撞，并从最佳视角捕获高分辨率图像。这是一个规划问题：找到覆盖所有检测点同时满足燃料约束、光照条件和碰撞避免的轨迹。

## 通信约束（Communication Constraints）

- 在太空中，通信受限于光速、可用带宽和轨道几何（火星背面的探测车根本没有中继卫星就无法与地球通信）。

- 这些约束从根本上改变了自主架构。在地球上，机器人可以将高清视频流传输到云服务器，在 GPU 集群上运行推理，并在毫秒内接收命令。在太空中，机器人必须在星上（onboard）完成一切。

- **高延迟**意味着机器人必须在没有实时人类指导的情况下规划和行动。自主软件必须处理正常操作、检测异常并在不等待人类输入的情况下响应危险。这需要鲁棒的星上状态估计、故障检测和应急规划。

- **有限带宽**意味着机器人不能传输原始传感器数据。一张高分辨率图像可能有几兆字节，但火星到地球的数据速率通过直接对地链路只有每秒几千比特（通过轨道中继更高，但仍然有限）。机器人必须积极压缩数据、优先确定发送哪些数据，并在本地做出大多数决策。

- **通信窗口**是间歇性的。火星探测车只能在特定的轨道几何条件下与地球通信，通常每个 sol 通过中继卫星有几个小时。在这些窗口之外，探测车完全靠自己。

- 对 AI 的影响是**星上自主性**必须高度可靠。系统需要检测是否有问题（轮子卡住了、传感器坏了、前方地形不可通过），决定安全的响应，并在下一个通信窗口可以报告并接收更新指示之前继续运行。

## 抗辐射计算（Radiation-Hardened Computing）

- 太空充满电离辐射：宇宙射线、太阳粒子事件和行星磁场中的俘获辐射。高能粒子可以翻转内存中的比特位（**单粒子翻转**，single-event upsets, SEUs）、永久损伤晶体管（**总电离剂量**，total ionising dose, TID），或在电路中引起破坏性闩锁。

- **抗辐射**（radiation-hardened, rad-hard）处理器被设计来承受这种环境。它们使用更大的晶体管几何形状、冗余逻辑（三模冗余：每个电路的三个副本对输出进行投票）和专门的制造工艺。代价是性能：一个最先进的 rad-hard 处理器可能提供 200 MIPS，而消费级 GPU 每秒可执行数十亿次运算。

- **RAD750**（BAE Systems）为 Curiosity 和许多其他航天器提供动力。它以 200 MHz 运行，具有约 400 MIPS 的处理能力，相当于 20 世纪 90 年代中期台式计算机的性能。Perseverance 使用类似级别的处理器。在这种硬件上运行现代神经网络（数百万参数、数十亿次乘加运算）是不可行的。

- **模型压缩**变得至关重要。来自第 6 章的技术（量化、剪枝、知识蒸馏）被用来缩小神经网络以适应极端的计算预算。一个在笔记本 GPU 上运行只需毫秒的模型，在 rad-hard 处理器上可能需要数分钟，或者根本无法放入内存。

- 另一种方法使用**商用现货**（commercial off-the-shelf, COTS）处理器，并通过软件中的辐射缓解手段：纠错码、看门狗定时器、定期内存刷新和优雅降级策略。一些现代任务使用这种方法来获取更强大的计算能力，代价是增加软件复杂性和风险。

- 未来的行星任务正在探索 **FPGA** 和专门的 AI 加速器，它们可以耐受辐射，同时提供比传统 rad-hard CPU 显著更多的计算能力，可能首次实现在星上使用深度学习。

## 非结构化地形中的自主导航

- 在地球上，道路是平坦的、标记良好的并且有地图。在火星、月球或灾难现场，没有道路。地形是非结构化的：岩石、斜坡、沙子、裂缝，以及可能无法支撑机器人重量的表面。

- **地形分类**（Terrain classification）评估每个地面补丁是否安全可通过。特征包括坡度（来自 3D 重建）、粗糙度（表面法线的方差）、岩石密度和土壤类型。经典方法从立体深度图中计算这些特征；现代方法在视觉和几何特征上使用学习的分类器。

- **视觉-惯性里程计**（Visual-inertial odometry, VIO）通过跨相机帧跟踪视觉特征并与 IMU 测量融合来估计机器人的运动。这是一个核心的 SLAM 组件（第 8 章），针对极端条件进行了适配。在火星上，VIO 必须处理：无特征的沙地（可跟踪的视觉特征很少）、苛刻的光照（极端阴影）和有限的计算。

- 估计使用**扩展卡尔曼滤波器**（Extended Kalman Filter, EKF）或因子图优化来融合视觉和惯性数据。状态向量包括位置、速度、朝向和 IMU 偏差。预测步骤使用 IMU 积分：

$$\mathbf{x}_{t+1} = f(\mathbf{x}_t, \mathbf{u}_t)$$

- 其中 $\mathbf{u}_t$ 是 IMU 测量（加速度和角速度）。更新步骤使用视觉特征观测来校正预测。这是贝叶斯估计（第 5 章）：IMU 提供先验，视觉观测更新信念。

- **危险规避**（Hazard avoidance）在行星着陆期间至关重要。当航天器向表面下降时，它必须使用星上相机或 LiDAR 实时识别安全的着陆区。NASA 在 Perseverance 上的**地形相对导航**（Terrain Relative Navigation, TRN）系统将星上相机图像与预加载的轨道地图进行比较，以确定其在下降过程中的位置，然后远离危险地形。这使得在 Jezero 陨石坑着陆成为可能，这是一个科学丰富但地形危险的场地，对以前的任务来说风险太大。

## 水下机器人学（Underwater Robotics）

- 深海和太空一样陌生：全海深处的巨大压力（1000+ 个大气压）、接近零的能见度、没有 GPS 和有限的通信。水下机器人对海洋科学、海上基础设施检测、深海采矿和搜索行动至关重要。

- **AUV**（自主水下航行器，Autonomous Underwater Vehicles）无缆操作，携带自己的电源和计算。它们遵循预先编程的测量模式或使用星上智能来适应发现。AUV 用于海底测绘、管道检测和环境监测。

- **ROV**（遥控潜器，Remotely Operated Vehicles）通过电缆与水面母船连接，电缆提供电力和通信。它们用于需要实时人类控制的任务：深海操作、施工和维修。电缆解除了通信约束，但限制了范围并增加了操作复杂性。

- **水声通信**是主要的水下通信方式（无线电波在水中迅速衰减）。水声调制解调器在几公里范围内实现 1-10 kbps 的数据速率，相比之下陆地上的无线电达到了千兆比特每秒。这比火星通信更受限，迫使 AUV 高度自主。

- **水下 SLAM** 特别具有挑战性。声纳提供距离测量，但角分辨率差、噪声显著（来自海底和表面的多路径反射）。相机仅在很短距离内工作（清水中几米，浑浊条件下更短）。基于特征的视觉 SLAM（第 8 章）必须适应水下场景独特的视觉特征：颜色衰减（红光首先被吸收）、反向散射，以及产生亮斑和深阴影的人工照明。

- 没有 GPS 的导航使用**航位推算**（dead reckoning）（从多普勒速度计 DVL 积分速度，DVL 使用声学多普勒频移测量相对于海底的速度），辅以偶尔浮出水面获取 GPS 定位或来自水面应答器的声学定位。这与纯 IMU 导航有相同的漂移问题：小的速度误差在长时间任务中累积。

## 搜索与救援机器人学（Search and Rescue Robotics）

- 在地震、建筑物坍塌或工业事故之后，机器人可以进入对人类救援者来说太危险的空间：结构不稳定的建筑物、有毒环境、火灾或密闭空间。

- 要求包括：快速部署（几分钟而非几小时）、在 GPS 拒止环境中运行（室内、地下）、通过墙壁和瓦砾的鲁棒通信，以及在高度杂乱、部分坍塌、有碎片、灰尘和不良照明的空间中导航的能力。

- **多机器人协调**在搜索和救援中很有价值，因为一组机器人可以比单个机器人更快地覆盖大面积区域。挑战在于协调：机器人必须划分搜索区域、避免重复工作并共享发现。

- **基于前沿的探索**（Frontier-based exploration）将机器人分配到已探索和未探索空间之间的边界（"前沿"）。每个机器人导航到最近的未探索前沿，对其建图，然后继续前进。集中式或分布式规划器将前沿分配给机器人以最小化总探索时间。这是一个覆盖优化问题。

- 通过瓦砾的通信是不可靠的。机器人可能失去与操作员和彼此的联系。系统必须对间歇性通信具有鲁棒性：每个机器人应能够独立运行，构建自己的本地地图并做出自己的决定，然后在通信恢复时合并信息。

## 群体机器人学（Swarm Robotics）

- **群体机器人学**使用大量简单、低成本的机器人，通过局部交互实现复杂的集体行为。单个机器人个体能力不足，但群体作为一个整体可以执行任何个体无法完成的任务。

- 灵感来自生物群体：蚂蚁用身体搭建桥梁、蜜蜂集体做出巢址决策、鱼群通过协调运动躲避捕食者。在每种情况下，简单的局部规则（跟随邻居、避免碰撞、向食物移动）产生复杂的全局行为。

- **去中心化控制**（Decentralised control）意味着没有中心指挥官。每个机器人遵循相同的局部规则，仅对其邻居和直接环境做出反应。全局行为从这些局部交互中**涌现**。这使群体天生鲁棒：如果一个机器人失败，群体继续运作。没有单点故障。

- **共识算法**（Consensus algorithms）使群体能够仅通过局部通信就集体决策达成一致（例如，朝哪个方向移动、优先考虑哪个任务）。一个简单的共识协议让每个机器人将其值与邻居的值进行平均：

$$x_i(t+1) = \frac{1}{|N_i| + 1} \left( x_i(t) + \sum_{j \in N_i} x_j(t) \right)$$

![群体共识：机器人从分散开始，与邻居迭代平均，最终收敛到共享位置](../../images/swarm_consensus.svg)

- 其中 $N_i$ 是机器人 $i$ 的邻居集合。反复迭代直到所有机器人收敛到同一值（全局平均值）。收敛速度取决于通信图的拓扑，具体来说是它的代数连通度（图拉普拉斯的第二小特征值，与第 2 章的特征值相关联）。

![Reynolds 三个集群规则：分离避免碰撞，对齐匹配方向，凝聚力保持群体在一起](../../images/reynolds_flocking.svg)

- **集群算法**（Flocking algorithms，Reynolds 规则）通过每个机器人的三个简单规则产生协调的群体运动：
    - **分离**（Separation）：远离太近的邻居（避免碰撞）。
    - **对齐**（Alignment）：转向邻居的平均朝向（朝同一方向移动）。
    - **凝聚力**（Cohesion）：转向邻居的平均位置（保持与群体在一起）。

- 每个规则是对机器人速度的一个向量贡献。这些向量的加权和产生自然主义的集群行为。这是向量的线性组合（第 1 章），其中权重控制每种行为的相对重要性。

- 群体机器人学的应用包括环境监测（在大范围内分布传感器）、精准农业（协调无人机进行喷洒）、建造（机器人集体组装结构）和搜索行动（高效覆盖大面积区域）。

## 人机交互（Human-Robot Interaction）

- 大多数现实世界的自主系统与人类并肩运行，而非孤立。人类与机器人之间的交互——他们如何沟通、共享控制权和建立信任——与机器人的技术能力同样重要。

![共享自主谱系：从完全人类遥操作（alpha=1）到混合控制再到完全机器人自主（alpha=0）](../../images/shared_autonomy_spectrum.svg)

- **共享自主**（Shared autonomy）混合了人和机器人的控制。不是完全的遥操作（人类控制一切）或完全的自主（机器人控制一切），共享自主让人类提供高层意图而机器人处理低层执行。例如，人类可能指向一个物体说"拿起那个"，机器人自主规划抓取和手臂运动。

- 数学上，共享自主可以建模为人类输入 $\mathbf{u}_h$ 和机器人自主动作 $\mathbf{u}_r$ 的混合：

$$\mathbf{u} = \alpha \mathbf{u}_h + (1 - \alpha) \mathbf{u}_r$$

- 其中 $\alpha \in [0, 1]$ 是混合参数。当 $\alpha = 1$，人类完全控制（遥操作）。当 $\alpha = 0$，机器人完全自主。自适应共享自主根据情况调整 $\alpha$：当机器人自信时它接管更多控制，当它不确定或情况异常时让出控制。

- **遥操作**（Teleoperation）对于超出当前自主能力的任务仍然重要。人类操作员通过机器人的相机观看场景远程控制机器人。挑战在于**延迟**：即使 100ms 的延迟也使遥操作困难，而在太空中数秒的延迟使精细操作几乎不可能。预测显示（显示机器人预测的未来状态）和虚拟夹具（阻止操作员命令危险动作的软件引导）有助于补偿。

- **信任校准**（Trust calibration）是确保人类对机器人有适当信任的问题：不能太多（过度信任导致自满和在需要时未能干预），不能太少（信任不足导致不必要的干预和未充分利用）。信任应校准到机器人的实际能力：在它处理良好的情况下信任它，在接近其能力边缘的情况下保持怀疑。

- 研究表明信任受以下因素影响：机器人的透明度（它是否解释其决策？）、可靠性（它是否可预测地还是随机地失败？）和沟通（它是否表达不确定性？）。一个说"我有 40% 的把握确定这是一条安全路径，我应该继续吗？"的机器人比一个默默向前开的机器人能让人做出更好的决策。

- 机器人运动中的**可解读性**（Legibility）意味着机器人的移动方式向其附近的人类传达其意图。如果一个机器人去够一个物体，它的路径应该使其目标物体明显，甚至在它到达之前。这涉及规划最大化观察者早期推断目标能力的轨迹，可以形式化为在给定观察到的部分轨迹下最大化真实目标的后验概率：

$$\pi^* = \arg\max_\pi P(G \mid \xi_{0:t})$$

- 其中 $G$ 是目标，$\xi_{0:t}$ 是迄今为止观察到的轨迹。这使用了贝叶斯推断（第 5 章）：观察者有关于可能目标的先验，机器人的轨迹提供更新这一信念的证据。

1. 模拟一群机器人对目标位置达成一致的共识算法。从随机初始位置开始，观察收敛过程。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

n_robots = 10
rng = jax.random.PRNGKey(0)
positions = jax.random.uniform(rng, (n_robots, 2), minval=-5, maxval=5)

# Communication graph: each robot talks to its 3 nearest neighbours
def get_neighbours(positions, k=3):
    dists = jnp.linalg.norm(positions[:, None] - positions[None, :], axis=-1)
    # For each robot, find k nearest (excluding self)
    neighbours = jnp.argsort(dists, axis=1)[:, 1:k+1]
    return neighbours

history = [positions.copy()]

for step in range(30):
    neighbours = get_neighbours(positions)
    new_positions = jnp.zeros_like(positions)
    for i in range(n_robots):
        nbr_pos = positions[neighbours[i]]
        new_positions = new_positions.at[i].set(
            (positions[i] + nbr_pos.sum(axis=0)) / (len(neighbours[i]) + 1)
        )
    positions = new_positions
    history.append(positions.copy())

# Plot convergence
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, step_idx, title in zip(axes, [0, 10, 29], ["Initial", "Step 10", "Final"]):
    h = history[step_idx]
    ax.scatter(h[:, 0], h[:, 1], s=50)
    ax.set_xlim(-6, 6); ax.set_ylim(-6, 6)
    ax.set_aspect("equal"); ax.grid(True); ax.set_title(title)
plt.suptitle("Swarm Consensus: Robots Converge to Agreement")
plt.tight_layout()
plt.show()
```

2. 实现 Reynolds 集群规则（分离、对齐、凝聚力）并模拟一个群体一起移动。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

n = 30
rng = jax.random.PRNGKey(1)
k1, k2 = jax.random.split(rng)
pos = jax.random.uniform(k1, (n, 2), minval=-5, maxval=5)
vel = jax.random.uniform(k2, (n, 2), minval=-0.5, maxval=0.5)

dt = 0.1
separation_radius = 1.0
neighbour_radius = 3.0

trajectories = [pos.copy()]

for _ in range(200):
    new_vel = jnp.zeros_like(vel)
    for i in range(n):
        diffs = pos - pos[i]
        dists = jnp.linalg.norm(diffs, axis=1)

        # Neighbours within radius (exclude self)
        nbr_mask = (dists < neighbour_radius) & (dists > 0)
        sep_mask = (dists < separation_radius) & (dists > 0)

        # Separation: steer away from very close neighbours
        if sep_mask.any():
            sep = -diffs[sep_mask].sum(axis=0)
        else:
            sep = jnp.zeros(2)

        # Alignment: match average velocity of neighbours
        if nbr_mask.any():
            align = vel[nbr_mask].mean(axis=0) - vel[i]
        else:
            align = jnp.zeros(2)

        # Cohesion: steer toward average position of neighbours
        if nbr_mask.any():
            cohesion = pos[nbr_mask].mean(axis=0) - pos[i]
        else:
            cohesion = jnp.zeros(2)

        new_vel = new_vel.at[i].set(vel[i] + 1.5 * sep + 0.5 * align + 0.3 * cohesion)

    # Limit speed
    speeds = jnp.linalg.norm(new_vel, axis=1, keepdims=True)
    vel = jnp.where(speeds > 2.0, new_vel / speeds * 2.0, new_vel)
    pos = pos + vel * dt
    trajectories.append(pos.copy())

# Plot snapshots
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, idx, title in zip(axes, [0, 50, 199], ["Start", "Step 50", "Step 200"]):
    p = trajectories[idx]
    v = vel if idx == 199 else jnp.zeros_like(vel)
    ax.scatter(p[:, 0], p[:, 1], s=20, c="blue")
    ax.set_aspect("equal"); ax.grid(True); ax.set_title(title)
    lim = max(abs(p).max() + 1, 6)
    ax.set_xlim(-lim, lim); ax.set_ylim(-lim, lim)
plt.suptitle("Reynolds' Flocking: Separation + Alignment + Cohesion")
plt.tight_layout()
plt.show()
```

3. 模拟共享自主混合：人类提供嘈杂的方向输入，机器人的自主系统提供到目标的平滑路径。用不同的 alpha 值混合它们。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

goal = jnp.array([10.0, 5.0])
pos = jnp.array([0.0, 0.0])
dt = 0.1

rng = jax.random.PRNGKey(3)

fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, alpha in zip(axes, [1.0, 0.5, 0.0]):
    pos = jnp.array([0.0, 0.0])
    path = [pos.copy()]

    for step in range(150):
        # Robot autonomy: smooth path to goal
        direction = goal - pos
        u_robot = direction / (jnp.linalg.norm(direction) + 1e-6) * 1.0

        # Human input: roughly correct direction but noisy
        noise = jax.random.normal(jax.random.fold_in(rng, step), (2,)) * 0.5
        u_human = u_robot + noise

        # Blend
        u = alpha * u_human + (1 - alpha) * u_robot
        pos = pos + u * dt
        path.append(pos.copy())

        if jnp.linalg.norm(pos - goal) < 0.3:
            break

    path = jnp.stack(path)
    ax.plot(path[:, 0], path[:, 1], "b-", alpha=0.7)
    ax.plot(*goal, "r*", markersize=15)
    ax.plot(0, 0, "go", markersize=10)
    ax.set_title(f"α={alpha:.1f} ({'human' if alpha==1 else 'robot' if alpha==0 else 'shared'})")
    ax.set_xlim(-1, 12); ax.set_ylim(-3, 8)
    ax.set_aspect("equal"); ax.grid(True)

plt.suptitle("Shared Autonomy: Blending Human and Robot Control")
plt.tight_layout()
plt.show()
```

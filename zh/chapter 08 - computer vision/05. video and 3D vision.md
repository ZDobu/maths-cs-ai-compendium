# 视频与三维视觉

*视频和三维视觉将图像理解扩展到时间和空间域。本文件涵盖光流、视频分类（3D CNN、TimeSformer）、目标跟踪（SORT、DeepSORT）、动作识别、深度估计（单目和立体）、点云、NeRF以及3D高斯泼溅。*

- 文件01-04将图像视为孤立的快照。但视觉世界是连续的：物体移动，场景变化，深度存在。本文件将计算机视觉扩展到时间域（视频）和空间域（3D），涵盖模型如何理解运动、跟踪物体、估计深度和重建场景。

- **视频（video）**是随时间捕获的图像（帧）序列。以每秒30帧的速度，10秒的片段包含300帧。关键挑战是建模**时间维度（temporal dimension）**：物体如何移动，场景如何演变，以及我们如何在帧之间关联信息？

- **光流（optical flow）**估计两个连续帧之间像素的表观运动。对于帧$t$中的每个像素，光流产生一个二维位移向量$(u, v)$，指向该像素在帧$t+1$中的位置。结果是一个与图像大小相同的稠密运动场。

![两个连续视频帧及其之间的光流场，可视化为显示像素运动方向和幅值的彩色箭头](../../images/optical_flow.svg)

- 光流在**亮度恒定假设（brightness constancy assumption）**下计算：一个像素在移动时其强度不变。如果帧$t$中位置$(x, y)$处的像素强度为$I(x, y, t)$，并在小时间间隔$\delta t$内移动$(u, v)$：

$$I(x + u\delta t, \, y + v\delta t, \, t + \delta t) = I(x, y, t)$$

- 取一阶泰勒展开（第03章）并除以$\delta t$：

$$I_x u + I_y v + I_t = 0$$

- 其中$I_x, I_y$是空间梯度（Sobel，文件01），$I_t$是时间梯度（连续帧之间的差异）。这是**光流约束方程（optical flow constraint equation）**。一个方程，两个未知数$(u, v)$：我们需要一个额外的约束。

- **Lucas-Kanade**假设在小窗口（例如，5x5像素）内流动是恒定的。这给出了一个超定系统（25个方程，2个未知数），通过最小二乘法求解（第06章的正规方程）：

```math
\begin{bmatrix} u \\ v \end{bmatrix} = \begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix}^{-1} \begin{bmatrix} -\sum I_x I_t \\ -\sum I_y I_t \end{bmatrix}
```

- 这个2x2矩阵是文件01中的结构张量（与Harris角点检测中使用的矩阵相同）。Lucas-Kanade对小运动效果很好，但当物体在帧之间移动超过几个像素时失效。

- **Farneback方法**对每个像素的邻域拟合多项式展开，并估计最能解释帧间变化的位移场。它产生稠密流（每个像素一个向量），并处理比Lucas-Kanade更大的运动。

- 现代**深度学习光流**方法（FlowNet、RAFT）学习从帧对端到端预测光流。**RAFT**（Recurrent All-Pairs Field Transforms，Teed和Deng，2020）计算两帧中所有像素对之间的4D相关体，并使用基于GRU的更新算子迭代精炼流估计。RAFT实现了最先进的准确率，已成为标准流主干。

- **双流网络（two-stream networks）**（Simonyan和Zisserman，2014）是视频理解的早期方法。一个流处理单个RGB帧（外观），另一个流处理光流帧的堆叠（运动）。两个流在末端融合（通过平均或拼接）。这种架构明确地将"物体长什么样"与"它们如何移动"分开。

- **三维卷积网络（3D Convolutional Networks）**将二维卷积扩展到时间维度。3D卷积应用大小为$k \times k \times k_t$的滤波器，同时跨越空间和时间维度，直接学习时空特征。

- **C3D**（Tran等人，2015）堆叠具有3x3x3滤波器的3D卷积，表明时间卷积可以在没有显式光流的情况下学习运动特征。代价很高：3D卷积的参数和计算量是其2D对应物的$k_t$倍。

- **I3D**（Inflated 3D，Carreira和Zisserman，2017）采用更实际的方法：从预训练的2D CNN（如Inception或ResNet）开始，通过沿时间维度重复权重并除以$k_t$，将所有2D滤波器"膨胀"到3D。这将ImageNet预训练迁移到视频，同时添加时间建模。2D $k \times k$滤波器变为$k \times k \times k_t$滤波器，初始化为$W_{\text{3D}}[:,:,j] = W_{\text{2D}} / k_t$（对所有时间位置$j$）。

- **SlowFast网络**（Feichtenhofer等人，2019）使用两条以不同时间分辨率运行的并行通路：
    - **慢通路（Slow pathway）**以低帧率处理帧（例如，每16帧一次），具有高空间分辨率和许多通道，捕获精细的空间细节。
    - **快通路（Fast pathway）**以高帧率处理帧（每2帧一次），具有降低的空间分辨率和更少的通道（通常为慢通路的$1/8$），捕获快速的时间变化。
    - 横向连接通过步长卷积将信息从快通路融合到慢通路。

- 其洞察是空间和时间信息具有不同的带宽要求：物体外观变化缓慢，但运动可以很快。SlowFast通过设计匹配这种不对称性。

- **TimeSformer**（Bertasius等人，2021）将Vision Transformer应用于视频。它将完整的时空注意力（其代价高得难以承受：对于$T$帧和每帧$N$个块为$O((T \times N)^2)$）分解为**分离注意力（divided attention）**：每个块交替进行时间注意力（每个块在同一空间位置跨时间关注）和空间注意力（每个块在同一帧内跨空间关注）。这将成本从$O(T^2 N^2)$降低到$O(T^2 + N^2)$。

- **VideoMAE**（Tong等人，2022）将掩膜自编码器思想（文件04）扩展到视频。使用极高的掩膜比（90-95%），因为视频具有高时间冗余：相邻帧看起来几乎相同，因此掩膜大部分块仍然留下足够的信息用于重建。VideoMAE在无标签视频上预训练ViT主干，并迁移到下游任务。

- **动作识别（action recognition）**将视频片段分类为众多动作类别之一（例如，"跑步"、"做饭"、"弹吉他"）。它是图像分类的视频类比。标准基准包括Kinetics-400（400个动作类别，约30万个片段）、Something-Something（174个需要时间推理的细粒度动作）和ActivityNet（200个类别，带有长、未修剪的视频）。

- **时间动作检测（temporal action detection）**超越分类：给定一个长的未修剪视频，找到每个动作的开始时间、结束时间和类别。这是目标检测的时间类比。像ActionFormer这样的方法使用Transformer处理时间特征并预测动作边界。

- **视频目标跟踪（video object tracking）**在第一帧中识别物体后，跨帧跟踪该特定物体。

- **SORT**（Simple Online and Realtime Tracking，Bewley等人，2016）将检测模型（在每帧中独立检测物体）与用于运动预测的**卡尔曼滤波器（Kalman filter）**和用于匹配的**匈牙利算法（Hungarian algorithm）**相结合。

- **卡尔曼滤波器**为每个被跟踪物体维护状态估计（位置、速度、大小），并使用线性运动模型预测它在下一帧中的位置。当新检测到达时，卡尔曼滤波器通过将预测与观测相结合来更新其估计，按各自的不确定性加权。这是应用于跟踪的贝叶斯更新（第05章）。

- **匈牙利算法**解决双线性分配问题：给定$M$个被跟踪物体和$N$个新检测，找到最小化总成本的最优一对一匹配（使用文件03中的IoU距离）。未匹配的检测开始新轨迹；未匹配的轨迹在宽限期后终止。

- **DeepSORT**通过添加**深度外观特征（deep appearance feature）**扩展了SORT：每个检测到的物体通过一个小型CNN，产生外观嵌入（描述子向量）。匹配成本将IoU距离与嵌入空间中的余弦距离（第01章）相结合。这处理了遮挡和重识别：即使一个物体在另一个物体后面消失了若干帧，其外观嵌入允许在它重新出现时重新匹配。

- **ByteTrack**（Zhang等人，2022）通过使用每个检测（包括低置信度检测）来改进跟踪。大多数跟踪器丢弃低于置信度阈值的检测。ByteTrack首先将高置信度检测与现有轨迹匹配，然后将剩余的低置信度检测与未匹配的轨迹匹配。这恢复了暂时被遮挡或模糊（因此检测置信度低）的物体。

- **三维视觉（3D vision）**恢复在二维图像投影中丢失的第三空间维度（文件01）。

- **深度估计（depth estimation）**预测从相机到场景中每个点的距离。

- **立体深度（stereo depth）**使用由已知基线$b$分隔的两个相机。同一点在左右图像中出现在不同的水平位置（此偏移称为**视差（disparity）** $d$）。深度与视差成反比：

$$Z = \frac{f \cdot b}{d}$$

- 其中$f$是焦距，$b$是基线距离。计算视差需要找到两个图像之间的对应点（立体匹配），这是沿水平扫描线的一维搜索（因为相机水平对齐，3D中相同高度的点投影到两幅图像中的同一行）。

- **单目深度估计（monocular depth estimation）**从单张图像预测深度，这从根本上是不适定的（无限多个3D场景可以产生相同的2D图像）。然而，人类使用相对大小、纹理梯度、遮挡和大气雾霾等线索毫不费力地做到这一点。深度网络从训练数据中学习这些线索。

- 像**MiDaS**和**Depth Anything**这样的模型从单张图像预测相对深度图（排列哪些物体更近）。它们在多样化数据集上使用尺度不变损失进行训练，尽管存在理论上的模糊性，但产生了非常准确的结果。

- **点云（point clouds）**是由LiDAR传感器或立体重建捕获的三维点$(x, y, z)$的集合，可选地带颜色或其他属性。与图像不同，点云是无序且不规则分布的。

- **PointNet**（Qi等人，2017）通过对每个点独立应用共享MLP，然后使用最大池化（这是置换不变的，解决了排序问题）进行聚合，直接处理点云。**PointNet++**添加了层次化分组以在多个尺度上捕获局部结构。

- **神经辐射场（NeRFs）**（Mildenhall等人，2020）将3D场景表示为一个连续函数，将3D位置$(x, y, z)$和观察方向$(\theta, \phi)$映射到颜色$(r, g, b)$和密度$\sigma$。该函数由MLP参数化：

$$F_\theta: (x, y, z, \theta, \phi) \to (r, g, b, \sigma)$$

- 要渲染一个像素，从相机通过该像素向场景投射一条光线。沿光线采样点，MLP预测每个点的颜色和密度。像素颜色通过**体渲染（volume rendering）**计算：沿光线对颜色按密度加权积分：

$$C(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \cdot \sigma(\mathbf{r}(t)) \cdot \mathbf{c}(\mathbf{r}(t), \mathbf{d}) \, dt$$

- 其中$T(t) = \exp(-\int_{t_n}^{t} \sigma(\mathbf{r}(s)) \, ds)$是累积透射率（到目前为止吸收了多少光）。实践中，该积分通过在光线上采样$N$个点并求和来近似：

$$\hat{C} = \sum_{i=1}^{N} T_i \cdot (1 - \exp(-\sigma_i \delta_i)) \cdot c_i$$

- NeRF通过最小化渲染像素和来自一组姿态照片的真实像素之间的MSE进行训练。训练后，NeRF可以从任意相机位置渲染逼真的新视角。限制是速度：渲染需要评估MLP数百万次（每像素每采样点一次），使得实时渲染困难。

- **3D高斯泼溅（3D Gaussian Splatting）**（Kerbl等人，2023）通过将场景表示为3D高斯原语的集合而不是连续的体函数来解决NeRF的速度限制。每个高斯具有3D位置（均值）、3D协方差矩阵（控制形状和方向）、不透明度和颜色（表示为用于视角依赖效果的球谐函数）。

- 渲染将每个3D高斯投影到图像平面上（产生2D高斯"splat"），按深度排序，并使用alpha混合从前到后合成。这是在GPU上实时运行的光栅化过程（100+ FPS），比NeRF的光线行进快几个数量级。高斯泼溅匹敌或超过NeRF的质量，同时支持实时渲染。

- **SLAM**（Simultaneous Localisation and Mapping，同时定位与建图）是构建未知环境地图同时跟踪相机在其中的位置的问题。它对机器人、自动驾驶和AR至关重要。

- **视觉里程计（visual odometry）**通过跨图像跟踪特征来估计帧到帧的相机运动。特征点（文件01中的SIFT、ORB）在连续帧之间匹配，相机的旋转和平移使用**本质矩阵（essential matrix）**（编码两个视图之间的几何关系，从文件01的内参和外参导出）从对应点估计。

- **基于特征的SLAM**通过维护持久地图来扩展视觉里程计。**ORB-SLAM**（Mur-Artal等人，2015）是使用最广泛的基于特征的SLAM系统。它有三个并行线程：
    1. **跟踪**：将每帧新图像中的ORB特征与地图匹配，使用PnP（Perspective-n-Point）和RANSAC估计相机姿态
    2. **局部建图**：从匹配的特征中三角化新的地图点，使用光束法平差（最小化所有看到该点的视图上的重投影误差）优化它们的位置
    3. **回环检测**：检测相机何时重新访问先前已建图的区域（使用视觉词袋），然后通过全局优化地图来纠正累积的漂移

- **LiDAR SLAM**使用来自LiDAR传感器的3D点云替代（或作为补充）相机图像。LiDAR提供直接的深度测量，使几何估计更鲁棒，但硬件成本更高。像LOAM（LiDAR Odometry and Mapping）这样的方法使用迭代最近点（ICP）对齐在连续扫描之间注册点云。

- **视觉-惯性SLAM**将相机数据与来自IMU（加速度计+陀螺仪）的测量融合。IMU提供高频旋转和加速度估计，填补相机帧之间的间隙，处理快速运动或暂时的视觉特征丢失。

- **VR/AR**应用是计算机视觉中最苛刻的消费者之一。

- **姿态估计（pose estimation）**从图像中确定人体（或面部、或手部）的位置和方向。**人体姿态**通常表示为一组2D或3D关键点位置（关节：肩、肘、腕、髋、膝、踝）。像**OpenPose**和**MediaPipe**这样的模型使用热力图回归预测这些关键点：对于每个关节，模型输出一个热力图，其峰值指示关节位置。

- **自顶向下**方法首先使用边界框检测器（文件03）检测人，然后在每个框内估计姿态。**自底向上**方法首先检测图像中的所有关键点，然后使用部件亲和场（编码连接关节之间关联的向量场）将它们分组成个体。

- **场景重建（scene reconstruction）**从传感器数据构建环境的3D模型。在AR中，这使得能够在真实表面上放置虚拟物体、在真实物体后面遮挡虚拟物体以及投射虚拟阴影。实时场景重建方法（如ARKit和ARCore中基于深度传感器的系统）构建环境的稀疏网格，该网格随用户移动而更新。

- VR中的**实时渲染（real-time rendering）**约束极其严格：双眼都需要以90+ FPS分别渲染（以避免晕动症），从头动到显示更新的延迟低于20毫秒。像**注视点渲染（foveated rendering）**（仅以高分辨率渲染用户正在看的地方，使用眼动追踪）和**重投影（reprojection）**（基于新的头部姿态扭曲前一帧以填补间隙，同时下一帧正在渲染）等技术对于满足这些约束至关重要。

- 实时神经渲染（3D高斯泼溅）、鲁棒跟踪（视觉-惯性SLAM）和高效姿态估计的融合正在使逼真的、交互式的AR/VR体验变得越来越可行。

1. 从零开始实现Lucas-Kanade光流算法。在两个合成帧之间计算光流，其中一个方块向右移动。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

def lucas_kanade(frame1, frame2, window_size=5):
    """Lucas-Kanade optical flow."""
    # Compute gradients
    Ix = jnp.zeros_like(frame1)
    Iy = jnp.zeros_like(frame1)
    It = frame2 - frame1

    # Sobel-like gradients
    Ix = Ix.at[1:-1, :].set((frame1[2:, :] - frame1[:-2, :]) / 2)
    Iy = Iy.at[:, 1:-1].set((frame1[:, 2:] - frame1[:, :-2]) / 2)

    H, W = frame1.shape
    half_w = window_size // 2
    u = jnp.zeros_like(frame1)
    v = jnp.zeros_like(frame1)

    for i in range(half_w, H - half_w):
        for j in range(half_w, W - half_w):
            Ix_win = Ix[i-half_w:i+half_w+1, j-half_w:j+half_w+1].ravel()
            Iy_win = Iy[i-half_w:i+half_w+1, j-half_w:j+half_w+1].ravel()
            It_win = It[i-half_w:i+half_w+1, j-half_w:j+half_w+1].ravel()

            A = jnp.stack([Ix_win, Iy_win], axis=1)
            ATA = A.T @ A
            ATb = -A.T @ It_win

            # Check if the system is well-conditioned
            det = ATA[0,0] * ATA[1,1] - ATA[0,1] * ATA[1,0]
            if jnp.abs(det) > 1e-6:
                flow = jnp.linalg.solve(ATA, ATb)
                u = u.at[i, j].set(flow[0])
                v = v.at[i, j].set(flow[1])

    return u, v

# Create two frames: a white square that moves right
frame1 = jnp.zeros((64, 64))
frame1 = frame1.at[20:40, 15:35].set(1.0)

frame2 = jnp.zeros((64, 64))
frame2 = frame2.at[20:40, 20:40].set(1.0)  # shifted 5 pixels right

u, v = lucas_kanade(frame1, frame2, window_size=7)

# Visualise
fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].imshow(frame1, cmap='gray'); axes[0].set_title('Frame 1'); axes[0].axis('off')
axes[1].imshow(frame2, cmap='gray'); axes[1].set_title('Frame 2'); axes[1].axis('off')

# Quiver plot of flow (subsample for clarity)
step = 4
Y, X = jnp.mgrid[0:64:step, 0:64:step]
axes[2].imshow(frame1, cmap='gray', alpha=0.5)
axes[2].quiver(X, Y, u[::step, ::step], v[::step, ::step],
               color='#e74c3c', scale=50, width=0.005)
axes[2].set_title('Optical Flow'); axes[2].axis('off')

plt.tight_layout(); plt.show()

# Check average flow in the moving region
region_u = u[20:40, 15:35]
print(f"Average horizontal flow in object region: {region_u[region_u != 0].mean():.2f} pixels")
```

2. 为二维目标跟踪实现一个简单的卡尔曼滤波器。模拟一条带噪声的轨迹，展示卡尔曼滤波器如何平滑估计。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def kalman_predict(x, P, F, Q):
    """Kalman filter prediction step."""
    x_pred = F @ x
    P_pred = F @ P @ F.T + Q
    return x_pred, P_pred

def kalman_update(x_pred, P_pred, z, H, R):
    """Kalman filter update step."""
    y = z - H @ x_pred                        # innovation
    S = H @ P_pred @ H.T + R                  # innovation covariance
    K = P_pred @ H.T @ jnp.linalg.inv(S)      # Kalman gain
    x_updated = x_pred + K @ y
    P_updated = (jnp.eye(len(x_pred)) - K @ H) @ P_pred
    return x_updated, P_updated

# State: [x, y, vx, vy]
dt = 1.0
F = jnp.array([[1, 0, dt, 0],    # state transition
                [0, 1, 0, dt],
                [0, 0, 1, 0],
                [0, 0, 0, 1]])
H = jnp.array([[1, 0, 0, 0],     # observation: we measure x, y
                [0, 1, 0, 0]])
Q = jnp.eye(4) * 0.01            # process noise
R = jnp.eye(2) * 4.0             # measurement noise (noisy detector)

# Simulate ground truth: circular motion
n_steps = 50
t = jnp.linspace(0, 2 * jnp.pi, n_steps)
true_x = 10 * jnp.cos(t) + 20
true_y = 10 * jnp.sin(t) + 20

# Noisy observations
key = jax.random.PRNGKey(42)
noise = jax.random.normal(key, (n_steps, 2)) * 2.0
obs_x = true_x + noise[:, 0]
obs_y = true_y + noise[:, 1]

# Run Kalman filter
x = jnp.array([obs_x[0], obs_y[0], 0.0, 0.0])  # initial state
P = jnp.eye(4) * 10.0                             # initial uncertainty

kalman_x, kalman_y = [], []
for i in range(n_steps):
    x, P = kalman_predict(x, P, F, Q)
    z = jnp.array([obs_x[i], obs_y[i]])
    x, P = kalman_update(x, P, z, H, R)
    kalman_x.append(x[0])
    kalman_y.append(x[1])

kalman_x = jnp.array(kalman_x)
kalman_y = jnp.array(kalman_y)

# Visualise
plt.figure(figsize=(8, 8))
plt.plot(true_x, true_y, 'k-', linewidth=2, label='Ground Truth')
plt.scatter(obs_x, obs_y, c='#e74c3c', s=20, alpha=0.5, label='Noisy Observations')
plt.plot(kalman_x, kalman_y, '#3498db', linewidth=2, label='Kalman Filter')
plt.legend(); plt.grid(alpha=0.3)
plt.title('Kalman Filter Tracking')
plt.xlabel('x'); plt.ylabel('y')
plt.axis('equal'); plt.show()

obs_error = jnp.mean(jnp.sqrt((obs_x - true_x)**2 + (obs_y - true_y)**2))
kalman_error = jnp.mean(jnp.sqrt((kalman_x - true_x)**2 + (kalman_y - true_y)**2))
print(f"Observation RMSE: {obs_error:.2f}")
print(f"Kalman filter RMSE: {kalman_error:.2f}")
print(f"Error reduction: {(1 - kalman_error/obs_error) * 100:.1f}%")
```

3. 实现一个简化的NeRF风格体渲染流水线。穿过一个简单的3D场景（已知颜色和密度的球体）投射光线，并通过沿每条光线积分来渲染图像。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def render_ray(origin, direction, spheres, n_samples=64, t_near=1.0, t_far=6.0):
    """Volume render a single ray through a scene of spheres."""
    t_vals = jnp.linspace(t_near, t_far, n_samples)
    deltas = jnp.concatenate([jnp.diff(t_vals), jnp.array([1e-3])])

    colour = jnp.zeros(3)
    transmittance = 1.0

    for i in range(n_samples):
        point = origin + t_vals[i] * direction

        # Compute density and colour at this point
        density = 0.0
        point_colour = jnp.zeros(3)

        for center, radius, col, sigma in spheres:
            dist = jnp.linalg.norm(point - center)
            # Soft sphere: density falls off with distance from surface
            d = jnp.exp(-jnp.maximum(0, dist - radius) * sigma) * sigma
            density += d
            point_colour += d * jnp.array(col)

        # Normalise colour by total density
        point_colour = jnp.where(density > 1e-6, point_colour / density, point_colour)

        # Volume rendering equation
        alpha = 1.0 - jnp.exp(-density * deltas[i])
        colour += transmittance * alpha * point_colour
        transmittance *= (1.0 - alpha)

    return colour

# Scene: three coloured spheres
spheres = [
    (jnp.array([0.0, 0.0, 4.0]), 0.8, [1.0, 0.2, 0.2], 5.0),   # red
    (jnp.array([1.5, 0.5, 5.0]), 0.6, [0.2, 1.0, 0.2], 5.0),   # green
    (jnp.array([-1.0, -0.5, 3.5]), 0.5, [0.2, 0.2, 1.0], 5.0), # blue
]

# Camera setup
img_h, img_w = 64, 64
focal = 60.0
origin = jnp.array([0.0, 0.0, 0.0])

image = jnp.zeros((img_h, img_w, 3))
for i in range(img_h):
    for j in range(img_w):
        # Compute ray direction
        px = (j - img_w / 2) / focal
        py = -(i - img_h / 2) / focal
        direction = jnp.array([px, py, 1.0])
        direction = direction / jnp.linalg.norm(direction)

        colour = render_ray(origin, direction, spheres)
        image = image.at[i, j].set(jnp.clip(colour, 0, 1))

plt.figure(figsize=(6, 6))
plt.imshow(image)
plt.title('NeRF-style Volume Rendering\n(3 spheres)')
plt.axis('off')
plt.tight_layout(); plt.show()
print(f"Image shape: {image.shape}")
print(f"Rendered {img_h * img_w} rays with 64 samples each")
```

# 卷积网络

*卷积神经网络直接从像素数据中学习空间特征层次，用梯度优化的滤波器取代手工设计的滤波器。本文件涵盖卷积机制、池化、步长、空洞卷积、感受野以及定义了图像分类的里程碑式架构（LeNet、AlexNet、VGG、ResNet、Inception、EfficientNet）。*

- 在文件01中，我们手工设计了用于边缘检测、模糊和角点检测的滤波器。一个自然的问题是：我们能否从数据中学习最优滤波器？这正是卷积神经网络（CNN）所做的。

- CNN不是手工选择滤波器权重，而是通过梯度下降（第06章）来学习它们，发现对手头任务直接有用的特征。

- 在第06章中，我们介绍了卷积运算、CNN基础知识以及滤波器学习的思想。在这里，我们更深入地探讨使CNN成为计算机视觉十多年来主导范式的架构创新。

- 回顾核心的**卷积运算（convolution operation）**：一个大小为$k \times k$的滤波器$K$在输入特征图上滑动，在每个位置计算点积（第06章）。输出大小由三个超参数控制：

    - **步长（stride）**：滤波器在位置之间移动的像素数。步长为1意味着滤波器每次移动一个像素。步长为2意味着移动两个像素，将空间维度减半。步长卷积是池化进行下采样的一种替代方案。
    - **填充（padding）**：在输入边界周围添加零。"same"填充（$p = \lfloor k/2 \rfloor$）保持空间维度不变。"valid"填充（$p = 0$）减小维度。
    - **空洞（dilation）**：在滤波器元素之间插入间隙。一个空洞为2的3x3滤波器仅使用9个参数覆盖5x5的感受野。空洞卷积在不增加计算量的情况下扩展感受野。

- 卷积后的输出空间大小：

$$\text{out} = \left\lfloor \frac{\text{in} - k + 2p}{s} \right\rfloor + 1$$

- 其中$\text{in}$是输入大小，$k$是核大小，$p$是填充，$s$是步长。该公式独立应用于高度和宽度。

- 一个神经元的**感受野（receptive field）**是能够影响其值的原始输入区域。
    - 早期层具有小的感受野（它们看到局部模式，如边缘）。
    - 更深层具有更大的感受野（它们看到更大的结构，如物体部件）。

- 感受野随每一层增长：每个卷积层大约增长$k - 1$个像素（使用步长或空洞时更多）。

![感受野跨层增长：第1层神经元看到3x3块，第2层神经元看到5x5块，第3层神经元看到原始输入的7x7块](../../images/receptive_field.svg)

- **池化层（pooling layers）**在保留最重要信息的同时减小空间维度。
    - **最大池化（max pooling）**取每个窗口中的最大值，保留最强的激活（最显著的特征）。
    - **平均池化（average pooling）**取平均值，平滑特征图。步长为2的2x2池化将两个空间维度都减半。

- **全局平均池化（Global Average Pooling，GAP）**将每个通道的整个空间范围平均为一个数字，产生一个长度等于通道数的向量。GAP取代了许多现代架构末端的全连接层，大幅减少了参数数量并起到结构性正则化器的作用。

- **批归一化（Batch Normalisation，BatchNorm）**将每个小批次内的激活归一化为零均值和单位方差，然后应用可学习的缩放和平移（第06章）。在CNN中，BatchNorm按通道应用：统计量在批次和空间维度上为每个通道独立计算。它稳定了训练，允许更高的学习率，并起到轻微正则化的作用。

- **Dropout**（第06章）在训练期间随机将神经元置零。

- 在CNN中，**空间dropout**（Dropout2D）丢弃整个特征图通道而不是单个像素，这更有效，因为特征图中相邻像素高度相关。

- **数据增强（data augmentation）**通过在训练期间对每张图像应用随机变换来人工扩展训练集：水平翻转、随机裁剪、旋转、颜色抖动（调整亮度、对比度、饱和度、色调）和cutout（遮盖随机矩形块）。网络以多种不同的形式看到每张图像，迫使它学习变换不变的特征，而不是记忆特定的像素模式。

- 高级增强策略包括**Mixup**（混合两张图像及其标签：$\tilde{x} = \lambda x_i + (1-\lambda) x_j$，$\tilde{y} = \lambda y_i + (1-\lambda) y_j$）、**CutMix**（将一张图像的矩形块粘贴到另一张图像上，并按面积比例混合标签）和**RandAugment**（使用单一强度参数从固定集合中随机采样一系列增强操作）。

- CNN架构的历史是一个逐步更深、更高效设计的故事，每个设计解决了一个限制其前身的问题。

- **LeNet-5**（LeCun等人，1998）是原始的CNN，专为手写数字识别而设计。两个卷积层后接三个全连接层，使用平均池化和tanh激活。它证明了学习的滤波器优于手工设计的特征，但以现代标准来看它很小（6万参数）。

- **AlexNet**（Krizhevsky等人，2012）以巨大优势赢得了ImageNet竞赛，点燃了深度学习革命。关键创新：ReLU激活（替代受梯度消失困扰的tanh）、用于正则化的dropout、数据增强以及在GPU上训练。五个卷积层，三个全连接层，6000万参数。

- **VGG**（Simonyan和Zisserman，2014）表明仅使用深层堆叠的3x3滤波器比使用更大的滤波器效果更好。两个堆叠的3x3滤波器具有与一个5x5滤波器相同的感受野，但参数更少（$2 \times 3^2 = 18$ vs $5^2 = 25$）且多一个非线性。VGG-16（16层）和VGG-19（19层）仍然被广泛用作特征提取器。该架构非常简单：卷积块具有递增的通道数（64、128、256、512），每个块后跟最大池化。

![VGG架构：堆叠的3x3卷积块，通道深度递增（64→128→256→512），块之间有最大池化，末端为全连接层](../../images/vgg_architecture.svg)

- **GoogLeNet/Inception**（Szegedy等人，2014）引入了**Inception模块**：不是选择单一大小的滤波器，而是并行使用1x1、3x3和5x5卷积，拼接它们的输出，让网络决定哪个尺度最有用。1x1卷积在较大滤波器之前用作瓶颈以减少计算量。GoogLeNet以12倍更少的参数（6.8M vs 138M）实现了比VGG更好的准确率。

![Inception模块：四个并行分支（1×1、3×3、5×5和池化）带有1×1瓶颈，沿通道维度拼接](../../images/inception_module.svg)

- Inception模块同时捕获多个尺度的特征。1x1滤波器捕获逐点模式，3x3捕获局部纹理，5x5捕获更大的结构。拼接将所有视角组合成一个丰富的表示。

- **ResNet**（He等人，2016）解决了**退化问题（degradation problem）**：更深的网络比更浅的网络表现更差，不是因为过拟合，而是因为它们更难优化。解决方案是**跳跃连接（skip connection）**（残差连接）：

$$\text{output} = F(x) + x$$

- 该层学习残差$F(x) = \text{output} - x$。如果最优变换接近恒等映射（这在深度网络中很常见），学习一个接近零的残差比学习完整映射容易得多。跳跃连接还提供了一条直接的梯度高速公路，减少了梯度消失。ResNet训练了152层的网络，远超以往任何深度。

![ResNet块：输入x通过两个卷积层产生F(x)，然后跳跃连接将x加回，输出F(x) + x](../../images/resnet_block.svg)

- 当输入和输出维度不同时（由于步长或通道变化），**投影捷径（projection shortcut）**对$x$应用1x1卷积以匹配维度：$\text{output} = F(x) + W_s x$。

- **瓶颈块（bottleneck block）**（用于ResNet-50及更深的网络）使用三个卷积：1x1降低通道数，3x3进行空间处理，1x1将通道数扩展回来。这比两个3x3卷积便宜，允许更深的网络。

- **DenseNet**（Huang等人，2017）进一步推进了跳跃连接的思想：在稠密块内，每一层都连接到所有后续层。层$l$接收所有前驱层的特征图作为输入：$x_l = H_l([x_0, x_1, \ldots, x_{l-1}])$，其中$[\cdot]$表示沿通道维度的拼接。这鼓励了特征重用，加强了梯度流动，并减少了参数总数。

![DenseNet稠密块：每一层通过拼接接收所有前驱层的特征图，创建最大化特征重用的稠密连接](../../images/densenet_block.svg)

- **高效架构（efficient architectures）**针对计算、内存和能量受限的移动设备和边缘硬件上的部署。

- **MobileNet**（Howard等人，2017）用**深度可分离卷积（depthwise separable convolutions）**替代标准卷积，将操作分解为两个步骤：
    1. **深度卷积（depthwise convolution）**：每个输入通道应用单个$k \times k$滤波器（无跨通道交互）
    2. **逐点卷积（pointwise convolution）**：应用1x1卷积来跨通道组合信息

- 一个标准$k \times k$卷积，具有$C_{\text{in}}$个输入通道和$C_{\text{out}}$个输出通道，每个空间位置花费$k^2 \cdot C_{\text{in}} \cdot C_{\text{out}}$次乘法。深度可分离卷积花费$k^2 \cdot C_{\text{in}} + C_{\text{in}} \cdot C_{\text{out}}$，大约减少$k^2$倍。对于3x3滤波器，这大约便宜9倍。

![深度可分离卷积：深度步骤对每个通道应用一个k×k滤波器，然后逐点1×1卷积混合通道——相同的输出形状，约9倍更少的操作](../../images/depthwise_separable_conv.svg)

- **MobileNet-V2**引入了**倒残差块（inverted residual block）**：用1x1卷积扩展通道，在扩展空间中应用深度卷积，然后用1x1卷积投影回来。跳跃连接放在窄（瓶颈）层上，颠倒了ResNet的模式。扩展比通常为6。

- **EfficientNet**（Tan和Le，2019）引入了**复合缩放（compound scaling）**：不是仅独立缩放深度、仅缩放宽度或仅缩放分辨率，而是使用固定比率同时缩放所有三个维度。给定缩放系数$\phi$：

$$\text{depth}: d = \alpha^\phi, \quad \text{width}: w = \beta^\phi, \quad \text{resolution}: r = \gamma^\phi$$

- 受$\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2$约束（使得$\phi$每增加1，总计算量大约翻倍）。网格搜索找到$\alpha = 1.2$、$\beta = 1.1$、$\gamma = 1.15$作为基准比率。EfficientNet-B0到B7逐步扩展，以比以往模型少得多的参数和FLOPs实现了最先进的准确率。

![EfficientNet复合缩放：分别缩放宽度、深度或分辨率与使用单一系数φ同时缩放所有三个维度](../../images/efficientnet_scaling.svg)

- **ShuffleNet**通过使用**分组卷积（group convolutions）**后接**通道混洗（channel shuffle）**来减少1x1卷积的成本（在MobileNet风格的架构中占主导）。分组卷积将通道分成组并在每组内独立卷积，但这阻止了跨组信息流动。混洗操作在组之间重新排列通道，以可忽略的成本恢复了信息混合。

- **迁移学习（transfer learning）**是将在一个任务上训练的模型适应到不同任务的实践。在计算机视觉中，这几乎总是意味着从在ImageNet（140万张图像，1000个类别）上预训练的模型开始，适应到特定领域的数据集（医学图像、卫星图像、制造缺陷）。

- **特征提取（feature extraction）**：冻结所有卷积层，移除最终分类头，仅在上面训练一个新头。冻结的层充当通用特征提取器。当目标领域与ImageNet相似且目标数据集很小时，这种方法效果很好。

- **微调（fine-tuning）**：解冻部分或全部卷积层，使用小学习率进行训练。预训练的权重作为起点而不是固定特征。微调通常从仅解冻后面的层开始（这些层捕获高级的、任务特定的特征），并可选择性地也解冻更早的层。

- 迁移学习之所以有效，是因为CNN的早期层学习了跨任务有用的通用特征（边缘、纹理、颜色），而后期层学习了任务特定的特征。一个被训练来分类动物的网络仍然有用于分类建筑物的有用边缘检测器。

- **可视化CNN**揭示了网络学到了什么，并有助于调试意外行为。

- **激活图（activation maps）**（特征图）显示给定输入图像的每个滤波器的输出。早期层的激活看起来像边缘图；更深层产生越来越抽象、空间粗糙的激活。

- **Grad-CAM**（梯度加权类激活映射，Selvaraju等人，2017）突出显示对模型预测最重要的输入图像区域。它的工作原理是：
    1. 计算目标类别分数相对于最后卷积层特征图的梯度（使用第03章的链式法则）
    2. 对这些梯度进行全局平均池化以获得每通道的重要性权重
    3. 计算特征图的加权组合并应用ReLU

$$L_{\text{Grad-CAM}} = \text{ReLU}\!\left(\sum_k \alpha_k A^k\right), \quad \alpha_k = \frac{1}{Z} \sum_i \sum_j \frac{\partial y^c}{\partial A^k_{ij}}$$

- 其中$A^k$是第$k$个特征图，$\alpha_k$是通道$k$的重要性权重，$y^c$是类别$c$的分数。结果是一个粗略的热力图，显示哪些区域驱动了分类。应用ReLU是因为我们关注对类别有正向影响的特征。

![Grad-CAM：狗的输入图像，最后卷积层的特征图，梯度加权组合，以及叠加在原始图像上突出显示狗脸的结果热力图](../../images/grad_cam.svg)

- **特征反演（feature inversion）**通过优化随机图像以匹配目标特征（使用像素值上的梯度下降），从其特征表示重建输入图像。这揭示了网络在每一层保留了哪些信息。早期层重建近乎完美的图像；更深层产生可识别但扭曲的图像，表明精细的空间细节丢失了，而语义内容得以保留。

- **Deep Dream**和**神经风格迁移（neural style transfer）**是特征可视化的创造性应用。Deep Dream最大化所选层神经元激活以产生超现实的、模式放大的图像。神经风格迁移优化目标图像，使其匹配一张图像的内容特征（来自深层）和另一张图像的风格特征（滤波器激活的Gram矩阵，捕获纹理统计）。

## 编程任务（使用CoLab或notebook）

1. 在JAX中从零开始实现一个简单的CNN，包含两个卷积层、最大池化和一个分类头。在合成二维模式分类任务上训练它。
```python
import jax
import jax.numpy as jnp
import jax.lax as lax
import matplotlib.pyplot as plt

def conv2d(x, kernel, stride=1):
    """Simple 2D convolution for single input, single filter."""
    return lax.conv(x[None, None], kernel[None, None], (stride, stride), 'SAME')[0, 0]

def max_pool(x, size=2):
    """2x2 max pooling."""
    H, W = x.shape
    x = x[:H//size*size, :W//size*size]
    return x.reshape(H//size, size, W//size, size).max(axis=(1, 3))

def init_cnn(key):
    k1, k2, k3 = jax.random.split(key, 3)
    return {
        'conv1': jax.random.normal(k1, (5, 5)) * 0.3,
        'conv2': jax.random.normal(k2, (3, 3)) * 0.3,
        'fc_w': jax.random.normal(k3, (64, 1)) * 0.1,
        'fc_b': jnp.zeros(1),
    }

def forward_cnn(params, img):
    # Conv1 -> ReLU -> Pool
    h = jnp.maximum(0, conv2d(img, params['conv1']))
    h = max_pool(h)
    # Conv2 -> ReLU -> Pool
    h = jnp.maximum(0, conv2d(h, params['conv2']))
    h = max_pool(h)
    # Flatten and classify
    flat = h.ravel()
    # Pad or truncate to fixed size
    flat = jnp.pad(flat, (0, max(0, 64 - len(flat))))[:64]
    logit = (flat @ params['fc_w'] + params['fc_b']).squeeze()
    return jax.nn.sigmoid(logit)

# Generate synthetic data: class 0 = low-freq pattern, class 1 = high-freq
def make_data(key, n=200):
    images, labels = [], []
    for i in range(n):
        k1, key = jax.random.split(key)
        x, y = jnp.meshgrid(jnp.linspace(0, 4*jnp.pi, 32), jnp.linspace(0, 4*jnp.pi, 32))
        if i < n // 2:
            img = jnp.sin(x) + jax.random.normal(k1, (32, 32)) * 0.1
            labels.append(0)
        else:
            img = jnp.sin(4 * x) * jnp.sin(4 * y) + jax.random.normal(k1, (32, 32)) * 0.1
            labels.append(1)
        images.append(img)
    return images, jnp.array(labels, dtype=jnp.float32)

key = jax.random.PRNGKey(42)
images, labels = make_data(key)
params = init_cnn(jax.random.PRNGKey(0))

def loss_fn(params, img, label):
    pred = forward_cnn(params, img)
    return -(label * jnp.log(pred + 1e-7) + (1 - label) * jnp.log(1 - pred + 1e-7))

grad_fn = jax.grad(loss_fn)
lr = 0.01

for epoch in range(5):
    total_loss = 0.0
    for img, label in zip(images, labels):
        grads = grad_fn(params, img, label)
        params = {k: params[k] - lr * grads[k] for k in params}
        total_loss += loss_fn(params, img, label)
    print(f"Epoch {epoch}: loss = {total_loss / len(images):.4f}")

# Test accuracy
preds = jnp.array([forward_cnn(params, img) > 0.5 for img in images])
acc = jnp.mean(preds == labels)
print(f"Accuracy: {acc:.2%}")
```

2. 可视化不同滤波器大小如何影响感受野。展示两个堆叠的3x3滤波器覆盖与一个5x5滤波器相同的感受野但参数更少。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

def compute_receptive_field(layers):
    """Compute receptive field size from a list of (kernel_size, stride) tuples."""
    rf = 1  # start with 1 pixel
    stride_product = 1
    for k, s in layers:
        rf += (k - 1) * stride_product
        stride_product *= s
    return rf

# Compare architectures
configs = {
    'Single 5x5': [(5, 1)],
    'Two 3x3':    [(3, 1), (3, 1)],
    'Three 3x3':  [(3, 1), (3, 1), (3, 1)],
    'Single 7x7': [(7, 1)],
    '3x3 stride 2 + 3x3': [(3, 2), (3, 1)],
}

print(f"{'Config':<25} {'RF':>4} {'Params (per channel)':>20}")
print('-' * 55)
for name, layers in configs.items():
    rf = compute_receptive_field(layers)
    # Parameters: sum of k^2 for each layer (per input-output channel pair)
    params = sum(k * k for k, s in layers)
    print(f"{name:<25} {rf:>4} {params:>20}")

# Visualise receptive fields
fig, axes = plt.subplots(1, 3, figsize=(14, 4))
for ax, (name, rf_size) in zip(axes, [('5x5 filter', 5), ('Two 3x3 filters', 5), ('Three 3x3 filters', 7)]):
    grid = jnp.zeros((9, 9))
    c = 4  # centre
    half = rf_size // 2
    grid = grid.at[c-half:c+half+1, c-half:c+half+1].set(1.0)
    ax.imshow(grid, cmap='Blues', vmin=0, vmax=1)
    ax.set_title(f'{name}\nRF = {rf_size}x{rf_size}')
    ax.set_xticks(range(9)); ax.set_yticks(range(9))
    ax.grid(True, alpha=0.3)
plt.suptitle('Receptive Field Comparison')
plt.tight_layout(); plt.show()
```

3. 从零开始实现Grad-CAM。给定一个预构建的简单CNN，计算特定类别的梯度加权激活图并将其可视化为热力图。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def simple_cnn(params, img):
    """Simple CNN that returns both the prediction and last conv activations."""
    # Conv layer (our "last conv layer" for Grad-CAM)
    H, W = img.shape
    k = params['conv'].shape[0]
    pad = k // 2
    img_pad = jnp.pad(img, pad, mode='edge')
    activation_map = jnp.zeros((H, W))
    for i in range(H):
        for j in range(W):
            activation_map = activation_map.at[i, j].set(
                jnp.sum(img_pad[i:i+k, j:j+k] * params['conv'])
            )
    activation_map = jnp.maximum(0, activation_map)  # ReLU

    # Global average pool -> dense -> output
    pooled = activation_map.mean()
    logit = pooled * params['w'] + params['b']
    return jax.nn.sigmoid(logit), activation_map

# Create test image: bright region on the left (class indicator)
img = jnp.zeros((32, 32))
img = img.at[8:24, 4:16].set(1.0)
img = img.at[5:10, 20:28].set(0.3)

key = jax.random.PRNGKey(42)
params = {
    'conv': jax.random.normal(key, (5, 5)) * 0.3,
    'w': jnp.array(2.0),
    'b': jnp.array(-0.5),
}

# Compute Grad-CAM
def class_score(params, img):
    pred, _ = simple_cnn(params, img)
    return pred

# Get activation map and gradients
pred, act_map = simple_cnn(params, img)
grad_fn = jax.grad(lambda img: simple_cnn(params, img)[0])
img_grad = grad_fn(img)

# Weight = global average of gradients (simplified 1-channel Grad-CAM)
alpha = img_grad.mean()
grad_cam = jnp.maximum(0, alpha * act_map)  # ReLU
grad_cam = (grad_cam - grad_cam.min()) / (grad_cam.max() - grad_cam.min() + 1e-8)

fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].imshow(img, cmap='gray'); axes[0].set_title('Input Image'); axes[0].axis('off')
axes[1].imshow(act_map, cmap='viridis'); axes[1].set_title('Activation Map'); axes[1].axis('off')
axes[2].imshow(img, cmap='gray', alpha=0.6)
axes[2].imshow(grad_cam, cmap='jet', alpha=0.4)
axes[2].set_title(f'Grad-CAM (pred={pred:.2f})'); axes[2].axis('off')
plt.tight_layout(); plt.show()
```

4. 比较深度可分离卷积与标准卷积。计算两者的参数数量和FLOPs，展示它们用少得多的计算量产生相似的输出。
```python
import jax
import jax.numpy as jnp

def standard_conv(x, kernel):
    """Standard convolution: (H, W, C_in) * (k, k, C_in, C_out) -> (H, W, C_out)."""
    H, W, C_in = x.shape
    k, _, _, C_out = kernel.shape
    pad = k // 2
    x_pad = jnp.pad(x, ((pad, pad), (pad, pad), (0, 0)), mode='constant')
    out = jnp.zeros((H, W, C_out))
    for i in range(H):
        for j in range(W):
            patch = x_pad[i:i+k, j:j+k, :]  # (k, k, C_in)
            for c in range(C_out):
                out = out.at[i, j, c].set(jnp.sum(patch * kernel[:, :, :, c]))
    return out

def depthwise_separable_conv(x, dw_kernel, pw_kernel):
    """Depthwise separable: depthwise (k,k,C_in) then pointwise (C_in, C_out)."""
    H, W, C_in = x.shape
    k = dw_kernel.shape[0]
    pad = k // 2
    x_pad = jnp.pad(x, ((pad, pad), (pad, pad), (0, 0)), mode='constant')

    # Depthwise: one filter per channel
    dw_out = jnp.zeros((H, W, C_in))
    for i in range(H):
        for j in range(W):
            for c in range(C_in):
                patch = x_pad[i:i+k, j:j+k, c]
                dw_out = dw_out.at[i, j, c].set(jnp.sum(patch * dw_kernel[:, :, c]))

    # Pointwise: 1x1 conv across channels
    out = dw_out @ pw_kernel
    return out

# Setup
H, W, C_in, C_out, k = 8, 8, 16, 32, 3
key = jax.random.PRNGKey(42)
k1, k2, k3, k4 = jax.random.split(key, 4)

x = jax.random.normal(k1, (H, W, C_in))
std_kernel = jax.random.normal(k2, (k, k, C_in, C_out)) * 0.1
dw_kernel = jax.random.normal(k3, (k, k, C_in)) * 0.1
pw_kernel = jax.random.normal(k4, (C_in, C_out)) * 0.1

# Compare
std_params = k * k * C_in * C_out
dw_params = k * k * C_in + C_in * C_out

std_flops = H * W * k * k * C_in * C_out
dw_flops = H * W * (k * k * C_in + C_in * C_out)

print(f"Standard conv:            {std_params:>8,} params,  {std_flops:>10,} FLOPs")
print(f"Depthwise separable conv: {dw_params:>8,} params,  {dw_flops:>10,} FLOPs")
print(f"Parameter reduction:      {std_params / dw_params:.1f}x")
print(f"FLOP reduction:           {std_flops / dw_flops:.1f}x")

std_out = standard_conv(x, std_kernel)
ds_out = depthwise_separable_conv(x, dw_kernel, pw_kernel)
print(f"\nStandard output shape:    {std_out.shape}")
print(f"Depthwise sep output shape: {ds_out.shape}")
```

# 目标检测与分割

*目标检测定位并分类图像中的每个物体；分割为每个像素分配一个标签。本文件涵盖IoU、mAP、锚框、R-CNN系列、YOLO、SSD、特征金字塔网络、语义/实例/全景分割（U-Net、Mask R-CNN、SAM）以及评估它们的指标。*

- 图像分类（文件02）回答"这张图像里有什么？"目标检测提出一个更难的问题："这张图像里有哪些物体，它们在哪里？"

- 分割更进一步："哪些像素属于哪个物体或类别？"这些任务形成了越来越精确的空间理解层次。

- **目标检测（object detection）**模型输出一组**边界框（bounding boxes）**，每个由四个坐标（左上角$x, y$、宽度、高度）和一个带有置信度分数的类别标签定义。单张图像可能包含零个、一个或数百个来自多个类别的物体。

![包含多个物体的输入图像，每个物体被带有类别标签和置信度分数的彩色边界框包围](../../images/detection_boxes.svg)

- **交并比（Intersection over Union，IoU）**衡量预测边界框与真实值的匹配程度。它是交集面积除以并集面积：

$$\text{IoU} = \frac{\text{交集面积}}{\text{并集面积}}$$

- IoU为1表示完美重叠；IoU为0表示根本没有重叠。"正确"检测的标准阈值是IoU $\geq 0.5$，虽然也使用更严格的阈值（0.75、0.9）。

- 如果一个检测与真实边界框的IoU超过阈值且类别正确，则为**真正例（true positive，TP）**。

- **假正例（false positive，FP）**是不匹配任何真实值的预测框。

- **假负例（false negative，FN）**是没有预测匹配到的真实物体。这些是第06章中相同的精确率/召回率概念。

- **平均精度（Average Precision，AP）**总结了一个类别的检测质量。对于每个类别，按置信度分数对所有检测进行排序，在每个排序位置计算精确率和召回率，并计算精确率-召回率曲线下的面积：

$$\text{AP} = \int_0^1 p(r) \, dr$$

- 在实践中，曲线被插值：在每个召回率级别，精确率被设置为任何召回率$\geq r$处的最大精确率。这平滑了曲线并使其单调递减。

- **平均精度均值（Mean Average Precision，mAP）**对所有类别的AP取平均。"mAP@0.5"使用IoU阈值0.5。"mAP@[.5:.95]"（COCO标准）在从0.5到0.95每步0.05的十个IoU阈值上对mAP取平均，同时奖励检测和精确定位。

- **非极大值抑制（Non-Maximum Suppression，NMS）**去除重复检测。当模型对同一物体预测多个重叠的框时，NMS保留置信度最高的框，并移除与其IoU超过阈值的所有其他框。这在模型产生原始预测后按类别应用。

- **两阶段检测器（two-stage detectors）**首先提出候选区域，然后对每个提议进行分类和精炼。

- **R-CNN**（Girshick等人，2014）是第一个成功的深度学习检测器。它使用选择性搜索（一种经典算法）提出约2000个候选区域，将每个区域变形到固定大小，独立通过CNN运行每个区域，并使用SVM分类（第06章）。R-CNN准确但极慢：每张图像运行CNN 2000次。

- **Fast R-CNN**（Girshick，2015）通过在整张图像上运行一次CNN以产生共享特征图，然后使用**RoI池化（Region of Interest pooling）**从该共享图中为每个提议提取特征来解决冗余问题。

- RoI池化取特征图的一个可变大小区域，通过将区域划分为网格并在每个单元格内进行最大池化来产生固定大小的输出。这快得多，因为昂贵的CNN计算只发生一次。

- **Faster R-CNN**（Ren等人，2015）通过引入**区域提议网络（Region Proposal Network，RPN）**消除了外部区域提议算法。RPN是一个在共享特征图上运行的小型CNN，直接预测提议。RPN在特征图上滑动一个小窗口，在每个位置预测$k$个提议（每个**锚框（anchor box）**一个）。

![Faster R-CNN流水线：输入图像→主干CNN→共享特征图→RPN生成提议→RoI池化→分类和边界框回归头](../../images/faster_rcnn.svg)

- **锚框**是特征图每个空间位置处的预定义边界框，涵盖不同的尺度和宽高比（例如，三个尺度$\times$三个比率=每位置9个锚）。RPN为每个锚预测两件事：一个物体性分数（物体vs背景）和将锚精炼为更紧致提议的坐标偏移量。这种参数化使回归问题更容易：网络预测对合理起始框的小调整，而不是预测绝对坐标。

- 锚偏移量被参数化为：

$$t_x = \frac{x - x_a}{w_a}, \quad t_y = \frac{y - y_a}{h_a}, \quad t_w = \log\frac{w}{w_a}, \quad t_h = \log\frac{h}{h_a}$$

- 其中$(x, y, w, h)$是预测框的中心和大小，$(x_a, y_a, w_a, h_a)$是锚。宽度和高度的对数变换确保预测框始终为正，并使回归尺度不变。

- Faster R-CNN使用多任务损失进行训练：类别标签的分类损失（第05章中的交叉熵），加上边界框回归的**平滑L1损失（smooth L1 loss）**。平滑L1对异常值不如L2敏感：

```math
\text{smooth}_{L1}(x) = \begin{cases} 0.5x^2 & \text{if } |x| < 1 \\ |x| - 0.5 & \text{otherwise} \end{cases}
```

- **特征金字塔网络（Feature Pyramid Networks，FPN）**（Lin等人，2017）通过构建一个自上而下的通路与横向连接来解决多尺度问题，将高级语义与低级空间细节合并。主干网络在多个尺度上产生特征图（每个池化层将分辨率减半）。FPN添加了一条自上而下的路径，其中每个级别接收来自上一级别的上采样特征，并通过横向1x1卷积将其与相应的自下而上级别合并。结果是一个特征图金字塔，每个都具有强语义和良好的空间分辨率。

- 小物体从金字塔的高分辨率级别检测；大物体从低分辨率级别检测。FPN现在是大多数现代检测架构中的标准组件。

- **单阶段检测器（one-stage detectors）**完全跳过提议步骤，在单次传递中预测类别标签和边界框。这更快，但历史上不如两阶段检测器准确，直到focal loss缩小了差距。

- **YOLO**（You Only Look Once，Redmon等人，2016）将图像划分为$S \times S$网格。每个网格单元预测$B$个边界框和$C$个类别概率。如果物体的中心落在某个网格单元中，该单元负责检测它。YOLO非常快，因为整个检测是单个前向传递，没有提议阶段。

- **YOLOv2**添加了锚框、批归一化和多尺度训练。**YOLOv3**使用了特征金字塔网络并在三个尺度上预测。**YOLOv4-v8**继续改进，使用了更好的主干网络、路径聚合网络和马赛克数据增强（在训练期间将四张图像拼接在一起以增加上下文多样性）。

- **SSD**（Single Shot MultiBox Detector，Liu等人，2016）在主干网络内的多个特征图尺度上预测，在每个尺度上使用锚框。早期（高分辨率）特征图检测小物体；后期（低分辨率）图检测大物体。SSD比Faster R-CNN快，准确率有竞争力。

- **RetinaNet**（Lin等人，2017）识别了单阶段检测器的核心问题：类别不平衡。绝大多数锚框对应背景，产生容易的负样本，这些负样本主导了损失并压制了来自罕见正样本的梯度。

- **Focal loss**通过降低容易样本的权重来解决这个问题：

$$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$

- 其中$p_t$是正确类别的预测概率。当模型对正确预测有信心时（$p_t$高），$(1 - p_t)^\gamma$很小，减少了容易负样本的损失贡献。超参数$\gamma$（通常为2）控制降权强度。当$\gamma = 0$时，focal loss退化为标准交叉熵。有了focal loss，RetinaNet以单阶段速度实现了与两阶段检测器相当的准确率。

- **无锚检测（anchor-free detection）**完全消除锚框，减少超参数调优并简化流水线。

- **FCOS**（Fully Convolutional One-Stage，Tian等人，2019）在特征图的每个空间位置预测从该位置到最近边界框四边的距离（左、上、右、下）加上类别标签。**中心度（centerness）**分数降低远离物体中心的预测权重，提高质量。FCOS使用FPN来处理多个尺度。

- **CenterNet**（Zhou等人，2019）将物体检测为点：它预测一个热力图，其中峰值对应物体中心，然后在每个峰值处回归宽度和高度。检测变成了关键点估计。这优雅且无锚，但需要仔细的热力图后处理。

- **CornerNet**将物体检测为角点对（左上和右下）。它预测两个热力图（每种角点类型一个），并使用**关联嵌入（associative embedding）**将对应的角点匹配成边界框。这避免了对锚的需求，并能处理任意形状的物体。

- **语义分割（semantic segmentation）**为图像中的每个像素分配一个类别标签。与检测（输出框）不同，分割产生密集的像素级映射。街景可能将每个像素标记为道路、人行道、汽车、行人、建筑物、天空等。

![语义分割：输入的街景及其像素级标签图，每种颜色代表一个类别](../../images/semantic_segmentation.svg)

- **全卷积网络（Fully Convolutional Networks，FCN）**（Long等人，2015）通过用卷积层替换全连接层来适应分类CNN用于分割，允许网络输出空间映射而不是单一类别。上采样（通过转置卷积或双线性插值）将输出恢复到输入分辨率。来自早期层的跳跃连接加回了在下采样期间丢失的空间细节。

- **转置卷积（transposed convolution）**（有时称为"反卷积"）是卷积的上采样对应操作。步长卷积减小空间维度，而转置卷积增加空间维度。它在输入元素之间插入零，然后应用标准卷积，有效地学习如何上采样。

- **U-Net**（Ronneberger等人，2015）引入了一种对称的编码器-解码器架构，在每个级别都有跳跃连接。编码器（收缩路径）在增加通道数的同时减小空间分辨率，就像分类CNN一样。解码器（扩展路径）上采样回全分辨率。跳跃连接在每个级别将编码器特征图与解码器特征图拼接，为解码器提供精细的空间细节。这种高级语义和低级细节的组合产生了锐利、准确的分割边界。

![U-Net架构：左侧编码器路径带下采样，右侧解码器路径带上采样，跳跃连接桥接对应级别](../../images/unet_architecture.svg)

- U-Net最初设计用于生物医学图像分割（训练数据稀缺），其架构已成为许多后续模型的基础，包括潜在扩散模型中的U-Net（文件04）。

- **DeepLab**（Chen等人，2014-2018）为分割引入了两个关键创新：

    - **空洞卷积（atrous/dilated convolution）**：在滤波器元素之间插入间隙的标准卷积，由空洞率$r$控制。空洞率为$r$的3x3滤波器具有$(2r + 1) \times (2r + 1)$的感受野，仅使用9个参数。这在不进行下采样的情况下捕获多个尺度的上下文，保持了空间分辨率。

    - **空洞空间金字塔池化（Atrous Spatial Pyramid Pooling，ASPP）**：并行应用具有不同空洞率的多个空洞卷积（例如，空洞率1、6、12、18），拼接结果，并用1x1卷积融合。ASPP同时捕获多个尺度的上下文，精神上类似于Inception模块（文件02），但使用空洞而不是不同的核大小。

- DeepLab还使用**条件随机场（Conditional Random Field，CRF）**（第05章）作为后处理步骤，通过鼓励空间邻近且颜色相似的像素共享相同标签来细化分割边界。

- **实例分割（instance segmentation）**结合了检测和分割：它识别每个单独的物体实例并为每个产生像素级掩膜。场景中的两辆车得到两个单独的掩膜，而不是两辆车都只有"car"。

- **Mask R-CNN**（He等人，2017）通过添加一个小型分割头来扩展Faster R-CNN，为每个检测到的物体预测二值掩膜。架构是Faster R-CNN + 掩膜分支：掩膜分支取RoI池化特征并为每个类别输出$m \times m$的二值掩膜。它使用**RoIAlign**而不是RoI池化：在精确采样的点处进行双线性插值而不是量化网格单元，这避免了量化造成的空间不对齐。这个小改变显著提高了掩膜质量。

- Mask R-CNN使用多任务损失训练：分类损失 + 边界框回归损失 + 掩膜损失（逐像素二值交叉熵）。掩膜分支独立地为每个类别预测掩膜；仅使用与预测类别对应的掩膜，这使掩膜预测与分类解耦，改善了两者。

- **全景分割（panoptic segmentation）**将语义分割和实例分割统一为单个任务。每个像素获得一个类别标签（语义）和一个实例ID（实例，用于像汽车和行人这样的"thing"类别）。"stuff"类别（天空、道路、草地）仅获得语义标签，因为它们是无形区域，没有可数的实例。

- 全景质量（PQ）指标通过分解为分割质量（匹配片段的平均IoU）和识别质量（匹配片段的F1分数）来评估这一点：

$$\text{PQ} = \underbrace{\frac{\sum_{(p,g) \in \text{TP}} \text{IoU}(p,g)}{|\text{TP}|}}_{\text{SQ}} \times \underbrace{\frac{|\text{TP}|}{|\text{TP}| + \frac{1}{2}|\text{FP}| + \frac{1}{2}|\text{FN}|}}_{\text{RQ}}$$

- **实时分割（real-time segmentation）**对自动驾驶和增强现实等应用至关重要，这些应用的延迟预算很紧（通常每帧低于30毫秒）。

- **BiSeNet**（Bilateral Segmentation Network，Yu等人，2018）使用两条并行路径：一条保留空间细节的宽而浅的**空间路径（spatial path）**，以及一条捕获语义的深而窄的**上下文路径（context path）**。输出被融合，同时提供速度和准确率。

- **DDRNet**（Deep Dual-Resolution Network，Hong等人，2021）在整个网络中维护两个不同分辨率的分支，并在它们之间进行重复的信息交换。高分辨率分支保留空间细节，低分辨率分支捕获全局上下文。多个双边融合模块在两个方向上合并信息。

- 实时分割的总体趋势是避免繁重的编码器-解码器模式，而是在整个网络中保持足够的空间分辨率，以牺牲一些准确率换取大幅降低的延迟。

1. 从零开始实现IoU计算和非极大值抑制。将NMS应用于一组重叠的边界框并可视化结果。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt
import matplotlib.patches as patches

def compute_iou(box1, box2):
    """Compute IoU between two boxes [x1, y1, x2, y2]."""
    x1 = jnp.maximum(box1[0], box2[0])
    y1 = jnp.maximum(box1[1], box2[1])
    x2 = jnp.minimum(box1[2], box2[2])
    y2 = jnp.minimum(box1[3], box2[3])

    intersection = jnp.maximum(0, x2 - x1) * jnp.maximum(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - intersection

    return intersection / (union + 1e-6)

def nms(boxes, scores, iou_threshold=0.5):
    """Non-Maximum Suppression."""
    order = jnp.argsort(-scores)  # sort by descending confidence
    keep = []

    remaining = list(range(len(scores)))
    order_list = order.tolist()

    while order_list:
        idx = order_list[0]
        keep.append(idx)
        order_list = order_list[1:]

        new_order = []
        for j in order_list:
            iou = compute_iou(boxes[idx], boxes[j])
            if iou < iou_threshold:
                new_order.append(j)
        order_list = new_order

    return keep

# Example: overlapping detections of the same object
boxes = jnp.array([
    [50, 60, 150, 160],   # high confidence
    [55, 65, 155, 165],   # overlapping duplicate
    [52, 58, 148, 158],   # overlapping duplicate
    [200, 100, 300, 200], # different object
    [205, 105, 305, 205], # overlapping duplicate
])
scores = jnp.array([0.95, 0.80, 0.70, 0.90, 0.60])

keep = nms(boxes, scores, iou_threshold=0.5)

fig, axes = plt.subplots(1, 2, figsize=(14, 5))
colors = ['#3498db', '#e74c3c', '#27ae60', '#9b59b6', '#f39c12']

for ax, title, indices in zip(axes, ['Before NMS', 'After NMS'],
                               [range(len(boxes)), keep]):
    ax.set_xlim(0, 400); ax.set_ylim(0, 300)
    ax.set_aspect('equal'); ax.invert_yaxis()
    ax.set_title(title)
    for i in indices:
        b = boxes[i]
        rect = patches.Rectangle((b[0], b[1]), b[2]-b[0], b[3]-b[1],
                                  linewidth=2, edgecolor=colors[i],
                                  facecolor='none')
        ax.add_patch(rect)
        ax.text(b[0], b[1]-5, f'{scores[i]:.2f}', color=colors[i], fontsize=10)

plt.tight_layout(); plt.show()
print(f"Kept {len(keep)} of {len(boxes)} boxes after NMS")
```

2. 实现一个简化的区域提议网络（RPN）。给定一个特征图，生成多个尺度和宽高比的锚框，并预测物体性分数和边界框偏移量。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt
import matplotlib.patches as patches

def generate_anchors(feature_h, feature_w, stride, scales, ratios):
    """Generate anchor boxes for each position on the feature map."""
    anchors = []
    for y in range(feature_h):
        for x in range(feature_w):
            cx = (x + 0.5) * stride
            cy = (y + 0.5) * stride
            for s in scales:
                for r in ratios:
                    w = s * jnp.sqrt(r)
                    h = s / jnp.sqrt(r)
                    anchors.append([cx - w/2, cy - h/2, cx + w/2, cy + h/2])
    return jnp.array(anchors)

def rpn_forward(feature_map, params):
    """Simplified RPN: predicts objectness and box offsets per anchor."""
    H, W, C = feature_map.shape
    n_anchors = params['cls_w'].shape[1]

    # Slide a 1x1 conv over the feature map (simplified)
    cls_scores = feature_map.reshape(-1, C) @ params['cls_w']  # (H*W, n_anchors)
    box_offsets = feature_map.reshape(-1, C) @ params['reg_w']  # (H*W, n_anchors*4)

    cls_scores = jax.nn.sigmoid(cls_scores)
    return cls_scores.ravel(), box_offsets.reshape(-1, 4)

# Setup
feature_h, feature_w, channels = 4, 4, 16
stride = 16  # each feature map cell covers 16x16 pixels
scales = [32, 64, 128]
ratios = [0.5, 1.0, 2.0]
n_anchors_per_pos = len(scales) * len(ratios)

key = jax.random.PRNGKey(42)
k1, k2, k3 = jax.random.split(key, 3)

feature_map = jax.random.normal(k1, (feature_h, feature_w, channels))
params = {
    'cls_w': jax.random.normal(k2, (channels, n_anchors_per_pos)) * 0.01,
    'reg_w': jax.random.normal(k3, (channels, n_anchors_per_pos * 4)) * 0.01,
}

anchors = generate_anchors(feature_h, feature_w, stride, scales, ratios)
```

3. 实现一个简化的一维分割U-Net编码器-解码器，带跳跃连接（对一维信号进行二值标记）。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def conv1d_same(x, kernel):
    """1D convolution with same padding."""
    k = len(kernel)
    pad = k // 2
    x_pad = jnp.pad(x, pad, mode='edge')
    n = len(x)
    out = jnp.zeros(n)
    for i in range(n):
        out = out.at[i].set(jnp.sum(x_pad[i:i+k] * kernel))
    return out

def downsample(x):
    return x[::2]

def upsample(x, target_len):
    return jnp.interp(jnp.linspace(0, 1, target_len), jnp.linspace(0, 1, len(x)), x)

def unet_1d(x, params):
    """Simplified 1D U-Net with 2 encoder/decoder levels."""
    # Encoder
    e1 = jnp.maximum(0, conv1d_same(x, params['enc1']))
    e1_down = downsample(e1)

    e2 = jnp.maximum(0, conv1d_same(e1_down, params['enc2']))
    e2_down = downsample(e2)

    # Bottleneck
    bottleneck = jnp.maximum(0, conv1d_same(e2_down, params['bottleneck']))

    # Decoder with skip connections
    d2_up = upsample(bottleneck, len(e2))
    d2 = jnp.maximum(0, conv1d_same(d2_up + e2, params['dec2']))  # skip connection

    d1_up = upsample(d2, len(e1))
    d1 = conv1d_same(d1_up + e1, params['dec1'])  # skip connection

    return jax.nn.sigmoid(d1)

# Create signal with labelled regions
n = 128
t = jnp.linspace(0, 4 * jnp.pi, n)
signal = jnp.sin(t) + 0.5 * jnp.sin(3 * t)
labels = (signal > 0.5).astype(jnp.float32)  # binary segmentation target

key = jax.random.PRNGKey(42)
keys = jax.random.split(key, 5)
params = {
    'enc1': jax.random.normal(keys[0], (5,)) * 0.3,
    'enc2': jax.random.normal(keys[1], (5,)) * 0.3,
    'bottleneck': jax.random.normal(keys[2], (3,)) * 0.3,
    'dec2': jax.random.normal(keys[3], (5,)) * 0.3,
    'dec1': jax.random.normal(keys[4], (5,)) * 0.3,
}

def loss_fn(params, signal, labels):
    pred = unet_1d(signal, params)
    return -jnp.mean(labels * jnp.log(pred + 1e-7) + (1 - labels) * jnp.log(1 - pred + 1e-7))

grad_fn = jax.jit(jax.grad(loss_fn))
lr = 0.05

for step in range(500):
    grads = grad_fn(params, signal, labels)
    params = {k: params[k] - lr * grads[k] for k in params}

pred = unet_1d(signal, params)

fig, axes = plt.subplots(3, 1, figsize=(12, 7), sharex=True)
axes[0].plot(t, signal, color='#3498db', linewidth=1.5)
axes[0].set_title('Input Signal'); axes[0].set_ylabel('Value')

axes[1].fill_between(t, 0, labels, alpha=0.3, color='#27ae60')
axes[1].set_title('Ground Truth Labels'); axes[1].set_ylabel('Label')

axes[2].plot(t, pred, color='#e74c3c', linewidth=1.5)
axes[2].fill_between(t, 0, (pred > 0.5).astype(float), alpha=0.2, color='#e74c3c')
axes[2].set_title('U-Net Prediction'); axes[2].set_ylabel('Probability')
axes[2].set_xlabel('t')

plt.tight_layout(); plt.show()
print(f"Final loss: {loss_fn(params, signal, labels):.4f}")
print(f"Pixel accuracy: {jnp.mean((pred > 0.5) == labels):.2%}")
```

# 视觉Transformer与图像生成

*视觉Transformer将自注意力应用于图像块，以数据驱动的空间学习挑战CNN的主导地位。本文件涵盖ViT、DeiT、Swin Transformer、使用GAN（StyleGAN）、VAE和扩散模型（DDPM、Stable Diffusion）的图像生成，以及超分辨率和神经风格迁移。*

- CNN（文件02）内置了强烈的空间归纳偏置：局部连接、权重共享和平移等变性。视觉Transformer（ViT）提出了一个挑衅性的问题：如果我们完全放弃这些偏置，让模型从数据中学习空间结构，仅使用第06章中的注意力机制，会怎样？

- **Vision Transformer（ViT）**（Dosovitskiy等人，2021）将标准的Transformer编码器直接应用于图像。关键思想是将图像视为一系列块（patches），就像NLP将文本视为一系列token一样。

- 该过程如下：
    1. 将图像（高度$H$、宽度$W$、通道$C$）分割成大小为$P \times P$的非重叠块的网格。这产生$N = HW / P^2$个块。
    2. 将每个块展平为长度为$P^2 \cdot C$的向量，并通过学习的线性嵌入（单个矩阵乘法，第02章）将其投影到模型维度$D$。
    3. 前置一个可学习的**[CLS] token**嵌入（类似于BERT的[CLS]，第07章）。这个token关注所有块，其最终表示用于分类。
    4. 添加**位置嵌入（position embeddings）**（每个位置一个可学习向量）以提供空间信息，因为注意力是置换等变的。
    5. 通过标准的Transformer编码器（多头自注意力 + FFN，第06章）传递$(N + 1)$个token嵌入序列。
    6. [CLS] token的最终表示通过一个分类头（一个小型MLP）。

![ViT流水线：图像分割成16x16的块，每个块被展平并线性投影，前置[CLS] token，添加位置嵌入，然后由Transformer编码器块处理](../../images/vit_pipeline.svg)

- **块嵌入（patch embedding）**等效于核大小为$P$、步长为$P$的卷积（非重叠）。ViT实际上将二维图像转换为一个一维序列，然后用与语言相同的架构处理它。

- ViT比CNN具有更少的归纳偏置：它不强制局部连接或平移等变性。这意味着它需要更多的训练数据才能从零开始学习空间结构。在小数据集上，CNN优于ViT。但当在非常大的数据集（JFT-300M，3亿张图像）上训练时，ViT匹敌或超过最好的CNN，这表明CNN的归纳偏置有助于数据效率，但对于最终性能并非必需。

- ViT自注意力在块数量上是$O(N^2)$。对于224x224的图像，使用16x16的块，$N = 196$，这是可管理的。但对于更高分辨率的图像或更小的块，二次成本变得难以承受。

- **DeiT**（Data-efficient Image Transformer，Touvron等人，2021）表明ViT可以在仅使用ImageNet（没有庞大的JFT数据集）的情况下有效训练，使用强数据增强、正则化（随机深度、标签平滑、dropout）和**知识蒸馏（knowledge distillation）**：预训练的CNN教师提供软标签，ViT学生学习匹配。DeiT在[CLS] token旁边添加了一个**蒸馏token（distillation token）**，训练来预测教师的输出。

- **Swin Transformer**（Liu等人，2021）解决了ViT的两个主要限制：其随图像大小二次增长的成本以及缺乏层次化特征图（检测和分割所需要的）。

- Swin引入了**移位窗口（shifted windows）**：不是对所有块进行全局自注意力，而是在局部窗口内计算注意力（例如，7x7块）。这使成本与图像大小成线性关系：$O(N)$而不是$O(N^2)$。但仅使用局部窗口会阻止区域之间的信息流动。

- **窗口移位（window shifting）**解决了这个问题：在交替的层中，窗口分区被移位窗口大小的一半。这创建了跨窗口连接，允许信息在没有全局注意力成本的情况下跨层在图像的所有部分之间流动。

![Swin Transformer：第l层在常规窗口内计算注意力，第l+1层将窗口分区移位一半，创建跨窗口连接](../../images/swin_shifted_windows.svg)

- Swin还通过跨阶段合并块来构建**层次化表示（hierarchical representation）**。每个阶段后，相邻的2x2块被拼接并投影，使通道维度加倍，空间分辨率减半。这产生了类似于CNN和FPN（文件03）中的多尺度特征图，使Swin直接兼容Faster R-CNN等检测头和U-Net等分割头。

- **PVT**（Pyramid Vision Transformer）采用类似的层次化方法，使用空间缩减注意力：在每个阶段，键和值在计算注意力之前进行空间下采样，在保持全局感受野的同时减少二次成本。

- **自监督视觉学习（self-supervised visual learning）**从无标签图像训练表示。标签收集昂贵，但图像很丰富。目标是在没有任何人工标注的情况下学习能很好地迁移到下游任务的特征。

- **对比学习（contrastive learning）**训练模型识别同一图像的两个增强视图（"正样本对"）应具有相似的表示，而不同图像的视图（"负样本对"）应具有不相似的表示。

- **SimCLR**（Chen等人，2020）为批次中的每张图像创建两个增强视图，使用共享主干 + 投影头对两者进行编码，并应用**NT-Xent损失**（归一化温度缩放交叉熵）：

$$\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k \neq i} \exp(\text{sim}(z_i, z_k) / \tau)}$$

- 其中$\text{sim}$是余弦相似度（第01章），$\tau$是温度参数。分子拉近正样本对；分母推开负样本对。SimCLR需要大批量（4,096+）以提供足够的负样本。

- **MoCo**（Momentum Contrast，He等人，2020）通过维护一个**动量更新的负嵌入队列**来解决大批量要求。查询编码器通过梯度下降更新；键编码器作为查询编码器的指数移动平均（EMA，第04章）进行更新：$\theta_k \leftarrow m \theta_k + (1 - m) \theta_q$，其中$m = 0.999$。队列存储最近的键嵌入，在不需要巨量批次的情况下提供大量一致的负样本。

- **BYOL**（Bootstrap Your Own Latent，Grill等人，2020）完全消除了负样本对。它使用两个网络：一个"在线"网络和一个"目标"网络（在线网络的EMA）。在线网络预测目标网络对不同增强视图的表示。没有负样本，BYOL通过预测头的不对称性和EMA目标避免了坍缩问题（模型对所有输入输出相同向量）。

- **DINO**（Self-Distillation with No Labels，Caron等人，2021）将自蒸馏应用于ViT。学生网络跨不同的增强视图预测教师网络（学生的EMA）的输出。教师使用更大的裁剪；学生使用更小的裁剪。DINO产生的特征包含关于场景布局的显式信息：DINO训练的ViT的自注意力图自然地分割对象，无需任何分割监督。

- **掩膜图像建模（masked image modelling）**是BERT掩膜语言建模（第07章）的视觉类比。输入块的大部分被掩膜，模型学习重建它们。

- **MAE**（Masked Autoencoders，He等人，2022）掩膜75%的块，并训练一个ViT编码器-解码器来重建缺失的像素值。编码器仅处理未掩膜的块（在预训练期间节省4倍计算量），轻量级解码器从编码的可见块加上可学习的掩膜token重建完整图像。

- **BEiT**（BERT Pre-training of Image Transformers，Bao等人，2022）掩膜块并预测离散的视觉token（从预训练的dVAE tokenizer获得）而不是原始像素。这类似于BERT对离散词token的预测，避免了像素重建的低级细节。

- **图像生成（image generation）**旨在产生训练集中不存在的新颖、逼真的图像。核心挑战是对自然图像的高维概率分布进行建模。

- **生成对抗网络（GAN）**（Goodfellow等人，2014）使用两个竞争的网络：一个从随机噪声创建假图像的**生成器（generator）** $G$，以及一个试图区分真图像和假图像的**判别器（discriminator）** $D$。它们以对抗方式训练：$G$试图欺骗$D$，$D$试图抓住$G$。

$$\min_G \max_D \; \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$$

- 生成器获取一个随机隐向量$z$（从简单分布如高斯采样），并通过一系列转置卷积将其映射以产生图像。判别器是一个标准的CNN分类器。在均衡状态下，$G$产生与真实数据无法区分的图像，$D$对所有输入输出0.5。

- **模式坍缩（mode collapse）**是GAN的主要失败模式：生成器学习只产生少数几种能欺骗判别器的图像类型，忽略了训练数据的多样性。生成器找到一小组"安全"的输出，而不是覆盖完整的分布。

- 稳定GAN的训练技巧包括：谱归一化（约束判别器的Lipschitz常数）、渐进式增长（首先在低分辨率训练，然后逐渐增加）、特征匹配（匹配中间判别器特征的统计量而不是最终输出），以及使用Wasserstein距离代替原始的JS散度目标。

- **StyleGAN**（Karras等人，2019）是用于高质量图像合成的最具影响力的GAN架构。其关键创新是**基于样式的生成器（style-based generator）**：不是将隐向量$z$直接输入生成器，而是首先通过**映射网络（mapping network）**（一个8层MLP）产生一个样式向量$w$。这个样式向量通过**自适应实例归一化（AdaIN）**注入生成器的每一层，调制特征图统计量：

$$\text{AdaIN}(x, y) = y_{s} \cdot \frac{x - \mu(x)}{\sigma(x)} + y_{b}$$

- 其中$y_s$和$y_b$是从$w$导出的缩放和偏置。不同层控制不同方面：早期层控制粗略特征（姿态、脸型），中间层控制中等特征（发型、眼睛），后期层控制精细细节（雀斑、头发纹理）。StyleGAN可以在1024x1024分辨率生成逼真的人脸。

- **变分自编码器（VAE）**（第06章）提供了另一种生成方法。与GAN不同，VAE具有原则性的概率框架和明确的训练目标（ELBO）。它们往往产生比GAN更模糊的图像，但提供更平滑、更结构化的隐空间。VAE是在潜在扩散模型中将图像压缩到隐空间和从隐空间解压的编码器-解码器对。

- **扩散模型（diffusion models）**已成为图像生成的主导范式，在质量和多样性上超越了GAN。其思想在概念上很简单：逐渐向数据添加噪声直到它变成纯高斯噪声（**前向过程（forward process）**），然后学习逐步逆转这个过程（**逆向过程（reverse process）**）。

- **前向过程**在$T$个时间步上添加高斯噪声：

$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} \, x_{t-1}, \beta_t I)$$

- 其中$\beta_t$是一个随时间增加的噪声调度。经过足够多的步数后，$x_T$近似为纯高斯噪声，无论原始图像$x_0$是什么。使用重参数化技巧（第06章）并设$\alpha_t = 1 - \beta_t$、$\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$，我们可以直接从$x_0$采样$x_t$：

$$x_t = \sqrt{\bar{\alpha}_t} \, x_0 + \sqrt{1 - \bar{\alpha}_t} \, \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

- **逆向过程**学习去噪：从纯噪声$x_T$开始，模型预测每步添加的噪声$\epsilon$并减去它以恢复$x_{t-1}$。这由神经网络$\epsilon_\theta$（通常是U-Net，来自文件03）参数化，使用简单的MSE损失训练：

$$\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

![扩散前向和逆向过程：干净图像在T步中逐渐被噪声破坏（前向），神经网络学习逆转每一步（逆向），从纯噪声开始生成干净图像](../../images/diffusion_process.svg)

- **DDPM**（Denoising Diffusion Probabilistic Models，Ho等人，2020）建立了这个框架。采样需要迭代所有$T$步（通常为1,000步），这很慢。**DDIM**（Denoising Diffusion Implicit Models，Song等人，2021）将采样过程重新表述为确定性映射，允许大步跳跃（例如，50步而不是1,000步），质量损失最小。

- **基于分数的模型（score-based models）**（Song和Ermon，2019）提供了另一种视角。模型不是预测噪声$\epsilon$，而是估计**分数函数（score function）** $\nabla_{x_t} \log p(x_t)$，即对数概率相对于噪声图像的梯度。这个梯度指向数据分布中更高概率（更干净）的区域。采样使用Langevin动力学沿这个梯度行进。基于分数的模型和DDPM在**随机微分方程（SDE）**框架中得到统一：前向过程是添加噪声的SDE，逆向过程是时间反转的SDE。

- **无分类器引导（classifier-free guidance）**（Ho和Salimans，2022）控制了样本质量和多样性之间的权衡。模型同时在有条件（带文本提示或类别标签）和无条件（条件随机丢弃）的情况下训练。在采样时，预测是加权组合：

$$\hat{\epsilon} = \epsilon_\theta(x_t, \varnothing) + s \cdot (\epsilon_\theta(x_t, c) - \epsilon_\theta(x_t, \varnothing))$$

- 其中$c$是条件，$\varnothing$是空条件，$s > 1$是引导尺度。更高的$s$产生更强烈匹配条件的图像，但多样性更低。$s = 1$给出无引导的模型；$s = 7.5$是常见的默认值。

- **潜在扩散（latent diffusion）**（Rombach等人，2022；Stable Diffusion）将扩散过程从像素空间移动到学习的隐空间。预训练的VAE编码器将图像压缩到低维隐表示（通常4倍或8倍空间下采样），扩散在此压缩空间中进行，VAE解码器从去噪后的隐变量重建像素。这显著更高效：在像素空间中扩散512x512图像意味着处理$512 \times 512 \times 3$的张量，但在隐空间中仅处理$64 \times 64 \times 4$的张量。

- 潜在扩散中的去噪U-Net接收带噪声的隐变量、时间步（编码为正弦嵌入，类似于Transformer中的位置编码）和条件信号（来自冻结的CLIP或T5文本编码器的文本嵌入）。文本条件通过U-Net内的交叉注意力层进入：文本嵌入作为键和值，图像特征作为查询。这使模型能够在每个空间位置关注文本提示的相关部分。

- **流匹配（flow matching）**是扩散模型的一种新兴替代方案，学习噪声和数据之间的直接传输路径，而不是DDPM的迭代去噪。

- **连续归一化流（CNF）**定义了一个时间依赖的速度场$v_\theta(x, t)$，将样本从简单分布$p_0$（噪声）沿平滑轨迹推送到数据分布$p_1$。变换遵循常微分方程（ODE）：

$$\frac{dx}{dt} = v_\theta(x, t), \quad t \in [0, 1]$$

- 从$x_0 \sim \mathcal{N}(0, I)$开始，将ODE向前积分到$t = 1$产生数据分布的样本。速度场由神经网络参数化，并训练以匹配目标条件流。

- **最优传输（optimal transport，OT）流匹配**（Lipman等人，2023）使用噪声和数据之间的直线路径作为目标流：从噪声样本$x_0$到数据样本$x_1$的条件路径简单地为$x_t = (1 - t) x_0 + t x_1$，目标速度为$v = x_1 - x_0$。训练损失变为：

$$\mathcal{L} = \mathbb{E}_{t, x_0, x_1} \left[\|v_\theta(x_t, t) - (x_1 - x_0)\|^2\right]$$

- **整流流（rectified flows）**（Liu等人，2022）迭代拉直学习到的流路径。初始训练轮次后，模型用于通过模拟ODE生成（噪声，数据）对。这些比随机配对更紧密对齐的对用于重新训练模型。重复此过程产生越来越直的路径，可以用更少的ODE步数（甚至单步）遍历，实现极快的生成。

- 流匹配比扩散有几个优势：训练目标更简单（直接速度回归，无需噪声调度），采样ODE更平滑（需要更少的积分步数），与最优传输的联系提供了理论基础。Stable Diffusion 3和Flux使用流匹配代替传统的DDPM。

## 编程任务（使用CoLab或notebook）

1. 从零开始实现ViT块嵌入。将图像分割成块，展平它们，投影到模型维度，添加位置嵌入，并前置[CLS] token。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def create_patch_embedding(image, patch_size, d_model, params):
    """Convert an image into a sequence of patch embeddings."""
    H, W, C = image.shape
    n_patches_h = H // patch_size
    n_patches_w = W // patch_size
    n_patches = n_patches_h * n_patches_w

    # Extract patches
    patches = []
    for i in range(n_patches_h):
        for j in range(n_patches_w):
            patch = image[i*patch_size:(i+1)*patch_size,
                          j*patch_size:(j+1)*patch_size, :]
            patches.append(patch.ravel())
    patches = jnp.stack(patches)  # (N, P*P*C)

    # Linear projection to d_model
    embeddings = patches @ params['proj_w'] + params['proj_b']  # (N, d_model)

    # Prepend CLS token
    cls_token = params['cls_token']  # (1, d_model)
    embeddings = jnp.concatenate([cls_token, embeddings], axis=0)  # (N+1, d_model)

    # Add position embeddings
    embeddings = embeddings + params['pos_embed']  # (N+1, d_model)

    return embeddings, patches

# Setup
H, W, C = 32, 32, 3
patch_size = 8
d_model = 64
n_patches = (H // patch_size) * (W // patch_size)  # 16

key = jax.random.PRNGKey(42)
keys = jax.random.split(key, 5)

# Create a synthetic image with distinct quadrants
image = jnp.zeros((H, W, C))
image = image.at[:16, :16, 0].set(1.0)   # red top-left
image = image.at[:16, 16:, 1].set(1.0)   # green top-right
image = image.at[16:, :16, 2].set(1.0)   # blue bottom-left
image = image.at[16:, 16:, :2].set(1.0)  # yellow bottom-right

params = {
    'proj_w': jax.random.normal(keys[0], (patch_size**2 * C, d_model)) * 0.02,
    'proj_b': jnp.zeros(d_model),
    'cls_token': jax.random.normal(keys[1], (1, d_model)) * 0.02,
    'pos_embed': jax.random.normal(keys[2], (n_patches + 1, d_model)) * 0.02,
}

embeddings, patches = create_patch_embedding(image, patch_size, d_model, params)

print(f"Image shape: {image.shape}")
print(f"Patch size: {patch_size}x{patch_size}")
print(f"Number of patches: {n_patches}")
print(f"Patch vector length: {patch_size**2 * C}")
print(f"Embedding shape: {embeddings.shape}  (CLS + {n_patches} patches)")

# Visualise patches
fig, axes = plt.subplots(2, 5, figsize=(14, 6))
axes[0, 0].imshow(image); axes[0, 0].set_title('Full Image'); axes[0, 0].axis('off')
for idx in range(min(9, n_patches)):
    ax = axes[(idx+1) // 5, (idx+1) % 5]
    patch_img = patches[idx].reshape(patch_size, patch_size, C)
    ax.imshow(patch_img); ax.set_title(f'Patch {idx}'); ax.axis('off')
plt.suptitle('ViT Patch Decomposition')
plt.tight_layout(); plt.show()
```

2. 实现一个简单的GAN训练循环。在二维数据上训练生成器和判别器，并可视化生成的分布向真实分布收敛。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def generator(z, params):
    h = jnp.tanh(z @ params['g_w1'] + params['g_b1'])
    h = jnp.tanh(h @ params['g_w2'] + params['g_b2'])
    return h @ params['g_w3'] + params['g_b3']

def discriminator(x, params):
    h = jax.nn.leaky_relu(x @ params['d_w1'] + params['d_b1'], 0.2)
    h = jax.nn.leaky_relu(h @ params['d_w2'] + params['d_b2'], 0.2)
    return jax.nn.sigmoid(h @ params['d_w3'] + params['d_b3'])

def init_params(key):
    keys = jax.random.split(key, 6)
    z_dim, h_dim, data_dim = 2, 32, 2
    scale = 0.1
    return {
        'g_w1': jax.random.normal(keys[0], (z_dim, h_dim)) * scale,
        'g_b1': jnp.zeros(h_dim),
        'g_w2': jax.random.normal(keys[1], (h_dim, h_dim)) * scale,
        'g_b2': jnp.zeros(h_dim),
        'g_w3': jax.random.normal(keys[2], (h_dim, data_dim)) * scale,
        'g_b3': jnp.zeros(data_dim),
        'd_w1': jax.random.normal(keys[3], (data_dim, h_dim)) * scale,
        'd_b1': jnp.zeros(h_dim),
        'd_w2': jax.random.normal(keys[4], (h_dim, h_dim)) * scale,
        'd_b2': jnp.zeros(h_dim),
        'd_w3': jax.random.normal(keys[5], (h_dim, 1)) * scale,
        'd_b3': jnp.zeros(1),
    }

def d_loss(params, real_data, fake_data):
    real_score = discriminator(real_data, params)
    fake_score = discriminator(fake_data, params)
    return -jnp.mean(jnp.log(real_score + 1e-7) + jnp.log(1 - fake_score + 1e-7))

def g_loss(params, fake_data):
    fake_score = discriminator(fake_data, params)
    return -jnp.mean(jnp.log(fake_score + 1e-7))

# Real data: ring distribution
key = jax.random.PRNGKey(42)
theta = jax.random.uniform(key, (512,)) * 2 * jnp.pi
real_data = jnp.stack([jnp.cos(theta), jnp.sin(theta)], axis=1)
real_data = real_data + jax.random.normal(key, real_data.shape) * 0.05

params = init_params(jax.random.PRNGKey(0))
d_grad = jax.grad(d_loss)
g_grad = jax.grad(g_loss)
lr = 0.001

snapshots = []
for step in range(3000):
    key, k1 = jax.random.split(key)
    z = jax.random.normal(k1, (512, 2))
    fake_data = generator(z, params)

    # Update discriminator
    grads = d_grad(params, real_data, fake_data)
    for k in ['d_w1', 'd_b1', 'd_w2', 'd_b2', 'd_w3', 'd_b3']:
        params[k] = params[k] - lr * grads[k]

    # Update generator
    fake_data = generator(z, params)
    grads = g_grad(params, fake_data)
    for k in ['g_w1', 'g_b1', 'g_w2', 'g_b2', 'g_w3', 'g_b3']:
        params[k] = params[k] - lr * grads[k]

    if step in [0, 500, 1500, 2999]:
        snapshots.append((step, fake_data.copy()))

fig, axes = plt.subplots(1, 4, figsize=(16, 4))
for ax, (step, fake) in zip(axes, snapshots):
    ax.scatter(real_data[:, 0], real_data[:, 1], s=5, alpha=0.3, c='#3498db', label='Real')
    ax.scatter(fake[:, 0], fake[:, 1], s=5, alpha=0.3, c='#e74c3c', label='Generated')
    ax.set_title(f'Step {step}'); ax.set_xlim(-2, 2); ax.set_ylim(-2, 2)
    ax.set_aspect('equal'); ax.legend(markerscale=3)
plt.suptitle('GAN Training: Generator Learns the Ring Distribution')
plt.tight_layout(); plt.show()
```

3. 实现扩散前向过程：在逐渐增加的时间步向图像添加噪声，并可视化渐进式破坏。然后实现单个去噪步骤。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def noise_schedule(T, beta_start=0.0001, beta_end=0.02):
    """Linear noise schedule."""
    betas = jnp.linspace(beta_start, beta_end, T)
    alphas = 1.0 - betas
    alpha_bars = jnp.cumprod(alphas)
    return betas, alphas, alpha_bars

def forward_diffusion(x0, t, alpha_bars, key):
    """Add noise to x0 at timestep t."""
    alpha_bar_t = alpha_bars[t]
    noise = jax.random.normal(key, x0.shape)
    xt = jnp.sqrt(alpha_bar_t) * x0 + jnp.sqrt(1 - alpha_bar_t) * noise
    return xt, noise

# Create a simple 2D "image" (checkerboard)
img = jnp.zeros((32, 32))
for i in range(4):
    for j in range(4):
        if (i + j) % 2 == 0:
            img = img.at[i*8:(i+1)*8, j*8:(j+1)*8].set(1.0)

T = 1000
betas, alphas, alpha_bars = noise_schedule(T)

# Visualise forward process
timesteps = [0, 50, 200, 500, 999]
key = jax.random.PRNGKey(42)

fig, axes = plt.subplots(1, len(timesteps), figsize=(16, 3.5))
for ax, t in zip(axes, timesteps):
    key, subkey = jax.random.split(key)
    xt, noise = forward_diffusion(img, t, alpha_bars, subkey)
    ax.imshow(xt, cmap='gray', vmin=-2, vmax=2)
    ax.set_title(f't={t}\n$\\bar{{\\alpha}}$={alpha_bars[t]:.3f}')
    ax.axis('off')
plt.suptitle('Diffusion Forward Process: Progressive Noise Addition')
plt.tight_layout(); plt.show()

# Simple denoising: train a tiny network to predict noise at t=200
t_denoise = 200
key, k1 = jax.random.split(key)
xt, true_noise = forward_diffusion(img, t_denoise, alpha_bars, k1)

# Tiny "denoiser": just learn a constant noise estimate (for illustration)
noise_estimate = jnp.zeros_like(img)
lr = 0.01
for step in range(100):
    residual = noise_estimate - true_noise
    noise_estimate = noise_estimate - lr * residual

# Reverse one step
alpha_bar_t = alpha_bars[t_denoise]
x_denoised = (xt - jnp.sqrt(1 - alpha_bar_t) * noise_estimate) / jnp.sqrt(alpha_bar_t)

fig, axes = plt.subplots(1, 3, figsize=(12, 4))
axes[0].imshow(img, cmap='gray'); axes[0].set_title('Original $x_0$'); axes[0].axis('off')
axes[1].imshow(xt, cmap='gray', vmin=-2, vmax=2)
axes[1].set_title(f'Noisy $x_{{200}}$'); axes[1].axis('off')
axes[2].imshow(x_denoised, cmap='gray')
axes[2].set_title('Denoised (one step)'); axes[2].axis('off')
plt.tight_layout(); plt.show()

mse = jnp.mean((x_denoised - img)**2)
print(f"Denoising MSE: {mse:.4f}")
```

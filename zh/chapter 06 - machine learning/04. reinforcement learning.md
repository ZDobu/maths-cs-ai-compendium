# 强化学习（Reinforcement Learning）

*强化学习（Reinforcement Learning，RL）通过试错训练智能体（Agent）做出序列决策，以最大化累积奖励。本文件涵盖马尔可夫决策过程（MDP）、价值函数（Value Functions）、贝尔曼方程（Bellman Equations）、Q-learning、策略梯度（Policy Gradients）、Actor-Critic 方法、PPO 和 RLHF——游戏 AI 和语言模型对齐背后的框架。*

- 监督学习需要标注数据。无监督学习在无标签数据中发现模式。**强化学习（Reinforcement Learning，RL）** 与两者都不同：智能体通过与环境的交互来学习，采取动作并获得奖励。没有正确标签；智能体必须通过试错来发现好的行为。

- 想象教一只狗学新把戏。你不会给它展示正确行为的数据集。相反，它尝试各种动作，你给好的行为食物奖励，久而久之它就明白了你的意图。RL 将这个过程形式化了。

- RL 的设置包含五个核心组件。**智能体（Agent）** 是学习者和决策者。**环境（Environment）** 是智能体外部的、与之交互的一切。在每个时间步骤，智能体观察一个**状态（State）** $s_t$，选择一个**动作（Action）** $a_t$，收到一个**奖励（Reward）** $r_t$，并转移到新状态 $s_{t+1}$。智能体的目标是最大化它随时间收集的总奖励。

![智能体-环境循环：智能体观察状态，采取动作，获得奖励，环境转移到新状态](../../images/mdp_agent_loop.svg)

- **策略（Policy）** $\pi$ 是智能体的策略：从状态到动作的映射。确定性策略（Deterministic Policy）对每个状态给出一个动作：$a = \pi(s)$。随机策略（Stochastic Policy）给出动作上的概率分布：$\pi(a \mid s)$。RL 的目标是找到最优策略，即使期望累积奖励最大化的策略。

- RL 的数学框架是**马尔可夫决策过程（Markov Decision Process，MDP）**，由一个元组 $(S, A, P, R, \gamma)$ 定义：状态集合 $S$，动作集合 $A$，转移概率 $P(s' \mid s, a)$，奖励函数 $R(s, a)$，和折扣因子 $\gamma$。

- **马尔可夫性质（Markov Property）**（来自第05章）说未来仅依赖于当前状态，而不依赖于你如何到达那里的历史：$P(s_{t+1} \mid s_t, a_t, s_{t-1}, \ldots) = P(s_{t+1} \mid s_t, a_t)$。这意味着状态包含了做决策所需的所有信息。

- **折扣因子（Discount Factor）** $\gamma \in [0, 1)$ 决定智能体对未来奖励相对于即时奖励的关心程度。从时间 $t$ 开始的折扣回报为：

$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

- $\gamma = 0$ 时，智能体完全短视，只关心下一个奖励。$\gamma$ 接近1时，智能体有远见。折扣因子也确保总和收敛（如果奖励有界），这对数学定义良好很重要。

- **价值函数（Value Functions）** 估计处于某个状态（或在某个状态下采取某个动作）有多好。**状态价值函数（State-Value Function）** $V^\pi(s)$ 是从状态 $s$ 开始并遵循策略 $\pi$ 的期望回报：

$$V^\pi(s) = \mathbb{E}_\pi \left[ G_t \mid s_t = s \right]$$

- **动作价值函数（Action-Value Function）** $Q^\pi(s, a)$ 是从状态 $s$ 开始，采取动作 $a$，然后遵循 $\pi$ 的期望回报：

$$Q^\pi(s, a) = \mathbb{E}_\pi \left[ G_t \mid s_t = s, a_t = a \right]$$

- 关系：$V^\pi(s) = \sum_a \pi(a \mid s) \, Q^\pi(s, a)$。状态价值是按策略加权的动作价值的平均值。

- **贝尔曼方程（Bellman Equation）** 表达一种递归关系：一个状态的价值等于即时奖励加上下一个状态的折扣价值。对于状态价值函数：

$$V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V^\pi(s') \right]$$

- 对于最优价值函数 $V^{*}(s)$，智能体始终选择最佳动作：

$$V^{*}(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V^{*}(s') \right]$$

- 类似地，$Q^{*}$ 的**贝尔曼最优方程（Bellman Optimality Equation）**：

$$Q^{*}(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \max_{a'} Q^{*}(s', a') \right]$$

- 一旦你有了 $Q^{*}$，最优策略是平凡的：始终选择具有最高 Q 值的动作：$\pi^{*}(s) = \arg\max_a Q^{*}(s, a)$。

- **动态规划（Dynamic Programming）** 方法在你知道转移概率和奖励（完整模型）时求解 MDP。**策略评估（Policy Evaluation）** 通过迭代应用贝尔曼方程直到收敛来计算给定策略的 $V^\pi$。**策略改进（Policy Improvement）** 取价值函数并贪心地构造一个更好的策略：$\pi'(s) = \arg\max_a \sum_{s'} P(s' \mid s, a)[R(s,a) + \gamma V^\pi(s')]$。

- **策略迭代（Policy Iteration）** 在评估和改进之间交替，直到策略不再改变。它保证收敛到最优策略。

- **价值迭代（Value Iteration）** 将两步合并为一步：重复应用贝尔曼最优方程直到 $V^{*}$ 收敛，然后提取策略。

$$V(s) \leftarrow \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a) + \gamma \, V(s') \right]$$

- 动态规划需要知道 $P(s' \mid s, a)$，这通常是不现实的。在大多数实际问题中，智能体不知道环境的动态；它只能与它交互。这就是**无模型（Model-Free）** 方法的用武之地。

- **时序差分学习（Temporal Difference Learning，TD学习）** 在不知道模型的情况下从经验中学习。关键思想是**自助法（Bootstrapping）**：与其等到回合结束才计算实际回报 $G_t$，你使用当前价值函数来估计它：

$$V(s_t) \leftarrow V(s_t) + \alpha \left[ r_t + \gamma \, V(s_{t+1}) - V(s_t) \right]$$

- 括号中的项是**TD误差（TD Error）**：**TD目标（TD Target）**（$r_t + \gamma V(s_{t+1})$）与当前估计 $V(s_t)$ 之间的差值。如果 TD 误差为正，说明该状态比预期好，我们增加其价值。如果为负，则减小。

![状态转移图，显示 TD 目标：当前价值、奖励和自助的下一个状态价值及更新公式](../../images/td_update.svg)

- TD 学习每一步都更新（而不是在完整回合之后），这使它比蒙特卡洛方法（Monte Carlo Methods）高效得多。它也适用于持续（非回合制）环境。

- **SARSA**（State-Action-Reward-State-Action，状态-动作-奖励-状态-动作）是将 TD 学习应用于 Q 值。智能体在状态 $s$ 采取动作 $a$，观察奖励 $r$ 和下一个状态 $s'$，然后根据其策略选择下一个动作 $a'$：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \, Q(s', a') - Q(s, a) \right]$$

- SARSA 是**同策略（On-Policy）** 的：它使用智能体实际采取的动作进行更新，这包含了探索。这使得 SARSA 更保守；它学习的是一个考虑了自身探索噪声的策略。

- **Q-learning** 是最著名的 RL 算法。它与 SARSA 类似，但不是使用智能体实际采取的动作，而是使用最佳可能的动作：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

- Q-learning 是**异策略（Off-Policy）** 的：无论遵循什么策略，它都学习最优 Q 值。智能体可以随机探索，同时仍在学习最优动作值。这使 Q-learning 更激进，通常收敛更快，但可能高估值。

- **探索与利用（Exploration vs Exploitation）** 是根本困境：智能体应该利用（Exploit）它已经知道的（选择具有最高估计价值的动作）还是探索（Explore）未知的动作（可能后来发现更好）？

- 最简单的策略是**epsilon-贪心（Epsilon-Greedy）**：以概率 $\epsilon$，采取随机动作（探索）；以概率 $1 - \epsilon$，采取贪心动作（利用）。常见的调度是从高 $\epsilon$（大量探索）开始，随时间衰减。

- 表格方法（为每个状态-动作对存储一个值）适用于小型离散状态空间。对于大型或连续状态空间，你需要函数逼近。**深度 Q 网络（Deep Q-Networks，DQN）** 使用神经网络来逼近 $Q(s, a; \theta)$，其中 $\theta$ 是网络权重。

- DQN 引入了两项关键稳定技术。**经验回放（Experience Replay）**：不从连续的转移中学习（它们高度相关），而是将转移存储在回放缓冲区（Replay Buffer）中，随机采样小批次进行训练。这打破了相关性并高效地重用数据。

- **目标网络（Target Network）**：使用网络的一个单独的、缓慢更新的副本计算 TD 目标。没有这一点，每次更新网络时目标都会移动，造成"追赶自己尾巴"的不稳定性。目标网络定期更新（每 $N$ 步硬更新）或连续更新（软更新：$\theta^{-} \leftarrow \tau\theta + (1-\tau)\theta^{-}$）。

- DQN 的损失就是预测 Q 值与 TD 目标之间的 MSE：

$$\mathcal{L}(\theta) = \mathbb{E} \left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta^{-}) - Q(s, a; \theta) \right)^2 \right]$$

- 到目前为止所有方法都是学习价值函数并从中推导策略。**策略梯度（Policy Gradient）** 方法采取了不同的方法：它们直接参数化策略 $\pi(a \mid s; \theta)$ 并通过梯度上升来优化期望回报。

- **策略梯度定理（Policy Gradient Theorem）** 给出了期望回报对策略参数的梯度：

$$\nabla_\theta J(\theta) = \mathbb{E}_\pi \left[ \nabla_\theta \log \pi(a \mid s; \theta) \cdot G_t \right]$$

- 这意味着：增加导致高回报的动作的概率，减少导致低回报的动作的概率。对数概率梯度给出了改变策略的方向，而 $G_t$ 缩放了改变的程度。

- **REINFORCE** 是最简单的策略梯度算法。运行一个回合，计算每个步骤的回报 $G_t$，并更新：

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot G_t$$

- REINFORCE 有高方差，因为 $G_t$ 是期望回报的带噪声的单样本估计。一个常见的修复是减去一个**基线（Baseline）**（通常是平均回报或已学习的价值函数）来在不引入偏差的情况下减少方差：

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot (G_t - b)$$

- **Actor-Critic** 方法使用两个网络。**Actor** 是策略 $\pi(a \mid s; \theta)$。**Critic** 是价值函数 $V(s; \phi)$，充当基线。优势 $A_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ 替代了 $G_t - b$：

$$\theta \leftarrow \theta + \alpha \, \nabla_\theta \log \pi(a_t \mid s_t; \theta) \cdot A_t$$

- Critic 通过最小化 TD 误差来更新，就像基于价值的方法一样。Actor 使用策略梯度更新，Critic 的优势估计降低了方差。这是两个世界最好的结合。

![双头架构：Actor 输出动作概率，Critic 输出价值估计，优势信号指导 Actor 更新](../../images/actor_critic.svg)

- **PPO**（Proximal Policy Optimization，近端策略优化）是实践中使用最广泛的策略梯度算法。它解决了一个关键问题：如果策略更新太大，性能可能灾难性地崩溃。

- PPO 使用**裁剪的替代目标（Clipped Surrogate Objective）**。设 $r_t(\theta) = \frac{\pi(a_t | s_t; \theta)}{\pi(a_t | s_t; \theta_{\text{old}})}$ 为新旧策略之间的概率比率。损失为：

$$\mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E} \left[ \min\!\left( r_t(\theta) A_t, \; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t \right) \right]$$

- 裁剪（通常 $\epsilon = 0.2$）防止比率偏离1太远，使更新保持小而稳定。如果优势为正（动作是好的），比率被限制在 $1 + \epsilon$。如果为负（动作是差的），比率被限制在 $1 - \epsilon$。这比早期的信任域方法（TRPO）更简单且更稳定。

- PPO 正是通过 **RLHF**（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）训练 ChatGPT 式模型所使用的方法。在 RLHF 中，一个奖励模型（Reward Model）在人类偏好数据上训练（人类更喜欢两个输出中的哪一个？），然后 PPO 优化语言模型的策略以最大化这个学习到的奖励。

- **DPO**（Direct Preference Optimization，直接偏好优化）通过完全消除奖励模型来简化 RLHF。不是先训练奖励模型再运行 RL，DPO 推导出一个直接根据偏好数据优化策略的闭式损失：

$$\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E} \left[ \log \sigma\!\left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right]$$

- 这里 $y_w$ 是被偏好的（获胜）回复，$y_l$ 是不被偏好的（失败）回复。DPO 增加被偏好输出的相对概率，比基于 PPO 的 RLHF 实现简单得多。

- RL 算法中有两个重要区分。**同策略 vs 异策略**：同策略方法（SARSA、PPO）从当前策略生成的数据中学习；异策略方法（Q-learning、DQN）可以从任何策略生成的数据中学习。异策略方法样本效率更高（重用旧数据）但可能更不稳定。

- **基于模型 vs 无模型**：无模型方法（目前为止讨论的所有方法）直接从经验中学习价值或策略。基于模型的方法学习环境的模型（$P(s' \mid s, a)$ 和 $R(s, a)$）并用它进行规划（在想象中推演未来轨迹而不实际采取动作）。基于模型的方法样本效率更高，但增加了学习准确模型的复杂性。

- 总结 RL 的全貌：

| 方法 | 类型 | 核心思想 | 优势 |
|---|---|---|---|
| 价值迭代 | DP，基于模型 | 贝尔曼最优性 | 精确解（小型 MDP） |
| SARSA | TD，同策略 | 同策略学习 Q | 保守、安全 |
| Q-Learning | TD，异策略 | 学习 Q*，贪心目标 | 简单、有效 |
| DQN | 深度，异策略 | 神经 Q + 回放 + 目标网络 | 扩展到高维状态 |
| REINFORCE | 策略梯度 | 对数概率梯度 * 回报 | 简单的策略优化 |
| Actor-Critic | PG + 价值 | Actor + Critic 降低方差 | 实用且灵活 |
| PPO | PG，裁剪 | 类似信任域的稳定性 | 行业标准 |
| DPO | 直接偏好 | 跳过奖励模型 | 更简单的 RLHF |

1. 为一个简单的网格世界实现价值迭代。计算最优价值函数并提取最优策略。将二者可视化为热力图和箭头图。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

# 4x4 gridworld: goal at (3,3), reward -1 per step, 0 at goal
grid_size = 4
gamma = 0.99
goal = (3, 3)

# Actions: up, down, left, right
actions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
action_names = ['up', 'down', 'left', 'right']
action_arrows = ['↑', '↓', '←', '→']

def step(s, a):
    """Deterministic transition."""
    ns = (max(0, min(grid_size-1, s[0]+a[0])),
          max(0, min(grid_size-1, s[1]+a[1])))
    return ns

# Value iteration
V = jnp.zeros((grid_size, grid_size))
for iteration in range(100):
    V_new = jnp.array(V)
    for i in range(grid_size):
        for j in range(grid_size):
            if (i, j) == goal:
                continue
            values = []
            for a in actions:
                ns = step((i, j), a)
                values.append(-1 + gamma * float(V[ns[0], ns[1]]))
            V_new = V_new.at[i, j].set(max(values))
    if jnp.max(jnp.abs(V_new - V)) < 1e-6:
        print(f"Converged in {iteration+1} iterations")
        break
    V = V_new

# Extract policy
policy = [['' for _ in range(grid_size)] for _ in range(grid_size)]
for i in range(grid_size):
    for j in range(grid_size):
        if (i, j) == goal:
            policy[i][j] = 'G'
            continue
        best_a = max(range(4), key=lambda a: -1 + gamma * float(V[step((i,j), actions[a])[0], step((i,j), actions[a])[1]]))
        policy[i][j] = action_arrows[best_a]

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
im = axes[0].imshow(V, cmap='YlOrRd_r')
axes[0].set_title("Optimal Value Function")
for i in range(grid_size):
    for j in range(grid_size):
        axes[0].text(j, i, f"{V[i,j]:.1f}", ha='center', va='center', fontsize=10)
plt.colorbar(im, ax=axes[0])

axes[1].imshow(jnp.ones((grid_size, grid_size)), cmap='Greys', vmin=0, vmax=2)
axes[1].set_title("Optimal Policy")
for i in range(grid_size):
    for j in range(grid_size):
        axes[1].text(j, i, policy[i][j], ha='center', va='center', fontsize=18)
plt.tight_layout(); plt.show()
```

2. 在一个简单的网格世界上实现表格 Q-learning。训练智能体，绘制学习曲线，展示学习到的 Q 值。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

grid_size = 5
goal = (4, 4)
actions = [(-1,0), (1,0), (0,-1), (0,1)]

# Q-table
Q = {}
for i in range(grid_size):
    for j in range(grid_size):
        Q[(i,j)] = [0.0] * 4

alpha = 0.1
gamma = 0.95
epsilon = 1.0
epsilon_decay = 0.995
min_epsilon = 0.01

def step(s, a_idx):
    a = actions[a_idx]
    ns = (max(0, min(grid_size-1, s[0]+a[0])),
          max(0, min(grid_size-1, s[1]+a[1])))
    r = 0.0 if ns == goal else -1.0
    done = ns == goal
    return ns, r, done

key = jax.random.PRNGKey(42)
rewards_per_episode = []

for ep in range(500):
    s = (0, 0)
    total_reward = 0
    for _ in range(100):
        key, subkey = jax.random.split(key)
        if float(jax.random.uniform(subkey)) < epsilon:
            key, subkey = jax.random.split(key)
            a = int(jax.random.randint(subkey, (), 0, 4))
        else:
            a = max(range(4), key=lambda i: Q[s][i])

        ns, r, done = step(s, a)
        total_reward += r
        # Q-learning update
        Q[s][a] += alpha * (r + gamma * max(Q[ns]) - Q[s][a])
        s = ns
        if done:
            break
    rewards_per_episode.append(total_reward)
    epsilon = max(min_epsilon, epsilon * epsilon_decay)

plt.figure(figsize=(8, 4))
# Smooth the curve
window = 20
smoothed = [sum(rewards_per_episode[max(0,i-window):i+1])/min(i+1, window)
            for i in range(len(rewards_per_episode))]
plt.plot(smoothed, color='#3498db', linewidth=1.5)
plt.xlabel("Episode"); plt.ylabel("Total Reward (smoothed)")
plt.title("Q-Learning on Gridworld")
plt.grid(alpha=0.3); plt.show()

# Show learned policy
arrow = ['↑', '↓', '←', '→']
print("Learned policy:")
for i in range(grid_size):
    row = ""
    for j in range(grid_size):
        if (i,j) == goal:
            row += " G "
        else:
            row += f" {arrow[max(range(4), key=lambda a: Q[(i,j)][a])]} "
    print(row)
```

3. 在一个多臂赌博机问题上实现 REINFORCE。展示策略如何在训练过程中演化，逐渐偏好最好的臂。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

# 5-armed bandit with different expected rewards
true_rewards = jnp.array([0.2, 0.5, 0.8, 0.3, 0.1])
n_arms = len(true_rewards)

# Policy: softmax over logits
logits = jnp.zeros(n_arms)
lr = 0.1
key = jax.random.PRNGKey(42)

policy_history = []
reward_history = []

for step in range(2000):
    probs = jax.nn.softmax(logits)
    policy_history.append(probs)

    # Sample action
    key, subkey = jax.random.split(key)
    action = jax.random.choice(subkey, n_arms, p=probs)

    # Get reward (Bernoulli)
    key, subkey = jax.random.split(key)
    reward = float(jax.random.uniform(subkey) < true_rewards[action])
    reward_history.append(reward)

    # REINFORCE update
    # grad log pi(a) = e_a - probs (for softmax parameterisation)
    grad_log_pi = -probs.at[action].add(1.0)  # one-hot(a) - probs
    logits = logits + lr * reward * grad_log_pi

policy_history = jnp.stack(policy_history)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
colors = ['#3498db', '#e74c3c', '#27ae60', '#9b59b6', '#f39c12']
for i in range(n_arms):
    axes[0].plot(policy_history[:, i], color=colors[i],
                 label=f'Arm {i} (true={true_rewards[i]:.1f})', linewidth=1.5)
axes[0].set_xlabel("Step"); axes[0].set_ylabel("P(arm)")
axes[0].set_title("Policy Evolution (REINFORCE)")
axes[0].legend(fontsize=8); axes[0].grid(alpha=0.3)

# Smoothed reward
window = 50
smoothed = [sum(reward_history[max(0,i-window):i+1])/min(i+1,window)
            for i in range(len(reward_history))]
axes[1].plot(smoothed, color='#27ae60', linewidth=1.5)
axes[1].axhline(y=0.8, color='#e74c3c', linestyle='--', alpha=0.5, label='Best arm')
axes[1].set_xlabel("Step"); axes[1].set_ylabel("Avg Reward")
axes[1].set_title("Reward Over Time"); axes[1].legend()
axes[1].grid(alpha=0.3)
plt.tight_layout(); plt.show()
```

# 深度学习（Deep Learning）

*深度学习堆叠非线性层来构建层次化表示，将原始输入自动转化为有用的特征。本文件涵盖多层感知机（MLP）、激活函数（Activation Functions）、反向传播（Backpropagation）、卷积神经网络（CNN）、循环神经网络（RNN）、长短期记忆网络（LSTM）、注意力机制（Attention）、Transformer、生成对抗网络（GAN）、变分自编码器（VAE）、扩散模型（Diffusion Models）和归一化技术*

- 什么使网络"深"？一个浅网络只有一层隐藏层；深度网络有许多层。深度让网络能够构建层次化的表示，早期层学习简单特征（边缘、音调），后面的层将它们组合成复杂概念（人脸、句子）。这种组合性是深度学习强大之所在。

- 最简单的深度网络是**多层感知机（Multi-Layer Perceptron，MLP）**，也称为全连接或密集网络。每层计算：

$$h = \sigma(Wx + b)$$

- 这里 $W$ 是权重矩阵（第02章），$b$ 是偏置向量，$\sigma$ 是非线性激活函数。一层的输出成为下一层的输入。如果没有非线性，堆叠层将毫无意义：$W_2(W_1 x) = (W_2 W_1)x$，这只是另一个线性变换。这正是第02章的矩阵乘法坍缩。

- **激活函数（Activation Functions）** 引入使深度有意义的非线性。

- **ReLU**（Rectified Linear Unit，修正线性单元）：$\text{ReLU}(x) = \max(0, x)$。它是最广泛使用的激活函数。计算快速，对正输入不饱和，并产生稀疏激活（许多神经元输出恰好为零）。缺点：负输入的神经元永远输出零，如果它们永久卡在那里，就会"死亡"并停止学习。

- **Sigmoid**：$\sigma(x) = \frac{1}{1+e^{-x}}$，将输入压缩到 $(0, 1)$。对二分类的输出层很有用，但在隐藏层中有问题，因为当输入远离零时梯度消失（曲线几乎平坦）。

- **Tanh**：$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$，压缩到 $(-1, 1)$。以零为中心（不像 sigmoid），有助于梯度流动，但在极端值处仍有梯度消失问题。

- **GELU**（Gaussian Error Linear Unit，高斯误差线性单元）：$\text{GELU}(x) = x \cdot \Phi(x)$，其中 $\Phi$ 是标准正态累积分布函数（CDF）。它是 ReLU 的平滑近似，允许小的负值通过。GELU 是 GPT 和 BERT 中的默认激活函数。

- **Swish**：$\text{Swish}(x) = x \cdot \sigma(x)$，另一种平滑门控。实践中与 GELU 类似。

![并排绘制 ReLU、Sigmoid、Tanh 和 GELU 及其关键属性](../../images/activation_functions.svg)

- 一个有 $d_{\text{in}}$ 个输入和 $d_{\text{out}}$ 个输出的密集层有 $d_{\text{in}} \times d_{\text{out}} + d_{\text{out}}$ 个参数（权重加偏置）。矩阵乘法 $Wx$ 就是第02章的矩阵-向量乘法。在批次设置中，输入是一个形状为 $(B, d_{\text{in}})$ 的矩阵 $X$，输出是形状为 $(B, d_{\text{out}})$ 的 $XW^T + b$。

- **万能近似定理（Universal Approximation Theorem）** 指出，一个具有足够多神经元的单隐藏层可以以任意精度逼近紧致域上的任何连续函数。这听起来好像深度不重要，但关键在于"足够多的神经元"。在实践中，深度网络可以用比浅网络指数级少的参数表示相同的函数。深度给你的是效率，而不仅仅是表达能力。

- 随着网络变深，会出现两种梯度病理现象。**梯度消失（Vanishing Gradients）**：当梯度通过许多层时（通过链式法则，第03章），它们被乘以许多因子。如果这些因子一直小于1（如 sigmoid 和 tanh 饱和时的情况），梯度指数级缩小到零。早期层几乎不学习。**梯度爆炸（Exploding Gradients）**：如果因子一直大于1，梯度指数级增长，导致数值溢出和不稳定的训练。

- 梯度消失/爆炸的解决方案：
  - 使用 ReLU 或 GELU 激活（对正输入梯度为1，不饱和）
  - 谨慎的权重初始化
  - 归一化层
  - 残差连接（跳跃连接）
  - 梯度裁剪（Gradient Clipping，用于梯度爆炸）：将梯度范数限制在最大值

- **权重初始化（Weight Initialisation）** 很重要，因为它决定了训练开始时激活和梯度的规模。如果权重太大，激活会爆炸；太小则会消失。

- **Xavier（Glorot）初始化** 从方差为 $\frac{2}{d_{\text{in}} + d_{\text{out}}}$ 的分布中采样权重。这使激活的方差在各层之间大致保持恒定，假设使用线性或 tanh 激活。

- **He（Kaiming）初始化** 使用方差 $\frac{2}{d_{\text{in}}}$，这是为 ReLU 激活校准的（因为 ReLU 将一半激活清零，你需要双倍方差来补偿）。

- **归一化层（Normalisation Layers）** 通过确保每层的输入具有一致的统计量（大致为零均值、单位方差）来稳定训练。

- **批量归一化（Batch Normalisation，BatchNorm）** 沿批次维度进行归一化：对每个通道/特征，计算小批次中所有样本的均值和方差，然后进行归一化。它添加了可学习的缩放（$\gamma$）和平移（$\beta$）参数，以便网络在需要时可以撤销归一化：

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y = \gamma \hat{x} + \beta$$

- BatchNorm 有一个问题：它依赖于批次大小。在非常小的批次中，统计量是有噪声的。在推理时，你使用运行均值而不是批次统计量，这造成了训练/测试的不一致。

- **层归一化（Layer Normalisation，LayerNorm）** 对每个单独样本沿特征维度进行归一化。它不依赖于批次中的其他样本，使其成为 Transformer 和循环网络的标准选择。

- **实例归一化（Instance Normalisation）** 对每个样本和每个通道独立地沿空间维度进行归一化。在风格迁移中很流行。

- **组归一化（Group Normalisation）** 将通道分成组，在每组内进行归一化。它是 LayerNorm 和 InstanceNorm 之间的折中方案。

![三维张量，彩色切片显示 BatchNorm、LayerNorm 和 InstanceNorm 分别在哪些维度上进行归一化](../../images/normalization_types.svg)

- **Dropout** 是一种正则化技术，在训练期间随机将一部分 $p$ 的神经元清零。这迫使网络不依赖任何单个神经元，鼓励冗余表示。在测试时，所有神经元都活跃。**Inverted Dropout** 在训练期间将激活乘以 $\frac{1}{1-p}$，这样在测试时就不需要任何缩放。这是标准实现。

- **卷积神经网络（Convolutional Neural Networks，CNNs）** 利用空间结构。与将每个输入连接到每个输出不同（如密集层），卷积层在输入上滑动一个小过滤器（卷积核），在每个位置计算点积。相同的过滤器权重在所有位置共享，这大幅减少了参数数量，并内置了平移不变性（Translation Invariance）。

- 带大小为 $k \times k$ 的过滤器 $K$ 的二维输入的**卷积运算**：

$$(\text{input} * K)[i,j] = \sum_{m=0}^{k-1} \sum_{n=0}^{k-1} \text{input}[i+m, j+n] \cdot K[m, n]$$

![输入网格，3x3 过滤器在上面滑动，在每个位置逐元素乘加，产生输出特征图](../../images/cnn_convolution.svg)

- 输出大小取决于三个超参数。**步长（Stride）** 控制过滤器在两次操作之间移动多少像素（步长为2使空间维度减半）。**填充（Padding）** 在输入边界周围加零（"same"填充保持空间大小，"valid"填充不保持）。输出大小公式：$\text{out} = \lfloor (\text{in} - k + 2p) / s \rfloor + 1$。

- **池化（Pooling）** 层下采样特征图。最大池化（Max Pooling）取每个窗口中的最大值；平均池化（Average Pooling）取均值。池化减少空间维度，同时保留最重要的信息。

- **空洞卷积（Dilated Convolutions）** 在过滤器元素之间插入间隔，在不增加参数的情况下增大感受野。空洞率（Dilation Rate）为2意味着3x3过滤器覆盖5x5的区域。

- **1x1卷积（1x1 Convolutions）** 是使用1x1过滤器的卷积。它们不查看空间邻居；而是在通道之间混合信息。可以把它想象成在每个空间位置应用一个密集层。它们用于廉价地改变通道数量。

- **跳跃连接（Skip Connections）**（残差连接）让输入绕过一层或多层：$\text{output} = F(x) + x$。该层只需学习残差 $F(x) = \text{output} - x$，当最优变换接近恒等时这更容易。残差网络（ResNets）利用这个技巧堆叠了超过100层，解决了深层网络性能不如浅层网络的退化问题。

- CNN 构建一个**特征层次结构（Feature Hierarchy）**。早期层检测边缘和纹理。中间层将这些组合成部件（眼睛、车轮）。后期层识别整个物体。每层的感受野（Receptive Field，即它能"看到"的输入区域）随深度增长。

- **嵌入（Embeddings）** 将离散标记（单词、字符、物品ID）映射到密集向量。嵌入层只是一个查找表：一个形状为（词汇表大小, 嵌入维度）的矩阵 $E$。查找标记 $i$ 意味着选择 $E$ 的第 $i$ 行。这等价于乘以一个独热向量（One-Hot Vector），这只是矩阵-向量乘法的特例（第02章）。嵌入在训练过程中被学习，因此相似的标记最终具有相似的向量。

- **分词（Tokenisation）** 是将原始文本转换为标记序列的过程。词级分词按空格分割，但无法处理未见过的单词。**子词分词（Subword Tokenisation）**（BPE、WordPiece、SentencePiece）将文本拆分为频繁的子词单元，平衡词汇量大小和覆盖率。单词"unhappiness"可能变成 ["un", "happiness"] 或 ["un", "happ", "iness"]。

- **循环神经网络（Recurrent Neural Networks，RNNs）** 一次处理一个序列元素，维护一个携带信息向前的隐藏状态：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

- 隐藏状态 $h_t$ 是网络在时间 $t$ 之前看到的所有内容的压缩摘要。相同的权重 $W_h$ 和 $W_x$ 在所有时间步上共享（权重共享，就像 CNN 共享空间权重一样）。

- 普通 RNN 难以处理长序列，因为有梯度消失问题：从第 $t$ 步到第 $t-k$ 步的梯度信号经过 $k$ 次乘以 $W_h$，它会指数级地缩小（或爆炸）。

- **LSTM**（Long Short-Term Memory，长短期记忆）通过引入一个单独的细胞状态 $c_t$ 来解决这个问题，它在时间中流动时受到最小干扰。三个门控制什么信息进入、离开和保留：

- **遗忘门（Forget Gate）** 决定从细胞状态中删除什么：$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$
- **输入门（Input Gate）** 决定写入什么新信息：$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$，候选值 $\tilde{c}_t = \tanh(W_c [h_{t-1}, x_t] + b_c)$
- 细胞状态更新：$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$
- **输出门（Output Gate）** 决定暴露什么：$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$，且 $h_t = o_t \odot \tanh(c_t)$

![LSTM 单元，显示遗忘门、输入门、输出门、细胞状态通道和数据流连接](../../images/rnn_lstm_cell.svg)

- 细胞状态就像一个传送带：信息可以跨多个时间步无变化地流动（遗忘门保持接近1），这解决了长距离依赖的梯度消失问题。

- **GRU**（Gated Recurrent Unit，门控循环单元）通过将细胞状态和隐藏状态合并为一个，并使用两个门而不是三个，简化了 LSTM：一个更新门（Update Gate，结合了遗忘和输入）和一个重置门（Reset Gate）。GRU 参数更少，通常表现与 LSTM 相当。

- RNN（包括 LSTM）的根本局限在于顺序处理：你必须先处理标记1，然后标记2，然后标记3。这阻止了并行化，并造成了信息瓶颈，因为所有上下文必须挤过固定大小的隐藏状态。

- **注意力机制（Attention）** 解决了这两个问题。不是将整个输入压缩到一个固定向量，注意力让模型回顾所有输入位置，并决定哪些与当前输出相关。

- 现代公式使用**查询、键和值（Queries, Keys, and Values，Q, K, V）**。把它想象成图书馆搜索：你有一个查询（你要找什么），键（每本书上的标签），和值（书的实际内容）。你将查询与所有键进行比较，以确定检索哪些值。

- **缩放点积注意力（Scaled Dot-Product Attention）**：

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

- $QK^T$ 计算每个查询与每个键之间的相似度。这是一个矩阵乘法（第02章），条目是点积，衡量余弦相似度（第01章）。除以 $\sqrt{d_k}$ 防止点积变得太大（这会使得 softmax 饱和并产生近乎独热的分布，梯度消失）。softmax 将相似度转换为概率分布。乘以 $V$ 产生值的加权组合。

- **多头注意力（Multi-Head Attention）** 运行 $h$ 个并行的注意力操作，每个使用不同的 Q、K 和 V 的已学习投影。这使模型能够同时关注来自不同表示子空间的信息。一个头可能关注句法关系，另一个关注语义关系。输出被拼接并投影：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O$$

- **Transformer** 架构（Vaswani et al., 2017）完全由注意力和前馈层构建，没有循环。编码器块重复：多头自注意力、相加和层归一化、前馈网络、相加和层归一化。解码器块增加了一个掩盖自注意力（Masked Self-Attention，阻止模型看到未来的标记）和一个交叉注意力层（Cross-Attention），用于关注编码器输出。

![Transformer 编码器块：多头注意力、相加和 LayerNorm、前馈网络、相加和 LayerNorm，带残差连接](../../images/transformer_block.svg)

- **位置编码（Positional Encoding）** 是必要的，因为注意力是置换等变（Permutation-Equivariant）的，这意味着它将输入视为集合而非序列。没有位置信息，"the cat sat on the mat" 和 "the mat sat on the cat" 将是相同的。原始 Transformer 使用正弦位置编码：

$$PE_{(pos, 2i)} = \sin\!\left(\frac{pos}{10000^{2i/d}}\right), \quad PE_{(pos, 2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

- 每个位置获得一个唯一的向量，模型可以用它来区分位置。现代模型通常改用可学习的位置嵌入（Positional Embeddings）或相对位置编码（RoPE、ALiBi）。

- Transformer 并行处理所有标记（自注意力矩阵 $QK^T$ 在一次矩阵乘法中计算），这使它们在现代硬件上的训练远快于 RNN。代价是自注意力在序列长度上是 $O(n^2)$（每个标记要关注每个其他标记），而 RNN 是 $O(n)$。这就是为什么长上下文模型需要特殊的注意力变体（稀疏注意力、线性注意力、Flash Attention）。

- **视觉 Transformer（Vision Transformers，ViT）** 将 Transformer 应用于图像，通过将图像分割成固定大小的块（例如16x16），将每个块展平为向量，并将块视为标记序列。一个可学习的 [CLS] 标记被前置，其最终表示用于分类。尽管没有任何卷积的归纳偏置（Inductive Bias），ViT 在足够多的数据上训练时可以匹敌或超越 CNN。

- **MLP-Mixer** 是一种更简单的架构，用 MLP 替代了注意力和卷积。它在"标记混合"MLP（跨空间位置应用）和"通道混合"MLP（跨特征应用）之间交替。它的表现具有竞争力，表明现代架构的关键洞见不是注意力本身，而是跨标记和特征的高效信息混合。

- **自编码器（Autoencoders）** 通过训练网络重构自身的输入来学习压缩表示。编码器将输入映射到低维瓶颈（潜在编码），解码器将其映射回去：

$$z = f_{\text{enc}}(x), \quad \hat{x} = f_{\text{dec}}(z), \quad \mathcal{L} = \|x - \hat{x}\|^2$$

- 瓶颈迫使网络学习最重要的特征。自编码器用于降维、去噪（在带噪声输入上训练，重构干净输出）和异常检测（高重构误差表示异常输入）。

- **变分自编码器（Variational Autoencoders，VAEs）** 加入了概率的视角。不是编码到一个单一的点 $z$，编码器输出分布的参数（高斯的均值 $\mu$ 和方差 $\sigma^2$）。潜在编码从该分布中采样：$z = \mu + \sigma \odot \epsilon$，其中 $\epsilon \sim \mathcal{N}(0, I)$。这个**重参数化技巧（Reparameterisation Trick）** 使采样可微分，因此梯度可以流通。

- VAE 损失有两项：

$$\mathcal{L} = \underbrace{\|x - \hat{x}\|^2}_{\text{reconstruction}} + \underbrace{D_{\text{KL}}(q(z|x) \| p(z))}_{\text{regularisation}}$$

- KL 散度项（来自第05章）将学习到的后验分布 $q(z|x)$ 推向先验 $p(z) = \mathcal{N}(0, I)$，确保潜在空间平滑且结构良好。然后你可以从先验中采样并解码来生成新数据。这正是 VAE 成为生成式模型的原因。

## 编程任务（使用 CoLab 或 notebook）

1. 在 JAX 中从零构建一个简单的 MLP。在一个二维分类问题（例如同心圆）上训练，可视化决策边界。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt
from sklearn.datasets import make_circles

# Data
X, y = make_circles(n_samples=500, noise=0.1, factor=0.5, random_state=42)
X, y = jnp.array(X), jnp.array(y, dtype=jnp.float32)

# Initialise a 2-layer MLP: 2 -> 16 -> 16 -> 1
def init_params(key):
    k1, k2, k3 = jax.random.split(key, 3)
    return {
        'W1': jax.random.normal(k1, (2, 16)) * 0.5,
        'b1': jnp.zeros(16),
        'W2': jax.random.normal(k2, (16, 16)) * 0.5,
        'b2': jnp.zeros(16),
        'W3': jax.random.normal(k3, (16, 1)) * 0.5,
        'b3': jnp.zeros(1),
    }

def forward(params, x):
    h = jnp.maximum(0, x @ params['W1'] + params['b1'])  # ReLU
    h = jnp.maximum(0, h @ params['W2'] + params['b2'])   # ReLU
    logit = (h @ params['W3'] + params['b3']).squeeze()
    return jax.nn.sigmoid(logit)

def loss_fn(params, X, y):
    pred = forward(params, X)
    return -jnp.mean(y * jnp.log(pred + 1e-7) + (1 - y) * jnp.log(1 - pred + 1e-7))

grad_fn = jax.jit(jax.grad(loss_fn))
params = init_params(jax.random.PRNGKey(0))
lr = 0.1

for step in range(2000):
    grads = grad_fn(params, X, y)
    params = {k: params[k] - lr * grads[k] for k in params}

# Plot decision boundary
xx, yy = jnp.meshgrid(jnp.linspace(-2, 2, 200), jnp.linspace(-2, 2, 200))
grid = jnp.column_stack([xx.ravel(), yy.ravel()])
zz = forward(params, grid).reshape(xx.shape)

plt.figure(figsize=(7, 6))
plt.contourf(xx, yy, zz, levels=[0, 0.5, 1], alpha=0.3, colors=['#e74c3c', '#3498db'])
plt.scatter(X[y==0,0], X[y==0,1], c='#e74c3c', s=10, label='Class 0')
plt.scatter(X[y==1,0], X[y==1,1], c='#3498db', s=10, label='Class 1')
plt.title("MLP Decision Boundary on Concentric Circles")
plt.legend(); plt.grid(alpha=0.3); plt.show()

acc = jnp.mean((forward(params, X) > 0.5) == y)
print(f"Accuracy: {acc:.2%}")
```

2. 从零实现一维卷积。将一个简单的边缘检测过滤器应用于信号，并与内置的 `jnp.convolve` 比较。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

def conv1d(signal, kernel):
    """1D convolution (valid mode) from scratch."""
    n, k = len(signal), len(kernel)
    output = jnp.zeros(n - k + 1)
    for i in range(n - k + 1):
        output = output.at[i].set(jnp.sum(signal[i:i+k] * kernel))
    return output

# Create a signal with a step function
t = jnp.linspace(0, 4, 200)
signal = jnp.where(t < 1, 0.0, jnp.where(t < 2, 1.0, jnp.where(t < 3, 0.5, 1.5)))

# Edge detection kernel
edge_kernel = jnp.array([-1.0, 0.0, 1.0])

# Our implementation vs built-in
our_output = conv1d(signal, edge_kernel)
jnp_output = jnp.convolve(signal, edge_kernel, mode='valid')

fig, axes = plt.subplots(3, 1, figsize=(10, 6), sharex=True)
axes[0].plot(t, signal, color='#3498db', linewidth=1.5)
axes[0].set_title("Original Signal"); axes[0].set_ylabel("Value")

axes[1].plot(t[:len(our_output)], our_output, color='#e74c3c', linewidth=1.5)
axes[1].set_title("After Edge Detection (our conv1d)"); axes[1].set_ylabel("Value")

axes[2].plot(t[:len(jnp_output)], jnp_output, color='#27ae60', linewidth=1.5, linestyle='--')
axes[2].set_title("After Edge Detection (jnp.convolve)"); axes[2].set_ylabel("Value")
axes[2].set_xlabel("t")

plt.tight_layout(); plt.show()
print(f"Outputs match: {jnp.allclose(our_output, jnp_output)}")
```

3. 从零实现缩放点积注意力。为一个小的例子计算注意力权重，并将注意力矩阵可视化为热力图。

import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def scaled_dot_product_attention(Q, K, V):
    """Scaled dot-product attention."""
    d_k = Q.shape[-1]
    scores = Q @ K.T / jnp.sqrt(d_k)
    weights = jax.nn.softmax(scores, axis=-1)
    output = weights @ V
    return output, weights

# Example: 4 tokens, embedding dim 8

K = jax.random.normal(k2, (seq_len, d_model))
V = jax.random.normal(k3, (seq_len, d_model))

output, weights = scaled_dot_product_attention(Q, K, V)

print(f"Q shape: {Q.shape}")
print(f"Attention weights shape: {weights.shape}")
print(f"Output shape: {output.shape}")
print(f"\nAttention weights (rows sum to 1):")

4. 构建一个简单的自编码器，将二维数据通过一维瓶颈压缩并重构。可视化潜在空间和重构结果。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons

# Data
X, _ = make_moons(n_samples=500, noise=0.05, random_state=42)
X = jnp.array(X)

# Autoencoder: 2 -> 8 -> 1 -> 8 -> 2
def init_ae(key):
    k1, k2, k3, k4 = jax.random.split(key, 4)
    return {
        'enc_W1': jax.random.normal(k1, (2, 8)) * 0.5, 'enc_b1': jnp.zeros(8),
        'enc_W2': jax.random.normal(k2, (8, 1)) * 0.5, 'enc_b2': jnp.zeros(1),
        'dec_W1': jax.random.normal(k3, (1, 8)) * 0.5, 'dec_b1': jnp.zeros(8),
        'dec_W2': jax.random.normal(k4, (8, 2)) * 0.5, 'dec_b2': jnp.zeros(2),
    }

def encode(p, x):
    h = jnp.tanh(x @ p['enc_W1'] + p['enc_b1'])
    return h @ p['enc_W2'] + p['enc_b2']

def decode(p, z):
    h = jnp.tanh(z @ p['dec_W1'] + p['dec_b1'])
    return h @ p['dec_W2'] + p['dec_b2']

def ae_loss(p, X):
    z = encode(p, X)
    X_hat = decode(p, z)
    return jnp.mean((X - X_hat) ** 2)

grad_fn = jax.jit(jax.grad(ae_loss))
params = init_ae(jax.random.PRNGKey(0))
lr = 0.01

for step in range(3000):
    grads = grad_fn(params, X)
    params = {k: params[k] - lr * grads[k] for k in params}

z = encode(params, X)
X_hat = decode(params, z)

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].scatter(X[:,0], X[:,1], c=z.squeeze(), cmap='viridis', s=10)
axes[0].set_title("Original Data (coloured by latent code)")
axes[1].scatter(X_hat[:,0], X_hat[:,1], c=z.squeeze(), cmap='viridis', s=10)
axes[1].set_title("Reconstruction from 1D bottleneck")
for ax in axes:
    ax.set_aspect('equal'); ax.grid(alpha=0.3)
plt.tight_layout(); plt.show()

print(f"Reconstruction MSE: {ae_loss(params, X):.4f}")
```

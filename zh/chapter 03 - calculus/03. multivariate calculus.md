# 多元微积分

*多元微积分将导数和积分扩展到多变量函数——这在 ML 模型拥有数百万参数的情况下至关重要。本篇涵盖偏导数、梯度、Jacobian 矩阵、Hessian 矩阵以及使反向传播成为可能的多变量链式法则。*

- 到目前为止，我们的函数接收单一输入 $x$ 并产生单一输出 $f(x)$。但在 ML 中，我们几乎从不只处理一个变量。

- 考虑一个两变量函数，如 $f(x, y) = x^2 + y^2$。这定义了一个 3D 空间中的曲面——一个碗的形状。我们想知道：如果我们在保持 $y$ 不变的同时稍微推动 $x$，$f$ 如何变化？这就是**偏导数**（partial derivative）。

- $f$ 对 $x$ 的**偏导数**，记作 $\frac{\partial f}{\partial x}$，将其他每个变量视为常数，正常对 $x$ 求导。

- 对 $f(x, y) = x^2y + 3x - 2y$：

$$\frac{\partial f}{\partial x} = 2xy + 3 \qquad \frac{\partial f}{\partial y} = x^2 - 2$$

- 计算 $\frac{\partial f}{\partial x}$ 时，将 $y$ 当作常数，因此 $x^2y$ 求导为 $2xy$，$3x$ 为 $3$，$-2y$ 为 $0$。

- 计算 $\frac{\partial f}{\partial y}$ 时，将 $x$ 当作常数，因此 $x^2y$ 求导为 $x^2$，$3x$ 为 $0$，$-2y$ 为 $-2$。

- 几何上，对 $x$ 求偏导数就像用一个平行于 $xz$ 平面的平面（在某个固定的 $y$ 值处）切过 3D 曲面，并求所得曲线的斜率。

![偏导数：通过固定一个变量来切片曲面](../../images/partial_derivative.svg)

- **梯度**（gradient）将所有偏导数收集到一个向量中：

$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right)$$

- 对 $f(x, y) = x^2 + y^2$：$\nabla f(x, y) = (2x, 2y)$。在点 $(1, 2)$ 处：$\nabla f(1, 2) = (2, 4)$。

- 梯度有两个关键性质：

    - **方向**：它指向最陡上升的方向。想象一个登山者在一座山上。其位置处的梯度指向正上山方向，沿最陡的路径。

    - **大小**：$\|\nabla f\|$ 给出沿该最陡方向的上升速率。大梯度意味着地形陡峭；小梯度意味着近于平坦。

![梯度向量指向上坡，垂直于等高线](../../images/gradient_contour.svg)

- 由于梯度指向上坡，沿相反方向移动（$-\nabla f$）则向下坡走，走向更低的值。这个简单想法是**梯度下降**（gradient descent）的基础——我们将在后续章节中详细探讨的一种优化技术。目前，关键要点是梯度告诉你哪个方向是"上坡"以及爬升有多陡。

- **方向导数**（directional derivative）推广了偏导数。不是问"$f$ 沿 $x$ 轴方向如何变化？"，而是问"$f$ 沿任意方向 $\mathbf{u}$ 如何变化？"它计算为梯度与单位向量的点积：

$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$$

- 对于 $f(x, y) = x^2 + y^2$ 在 $(1, 2)$ 沿 $\mathbf{v} = (3, 4)$ 的方向：首先归一化得 $\mathbf{u} = (3/5, 4/5)$，然后 $D_{\mathbf{u}} f = (2, 4) \cdot (3/5, 4/5) = 6/5 + 16/5 = 22/5$。

- 偏导数是方向导数在方向沿坐标轴时的特例。如果方向导数在某方向上为零，函数在该方向上是平坦的。

- **等高线**（contour line，或等值线）连接函数值相同的点。对 $f(x, y) = x^2 + y^2$，等高线是以原点为中心的圆：$x^2 + y^2 = c$ 对不同 $c$ 值。

- 等高线永不相交（一个点不能有两个不同的函数值）。

- 梯度始终垂直于等高线，指向由低到高的方向。

- 密集的等高线表示陡峭地形；间距大的线表示缓坡。

- 到目前为止，我们的函数产生单个输出。但许多函数产生多个输出。函数 $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ 接收 $n$ 个输入并产生 $m$ 个输出。**Jacobian 矩阵**组织这种向量值函数的所用偏导数：

```math
J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}
```

- Jacobian 的每一行是一个输出分量的梯度。对有 3 个输入和 2 个输出的函数，Jacobian 是一个 $2 \times 3$ 矩阵。

- Jacobian 将导数推广到向量值函数。

- 正如标量函数的导数告诉你输出随输入变化多少，Jacobian 告诉你每个输出相对于每个输入的变化。

- **Jacobian 的行列式**衡量变换在局部拉伸或压缩空间的程度。

- 若行列式为 2，小块区域的面积加倍。若为 0，变换将空间压缩到更低的维度（回想我们在矩阵章节中学过的：零行列式意味着一个奇异的、不可逆的变换）。

- 当多个变换复合（一个的结果输入到下一个），整体映射的 Jacobian 是各个 Jacobian 的乘积。我们将在后续章节中看到这个想法变得至关重要。

- 梯度捕捉一阶信息（斜率），而**Hessian 矩阵**捕捉二阶信息（曲率）。

- 对标量函数 $f(x_1, \ldots, x_n)$，Hessian 是所有二阶偏导数的 $n \times n$ 矩阵：

```math
H = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix}
```

- 对 $f(x, y) = x^3 + 2xy^2 - y^3$，梯度是 $(3x^2 + 2y^2,\; 4xy - 3y^2)$，Hessian 是：

```math
H = \begin{bmatrix} 6x & 4y \\ 4y & 4x - 6y \end{bmatrix}
```

- 对角线条目（$6x$ 和 $4x - 6y$）告诉你 $x$ 方向的斜率在沿 $x$ 移动时如何变化，$y$ 方向同理。

- 非对角线条目（$4y$）告诉你一个方向的斜率在沿另一方向移动时如何变化。

- **Clairaut 定理**保证，对于具有连续二阶导数的函数，混合偏导数相等：$\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}$。

- 这意味着 Hessian 是对称的，这（如我们在矩阵章节中看到的）保证了实特征值和正交特征向量。

- Hessian 告诉我们临界点（梯度为零处）附近函数的形状：

    - 若 $H$ 正定（所有特征值正），该点是**局部最小值**（local minimum）——曲面在每个方向向上弯曲，像碗一样。
    - 若 $H$ 负定（所有特征值负），该点是**局部最大值**（local maximum）——曲面在每个方向向下弯曲，像倒扣的碗。
    - 若 $H$ 既有正特征值又有负特征值，该点是**鞍点**（saddle point）——曲面在一些方向向上弯曲，其他方向向下弯曲，像山坳。

- **多变量链式法则**将链式法则扩展到多个变量的函数。若 $z = f(x, y)$ 其中 $x = g(t)$ 和 $y = h(t)$，则：

$$\frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$$

- 从 $t$ 到 $z$ 的每条路径贡献一项：沿该路径的偏导数乘以中间变量对 $t$ 的导数。

- 例如，若 $z = x^2 y + 3x - y^2$，$x = \cos(t)$，$y = \sin(t)$：

$$\frac{dz}{dt} = (2xy + 3)(-\sin t) + (x^2 - 2y)(\cos t)$$

- 除了手工求导，有三种方法：

    - **数值微分**：近似 $f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$ 对小 $h$。简单但有噪声和不准确。
    - **符号微分**：代数地应用求导规则产生精确公式。可能产生指数级膨胀的表达式。
    - **自动微分**（autodiff）：跟踪运算链并高效计算精确导数。这就是 JAX、PyTorch 和 TensorFlow 使用的方法。它给出精确的数值（不是近似的），而不产生膨胀的符号表达式。

1. 使用 `jax.grad` 计算 $f(x, y) = x^2 y + 3x - 2y$ 在点 $(1, 2)$ 处的梯度。由于 $f$ 接收向量输入，使用带 `argnums` 的 `jax.grad`。
```python
import jax
import jax.numpy as jnp

def f(x, y):
    return x**2 * y + 3*x - 2*y

df_dx = jax.grad(f, argnums=0)
df_dy = jax.grad(f, argnums=1)

x, y = 1.0, 2.0
print(f"∂f/∂x = {df_dx(x, y):.4f}  (expected: {2*x*y + 3:.4f})")
print(f"∂f/∂y = {df_dy(x, y):.4f}  (expected: {x**2 - 2:.4f})")
```

2. 使用 `jax.jacobian` 计算向量值函数的 Jacobian。与手工计算比较。
```python
import jax
import jax.numpy as jnp

def F(x):
    return jnp.array([x[0]**2 + x[1], x[0] * x[1]**2])

J = jax.jacobian(F)
x = jnp.array([1.0, 2.0])
print(f"Jacobian at (1,2):\n{J(x)}")
# 预期：[[2*x[0], 1], [x[1]**2, 2*x[0]*x[1]]] = [[2, 1], [4, 4]]
```

3. 使用 `jax.hessian` 计算 $f(x, y) = x^3 + 2xy^2 - y^3$ 的 Hessian，验证它是对称的。
```python
import jax
import jax.numpy as jnp

def f(xy):
    x, y = xy[0], xy[1]
    return x**3 + 2*x*y**2 - y**3

H = jax.hessian(f)
point = jnp.array([1.0, 2.0])
hess = H(point)
print(f"Hessian:\n{hess}")
print(f"Symmetric: {jnp.allclose(hess, hess.T)}")
# 预期：[[6x, 4y], [4y, 4x-6y]] = [[6, 8], [8, -8]]
```

4. 从零构建一个最小的 autodiff 引擎。
    - 每个 `Var` 跟踪其值和如何通过链式法则反向传播梯度。
    - 尝试用更多运算（除法、乘方等）扩展它。
    - 这就是 JAX、PyTorch 和 NumPy 设计的基础。
```python
class Var:
    def __init__(self, val, children=(), backward_fn=None):
        self.val = val
        self.grad = 0.0
        self.children = children
        self.backward_fn = backward_fn

    def __add__(self, other):
        out = Var(self.val + other.val, children=(self, other))
        def _backward():
            self.grad += out.grad    # d(a+b)/da = 1
            other.grad += out.grad   # d(a+b)/db = 1
        out.backward_fn = _backward
        return out

    def __mul__(self, other):
        out = Var(self.val * other.val, children=(self, other))
        def _backward():
            self.grad += other.val * out.grad  # d(a*b)/da = b
            other.grad += self.val * out.grad  # d(a*b)/db = a
        out.backward_fn = _backward
        return out

    def backward(self):
        # 拓扑排序然后传播梯度
        # 我们将在数据结构和算法章节中详细讨论
        order, visited = [], set()
        def topo(v):
            if v not in visited:
                visited.add(v)
                for c in v.children:
                    topo(c)
                order.append(v)
        topo(self)
        self.grad = 1.0
        for v in reversed(order):
            if v.backward_fn:
                v.backward_fn()

# f(x, y) = x*x*y + x  在 (3, 2)
x = Var(3.0)
y = Var(2.0)
f = x * x * y + x       # = 3*3*2 + 3 = 21

f.backward()
print(f"f = {f.val}")           # 21.0
print(f"df/dx = {x.grad}")     # 2*x*y + 1 = 13.0
print(f"df/dy = {y.grad}")     # x*x = 9.0
```

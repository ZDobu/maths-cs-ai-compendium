# 微分学

*微分学捕捉瞬时变化率。本篇涵盖极限、导数、求导法则、链式法则（反向传播的基础）以及贯穿 ML 的常用导数。*

- 在前面的章节中，我们学习了如何把数据表示为向量并用矩阵进行变换。但许多现实世界现象不是静态的。汽车加速、股价波动、神经网络损失随权重更新而变化。**微积分**（calculus）就是关于变化的数学。

- 微积分问两个问题：某事物此刻变得多快？（微分学）以及它随时间累积了多少？（积分学）。本节处理的是"变得多快"的问题。

- 想象你正在开车，瞥了一眼里程表。上面写着 60 km/h。这个数字不是你整趟旅程的平均速度，而是你在这确切一瞬间的速度。微分学给了我们计算这种瞬时变化率的工具。

- 但首先，我们回顾一下直线方程：$y = mx + b$。

- 这是两个量之间最简单的关系。

    - $b$ 是**y 截距**（y-intercept），直线与 y 轴的交点（当 $x = 0$ 时的起始值）。
    - $m$ 是**斜率**（slope），变化率：$x$ 每增加 1 单位，$y$ 变化 $m$。
- 若 $m = 3$，线陡峭上升；若 $m = 0$，线是平的；若 $m = -2$，线下降。

- 斜率计算为 $m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$，即"$y$ 变化了多少"与"$x$ 变化了多少"的比值。

![直线方程：b 是 y 截距，m 是斜率（升量除以跑量）](../../images/line_equation.svg)

- 一旦你知道 $m$ 和 $b$，就可以计算任意 $x$ 处的 $y$。

- 例如，若 $m = 2$ 且 $b = 3$，则在 $x = 5$ 处：$y = 2(5) + 3 = 13$。

- 这两个参数完全决定了一条直线，预测任何输出只需代入。

- 对直线来说，斜率处处相同。

- 这个想法推广到直线之外。任何函数都是将输入映射到输出的规则，一旦你知道了它的公式（它的参数和形状），就可以计算任意输入的输出并绘制结果。

- $y = x^2$ 给出抛物线，$y = \sin(x)$ 给出波，$y = e^x$ 给出指数增长。每个公式定义了一条特定的曲线，而能够舒适地将函数理解为一个形状是后续一切的基础。

- 对直线而言，斜率处处相同。但大多数有趣的函数是弯曲的，因此斜率逐点变化。微积分给了我们一种找出曲线上任意单点处斜率的方法。

- 我们还需要**极限**（limit）的概念。极限描述了当函数的输入越来越接近某个目标时，函数值趋近于什么，而不必真正达到它。

$$\lim_{x \to a} f(x) = L$$

- 这读作："当 $x$ 趋近 $a$，$f(x)$ 趋近 $L$。"函数不必在 $x = a$ 处真正等于 $L$。它只需要任意接近。

- 例如，取 $f(x) = \frac{x^2 - 1}{x - 1}$。如果你直接代入 $x = 1$，会得到 $\frac{0}{0}$，这是无定义的。

- 但尝试接近 1 的值：$f(0.9) = 1.9$，$f(0.99) = 1.99$，$f(1.01) = 2.01$。输出明显趋向 2。

- 代数上我们可以看到原因：将分子因式分解为 $(x-1)(x+1)$，消去 $(x-1)$ 项，得 $f(x) = x + 1$ 对所有 $x \neq 1$ 成立。所以当 $x \to 1$，$f(x) \to 2$。

- 该函数在 $x = 1$ 处有一个洞，但极限仍然存在。

- 极限是微积分其余一切内容的基础。

- 函数 $f(x)$ 在点 $x = a$ 处的**导数**（derivative）测量瞬时变化率。几何上，它是曲线在该点处切线的斜率。

![导数即曲线上某点处切线的斜率](../../images/tangent_line.svg)

- 要计算这个斜率，我们从曲线上两点开始，计算过这两点的线的斜率（**割线**，secant line）。然后让第二点越来越接近第一点，观察割线斜率趋近于什么。这就是**差商**（difference quotient）：

$$f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}$$

![随 h 缩小，割线趋近于切线](../../images/difference_quotient.svg)

- 分子 $f(a+h) - f(a)$ 是输出的变化。分母 $h$ 是输入的变化。它们的比值是一个微小区间上的平均变化率。当 $h \to 0$，这个平均变为瞬时率。

- 例如，设 $f(x) = x^2$。在 $x = 3$ 处：

$$f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 9}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} (6 + h) = 6$$

- 因此在 $x = 3$ 处，函数 $x^2$ 以每单位输入 6 单位输出的速率递增。

- 如果极限存在，函数在该点是**可微**（differentiable）的。为此，函数必须是连续的（无跳跃）、光滑的（无尖锐转角），并在该点附近有定义。

- 如果你能不抬笔也不遇到任何尖角地画出曲线，它大概在那里是可微的。

- 每次都从极限定义计算导数会很繁琐。幸运的是，有一小套规则能让我们几乎对任何函数快速求导。

- **常数规则**：常数的导数为零。若 $f(x) = 5$，则 $f'(x) = 0$。平的线斜率为零。

- **幂规则**：微分的主力工具。将指数下移并减一：

$$\frac{d}{dx} x^n = n x^{n-1}$$

- 例如：$\frac{d}{dx} x^3 = 3x^2$。三次变成二次。这对任何实指数都有效，包括负数和分数：$\frac{d}{dx} x^{-1} = -x^{-2}$ 和 $\frac{d}{dx} \sqrt{x} = \frac{d}{dx} x^{1/2} = \frac{1}{2}x^{-1/2}$。

- **和/差规则**：逐项求导。

$$\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$$

- **乘积规则**：两个函数相乘时，导数不是简单导数的乘积。相反：

$$\frac{d}{dx}[f(x) \cdot g(x)] = f'(x)g(x) + f(x)g'(x)$$

- 可以这样理解："第一个的变化率乘以第二个，加第一个乘以第二个的变化率。"例如，$\frac{d}{dx}[x^2 \sin x] = 2x \sin x + x^2 \cos x$。

- **商规则**：对函数的比值：

$$\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$$

- 一个实用的记忆口诀："低 d 高减高 d 低，除以低方的平方。"

- **链式法则**：ML 中最重要的规则。当函数复合（一个在另一个内部），导数是链上各导数的乘积：

$$\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)$$

- 可以把它想象成剥洋葱。对外部函数求导（保持内部函数不变），然后乘以内层函数的导数。

![链式法则：对外层求导，乘以内层的导数](../../images/chain_rule.svg)

- 例如，$\frac{d}{dx} (3x + 1)^5 = 5(3x+1)^4 \cdot 3 = 15(3x+1)^4$。外层是 $(\cdot)^5$，内层是 $3x+1$。

- 链式法则是神经网络中**反向传播**（backpropagation）的数学基础。深度网络是一长串复合函数。要计算损失对每个权重如何变化，我们从输出层一路向后到输入层反复应用链式法则，在每一步乘上局部导数。

- 以下是你最常见到的导数。每个都可以从极限定义推导，但熟记它们能节省时间：

| 函数 | 导数 | 注记 |
|---|---|---|
| $e^x$ | $e^x$ | 唯一等于自身导数的函数 |
| $a^x$ | $a^x \ln a$ | 指数函数的推广 |
| $\ln x$ | $\frac{1}{x}$ | 自然对数 |
| $\log_a x$ | $\frac{1}{x \ln a}$ | 一般对数 |
| $\sin x$ | $\cos x$ | |
| $\cos x$ | $-\sin x$ | 注意负号 |
| $\tan x$ | $\sec^2 x$ | |

- 指数函数 $e^x$ 是非凡的：它是唯一等于自身导数的函数。这就是为什么 $e$ 在 ML 中无处不在——从 softmax 激活到概率分布。

- **洛必达法则**（L'Hopital's Rule）处理产生不定型（如 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$）的极限。当直接代入给出这些形式时，你可以分别对分子和分母求导，再试一次极限：

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

- 条件：$f$ 和 $g$ 必须在 $a$ 附近可微，且 $g'(x) \neq 0$ 在 $a$ 附近（可能在 $a$ 本身除外）。原极限必须给出不定型。

- 例如：$\lim_{x \to 0} \frac{\sin x}{x}$。直接代入得 $\frac{0}{0}$。应用洛必达法则：$\lim_{x \to 0} \frac{\cos x}{1} = 1$。这个极限是基础性的，出现在信号处理和傅里叶分析中。

- 如果结果仍是不定型，可以反复应用该法则。例如，$\lim_{x \to 0} \frac{1 - \cos x}{x^2}$ 得 $\frac{0}{0}$。第一次应用：$\lim_{x \to 0} \frac{\sin x}{2x}$，仍是 $\frac{0}{0}$。第二次应用：$\lim_{x \to 0} \frac{\cos x}{2} = \frac{1}{2}$。

- 若两个函数可微，它们的和、差、乘积、复合和商（分母非零处）也可微。这就是为什么我们可以有信心地对从简单部件构建的复杂表达式求导。

1. 可视化常见函数。并排绘制 $x^2$、$\sin(x)$ 和 $e^x$，建立对不同公式如何产生不同形状的直觉。尝试改变参数（如 $2x^2$、$\sin(2x)$）观察曲线的变化。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

x = jnp.linspace(-3, 3, 300)

fig, axes = plt.subplots(1, 3, figsize=(12, 3))
axes[0].plot(x, x**2, color="#e74c3c")
axes[0].set_title("x²  (parabola)")
axes[1].plot(x, jnp.sin(x), color="#3498db")
axes[1].set_title("sin(x)  (wave)")
axes[2].plot(x, jnp.exp(x), color="#27ae60")
axes[2].set_title("eˣ  (exponential)")
for ax in axes:
    ax.axhline(0, color="gray", linewidth=0.5)
    ax.axvline(0, color="gray", linewidth=0.5)
plt.tight_layout()
plt.show()
```

2. 使用 JAX 的自动微分计算 $f(x) = x^3 - 2x + 1$ 在若干点的导数。与解析导数 $f'(x) = 3x^2 - 2$ 比较。
```python
import jax
import jax.numpy as jnp

f = lambda x: x**3 - 2*x + 1
df = jax.grad(f)

for x in [0.0, 1.0, 2.0, -1.0]:
    print(f"x={x:5.1f}  autodiff: {df(x):.4f}  analytical: {3*x**2 - 2:.4f}")
```

2. 数值验证链式法则。定义 $f(x) = \sin(x^2)$，通过 `jax.grad` 计算其导数，与解析结果 $2x\cos(x^2)$ 比较。
```python
import jax
import jax.numpy as jnp

f = lambda x: jnp.sin(x**2)
df = jax.grad(f)

for x in [0.5, 1.0, 2.0]:
    auto = df(x)
    analytical = 2*x * jnp.cos(x**2)
    print(f"x={x:.1f}  autodiff: {auto:.6f}  analytical: {analytical:.6f}")
```

3. 可视化导数。在同图上绘制 $f(x) = x^3 - 3x$ 和其导数 $f'(x) = 3x^2 - 3$。注意 $f'(x) = 0$ 对应 $f$ 的峰和谷。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

f = lambda x: x**3 - 3*x
# jax.grad 对标量操作；jax.vmap 将其向量化以对输入数组同时操作
df = jax.vmap(jax.grad(f))

x = jnp.linspace(-2.5, 2.5, 200)
plt.plot(x, jax.vmap(f)(x), label="f(x)")
plt.plot(x, df(x), label="f'(x)", linestyle="--")
plt.axhline(0, color="gray", linewidth=0.5)
plt.legend()
plt.title("A function and its derivative")
plt.show()
```

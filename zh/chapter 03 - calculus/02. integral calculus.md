# 积分学

*积分学在区间上累积量，将局部速率还原为总量。本篇涵盖定积分和不定积分、微积分基本定理、积分技巧以及在 ML 中对概率密度和期望值的应用。*

- 微分告诉我们单点处的变化率。积分走另一条路：它累积许多微小片段来计算总量。

- 如果导数回答"有多快？"，积分回答"有多少？"

- 理解积分最简单的方法是将其视为**曲线下的面积**。如果绘制函数 $f(x)$ 并对曲线和 x 轴之间从 $x = a$ 到 $x = b$ 的区域进行着色，积分给出了该区域的带符号面积。

![积分通过求和小矩形来计算曲线下的面积](../../images/area_under_curve.svg)

- 为什么是"带符号"？x 轴上方的区域贡献正面积，下方的贡献负面积。这在物理上很合理：若 $f(x)$ 表示速度，积分给出净位移（前进减后退），而不是总路程。

- 要计算这个面积，想象将区域切成 $n$ 个宽度各为 $\Delta x$ 的细长矩形。每个矩形的高度是该切片内某点的函数值。将它们全部加起来：

$$\text{Area} \approx \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- 当我们将矩形变得越来越细（$n \to \infty$，$\Delta x \to 0$），和变得精确。这个极限过程定义了**定积分**（definite integral）：

$$\int_a^b f(x)\, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- $\int$ 符号是一个拉长的"S"代表"求和"（sum）。$dx$ 提醒我们正在沿 x 轴对无限薄的切片求和。

- **不定积分**（indefinite integral，或**原函数** antiderivative）是一个函数 $F(x)$，其导数为 $f(x)$。我们写：

$$\int f(x)\, dx = F(x) + C$$

- $+ C$ 是**积分常数**。因为任何常数的导数为零，存在无穷多个原函数，它们之间只差一个常数。例如，$\int 2x\, dx = x^2 + C$，因为 $x^2 + 7$ 或 $x^2 - 3$ 的导数仍然是 $2x$。

- **微积分基本定理**（Fundamental Theorem of Calculus）是连接微分和积分的桥梁。它有两个部分：

- **第 1 部分**：若 $F(x)$ 是 $f(x)$ 的一个原函数，则定积分等于 $F$ 在两端点的差：

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

- 这非常实用。与其计算求和的极限（这很困难），不如找到一个原函数并在两点处求值（这通常很简单）。

- **第 2 部分**：若定义 $F(x) = \int_a^x f(t)\, dt$，则 $F'(x) = f(x)$。微分和积分是逆运算，它们互相撤销。

- 例如，计算 $\int_1^3 x^2\, dx$：$x^2$ 的原函数是 $\frac{x^3}{3}$。因此 $\int_1^3 x^2\, dx = \frac{27}{3} - \frac{1}{3} = \frac{26}{3} \approx 8.67$。

- 正如微分有求导规则，积分有对应的反转规则：

| 函数 | 积分 | 条件 |
|---|---|---|
| $x^n$ | $\frac{x^{n+1}}{n+1} + C$ | $n \neq -1$ |
| $\frac{1}{x}$ | $\ln\|x\| + C$ | |
| $e^x$ | $e^x + C$ | |
| $a^x$ | $\frac{a^x}{\ln a} + C$ | |
| $\sin x$ | $-\cos x + C$ | |
| $\cos x$ | $\sin x + C$ | |
| $k$（常数） | $kx + C$ | |

- **和/差规则**同样适用：$\int [f(x) \pm g(x)]\, dx = \int f(x)\, dx \pm \int g(x)\, dx$。常数可以提出：$\int k\, f(x)\, dx = k \int f(x)\, dx$。

- 当一个函数太复杂不能直接积分时，我们有技巧来简化它。

- **u 换元**（u-substitution）是链式法则的反转。如果看到复合函数 $f(g(x))$ 乘以 $g'(x)$，令 $u = g(x)$ 使得 $du = g'(x)\, dx$，积分就简化了。

- 例如：$\int 2x \cos(x^2)\, dx$。令 $u = x^2$，则 $du = 2x\, dx$。积分变为 $\int \cos(u)\, du = \sin(u) + C = \sin(x^2) + C$。

- **分部积分**（integration by parts）是乘积规则的反转。如果被积函数是两个函数的乘积：

$$\int u\, dv = uv - \int v\, du$$

- 策略性地选择 $u$ 和 $dv$，使得剩余的积分 $\int v\, du$ 比原来的更简单。一个常用的选择 $u$ 的记忆口诀是 **LIATE**：对数（Logarithmic）、反三角（Inverse trig）、代数（Algebraic）、三角（Trigonometric）、指数（Exponential）（从前面的类别中选 $u$）。

- 例如：$\int x\, e^x\, dx$。令 $u = x$（代数）和 $dv = e^x\, dx$。则 $du = dx$，$v = e^x$。因此：$\int x\, e^x\, dx = x\, e^x - \int e^x\, dx = x\, e^x - e^x + C = e^x(x - 1) + C$。

- 在 ML 中，积分出现在概率论中（通过对密度函数积分计算概率）、在期望值中（连续分布上的加权平均）以及在计算 ROC 曲线下的面积中。虽然实践中我们很少手工积分，但理解积分意味着什么有助于解释这些量。

## 编码任务（使用 CoLab 或 notebook）

1. 使用 Riemann 和，用逐渐增多的矩形数值近似 $\int_0^1 x^2\, dx$。与精确答案 $\frac{1}{3}$ 比较。
```python
import jax.numpy as jnp

for n in [10, 100, 1000, 10000]:
    x = jnp.linspace(0, 1, n, endpoint=False)
    dx = 1.0 / n
    area = jnp.sum(x**2 * dx)
    print(f"n={n:5d}  approx: {area:.6f}  exact: {1/3:.6f}")
```

2. 数值验证微积分基本定理。定义 $F(x) = \int_0^x t^2\, dt = \frac{x^3}{3}$ 并验证其导数（通过 `jax.grad` 计算）等于 $x^2$。
```python
import jax
import jax.numpy as jnp

F = lambda x: x**3 / 3
dF = jax.grad(F)

for x in [0.5, 1.0, 2.0, 3.0]:
    print(f"x={x:.1f}  F'(x)={dF(x):.4f}  x^2={x**2:.4f}")
```

3. 可视化从 $0$ 到 $\pi$ 的 $f(x) = \sin(x)$ 的曲线下面积。使用 `plt.fill_between` 着色面积并用 Riemann 和数值计算。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

x = jnp.linspace(0, jnp.pi, 500)
y = jnp.sin(x)

plt.plot(x, y, color="purple", linewidth=2)
plt.fill_between(x, y, alpha=0.2, color="purple")
plt.title(f"Area = {jnp.sum(jnp.sin(x) * (jnp.pi / 500)):.4f}  (exact: 2.0)")
plt.show()
```

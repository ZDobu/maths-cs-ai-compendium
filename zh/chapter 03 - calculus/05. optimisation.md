# 优化

*优化是模型训练的数学核心，寻找使损失函数最小化的参数。本篇涵盖临界点、凸性、梯度下降、Newton 法、使用 Lagrange 乘子的约束优化，以及驱动现代深度学习的优化器（SGD、Adam）。*

- 训练神经网络、拟合回归直线、调超参数：几乎每个 ML 算法的核心都是一个**优化**（optimisation）问题。

- 我们有一些函数（损失、代价、目标），我们想找到使它尽可能小（或大）的输入。

- 在优化之前，我们需要理解函数的**零点**（zero，或根 root）。$f(x)$ 的一个零点是满足 $f(x) = 0$ 的值 $x$。图形上，这是 x 轴截距。

- 例如，$f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ 在 $x = 1$ 和 $x = 2$ 处有零点。在零点之间，函数为负（$f(1.5) = -0.25$）；在零点之外，函数为正。零点将数轴分成函数定号的区域。

- 零点的**重数**（multiplicity）是对应因子出现的次数。

- 在简单零点（重数 1），图形穿过 x 轴。在二重零点（重数 2），图形触碰 x 轴但弹回而不穿过，在该点看起来"平坦"。

- 找零点很重要，因为导数 $f'(x)$ 的零点是 $f(x)$ 的**临界点**（critical point），也就是最大值和最小值的候选点。

- 在最大值或最小值处，切线是平的（斜率 = 0），因此 $f'(x) = 0$。

![临界点：导数等于零处，函数有一个峰、谷或鞍点](../../images/critical_points.svg)

- 但并非每个临界点都是最大值或最小值。$f'(x) = 0$ 的点也可能是**拐点**（inflection point，如 $f(x) = x^3$ 在 $x = 0$），函数暂时变平但不改变方向。

- **二阶导数检验**（second derivative test）解决这个问题。在临界点 $x = c$ 处 $f'(c) = 0$：

    - 若 $f''(c) > 0$：曲线向上凹（像碗），因此 $c$ 是**局部最小值**。
    - 若 $f''(c) < 0$：曲线向下凹（像山），因此 $c$ 是**局部最大值**。
    - 若 $f''(c) = 0$：检验不可定论；需要更高阶导数或其他方法。

- 例如，$f(x) = x^3 - 3x$。导数为 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，因此临界点在 $x = -1$ 和 $x = 1$。二阶导数为 $f''(x) = 6x$。在 $x = -1$：$f''(-1) = -6 < 0$（局部最大值）。在 $x = 1$：$f''(1) = 6 > 0$（局部最小值）。

- 如果函数图形上任意两点之间的线段始终处于图形上方（或之上），该函数是**凸**（convex）的。把它想象成碗的形状，处处向上弯曲。数学上，$f$ 凸即 $f''(x) \geq 0$ 对所有 $x$ 成立。

![凸函数有唯一的全局最小值；非凸函数可以有多个局部最小值](../../images/convex_nonconvex.svg)

- 凸性之所以强大，是因为凸函数具有非凡的性质：每个局部最小值也是**全局最小值**。没有欺骗性的局部凹谷来困住你。如果将一个球滚入凸碗，它总是到达底部。

- 若 $-f$ 是凸的，函数是**凹**（concave）的（向下弯曲）。函数在凹和凸之间转换的点是**拐点**，出现在 $f''(x) = 0$ 处。

- **Newton 法**使用切线寻找函数的零点（进而寻其导数的临界点）。从初始猜测 $x_0$ 开始，迭代地改进：

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

![Newton 法：沿切线找到根的更好近似](../../images/newtons_method.svg)

- 想法：在 $x_n$ 处，画切线并找到它与 x 轴的交点。该交点成为 $x_{n+1}$。对行为良好的函数以好的起点开始，Newton 法收敛非常快（二次收敛，意味着正确位数大约每步翻倍）。

- 例如，要找 $\sqrt{5}$（$f(x) = x^2 - 5$ 的零点）：$f'(x) = 2x$，因此 $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$。从 $x_0 = 2$ 开始：$x_1 = 2.25$，$x_2 = 2.2361\ldots$，已有四位小数准确。

- Newton 法可能在初始猜测离根太远、$f'(x) = 0$ 在根附近、或函数附近有拐点时失败。它还需要计算导数，可能代价高昂。

- 对优化（找最小值而非零点），我们将 Newton 法应用于 $f'(x) = 0$，得到更新：

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$

- 在多元中，这变成 $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$，其中 $H$ 是 Hessian 矩阵。这就是前一篇的二阶 Taylor 逼近在实践中的应用：将函数近似为二次函数，跳到该二次函数的最小值处，重复。

- **Lagrange 乘子法**求解**约束优化**：在约束 $g(x, y) = c$ 下找到 $f(x, y)$ 的最优值。我们不是搜索整个 $\mathbb{R}^n$，而是被限制在约束成立的集合（一条曲线或曲面）上。

- 关键洞察是几何性的：在约束最优点处，$f$ 的梯度必须平行于 $g$ 的梯度。如果它们不平行，我们可以沿约束移动到一个方向，该方向仍能改进 $f$，因此我们还没有到达最优点。

- 我们引入一个新变量 $\lambda$（Lagrange 乘子）并定义**Lagrangian**：

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$

- 将全部偏导数置为零给出一个方程组，其解即是约束最优：

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$

![Lagrange 乘子：在最优点处，f 和 g 的梯度平行](../../images/lagrange_multiplier.svg)

- 例如，在 $x^2 + y^2 = 1$ 约束下最大化 $f(x,y) = x^2 y$。Lagrangian 为 $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$。取偏导：

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$

- 从第一个方程（假设 $x \neq 0$）：$\lambda = y$。代入第二个：$x^2 = 2y^2$。结合约束：$2y^2 + y^2 = 1$，因此 $y = \frac{1}{\sqrt{3}}$。最大值为 $f = \frac{2}{3\sqrt{3}}$。

- 对不等式约束（$g(x,y) \leq c$ 而非 $= c$），**Karush-Kuhn-Tucker (KKT) 条件**推广了 Lagrange 乘子。约束要么是激活的（约束生效，按等式处理），要么是非激活的（解在内部，约束无关）。

- 实践中，我们极少手工优化。以下是主要的算法系列：

    - **一阶方法**（仅用梯度）：梯度下降、随机梯度下降（SGD）、Adam。每一步便宜，但可能收敛缓慢，特别是在病态问题上。

    - **二阶方法**（用梯度和 Hessian）：Newton 法收敛快，但计算和求逆 Hessian 很贵（$n$ 个参数需要 $O(n^3)$）。**拟 Newton 法**（quasi-Newton，如 BFGS 和 L-BFGS）仅用梯度信息近似 Hessian，比一阶方法更快收敛而无需二阶方法的全部开销。

    - **共轭梯度**（conjugate gradient）：对大型稀疏系统高效，只用矩阵-向量乘积而非存储全 Hessian。

    - **Gauss-Newton** 和 **Levenberg-Marquardt**：专用于最小二乘问题（回归中常见），通过 Jacobian 近似 Hessian。

    - **自然梯度下降**（natural gradient descent）：使用 Fisher 信息矩阵考虑参数空间的几何结构，对概率模型可能更有效。

- 优化器的选择取决于问题。对深度学习，一阶方法（尤其是 Adam）占主导，因为参数数量巨大（百万到数十亿），使得 Hessian 计算不切实际。对有光滑目标的小型问题，二阶方法可能显著更快。

## 编码任务（使用 CoLab 或 notebook）

1. 实现 Newton 法求 $\sqrt{7}$（$f(x) = x^2 - 7$ 的零点）。观察快速收敛。
```python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # 初始猜测
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
```

2. 使用梯度下降最小化 $f(x, y) = (x - 3)^2 + (y + 1)^2$。最小值在 $(3, -1)$。尝试不同学习率。
```python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
```

3. 数值求解约束优化问题。通过参数化 $y = 10 - x$ 并找到单变量函数的最优值，在 $x + y = 10$ 约束下最大化 $f(x,y) = xy$。
```python
import jax
import jax.numpy as jnp

# 代入约束：y = 10 - x，因此 f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# 梯度上升（我们要求最大值，所以加梯度）
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # 应得 x=5, y=5, f=25
```

# 统计度量（Statistical Measures）

*统计度量通过单一数字来总结数据，捕捉离散度、位置、形状和关联性。本文件涵盖方差、标准差、四分位数、偏度、峰度、协方差、相关性（Correlation）和z-分数（z-score），这些是ML中探索性数据分析（EDA）和特征工程的工具包。*

- 在上一文件中，我们将矩作为一族汇总统计量引入。这里我们展开由它们衍生的实用工具：离散度（Dispersion）、位置（Position）、形状（Shape）和关联性（Association）的度量。

- **离散度**回答的问题是：数据有多分散？两个班级可以有相同的平均考试分数，但离散程度却可能截然不同。

![两个具有相同均值但不同离散程度的分布](../../images/variance_spread.svg)

- 狭窄的（蓝色）分布具有低方差：大多数值紧密聚集在均值周围。宽阔的（红色）分布具有高方差：值分散得更远。

- **方差**是到均值的平均平方距离。我们使用平方来避免正负偏差相互抵消。

$$\sigma^2 = \frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^2$$

- 当处理样本（而非完整总体）时，我们除以 $N - 1$ 而不是 $N$。这种修正（称为贝塞尔校正，Bessel's correction）是为了补偿样本往往会低估真实变异性的情况：

$$s^2 = \frac{1}{N-1} \sum_{i=1}^{N} (x_i - \bar{x})^2$$

- **标准差**是方差的平方根：$\sigma = \sqrt{\sigma^2}$。它使度量回到了原始单位。如果数据以厘米为单位，方差的单位是 cm$^2$，但标准差又回到了 cm。

- **平均绝对偏差（MAD，Mean Absolute Deviation）**是一种更简单的替代方法。不平方，而是取每个偏差的绝对值：

$$\text{MAD} = \frac{1}{N} \sum_{i=1}^{N} |x_i - \mu|$$

- MAD 对离群值比方差更鲁棒，因为它不会通过平方放大大的偏差。然而，方差在数学上更方便（它在证明和ML优化中具有良好的分解性质）。

- **位置**回答一个不同的问题：某个特定值在其余数据中的相对位置如何？

- **四分位数（Quartiles）**将排序后的数据分成四个相等的部分。Q1（第25百分位数）是25%的数据低于该值的值。Q2是中位数（第50百分位数）。Q3是第75百分位数。

- **四分位距（IQR，Interquartile Range）**是 $Q3 - Q1$。它捕捉了中间50%数据的离散程度，忽略了极端值。

![箱线图显示Q1、中位数、Q3、IQR、须线和离群值](../../images/quartiles_boxplot.svg)

- 箱线图（Box Plot）是统计学中最有用的可视化之一。箱子从Q1延伸到Q3，箱内横线是中位数，须线延伸到最极端的非离群值，须线以外的点是离群值。

- **百分位数（Percentiles）**是四分位数的推广。第 $p$-th百分位数是 $p\%$ 的观测值低于该值的值。Q1是第25百分位数，中位数是第50百分位数，Q3是第75百分位数。

- **z-分数**告诉你一个值距离均值有多少个标准差：

$$z = \frac{x - \mu}{\sigma}$$

- z-分数为2意味着该值比均值高2个标准差。z-分数为 $-1.5$ 意味着比均值低1.5个标准差。这也被称为**标准化**，在ML中广泛用于特征缩放，因为它可以将任何分布转换为均值为0、标准差为1的分布。

- **形状**描述分布在其中心和离散程度之外的几何特征。

- **偏度**（上一文件中的标准化第3矩）衡量不对称性。完全对称的分布（如正态曲线）偏度为零。正偏度意味着右尾更长（例如收入分布）。负偏度意味着左尾更长（例如退休年龄）。

$$\text{Skewness} = \frac{1}{N} \sum_{i=1}^{N} \left(\frac{x_i - \mu}{\sigma}\right)^3$$

- **峰度**（标准化第4矩）衡量尾部的厚重程度。正态分布的峰度为3。尾部更重的分布（更容易出现离群值）峰度大于3。

$$\text{Kurtosis} = \frac{1}{N} \sum_{i=1}^{N} \left(\frac{x_i - \mu}{\sigma}\right)^4$$

- **相关性**衡量两个变量之间关系的强度和方向。它回答的问题是：当一个变量上升时，另一个变量倾向于上升、下降，还是没有变化？

![三张散点图分别显示正相关、无相关和负相关](../../images/correlation_scatter.svg)

- **皮尔逊相关（Pearson correlation）**（$r$）衡量*线性*关联。范围从 $-1$（完全负相关）经过 $0$（无相关）到 $+1$（完全正相关）。

$$r = \frac{\sum_{i=1}^{N} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \cdot \sqrt{\sum (y_i - \bar{y})^2}}$$

- 如果你回顾第1章的点积，皮尔逊相关本质上是 $\mathbf{x}$ 和 $\mathbf{y}$ 去均值版本之间的余弦相似度（Cosine Similarity）。

- **斯皮尔曼相关（Spearman correlation）**（$\rho$）衡量*单调*关联。它不直接使用原始值，而是先对其排序，然后在秩上计算皮尔逊相关。这使得它对离群值具有鲁棒性，即使关系是非线性的也能工作，只要它是持续增加或持续减少的。

- **几何平均（Geometric mean）**是当数值相乘时（如增长率）适用的适当平均。如果你的投资增长了10%、然后20%、然后30%，平均增长因子不是这些增长率的算术平均。而应该是：

$$\bar{x}_{\text{geo}} = \left(\prod_{i=1}^{N} x_i\right)^{1/N}$$

- 对于增长率，先将百分比转换为因子（1.10, 1.20, 1.30），计算几何平均，然后减去1。

- **指数移动平均（EMA，Exponential Moving Average）**赋予近期观测值更大的权重。与简单移动平均中窗口内所有点权重相同不同，EMA呈指数衰减：

$$\text{EMA}_t = \alpha \cdot x_t + (1 - \alpha) \cdot \text{EMA}_{t-1}$$

- 平滑因子 $\alpha$（介于0和1之间）控制旧观测值影响力衰减的速度。$\alpha$ 越高表示对近期变化更敏感，$\alpha$ 越低表示更平滑。在ML中，EMA用于像 Adam 这样的优化器以及批归一化（Batch Normalisation）的运行统计量中。

- **离群值检测（Outlier detection）**识别那些异常远离其他数据点的数据点。两种常用方法：
    - **IQR方法**：如果一个点低于 $Q1 - 1.5 \times \text{IQR}$ 或高于 $Q3 + 1.5 \times \text{IQR}$，则它是离群值
    - **Z-分数方法**：如果 $|z| > 3$（距离均值超过3个标准差），则一个点是离群值

- IQR方法更为鲁棒，因为它不假设正态分布。Z-分数方法在数据近似正态时效果很好，但当分布严重偏斜时可能失效。

1. 计算数据集的方差、标准差和MAD并比较它们。观察添加一个极端离群值时会发生什么。
```python
import jax.numpy as jnp

data = jnp.array([4, 8, 6, 5, 3, 7, 9, 5, 6, 7], dtype=jnp.float32)

mean = jnp.mean(data)
variance = jnp.var(data)
std = jnp.std(data)
mad = jnp.mean(jnp.abs(data - mean))

print("Original data:")
print(f"  Variance: {variance:.3f}, Std: {std:.3f}, MAD: {mad:.3f}")

# Add an outlier and recompute
data_outlier = jnp.append(data, 100.0)
mean2 = jnp.mean(data_outlier)
print(f"\nWith outlier (100):")
print(f"  Variance: {jnp.var(data_outlier):.3f}, Std: {jnp.std(data_outlier):.3f}, MAD: {jnp.mean(jnp.abs(data_outlier - mean2)):.3f}")
```

2. 计算两个变量之间的皮尔逊和斯皮尔曼相关。尝试不同的关系。
```python
import jax
import jax.numpy as jnp

# Perfect linear relationship
x = jnp.array([1, 2, 3, 4, 5, 6, 7, 8], dtype=jnp.float32)
y = 2 * x + 1  # try changing this!

def pearson(a, b):
    a_c = a - jnp.mean(a)
    b_c = b - jnp.mean(b)
    return jnp.sum(a_c * b_c) / (jnp.sqrt(jnp.sum(a_c**2)) * jnp.sqrt(jnp.sum(b_c**2)))

def spearman(a, b):
    rank_a = jnp.argsort(jnp.argsort(a)).astype(jnp.float32)
    rank_b = jnp.argsort(jnp.argsort(b)).astype(jnp.float32)
    return pearson(rank_a, rank_b)

print(f"Pearson r:  {pearson(x, y):.4f}")
print(f"Spearman ρ: {spearman(x, y):.4f}")
```

3. 使用IQR和Z-分数两种方法实现离群值检测，然后比较它们在偏斜数据上的结果。
```python
import jax.numpy as jnp

data = jnp.array([2, 3, 3, 4, 5, 5, 5, 6, 6, 7, 50], dtype=jnp.float32)

# IQR method
q1, q3 = jnp.percentile(data, 25), jnp.percentile(data, 75)
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
iqr_outliers = data[(data < lower) | (data > upper)]
print(f"IQR bounds: [{lower:.1f}, {upper:.1f}]")
print(f"IQR outliers: {iqr_outliers}")

# Z-score method
z_scores = (data - jnp.mean(data)) / jnp.std(data)
z_outliers = data[jnp.abs(z_scores) > 3]
print(f"\nZ-scores: {z_scores}")
print(f"Z-score outliers (|z| > 3): {z_outliers}")
```

4. 在噪声数据上计算并绘制不同平滑因子的指数移动平均。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

# Generate noisy data
key = __import__("jax").random.PRNGKey(0)
noise = __import__("jax").random.normal(key, shape=(50,))
signal = jnp.linspace(0, 5, 50) + noise

def ema(data, alpha):
    result = jnp.zeros_like(data)
    result = result.at[0].set(data[0])
    for t in range(1, len(data)):
        result = result.at[t].set(alpha * data[t] + (1 - alpha) * result[t - 1])
    return result

plt.figure(figsize=(10, 4))
plt.plot(signal, "o", alpha=0.3, label="raw data", color="#999")
for alpha, color in [(0.1, "#e74c3c"), (0.3, "#3498db"), (0.7, "#27ae60")]:
    plt.plot(ema(signal, alpha), label=f"α={alpha}", color=color, linewidth=2)
plt.legend()
plt.title("EMA with different smoothing factors")
plt.show()
```

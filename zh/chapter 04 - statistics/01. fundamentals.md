# 统计学基础（Fundamentals of Statistics）

*统计学（Statistics）提供了描述数据和量化不确定性的语言。本文件涵盖分布（Distribution）、随机变量（Random Variable）、概率质量函数（PMF）、概率密度函数（PDF）、累积分布函数（CDF）、期望（Expectation）、方差（Variance）、矩（Moment）以及中心极限定理（Central Limit Theorem），这些概念是每个机器学习（ML）评估指标和损失函数的基础。*

- 统计学是从数据中学习的科学。你收集观测值，对其进行总结，并得出结论，通常是关于你无法直接测量的东西。

- 想象你想知道一个国家所有成年人的平均身高。你无法测量每一个人，所以你需要测量一个样本（Sample），并利用统计学来对整个总体（Population）做出有依据的推测。

- 统计学有两个主要分支：
    - **描述性统计（Descriptive statistics）**：总结你已有的数据（均值、图表、表格）
    - **推断性统计（Inferential statistics）**：利用样本对更大的群体做出断言

- 统计学的基石是**分布**，即对数值如何分散开的描述。其他一切——均值、检验、预测——都源于对分布的理解。

- **频率分布（Frequency distribution）**统计每个值（或值的区间）在数据中出现的次数。想象一下将考试分数分入不同的区间，然后统计每个区间有多少学生。结果就是一个直方图（Histogram）。

- **概率分布（Probability distribution）**用概率替代原始计数。不再说"有12名学生的分数在70到80之间"，而是说"分数落在70到80之间的概率为0.24"。当数据是连续型时，直方图的条形会变成一条平滑曲线。

![频率分布作为直方图 vs 概率分布作为平滑曲线](../../images/distribution_types.svg)

- 左侧的直方图是基于你收集的实际数据构建的。右侧的平滑曲线是一个描述数据背后模式的数学模型。一个是经验性的，另一个是理论性的。

- 为了在数学上处理分布，我们需要一种将数字分配给结果的方法。这正是**随机变量**所做的。

- 随机变量是一个将实验的每个结果映射到实数的函数。抛一枚硬币：结果是"正面"或"反面"，但随机变量 $X$ 将其转换为 $X(\text{heads}) = 1$ 和 $X(\text{tails}) = 0$。现在我们可以进行算术运算了。

![随机变量将结果（硬币、骰子）映射到数轴](../../images/random_variable.svg)

- **离散型（Discrete）**随机变量取可数个值：抛10次硬币中正面的次数、掷骰子的点数、一小时内收到的邮件数量。

- **连续型（Continuous）**随机变量可以取一个区间内的任意值：你的精确身高、下一班公交车到达的时间、正午的温度。

- 这种区分很重要，因为它改变了我们计算概率的方式。对于离散变量，我们求和。对于连续变量，我们积分（回顾第3章的积分）。

- 对于离散型随机变量，**概率质量函数（PMF，Probability Mass Function）**给出每个特定值的概率：

$$P(X = x) = p(x), \quad \text{where } \sum_{x} p(x) = 1$$

- 对于连续型随机变量，**概率密度函数（PDF，Probability Density Function）**给出落在某个区间内的概率。任何单个精确值的概率为零；只有区间才有正概率：

$$P(a \le X \le b) = \int_a^b f(x)\, dx, \quad \text{where } \int_{-\infty}^{\infty} f(x)\, dx = 1$$

- 现在我们可以将数字分配给结果了，最自然的问题是：我们平均期望的值是多少？

- **期望**（或称期望值）是所有可能值的加权平均，其中权重是概率。可以把它想象成分布的"重心"。

- 如果你多次掷一个公平的骰子，你的平均掷出值会收敛到3.5。这就是期望值，尽管你实际上永远不可能掷出3.5。

- 对于离散型随机变量：

$$E[X] = \sum_{x} x \cdot p(x)$$

- 对于连续型随机变量（使用第3章的积分）：

$$E[X] = \int_{-\infty}^{\infty} x \cdot f(x)\, dx$$

- 示例：一个公平的六面骰子，对于 $x = 1, 2, 3, 4, 5, 6$ 有 $p(x) = 1/6$。

$$E[X] = 1 \cdot \tfrac{1}{6} + 2 \cdot \tfrac{1}{6} + 3 \cdot \tfrac{1}{6} + 4 \cdot \tfrac{1}{6} + 5 \cdot \tfrac{1}{6} + 6 \cdot \tfrac{1}{6} = \frac{21}{6} = 3.5$$

- 期望是线性的，意味着 $E[aX + b] = aE[X] + b$。这个性质非常有用，在ML损失函数中经常出现。

- 期望告诉我们中心位置，但对数值的分散程度却只字未提。为了描述分布的完整形状，我们需要**矩**。

- 矩是 $X$ 的幂次的期望。第 $k$ 阶**原点矩（Raw Moment）**为：

$$\mu_k' = E[X^k]$$

- 第一原点矩（$k = 1$）就是均值：$\mu_1' = E[X] = \mu$。

- 原点矩是从零点开始测量的。通常我们更关心与均值的偏差。第 $k$ 阶**中心矩（Central Moment）**将测量中心化：

$$\mu_k = E[(X - \mu)^k]$$

- 第一中心矩始终为零（高于和低于均值的偏差相互抵消）。第二中心矩就是**方差**。

- 为了在不同尺度上比较分布，我们通过除以标准差 $\sigma$ 的适当幂次来进行**标准化（Standardise）**：

$$\tilde{\mu}_k = \frac{\mu_k}{\sigma^k}$$

- 每个矩捕捉分布形状的不同方面：

![钟形曲线标注各矩捕捉的内容：均值（中心）、方差（离散度）、偏度（不对称性）、峰度（尾部权重）](../../images/moments_shape.svg)

- **第1矩（均值）**：分布的中心位置。平衡点。
- **第2矩（方差）**：数值围绕均值的离散程度。方差越大表示分布越宽。
- **第3矩（偏度，Skewness）**：分布是左偏还是右偏。偏度为零表示对称。
- **第4矩（峰度，Kurtosis）**：尾部有多重。峰度越高表示极端离群值越多。

- 让我们用一个具体数据集 $X = \{2, 4, 4, 4, 5, 5, 7, 9\}$ 来计算全部四个矩。

- **步骤1：均值**（第一原点矩）

$$\mu = \frac{2 + 4 + 4 + 4 + 5 + 5 + 7 + 9}{8} = \frac{40}{8} = 5$$

- **步骤2：方差**（第二中心矩）。每个值减去均值，平方，然后求平均：

$$\sigma^2 = \frac{(2{-}5)^2 + (4{-}5)^2 + (4{-}5)^2 + (4{-}5)^2 + (5{-}5)^2 + (5{-}5)^2 + (7{-}5)^2 + (9{-}5)^2}{8}$$

$$= \frac{9 + 1 + 1 + 1 + 0 + 0 + 4 + 16}{8} = \frac{32}{8} = 4$$

- **标准差（Standard Deviation）**为 $\sigma = \sqrt{4} = 2$。

- **步骤3：偏度**（标准化第三中心矩）。将偏差立方，求平均，除以 $\sigma^3$：

$$\tilde{\mu}_3 = \frac{1}{8} \cdot \frac{(-3)^3 + (-1)^3 + (-1)^3 + (-1)^3 + 0^3 + 0^3 + 2^3 + 4^3}{2^3}$$

$$= \frac{1}{8} \cdot \frac{-27 -1 -1 -1 + 0 + 0 + 8 + 64}{8} = \frac{42}{64} = 0.656$$

- 正偏度意味着右尾更长，这是合理的，因为9远高于均值。

- **步骤4：峰度**（标准化第四中心矩）。将偏差提升到4次方：

$$\tilde{\mu}_4 = \frac{1}{8} \cdot \frac{(-3)^4 + (-1)^4 + (-1)^4 + (-1)^4 + 0^4 + 0^4 + 2^4 + 4^4}{2^4}$$

$$= \frac{1}{8} \cdot \frac{81 + 1 + 1 + 1 + 0 + 0 + 16 + 256}{16} = \frac{356}{128} = 2.781$$

- 正态分布的峰度为3（称为"常峰态的"，mesokurtic）。我们的值2.781非常接近，说明尾部大致是正态的。高于3的值（"尖峰态的"，leptokurtic）表示尾部更重；低于3的值（"低峰态的"，platykurtic）表示尾部更轻。有些公式通过减去3来报告**超额峰度（Excess Kurtosis）**，所以我们的超额峰度为 $-0.219$。

## 编程任务（在CoLab或notebook中使用）

1. 计算一个加权的骰子的期望值，其中面6的概率为0.3，其他各面均分剩余概率。通过模拟100,000次投掷来验证。
```python
import jax
import jax.numpy as jnp

# Loaded die: face 6 has p=0.3, others share 0.7 equally
probs = jnp.array([0.14, 0.14, 0.14, 0.14, 0.14, 0.30])
faces = jnp.array([1, 2, 3, 4, 5, 6])

# Analytical expected value
ev = jnp.sum(faces * probs)
print(f"Expected value (formula): {ev:.4f}")

# Simulation
key = jax.random.PRNGKey(42)
rolls = jax.random.choice(key, faces, shape=(100_000,), p=probs)
print(f"Expected value (simulation): {rolls.mean():.4f}")
```

2. 计算工作示例中数据集的所有四个矩（均值、方差、偏度、峰度），然后修改数据并观察每个矩如何变化。
```python
import jax.numpy as jnp

x = jnp.array([2, 4, 4, 4, 5, 5, 7, 9], dtype=jnp.float32)

mean = jnp.mean(x)
variance = jnp.mean((x - mean) ** 2)
std = jnp.sqrt(variance)
skewness = jnp.mean(((x - mean) / std) ** 3)
kurtosis = jnp.mean(((x - mean) / std) ** 4)

print(f"Mean:     {mean:.3f}")
print(f"Variance: {variance:.3f}")
print(f"Std Dev:  {std:.3f}")
print(f"Skewness: {skewness:.3f}")
print(f"Kurtosis: {kurtosis:.3f}")
print(f"Excess K: {kurtosis - 3:.3f}")
```

3. 并排可视化公平骰子投掷的PMF和CDF。尝试改变概率来观察形状如何变化。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

faces = jnp.array([1, 2, 3, 4, 5, 6])
pmf = jnp.ones(6) / 6  # fair die; try changing these!
cdf = jnp.cumsum(pmf)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

ax1.bar(faces, pmf, color="#3498db", alpha=0.8)
ax1.set_title("PMF")
ax1.set_xlabel("Face")
ax1.set_ylabel("P(X = x)")
ax1.set_ylim(0, 0.5)

ax2.step(faces, cdf, where="mid", color="#e74c3c", linewidth=2)
ax2.set_title("CDF")
ax2.set_xlabel("Face")
ax2.set_ylabel("P(X ≤ x)")
ax2.set_ylim(0, 1.1)

plt.tight_layout()
plt.show()
```

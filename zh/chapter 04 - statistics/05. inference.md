# 统计推断（Statistical Inference）

*统计推断超越了是/否的决策，以量化的不确定性来估计总体参数。本文件涵盖置信区间（Confidence Intervals）、点估计（Point Estimation）和区间估计（Interval Estimation）、最大似然估计（MLE，Maximum Likelihood Estimation）、矩估计法（Method of Moments）以及回归分析（Regression Analysis），这些是连接原始数据与ML中预测模型的桥梁。*

- 假设检验给你一个是/否的决策：拒绝或未能拒绝。但通常你需要更有信息量的东西——你正在估计的参数的一个合理取值范围。这就是**置信区间**所提供的内容。

- **点估计**是从你的样本计算出的单一数字，如样本均值 $\bar{x}$。它是你对总体参数的最佳猜测，但单独来看它无法传达估计有多精确。

- **置信区间**用反映不确定性的范围来包裹该点估计。它的形式为：

$$\text{CI} = \bar{x} \pm \text{ME}$$

- **误差容限（ME，Margin of Error）**取决于三个因素：你想要多高的置信度、数据中有多少变异性，以及你的样本有多大：

$$\text{ME} = z^\ast \cdot \frac{\sigma}{\sqrt{n}}$$

- 这里 $z^\ast$ 是与你期望的置信水平匹配的正态分布临界值。对于95%置信度，$z^\ast = 1.96$。对于99%置信度，$z^\ast = 2.576$。

![置信区间：点估计以及两侧的误差容限](../../images/confidence_interval.svg)

- **95%置信区间**意味着：如果你多次重复实验，每次都构建一个区间，大约95%的那些区间会包含真实的总体参数。这并不意味着参数有95%的概率在这个特定区间内。参数是固定的；变化的是区间。

- **计算示例**：你测量了50个人的身高，得到 $\bar{x} = 170$ cm，$\sigma = 8$ cm。构建一个95%置信区间。

$$\text{ME} = 1.96 \cdot \frac{8}{\sqrt{50}} = 1.96 \cdot 1.131 = 2.22 \text{ cm}$$

$$\text{CI} = [170 - 2.22, \; 170 + 2.22] = [167.78, \; 172.22]$$

- 你可以以95%的置信度说真实平均身高在167.78到172.22 cm之间。

- 当 $\sigma$ 未知时（通常的情况），改用样本标准差 $s$ 和t分布：

$$\text{CI} = \bar{x} \pm t^\ast_{n-1} \cdot \frac{s}{\sqrt{n}}$$

- 更宽的区间更可信但不太精确。更窄的区间更精确但不太可信。你可以通过增加样本量来在不损失置信度的情况下缩小区间。

- **功效分析（Power Analysis）**帮助你在运行实验之前规划它。问题是：我需要多大的样本才能检测到给定大小的效应，并达到指定的功效？

- 回顾上一文件，功效 = $1 - \beta$，即正确拒绝一个虚假的 $H_0$ 的概率。一个常见的目标是80%的功效。

- 在显著性水平 $\alpha$ 和功效 $1-\beta$ 下，用于检测差异 $\delta$ 的z检验所需样本量为：

$$n = \left(\frac{(z_{\alpha/2} + z_{\beta}) \cdot \sigma}{\delta}\right)^2$$

- 例如，要检测平均身高中2 cm的差异（$\sigma = 8$），$\alpha = 0.05$ 和80%功效（$z_{0.025} = 1.96$，$z_{0.20} = 0.84$）：

$$n = \left(\frac{(1.96 + 0.84) \cdot 8}{2}\right)^2 = \left(\frac{22.4}{2}\right)^2 = 11.2^2 \approx 126$$

- 每组大约需要126人。

- 功效分析防止两种常见错误：进行一个太小而无法检测到真实效应的实验（功效不足），或在远大于必要的实验上浪费资源（功效过大）。

- **蒙特卡罗方法（Monte Carlo methods）**使用随机抽样来解决难以或不可能解析求解的问题。核心思想是：如果你无法精确计算某事物，就多次模拟它，并用结果作为近似。

- 这个名字来源于蒙特卡罗赌场，是对随机性角色的一种致敬。这些方法是ML中的主力工具，用于估计积分、评估模型不确定性以及近似复杂分布等任务。

- 蒙特卡罗的通用方法：
    - 定义一个可能输入的域
    - 从该域中生成随机输入
    - 对每个输入评估一个函数
    - 汇总结果（平均、计数等）

- 一个经典的例子是估计 $\pi$。想象一个边长为2的正方形，以原点为中心，内部有一个内切的半径为1的圆。正方形的面积是4，圆的面积是 $\pi$。

![带有内切圆的正方形，随机点按内/外着色](../../images/monte_carlo_pi.svg)

- 在正方形中均匀随机撒点。落在圆内的点数比例近似于 $\pi/4$：

$$\pi \approx 4 \times \frac{\text{points inside circle}}{\text{total points}}$$

- 一个点 $(x, y)$ 在圆内当且仅当 $x^2 + y^2 \le 1$。你投掷的点越多，估计值越接近真实的 $\pi$ 值。

- 在ML中，蒙特卡罗方法出现在：
    - **蒙特卡罗丢弃法（Monte Carlo dropout）**：在启用丢弃法的情况下多次运行推理以估计预测不确定性
    - **MCMC（Markov Chain Monte Carlo，马尔可夫链蒙特卡罗）**：在贝叶斯模型（Bayesian models）中从复杂的后验分布中抽样
    - **策略梯度方法（Policy gradient methods）**：在强化学习（Reinforcement Learning）中通过抽样轨迹来估计梯度

- **因子分析（Factor Analysis）**是一种发现隐藏（潜在）变量来解释观测变量之间相关性的技术。如果10个性格调查问题可以用3个潜在特质（外向性、宜人性、尽责性）来解释，因子分析就能找出这些特质。

- 该模型假设每个观测变量 $x_i$ 是少数潜在因子 $f_j$ 的线性组合加上噪声：

$$x_i = \lambda_{i1} f_1 + \lambda_{i2} f_2 + \ldots + \lambda_{ik} f_k + \epsilon_i$$

- $\lambda$ 值被称为**因子载荷（Factor Loadings）**，告诉你每个观测变量与每个因子的关联强度。这与第2章的矩阵分解直接相关；因子分析与特征值分解（Eigenvalue Decomposition）和SVD密切相关。

- **实验设计（Experimental Design）**是构建实验以使其能够得出有效结论的艺术。糟糕的设计可以使即使很大的数据集也变得无用。

- 一个良好设计实验的关键组成部分：
    - **自变量（IV，Independent Variable）**：你操控的东西（例如药物剂量、模型架构）
    - **因变量（DV，Dependent Variable）**：你测量的东西（例如恢复时间、准确率）
    - **对照组（Control group）**：不接受处理（或接受安慰剂），为比较提供基线
    - **随机分配（Random assignment）**：参与者被随机分配到各组，这平衡了你没有测量的混杂变量

- **常见的实验设计**：
    - **完全随机设计（Completely randomised design）**：受试者被随机分配到处理组。简单有效，当各组具有可比性时效果很好。
    - **随机区组设计（Randomised block design）**：受试者首先按区组（例如按年龄）分组，然后在每个区组内随机分配处理。这减少了来自区组因素的变异性，精神上与分层抽样类似。
    - **因子设计（Factorial design）**：同时测试多个自变量。$2 \times 3$ 的因子设计有一个变量的2个水平和另一个变量的3个水平，共6种处理组合。这让你能够检测**交互作用（Interactions）**，即一个变量的效应取决于另一个变量的水平。
    - **交叉设计（Crossover design）**：每个受试者按顺序接受所有处理（之间有空窗期）。每个受试者作为自己的对照，减少了个体差异的影响。

- 在ML实验中，这些原则至关重要。在比较模型时，你应该控制随机种子、数据集划分和硬件。交叉验证是一种交叉设计的形式。消融研究（Ablation studies）——每次移除一个组件——遵循因子设计的逻辑。

## 编程任务（在CoLab或notebook中使用）

1. 为身高示例构建95%置信区间，然后尝试不同的置信水平和样本量。
```python
import jax.numpy as jnp

x_bar = 170.0    # sample mean
sigma = 8.0      # population std (known)
n = 50           # sample size

# Critical values for common confidence levels
z_stars = {0.90: 1.645, 0.95: 1.960, 0.99: 2.576}

for conf, z_star in z_stars.items():
    me = z_star * (sigma / jnp.sqrt(n))
    lower, upper = x_bar - me, x_bar + me
    print(f"{conf*100:.0f}% CI: [{lower:.2f}, {upper:.2f}]  (ME = {me:.2f})")
```

2. 使用蒙特卡罗模拟估计 $\pi$。绘制估计值如何随点数增加而收敛。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

key = jax.random.PRNGKey(42)

# Generate random points in [-1, 1] x [-1, 1]
n_points = 100_000
k1, k2 = jax.random.split(key)
x = jax.random.uniform(k1, shape=(n_points,), minval=-1, maxval=1)
y = jax.random.uniform(k2, shape=(n_points,), minval=-1, maxval=1)

# Check which points are inside the unit circle
inside = (x**2 + y**2) <= 1.0
cumulative_inside = jnp.cumsum(inside)
counts = jnp.arange(1, n_points + 1)
pi_estimates = 4.0 * cumulative_inside / counts

plt.figure(figsize=(10, 4))
plt.plot(pi_estimates, color="#3498db", alpha=0.7, linewidth=0.5)
plt.axhline(y=jnp.pi, color="#e74c3c", linestyle="--", label=f"π = {jnp.pi:.6f}")
plt.xlabel("Number of points")
plt.ylabel("Estimate of π")
plt.title("Monte Carlo estimation of π")
plt.legend()
plt.ylim(2.8, 3.5)
plt.show()

print(f"Final estimate: {pi_estimates[-1]:.6f}")
print(f"True value:     {jnp.pi:.6f}")
print(f"Error:          {abs(pi_estimates[-1] - jnp.pi):.6f}")
```

3. 执行一次简单的功效分析：对于给定的效应量和标准差，计算所需样本量并通过模拟验证。
```python
import jax
import jax.numpy as jnp

# Parameters
delta = 2.0      # effect size (difference in means)
sigma = 8.0      # population std
alpha = 0.05
power_target = 0.80

# Analytical sample size
z_alpha = 1.96   # two-tailed, alpha=0.05
z_beta = 0.84    # power=0.80
n_required = ((z_alpha + z_beta) * sigma / delta) ** 2
print(f"Required n per group: {n_required:.0f}")

# Verify by simulation
key = jax.random.PRNGKey(7)
n = int(jnp.ceil(n_required))
n_sims = 5000
rejections = 0

for _ in range(n_sims):
    key, k1, k2 = jax.random.split(key, 3)
    group_a = jax.random.normal(k1, shape=(n,)) * sigma + 50
    group_b = jax.random.normal(k2, shape=(n,)) * sigma + 50 + delta
    pooled_se = jnp.sqrt(2 * sigma**2 / n)
    z = (group_b.mean() - group_a.mean()) / pooled_se
    p = 2 * (1 - __import__("jax").scipy.stats.norm.cdf(jnp.abs(z)))
    if p <= alpha:
        rejections += 1

print(f"Simulated power: {rejections/n_sims:.3f}")
print(f"Target power:    {power_target:.3f}")
```

4. 可视化置信区间宽度如何随样本量变化。这展示了为什么收集更多数据能给出更精确的估计。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

sigma = 8.0
z_star = 1.96  # 95% confidence

sample_sizes = jnp.array([10, 20, 30, 50, 100, 200, 500, 1000], dtype=jnp.float32)
margins = z_star * sigma / jnp.sqrt(sample_sizes)

plt.figure(figsize=(8, 4))
plt.bar([str(int(n)) for n in sample_sizes], margins, color="#3498db", alpha=0.7)
plt.xlabel("Sample size")
plt.ylabel("Margin of error (cm)")
plt.title("95% CI margin of error shrinks with larger samples")
plt.show()
```

# 假设检验（Hypothesis Testing）

*假设检验提供了一个严谨的框架，用于判断观察到的效应是真实存在的还是由偶然造成的。本文件涵盖原假设（Null Hypothesis）和备择假设（Alternative Hypothesis）、p值（p-value）、显著性水平（Significance Level）、t检验（t-test）、卡方检验（Chi-squared Test）、方差分析（ANOVA）以及第I类和第II类错误（Type I/II Errors），这些逻辑与A/B测试、模型比较和研究中使用的是相同的。*

- 统计学不只是描述数据。通常你需要做出一个决策：一种新药有效吗？一种算法比另一种更快吗？平均值改变了吗？假设检验为你提供了使用数据回答这些问题的结构化框架。

- 思路很简单：假设什么都没有改变（"原假设"），然后检查数据是否如此极端以至于这个假设变得难以相信。

- **原假设**（$H_0$）是默认的主张，通常是一个"无效应"或"无差异"的陈述。例如："平均配送时间仍然是30分钟"或"新模型不比旧模型更好。"

- **备择假设**（$H_1$ 或 $H_a$）是你怀疑可能为真的情况："平均配送时间已改变"或"新模型更好。"

- 你永远不直接证明 $H_1$。相反，你问的是：如果 $H_0$ 为真，我看到这种极端数据的可能性有多大？如果非常不可能，你就拒绝 $H_0$ 而支持 $H_1$。

- **检验统计量（Test Statistic）**是一个单一数字，总结了你的样本结果与 $H_0$ 预测值之间的距离。不同的检验使用不同的公式，但逻辑始终相同：测量观测值与期望值之间的距离。

- **p值**是假设 $H_0$ 为真时，观察到至少与你的检验统计量一样极端的结果的概率。小的p值意味着数据在 $H_0$ 下是令人惊讶的。

- **显著性水平**（$\alpha$）是你在查看数据之前设定的阈值。如果 $p \le \alpha$，你拒绝 $H_0$。常见的选择是 $\alpha = 0.05$（5%）和 $\alpha = 0.01$（1%）。

![正态曲线带有阴影拒绝域、标记的检验统计量和突出显示的p值区域](../../images/hypothesis_test.svg)

- 阴影部分的两端是拒绝域（Rejection Region）。如果你的检验统计量落在这里，说明数据在 $H_0$ 下足够令人惊讶，你可以拒绝它。绿色区域显示了特定检验统计量的p值。

- 以下是逐步操作流程：
    - **步骤1**：陈述 $H_0$ 和 $H_1$
    - **步骤2**：选择显著性水平 $\alpha$
    - **步骤3**：收集数据并计算检验统计量
    - **步骤4**：找到p值（或将检验统计量与临界值比较）
    - **步骤5**：如果 $p \le \alpha$，拒绝 $H_0$。否则，未能拒绝 $H_0$

- **计算示例**：一家工厂声称其螺栓的平均长度为10厘米。你测量了36个螺栓，发现样本均值为10.3厘米。已知总体标准差为0.9厘米。是否有证据表明均值发生了变化？

- $H_0$: $\mu = 10$，$H_1$: $\mu \neq 10$，$\alpha = 0.05$

- 检验统计量（z检验，因为 $\sigma$ 已知且 $n$ 很大）：

$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}} = \frac{10.3 - 10}{0.9 / \sqrt{36}} = \frac{0.3}{0.15} = 2.0$$

- 对于 $\alpha = 0.05$ 的双尾检验，临界值为 $\pm 1.96$。我们的 $z = 2.0 > 1.96$，因此我们拒绝 $H_0$。p值约为0.046，小于0.05。

- 结论：有统计上显著的证据表明平均螺栓长度与10厘米有差异。

- **单尾检验（One-tailed test）**检验一个特定方向的效应（$H_1$: $\mu > 10$ 或 $\mu < 10$）。整个 $\alpha$ 放入一个尾部，使得拒绝该方向的 $H_0$ 更容易，但无法检测相反方向的效应。

- **双尾检验（Two-tailed test）**检验任何差异（$H_1$: $\mu \neq 10$）。$\alpha$ 被分配到两个尾部（各 $\alpha/2$）。这更保守，但能捕捉任一方向的效应。

- 即使有良好的流程，错误仍然会发生。确切有两种类型的错误：

![2x2网格显示第I类和第II类错误：真实情况 vs 决策](../../images/type_errors.svg)

- **第I类错误（Type I Error）**（假阳性，False Positive）：当 $H_0$ 实际上为真时你拒绝了它。其概率为 $\alpha$，你可以通过选择显著性水平来控制。就像没有火灾时火警响了。

- **第II类错误（Type II Error）**（假阴性，False Negative）：当 $H_0$ 实际上为假时你未能拒绝它。其概率为 $\beta$。就像真正发生火灾时火警保持沉默。

- **检验功效（Power）**是 $1 - \beta$，即正确拒绝一个虚假的 $H_0$ 的概率。更高的功效意味着你更善于检测真实效应。功效在以下情况下增加：
    - 真实效应量更大（更大的差异更容易检测）
    - 样本量更大（更多数据 = 更精确）
    - 显著性水平 $\alpha$ 更大（但这会增加第I类错误风险）
    - 变异性更低（更少的噪声）

- 在I类错误和II类错误之间存在权衡。降低 $\alpha$（对假阳性更谨慎）会增加 $\beta$（更多假阴性）。在固定样本量下，你无法同时最小化两者。

- **参数检验（Parametric tests）**假设数据遵循特定的分布（通常是正态分布）。当假设成立时，它们更强大。

- **Z检验**：当 $\sigma$ 已知且 $n$ 很大（$n \ge 30$）时，将样本均值与已知值比较。检验统计量：

$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

- **T检验**：类似于Z检验，但适用于 $\sigma$ 未知（从样本估计）或 $n$ 很小的情况。使用t分布（t-distribution），其尾部比正态分布更重。更重的尾部考虑到了估计 $\sigma$ 带来的额外不确定性。

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

- t分布有一个称为**自由度（Degrees of Freedom）**的参数（$df = n - 1$）。随着 $df$ 增加，t分布趋近于正态分布。

- 有几种不同形式的t检验：
    - **单样本t检验**：样本均值是否与某个特定值不同？
    - **独立双样本t检验**：两个独立组的均值是否不同？
    - **配对t检验**：两个相关测量的均值是否不同（例如同一受试者治疗前后）？

- **方差分析（ANOVA，Analysis of Variance）**：检验三个或更多组的均值是否相等。与其进行多次t检验（这会导致第I类错误率膨胀），ANOVA通过比较组间方差与组内方差来进行单一检验。

$$F = \frac{\text{variance between groups}}{\text{variance within groups}}$$

- 大的 $F$ 比值意味着组间差异比你单从随机变动中预期的要大。

- **非参数检验（Non-parametric tests）**对数据分布做出更少的假设。它们在秩上而非原始值上计算，使它们对离群值和非正态性具有鲁棒性。

- **卡方检验**（$\chi^2$）：检验观测频率是否与期望频率匹配。用于分类数据。例如：红色、蓝色和绿色汽车的比例是否与制造商声称的比例一致？

$$\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$$

- **曼-惠特尼U检验（Mann-Whitney U test）**：独立双样本t检验的非参数替代方法。通过比较秩来检验一个组是否倾向于有比另一个组更大的值。

- **威尔科克森符号秩检验（Wilcoxon signed-rank test）**：配对t检验的非参数替代方法。通过查看差异的大小和方向来比较配对观测。

- **克鲁斯卡尔-沃利斯检验（Kruskal-Wallis test）**：单因素ANOVA的非参数替代方法。通过比较所有组的秩来检验多个组是否来自同一分布。

- **拟合优度检验（Goodness-of-fit tests）**检查你的数据是否遵循某个特定的理论分布。卡方拟合优度检验将观测到的区间计数与假设分布下的期望计数进行比较。

- **正态性检验（Normality tests）**专门检验数据是否服从正态分布。常见的包括夏皮罗-威尔克检验（Shapiro-Wilk test，对小样本功能强大）和科尔莫戈罗夫-斯米尔诺夫检验（Kolmogorov-Smirnov test，将样本CDF与理论CDF进行比较）。

- 在ML中，当你比较模型性能时，假设检验就会出现。如果模型A达到92%的准确率（Accuracy）而模型B达到91%，这种差异是真实的还是仅仅是噪声？对交叉验证（Cross-Validation）分数进行配对t检验可以回答这个问题。

## 编程任务（在CoLab或notebook中使用）

1. 对文本中的螺栓工厂示例执行z检验。计算检验统计量、p值，并做出决策。
```python
import jax.numpy as jnp

x_bar = 10.3    # sample mean
mu_0 = 10.0     # null hypothesis value
sigma = 0.9     # known population std
n = 36           # sample size
alpha = 0.05

# Test statistic
z = (x_bar - mu_0) / (sigma / jnp.sqrt(n))
print(f"z = {z:.4f}")

# p-value (two-tailed) using the normal CDF approximation
# For |z| = 2.0, p ≈ 0.0456
from jax.scipy.stats import norm
p_value = 2 * (1 - norm.cdf(jnp.abs(z)))
print(f"p-value = {p_value:.4f}")
print(f"Reject H₀? {p_value <= alpha}")
```

2. 模拟第I类错误：当 $H_0$ 为真时，我们错误地拒绝它的频率是多少？运行10,000次试验，检查拒绝率是否匹配 $\alpha$。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(0)
mu_0 = 50.0
sigma = 10.0
n = 30
alpha = 0.05
n_experiments = 10_000

rejections = 0
for i in range(n_experiments):
    key, subkey = jax.random.split(key)
    sample = mu_0 + sigma * jax.random.normal(subkey, shape=(n,))
    z = (sample.mean() - mu_0) / (sigma / jnp.sqrt(n))
    p_value = 2 * (1 - __import__("jax").scipy.stats.norm.cdf(jnp.abs(z)))
    if p_value <= alpha:
        rejections += 1

print(f"Rejection rate: {rejections/n_experiments:.4f}")
print(f"Expected (α):   {alpha}")
```

3. 比较两组数据的t检验和曼-惠特尼U检验。生成一组均值略高的数据，看看哪种检验能检测到差异。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(99)
k1, k2 = jax.random.split(key)

group_a = jax.random.normal(k1, shape=(25,)) * 5 + 100
group_b = jax.random.normal(k2, shape=(25,)) * 5 + 103  # slightly higher mean

# Two-sample t-test (equal variance assumed)
n_a, n_b = len(group_a), len(group_b)
mean_a, mean_b = group_a.mean(), group_b.mean()
pooled_var = ((n_a - 1) * group_a.var() + (n_b - 1) * group_b.var()) / (n_a + n_b - 2)
se = jnp.sqrt(pooled_var * (1/n_a + 1/n_b))
t_stat = (mean_a - mean_b) / se
print(f"T-test statistic: {t_stat:.4f}")

# Mann-Whitney: count how often group_a values beat group_b values
u_stat = jnp.sum(group_a[:, None] < group_b[None, :])
print(f"Mann-Whitney U:   {u_stat}")
print(f"\nGroup A mean: {mean_a:.2f}, Group B mean: {mean_b:.2f}")
```

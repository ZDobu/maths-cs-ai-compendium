# 抽样（Sampling）

*抽样决定了我们如何收集数据，并直接控制我们得出的每个结论的质量。本文件涵盖简单随机抽样（Simple Random Sampling）、分层抽样（Stratified Sampling）、整群抽样（Cluster Sampling）和系统抽样（Systematic Sampling），抽样分布（Sampling Distributions）、大数定律（Law of Large Numbers）和自助法（Bootstrapping），这些方法对ML中的训练/测试划分和数据集整理至关重要。*

- 在理想世界中，你可以测量你关心的群体中的每一个成员。然而在现实中，这几乎从不可能是——你无法调查每位选民、测试每个灯泡，或扫描每位病人。所以你需要抽取一个**样本**，并用它来了解整体。

- **总体（Population）**是你要研究的全部个体或项目的完整集合。**样本**是你实际观察的子集。

- **参数（Parameter）**是描述总体的数字（例如一个国家所有成年人的真实平均身高）。

- **统计量（Statistic）**是从你的样本中计算出的数字（例如你测量的500人的平均身高）。统计量用于估计参数。

- 你结论的质量完全取决于你如何选择样本。一个有偏差的样本导致有偏差的结论，无论你的分析多么精密。

- **抽样框（Sampling frame）**是你实际从中抽取样本的所有个体的列表。理想情况下它应该与总体完全一致，但实际上存在差距。

- 例如，如果你通过电话调查人们，你就漏掉了所有没有电话的人。抽样框与总体之间的差异称为**覆盖误差（Coverage error）**。

- **抽样误差（Sampling error）**是样本统计量与总体参数之间的自然差异。

- 即使是一个完全随机的样本也不会完全精确地匹配总体。更大的样本可以减小抽样误差。

- 抽样有两大类：概率抽样和非概率抽样。

- **概率抽样（Probability sampling）**意味着总体中的每个成员都有已知的、非零的被选中机会。这使得你可以量化不确定性并推广结果。

- **简单随机抽样（Simple random sampling）**：每个个体有相等的被选中机会，且每个大小为 $n$ 的可能样本都等可能被选中。想象把每个人的名字放进帽子然后盲抽。

- **分层抽样（Stratified sampling）**：根据共同特征（如年龄组、地区）将总体划分为不重叠的组（层，strata），然后从每个层中随机抽样。这保证了每个组都有代表，并在层间差异较大时减小方差。

- **整群抽样（Cluster sampling）**：将总体划分为组（群），随机选取一些群，然后包含所选群中的每个人。这在总体地理分布广泛时很实用，比如抽样整个学校而非整个区域内的个别学生。

- **系统抽样（Systematic sampling）**：随机选择一个起点，然后从列表中每隔 $k$ 个人选取一个。例如，从第7个人开始，然后每10个人选取一个（7, 17, 27, ...）。实施简单，但如果列表存在隐藏模式可能引入偏差。

- **非概率抽样（Non-probability sampling）**不给每个成员一个已知的被选中概率。结果不能严格推广，但这些方法通常更快、更便宜。

- **便利抽样（Convenience sampling）**：选择最容易接触到的人。在商场调查人们很方便，但会漏掉那些不去该商场购物的人。

- **配额抽样（Quota sampling）**：类似于分层抽样，但没有随机性。研究人员通过从每个组中挑选可接触的个体来填充配额（例如50名男性和50名女性）。

- **滚雪球抽样（Snowball sampling）**：从少数参与者开始，请他们招募其他人。适用于难以接触的人群（例如研究罕见疾病），但偏向于社交联系更广的个体。

- 一旦你有了抽样方法，一个自然的问题就会出现：如果我抽取了不同的样本，会得到不同的统计量吗？几乎肯定会。**抽样分布**是同一统计量（如样本均值）在所有可能的大小相同的样本中的分布。

- 想象抽取1,000个不同的30人样本并计算每个样本的平均身高。这1,000个均值形成一个分布。有些会略高于真实总体均值，有些略低于，大多数会聚集在真实值周围。

- 这个抽样分布的标准差称为**标准误（Standard Error）**：

$$SE = \frac{\sigma}{\sqrt{n}}$$

- 注意标准误随着 $n$ 的增长而缩小。更大的样本给出更精确的估计。将样本量增加四倍会使标准误减半。

- 统计学中最重要的结论是**中心极限定理（CLT，Central Limit Theorem）**。它指出：无论原始总体的形状如何，随着样本量的增加，样本均值的分布趋近于正态分布。

![中心极限定理：偏态总体生成正态分布的样本均值](../../images/central_limit_theorem.svg)

- 更精确地说，如果 $X_1, X_2, \ldots, X_n$ 是来自任何具有均值 $\mu$ 和有限方差 $\sigma^2$ 的分布的独立观测值，那么随着 $n$ 增长：

$$\bar{X} \approx \text{Normal}\!\left(\mu, \frac{\sigma^2}{n}\right)$$

- CLT是使大多数推断统计得以成立的基础。它让我们在基础数据不服从正态时，只要样本足够大，就能使用正态分布作为近似。

- 多大算"足够大"？一个常见的经验法则是 $n \ge 30$，但这取决于总体的非正态程度。对于高度偏斜的分布，你可能需要更多。对于大致对称的总体，即使 $n = 10$ 也可能足够。

- CLT有三个关键条件：
    - **独立性（Independence）**：每个观测值不得影响其他观测值
    - **有限方差（Finite variance）**：总体方差必须存在（排除了一些奇异的分布）
    - **同分布（Identical distribution）**：所有观测值来自同一分布

1. 直观演示CLT：从一个高度偏斜的分布中抽取样本，计算样本均值，观察均值直方图如何变成钟形。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

key = jax.random.PRNGKey(0)

# Exponential distribution (very skewed)
population = jax.random.exponential(key, shape=(100_000,))

fig, axes = plt.subplots(1, 4, figsize=(14, 3))
sample_sizes = [1, 5, 30, 100]

for ax, n in zip(axes, sample_sizes):
    keys = jax.random.split(key, 2000)
    means = jnp.array([jax.random.choice(k, population, shape=(n,)).mean() for k in keys])
    ax.hist(means, bins=40, color="#3498db", alpha=0.7, density=True)
    ax.set_title(f"n = {n}")
    ax.set_xlim(0, 4)

fig.suptitle("CLT: sample means become normal as n increases", fontsize=13)
plt.tight_layout()
plt.show()
```

2. 比较简单随机抽样和分层抽样。创建一个具有不同组的总体，并展示分层抽样给出了更低方差的估计。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(42)

# Population: two distinct groups
group_a = jax.random.normal(key, shape=(500,)) + 10   # mean ~10
key, subkey = jax.random.split(key)
group_b = jax.random.normal(subkey, shape=(500,)) + 20  # mean ~20
population = jnp.concatenate([group_a, group_b])

# Simple random sampling: 1000 trials, sample size 20
srs_means = []
for i in range(1000):
    key, subkey = jax.random.split(key)
    sample = jax.random.choice(subkey, population, shape=(20,), replace=False)
    srs_means.append(sample.mean())
srs_means = jnp.array(srs_means)

# Stratified sampling: 10 from each group
strat_means = []
for i in range(1000):
    key, k1, k2 = jax.random.split(key, 3)
    s_a = jax.random.choice(k1, group_a, shape=(10,), replace=False)
    s_b = jax.random.choice(k2, group_b, shape=(10,), replace=False)
    strat_means.append(jnp.concatenate([s_a, s_b]).mean())
strat_means = jnp.array(strat_means)

print(f"Simple Random - Mean: {srs_means.mean():.3f}, Std: {srs_means.std():.3f}")
print(f"Stratified    - Mean: {strat_means.mean():.3f}, Std: {strat_means.std():.3f}")
print(f"Stratified sampling reduced variance by {(1 - strat_means.var()/srs_means.var())*100:.1f}%")
```

3. 探索样本量如何影响标准误。绘制标准误对样本量的关系图，确认 $1/\sqrt{n}$ 的关系。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

key = jax.random.PRNGKey(7)
population = jax.random.normal(key, shape=(50_000,)) * 10 + 50

sample_sizes = [5, 10, 20, 50, 100, 200, 500, 1000]
std_errors = []

for n in sample_sizes:
    means = []
    for _ in range(500):
        key, subkey = jax.random.split(key)
        sample = jax.random.choice(subkey, population, shape=(n,))
        means.append(sample.mean())
    std_errors.append(jnp.array(means).std())

plt.figure(figsize=(8, 4))
plt.plot(sample_sizes, std_errors, "o-", color="#e74c3c", label="Observed SE")
theoretical = population.std() / jnp.sqrt(jnp.array(sample_sizes, dtype=jnp.float32))
plt.plot(sample_sizes, theoretical, "--", color="#3498db", label="σ/√n (theoretical)")
plt.xlabel("Sample size (n)")
plt.ylabel("Standard error")
plt.legend()
plt.title("Standard error shrinks with larger samples")
plt.show()
```

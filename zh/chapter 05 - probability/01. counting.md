# 计数（Counting）

*计数是计算概率的前提，你必须知道有多少种可能的结果，才能为这些结果分配可能性。本文件涵盖了乘法规则和加法规则、阶乘、排列（permutation）、组合（combination）以及二项式系数，这些组合数学（combinatorics）工具支撑着机器学习中的抽样、哈希和概率分析。*

- 在计算概率之前，我们需要先统计结果的数量。如果你想计算在扑克中拿到一手好牌的概率，你首先需要知道总共可能有多少种手牌，其中又有多少种是获胜的。计数是使概率计算变得精确的数学工具。

- 最简单的计数原则是**乘法规则**（multiplication rule）。如果一个决策有 $m$ 个选项，另一个独立的决策有 $n$ 个选项，那么组合结果的总数为 $m \times n$。

- 想象一下早上穿衣服的场景。你有 3 件衬衫和 4 条裤子。每件衬衫都可以与每条裤子搭配，因此你有 $3 \times 4 = 12$ 种可能的穿搭。

![展示 3 件衬衫乘以 4 条裤子等于 12 种穿搭的树形图](../../images/counting_outfits.svg)

- 乘法规则可以扩展到任意数量的选择。如果你还有 2 双鞋，那么总的穿搭数变为 $3 \times 4 \times 2 = 24$。每一个新的独立选择都会以乘法方式增加结果总数。

- **加法规则**（addition rule）用于处理"或"的场景。如果事件 A 可以以 $m$ 种方式发生，事件 B 可以以 $n$ 种方式发生，且两者不能同时发生（互斥），则总方式数为 $m + n$。

- 假设你可以从城市 X 到城市 Y 乘坐汽车（3 条路线）或火车（2 条路线）。你不能同时乘坐两者，因此总选项数为 $3 + 2 = 5$。

- 当事件有重叠时，你需要减去被重复计数的结果。如果 $A$ 和 $B$ 可以同时发生，则计数为 $|A \cup B| = |A| + |B| - |A \cap B|$。这便是**容斥原理**（inclusion-exclusion principle），它在我们讨论概率加法规则时还会再次出现。

- 非负整数 $n$ 的**阶乘**（factorial）是所有不超过 $n$ 的正整数的乘积：

$$n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1$$

- 可以把阶乘理解为回答这样一个问题：用多少种方式可以将 $n$ 个不同的物体排成一行？书架上的三本书可以以 $3! = 3 \times 2 \times 1 = 6$ 种方式排列。按照惯例，$0! = 1$。

- 阶乘的增长速度极快。$10! = 3{,}628{,}800$，而 $20!$ 已经超过 $2.4 \times 10^{18}$。这种爆炸式增长正是暴力搜索（brute-force search）在组合问题中变得不切实际的原因。

- **排列**（permutation）是有序的物体排列方式。当你从 $n$ 个不同物体中选取 $r$ 个且顺序重要时，排列数为：

$$P(n, r) = \frac{n!}{(n - r)!}$$

- 想象一下，从一个 10 人的俱乐部中选出主席、副主席和财务官。第一个职位有 10 个候选人，第二个职位剩下 9 个候选，第三个职位剩下 8 个候选。因此共有 $P(10, 3) = 10 \times 9 \times 8 = 720$。公式验证了这一点：$\frac{10!}{7!} = 720$。

- **组合**（combination）是无序的选择。当你从 $n$ 个物体中选取 $r$ 个且顺序不重要时，我们需要除以冗余的排序数：

$$C(n, r) = \binom{n}{r} = \frac{n!}{r!(n - r)!}$$

- 记号 $\binom{n}{r}$ 读作"n 选 r"。其核心洞察是：每个组合对应 $r!$ 个排列（所选 $r$ 个物体可以以 $r!$ 种方式重新排列），因此我们只需将排列数除以 $r!$。

![并排对比：排列计算所有排序，组合则将相同的分组视为同一个](../../images/permutation_vs_combination.svg)

- 示例：从一组 10 人中，有多少种方式可以组成一个 3 人委员会？顺序不重要（没有主席或副主席之分，只是成员），因此我们使用组合：

$$\binom{10}{3} = \frac{10!}{3! \cdot 7!} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

- 同样的 10 人产生 720 个排列，但只有 120 个组合，因为每个 3 人组有 $3! = 6$ 种内部排序。

- 组合是概率论的核心。二项式系数（binomial coefficient）$\binom{n}{r}$ 统计了在 $n$ 次试验中恰好获得 $r$ 次成功的方式数，这正是二项分布（binomial distribution）的核心（在文件 03 中讨论）。

- 让我们通过一个经典委员会问题来综合运用多种计数思想。

- **问题**：一个俱乐部有 8 名男性和 6 名女性。有多少种方式可以组成一个恰好包含 3 名男性和 2 名女性的 5 人委员会？

- **步骤 1**：从 8 人中选 3 名男性。

$$\binom{8}{3} = \frac{8!}{3! \cdot 5!} = \frac{8 \times 7 \times 6}{3 \times 2 \times 1} = 56$$

- **步骤 2**：从 6 人中选 2 名女性。

$$\binom{6}{2} = \frac{6!}{2! \cdot 4!} = \frac{6 \times 5}{2 \times 1} = 15$$

- **步骤 3**：应用乘法规则。每次选择男性和每次选择女性可以任意组合：

$$56 \times 15 = 840 \text{ 种委员会}$$

- 这种模式——将一个复杂的计数问题分解为独立的子选择问题，再将结果相乘——是组合数学的标准方法。

- 还存在**可重复排列**（permutations with repetition）。当物体可以重复时，从 $n$ 种类型中选取 $r$ 个会得到 $n^r$ 种结果。一个使用数字 0-9 的 4 位 PIN 码有 $10^4 = 10{,}000$ 种可能性。每个位置有 10 个选项，乘法规则处理了剩余的计算。

- **可重复组合**（combinations with repetition，也称为"星与棒"方法）统计在允许重复且顺序不重要的情况下，从 $n$ 种类型中选取 $r$ 个物体的方式数：

$$\binom{n + r - 1}{r} = \frac{(n + r - 1)!}{r!(n - 1)!}$$

- 示例：从 4 种口味的冰淇淋中选 3 球（允许重复）得到 $\binom{4 + 3 - 1}{3} = \binom{6}{3} = 20$ 种选择。

- 计数工具箱总结如下：

| 场景 | 公式 |
|---|---|
| 有序，不可重复（排列） | $P(n,r) = \frac{n!}{(n-r)!}$ |
| 无序，不可重复（组合） | $\binom{n}{r} = \frac{n!}{r!(n-r)!}$ |
| 有序，可重复 | $n^r$ |
| 无序，可重复 | $\binom{n+r-1}{r}$ |

- 所有涉及等可能结果的计算都使用公式 $P(\text{事件}) = \frac{\text{有利结果数}}{\text{总结果数}}$。计数为我们提供了这两个数字。有了这个基础，我们就可以在下一个文件中形式化概率本身。

1. 分别使用阶乘公式和直接计算两种方法计算 $P(10, 3)$ 和 $\binom{10}{3}$。验证排列数始终是组合数的 $r!$ 倍。
```python
import jax.numpy as jnp
from math import factorial

n, r = 10, 3

perm = factorial(n) // factorial(n - r)
comb = factorial(n) // (factorial(r) * factorial(n - r))

print(f"P({n},{r}) = {perm}")
print(f"C({n},{r}) = {comb}")
print(f"P / C = {perm // comb} (should equal {r}! = {factorial(r)})")
```

2. 用编程方式求解委员会问题（从 8 名男性中选 3 名，从 6 名女性中选 2 名），并通过枚举所有有效委员会来验证结果。
```python
from itertools import combinations
from math import factorial

def comb_count(n, r):
    return factorial(n) // (factorial(r) * factorial(n - r))

# 公式方法
men_ways = comb_count(8, 3)
women_ways = comb_count(6, 2)
print(f"Formula: {men_ways} × {women_ways} = {men_ways * women_ways}")

# 枚举方法
men = [f"M{i}" for i in range(1, 9)]
women = [f"W{i}" for i in range(1, 7)]
count = sum(1 for _ in combinations(men, 3) for _ in combinations(women, 2))
print(f"Enumeration: {count}")
```

3. 计算用 26 个小写字母可以组成多少个 4 字符密码（允许重复）。然后计算其中有多少个密码不包含重复字母。
```python
from math import factorial

n = 26
r = 4

with_rep = n ** r
without_rep = factorial(n) // factorial(n - r)

print(f"With repetition:    {with_rep:>10,}")
print(f"Without repetition: {without_rep:>10,}")
print(f"Fraction with repeats: {1 - without_rep/with_rep:.2%}")
```

4. 模拟生日问题（birthday problem）：在一个有 $k$ 个人的小组中，至少有两人生日相同的概率是多少？绘制 $k = 1$ 到 $60$ 的概率图，并找出概率在何处超过 50%。
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

def birthday_prob_exact(k):
    """Probability of at least one shared birthday in group of k."""
    p_no_match = 1.0
    for i in range(k):
        p_no_match *= (365 - i) / 365
    return 1 - p_no_match

ks = list(range(1, 61))
probs = [birthday_prob_exact(k) for k in ks]

plt.figure(figsize=(8, 4))
plt.plot(ks, probs, color="#3498db", linewidth=2)
plt.axhline(y=0.5, color="#e74c3c", linestyle="--", alpha=0.7, label="50%")
cross = next(k for k, p in zip(ks, probs) if p >= 0.5)
plt.axvline(x=cross, color="#e74c3c", linestyle="--", alpha=0.7)
plt.xlabel("Group size (k)")
plt.ylabel("P(at least one shared birthday)")
plt.title(f"Birthday Problem (crosses 50% at k={cross})")
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

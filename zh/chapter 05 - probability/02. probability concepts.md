# 概率概念（Probability Concepts）

*概率论（probability theory）将不确定性形式化，并为在不确定条件下进行推理提供了规则。本文件涵盖样本空间（sample space）、事件（event）、概率公理（axioms of probability）、条件概率（conditional probability）、独立性（independence）、贝叶斯定理（Bayes' theorem）以及频率学派（frequentist）与贝叶斯学派（Bayesian）的解释，即机器学习中每个生成模型（generative model）和判别模型（discriminative model）背后的数学框架。*

- 概率为事件指派一个介于 0 和 1 之间的数字，衡量该事件发生的可能性。

- 概率 0 表示不可能，1 表示必然，0.5 则如同投掷一枚硬币。

- 存在两种主要的解释。**频率学派**（frequentist）观点认为，概率是长期相对频率：将一枚公平的硬币抛掷 10,000 次，正面朝上的次数将大约占 50%。

- **贝叶斯学派**（Bayesian）观点认为，概率是一种信念程度：你可能会说"明天下雨的概率是 70%"，尽管明天只能发生一次。

- 两种解释使用相同的数学规则。差异在于哲学层面，但在机器学习中很重要。频率学派方法给出点估计（point estimate）。贝叶斯方法则给出参数上的完整分布。

- **样本空间**（sample space）$S$ 是某次实验所有可能结果的集合。抛一枚硬币：$S = \{H, T\}$。掷一颗骰子：$S = \{1, 2, 3, 4, 5, 6\}$。

- **事件**（event）是样本空间的任意子集。"掷出偶数"是事件 $A = \{2, 4, 6\}$，它是 $S$ 的一个子集。

- 当所有结果等可能时，事件概率就是简单的计数（来自文件 01）：

$$P(A) = \frac{|A|}{|S|} = \frac{\text{有利结果数}}{\text{总结果数}}$$

- 对于偶数示例：$P(\text{偶数}) = \frac{3}{6} = 0.5$。

![展示事件 A 和 B 在样本空间 S 中，以及交集与补集的维恩图](../../images/venn_diagram.svg)

- 事件 $A$ 的**补集**（complement），记作 $A'$ 或 $A^c$，是 $S$ 中所有不在 $A$ 中的结果。由于每个结果要么在 $A$ 中，要么不在：

$$P(A') = 1 - P(A)$$

- 补集往往是更简单的路线。与其统计在 5 次抛硬币中至少得到一次正面的所有方式，不如统计得不到任何正面的那一种方式，然后用减法：$P(\text{至少一次正面}) = 1 - P(\text{全是反面}) = 1 - (0.5)^5 = 0.969$。

- 如果两个事件不能同时发生，则称它们是**互斥的**（mutually exclusive，也称不相交的）：$A \cap B = \emptyset$。在一次掷骰子中掷出 2 和掷出 5 是互斥的。

- **互斥事件的加法规则**（addition rule）是直截了当的：

$$P(A \cup B) = P(A) + P(B) \quad \text{（当 } A \cap B = \emptyset\text{）}$$

- 当事件可能重叠时，你需要使用**一般加法规则**（general addition rule）来避免重复计数交集：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

- 这反映了计数中的容斥原理。上面的维恩图说明了原因：紫色区域（交集）在 $P(A)$ 中被计了一次，在 $P(B)$ 中又被计了一次，因此我们减去一次。

- **联合概率**（joint probability）$P(A \cap B)$ 是 $A$ 和 $B$ 同时发生的概率。在一副扑克牌中，$P(\text{红色} \cap \text{国王}) = \frac{2}{52}$，因为有 2 张红色国王。

- **边缘概率**（marginal probability）是某个单独事件的概率，不考虑其他事件。$P(\text{红色}) = \frac{26}{52} = 0.5$ 就是一个边缘概率。如果你有两个变量的联合分布（joint distribution），可以通过在另一个变量上求和（或积分）来得到边缘概率。

- **条件概率**（conditional probability）回答的是：给定 $B$ 已经发生，$A$ 的概率是多少？我们将样本空间从 $S$ 缩小到 $B$，再问 $B$ 中有多大比例也属于 $A$：

$$P(A | B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

![条件概率将样本空间从 S 缩小到 B](../../images/conditional_probability.svg)

- 示例：你抽了一张牌，有人告诉你它是红色的。它是国王的概率是多少？共有 26 张红牌，其中 2 张是国王，因此 $P(\text{国王} | \text{红色}) = \frac{2}{26} = \frac{1}{13}$。使用公式：$P(\text{国王} \cap \text{红色}) / P(\text{红色}) = \frac{2/52}{26/52} = \frac{1}{13}$。

- 如果知道一个事件发生不能告诉你关于另一个事件的任何信息，则这两个事件是**独立的**（independent）。形式化表述为：

$$P(A \cap B) = P(A) \cdot P(B)$$

- 等价地，$P(A | B) = P(A)$。抛掷两枚独立的硬币是独立事件。不放回地抽两张牌则不是独立的（第一次抽取会改变剩余的牌）。

- 独立性是一个巨大的简化工具。对于独立事件，联合概率可以分解为乘积，这使得计算变得可处理。许多机器学习模型正是由于这种简化而假设特征之间具有独立性（例如，朴素贝叶斯（Naive Bayes））。

- 任意两个事件的**乘法规则**（multiplication rule）是对条件概率公式的重排：

$$P(A \cap B) = P(A | B) \cdot P(B) = P(B | A) \cdot P(A)$$

- 对于独立事件，由于条件概率等于边缘概率，这简化为 $P(A \cap B) = P(A) \cdot P(B)$。

- **贝叶斯定理**（Bayes' theorem）是概率论中最重要的结果之一，也是贝叶斯机器学习的基石。它允许你逆转条件概率的方向：

$$P(A | B) = \frac{P(B | A) \cdot P(A)}{P(B)}$$

- 该定理直接从用两种方式写 $P(A \cap B)$ 推出：$P(B|A) \cdot P(A) = P(A|B) \cdot P(B)$，然后解出 $P(A|B)$。

![贝叶斯定理的组成部分：后验、似然、先验和证据](../../images/bayes_components.svg)

- 每个组成部分都有一个名称：
    - **先验**（prior）$P(A)$：在观察证据之前你的初始信念
    - **似然**（likelihood）$P(B|A)$：假设 $A$ 为真时，证据出现的概率
    - **证据**（evidence）$P(B)$：观察到该证据的总概率，起归一化作用
    - **后验**（posterior）$P(A|B)$：在观察证据之后你更新后的信念

- 让我们通过经典的医学诊断示例来具体理解。假设某种疾病影响 1% 的人口。诊断该疾病的测试准确率为 95%：它正确识别 95% 的患病人（灵敏度（sensitivity）），并正确识别 90% 的健康人（特异度（specificity））。

- 你的测试结果为阳性。你真正患病的概率是多少？

- 令 $D$ = 患病，$+$ = 测试阳性。
    - 先验：$P(D) = 0.01$
    - 似然：$P(+ | D) = 0.95$
    - 假阳性率：$P(+ | D') = 0.10$

- 我们需要计算 $P(+)$。由全概率公式（law of total probability）：

$$P(+) = P(+ | D) \cdot P(D) + P(+ | D') \cdot P(D')$$
$$= 0.95 \times 0.01 + 0.10 \times 0.99 = 0.0095 + 0.099 = 0.1085$$

- 现在应用贝叶斯定理：

$$P(D | +) = \frac{P(+ | D) \cdot P(D)}{P(+)} = \frac{0.95 \times 0.01}{0.1085} \approx 0.088$$

- 尽管测试"准确率为 95%"，阳性结果只会给你大约 8.8% 的真实患病概率。先验信息极其重要。由于疾病很罕见，大多数阳性结果都是假阳性。这对于机器学习中的任何分类问题都是一个关键洞察：当类别不平衡时，仅凭准确率会具有误导性。

- **全概率公式**（law of total probability）将样本空间划分为互斥且穷尽的（mutually exclusive and exhaustive）事件 $B_1, B_2, \ldots, B_n$，并将任何事件 $A$ 表达为：

$$P(A) = \sum_{i=1}^{n} P(A | B_i) \cdot P(B_i)$$

- 这正是我们在医学示例中用来计算 $P(+)$ 的方法：我们将人群分为"患病"和"未患病"两个部分。

- 概率的**链式规则**（chain rule of probability）将乘法规则推广到任意数量的事件：

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2 | A_1) \cdot P(A_3 | A_1 \cap A_2) \cdots P(A_n | A_1 \cap \cdots \cap A_{n-1})$$

- 每个因子都以它之前的所有事件为条件。这是自回归语言模型（autoregressive language model）的骨干：一个句子的概率是每个词在给定其前面所有词的条件下的概率的乘积。

- **条件独立性**（conditional independence）意味着两个事件在给定第三个事件时是独立的。$A$ 和 $B$ 在给定 $C$ 时条件独立，如果：

$$P(A \cap B | C) = P(A | C) \cdot P(B | C)$$

- 事件可能在边缘分布上是相关的，但在条件分布上是独立的，反之亦然。例如，两位学生的考试成绩可能相关（两者都取决于试题难度），但给定试题难度后，他们的成绩是独立的。

- 条件独立性是贝叶斯网络（Bayesian network）等图模型背后的关键假设。它使你将复杂的联合分布分解为可管理的片段，使推理在计算上变得可行。

## 编程任务（使用 CoLab 或 notebook）

1. 模拟医学诊断问题。生成一个包含 100,000 人的总体，应用疾病流行率和测试准确率，验证贝叶斯定理给出正确的后验概率。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(42)
n = 100_000

# 生成总体
k1, k2 = jax.random.split(key)
has_disease = jax.random.bernoulli(k1, p=0.01, shape=(n,))

# 生成测试结果
k3, k4 = jax.random.split(k2)
# 灵敏度：P(+|D) = 0.95，特异度：P(-|D') = 0.90
test_positive = jnp.where(
    has_disease,
    jax.random.bernoulli(k3, p=0.95, shape=(n,)),
    jax.random.bernoulli(k4, p=0.10, shape=(n,))
)

# 在测试阳性的人中，有多大比例确实患病？
positives = test_positive.astype(bool)
true_positives = (has_disease & positives).sum()
total_positives = positives.sum()

print(f"Total positive tests: {total_positives}")
print(f"True positives: {true_positives}")
print(f"P(Disease | Positive) = {true_positives / total_positives:.4f}")
print(f"Bayes' formula:         {0.95 * 0.01 / 0.1085:.4f}")
```

2. 通过仿真验证加法规则。生成具有已知概率和重叠区间的随机事件 A 和 B，然后验证 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(0)
n = 200_000
k1, k2 = jax.random.split(key)

# 事件：A = 值 < 0.4，B = 值 < 0.6（重叠在 < 0.4）
vals_a = jax.random.uniform(k1, shape=(n,))
vals_b = jax.random.uniform(k2, shape=(n,))

A = vals_a < 0.4
B = vals_b < 0.6

p_a = A.mean()
p_b = B.mean()
p_a_and_b = (A & B).mean()
p_a_or_b = (A | B).mean()

print(f"P(A) = {p_a:.4f}")
print(f"P(B) = {p_b:.4f}")
print(f"P(A ∩ B) = {p_a_and_b:.4f}")
print(f"P(A ∪ B) simulated = {p_a_or_b:.4f}")
print(f"P(A) + P(B) - P(A∩B) = {p_a + p_b - p_a_and_b:.4f}")
```

3. 展示条件概率如何随证据变化。模拟掷两枚骰子，计算 $P(\text{总和} = 7)$，然后计算 $P(\text{总和} = 7 | \text{第一枚骰子} = 3)$。
```python
import jax
import jax.numpy as jnp

key = jax.random.PRNGKey(1)
n = 500_000
k1, k2 = jax.random.split(key)

d1 = jax.random.randint(k1, shape=(n,), minval=1, maxval=7)
d2 = jax.random.randint(k2, shape=(n,), minval=1, maxval=7)
total = d1 + d2

# 无条件概率
p_sum7 = (total == 7).mean()
print(f"P(sum=7) = {p_sum7:.4f} (exact: {6/36:.4f})")

# 条件在 first die = 3 上
mask = d1 == 3
p_sum7_given_d1_3 = (total[mask] == 7).mean()
print(f"P(sum=7 | d1=3) = {p_sum7_given_d1_3:.4f} (exact: {1/6:.4f})")
```

4. 将贝叶斯定理实现为函数，并用它迭代更新信念。从对硬币偏差（bias）的均匀先验开始，在观察每次抛掷后更新。
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

def bayes_update(prior, likelihood):
    """将对先验乘以似然并归一化。"""
    posterior = prior * likelihood
    return posterior / posterior.sum()

# 将可能的偏差值离散化
theta = jnp.linspace(0, 1, 200)
prior = jnp.ones_like(theta)  # 均匀先验
prior = prior / prior.sum()

# 观测到的抛掷：1 = 正面，0 = 反面
flips = [1, 1, 0, 1, 1, 1, 0, 1, 0, 1]

plt.figure(figsize=(10, 5))
plt.plot(theta, prior, "--", color="#999", label="prior")

for i, flip in enumerate(flips):
    likelihood = theta if flip == 1 else (1 - theta)
    prior = bayes_update(prior, likelihood)
    if i in [0, 2, 4, 9]:
        plt.plot(theta, prior, label=f"after {i+1} flips", linewidth=2)

plt.xlabel("Coin bias θ")
plt.ylabel("Belief (normalised)")
plt.title("Bayesian updating: belief about coin bias")
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```
